他到底在做什么？

小胡子哥的作品大多是给自己和同行解决小麻烦的工具：公众号排版难，就做一个专门的 Markdown 转换器；想在 Kindle 上读博客，就写一个从 RSS 生成电子书的工具；客户端直连 OpenAI 接口不通，就在 Cloudflare Worker 上写个代理。

2026 年的 Agent Pulse 则更像一个信息产品：把官方发布、论文、资本动向、政策变化和传播信号整理成可追溯的「事件」，再形成会随证据更新的行业判断，每天刷新数据，每周输出决策简报。它的口号是：「给需要做决定的人，而不只是想跟上节奏的人。」

  • 给自己的麻烦写工具：排版、电子书、代理都是这样来的。
