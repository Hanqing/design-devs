Adam Argyle：把 CSS 的未来先做出来给你看

他住在西雅图，自称老师、讲者和 CSS 工作组（CSSWG）成员。在 Google，他在 Google Cloud 和 Chrome 团队工作过，在 Chrome 做开发者关系时和 Una Kravets 一起主持 The CSS Podcast，在 YouTube 节目 GUI Challenges 里用最新的 CSS 一期期搭出无障碍、响应式、跨浏览器的组件，还做了「设计师的 FireBug」VisBug，可以直接在任何网页上点选、拖动和修改样式。他开源的 Open Props 是一套 CSS 变量，涵盖颜色、渐变、阴影、缓动、动画和尺寸，让设计系统开箱即用。现在他是 Shopify 的设计工程师，同时和 Robbie Wagner 主持播客 Whiskey Web and Whatnot，一边喝威士忌一边聊 AI 和前端。

他到底在做什么？

Adam 专注于让新的 CSS 能力尽快变得好用。Open Props 把设计系统里最常用的值做成 CSS 自定义属性；gradient.style 是支持 Color 4 广色域的 HDR 渐变生成器，可以在 oklch、display-p3、rec2020 等色彩空间间切换；2026 年的 prop-for-that 把「JavaScript 才知道的东西」变成 CSS 也能用的属性；css-color-component 是一个支持所有色彩空间的现代取色器。

在 Shopify，他写过 StyleX 在 Shopify 的实践，也在 nerdy.dev 上记录 CSS 新技巧，比如如何给 field-sizing: content 加过渡。他还给自己定制的 Agent 加上了 Discord 按钮，并提出一个新词「Shotgun Prompting」：两人以上和一个或多个 Agent 在同一个帖子里合作完成目标。

本页依据 nerdy.dev、open-props.style、gradient.style、GitHub 仓库与 README 和 X 帖子整理，资料截至 2026 年 10 月。他在 Google 各团队的具体年份未在网站上写明。
