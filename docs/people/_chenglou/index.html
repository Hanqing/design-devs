一句话：前 Facebook React 团队成员，react-motion 作者，ReasonML / ReScript 核心贡献者，现在是 Midjourney 的工程师。

代表作：react-motion（2015，★2 万+，启发了 react-spring 与 Framer Motion）、Pretext（2026，★5 万+，不碰 DOM 的多语言文本测量与排版）。

为什么值得关注：他总在问「这一层抽象是不是必要的」，并愿意为一个看似底层的问题写出极其精致的解法。

如果你在 2015 年之后写过前端动画，大概率间接受过 Cheng Lou 的影响。react-motion 用一句话介绍自己：「A spring that solves your animation problems.」十年后，他用同样简短的方式介绍 Pretext：快、准、全，支持「你都不知道存在的语言」。

成长与经历

  1. 2012–2014

    开源起步

    2012 年注册 GitHub，最早的仓库是一组 React 组件：react-treeview、react-radio-group、react-tween-state，以及无代码前端测试工具 node-huxley。

  2. 2015

    react-motion

    用物理弹簧代替「时长 + 缓动曲线」来描述动画：动画可以被打断、被重定向，始终连续。这个思路后来被 react-spring、Framer Motion 等库继承，成为前端动画的主流范式。

  3. 2016

    《On the Spectrum of Abstraction》

    他在 React Europe 上关于「抽象光谱」的演讲，被很多工程师视为理解「何时该抽象、何时不该」的经典。

  4. Facebook 时期

    React、Messenger 与 Reason

    在 Facebook 参与 React 与 Messenger 的工作，并与 Jordan Walke 等人一起推动 ReasonML：给 OCaml 一套 JavaScript 开发者熟悉的语法。Messenger 网页版的大量代码后来改用 Reason 编写。之后这条路线演化为 ReScript。

  5. 2022 前后

    加入 Midjourney

    在 Midjourney 负责前端相关工作。个人网站 chenglou.me 如今就是他的 Midjourney AI 作品集。

  6. 2026

    Pretext、Freerange、handwired

    3 月发布 Pretext：用浏览器自身的字体引擎作基准，自己实现文本测量与断行，从而绕开 getBoundingClientRect 等触发重排的 DOM 调用，48 小时内收获上万星。同年还有静态校验布局代码的 Freerange，以及把普通 JS 变成神经网络的 handwired。

个人网站

chenglou.me ↗

页面标题就是「My Midjourney AI Art」。没有简历，没有博客，只有他用 Midjourney 生成的图像。

Pretext 的一系列交互演示也放在 chenglou.me/pretext 下：气泡聊天、杂志式分栏、文字绕图等，这些都是浏览器原生排版做不到或者做起来很慢的效果。

这种「网站即作品」的态度和他的代码风格一致：不做多余的自我包装，让东西本身说话。

设计与手艺

Cheng Lou 的作品有一种少见的品味：他做的都是底层原语，却总是从用户能感受到的体验出发。弹簧动画解决的是「动画被打断时的突兀感」；Pretext 解决的是「聊天列表、虚拟滚动里文字高度算不准导致的跳动」。

Pretext 的 README 里有一句很典型的话：用浏览器自己的字体引擎作为「ground truth」，这是「对 AI 非常友好的迭代方式」。他把可验证的真值放进循环里，让 AI 辅助的开发可以不断逼近正确答案。

A spring that solves your animation problems.

— react-motion 的项目简介

可以从他身上学什么

  • 换一个模型看问题：动画不一定要用「时长」描述，用「物理」描述就自然可中断。
  • 警惕过早抽象：先理解抽象光谱，再决定站在哪个位置。
  • 为基础设施写演示：Pretext 的演示页让一个排版库变得人人都看得懂。
  • 给 AI 一个真值：可自动对照的基准，是 AI 时代写高质量底层代码的方法。
