徹言：一个写代码、也写书和剧本的人

一个隐含主题：语言。字体是语言的形状，书是语言的故事，Fudoki、Kotoba 和 Rime 输入法配置是学习与输入另一门语言的工具。

Fudoki 的副标题是「日本語を『見える化』する Web ツール」：把一段日文拆成词，标出词性、读音和结构，再用语音合成读出来。它面向日语学习者，也面向自然语言处理研究者。做它的人十多年前在北京做字体公司，写过小说和剧本，现在住在东京，每天都在和日语打交道。

TA 到底在做什么？

徹言的项目跟着生活走。到了东京，TA 做了日语文本分析工具 Fudoki、单词记忆工具 Kotoba，以及随机播放日本电视台 YouTube 频道节目的 Terebi。用上 Linux 和 Omarchy，TA 就写插件、翻译手册、整理一键配置。开始用 AI Agent，TA 就做了 Clawtter：把 OpenClaw Agent 的记忆和笔记发布成一个静态网站。
