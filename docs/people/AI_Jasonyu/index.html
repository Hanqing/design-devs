鱼总：688 元起步的一人公司

从月薪 3800 的 UI 实习生做到出海公司产品经理，2022 年裸辞时兜里只够付 688 元的苹果开发者年费。三年做了 20 个 App、12 个网站，靠自然流量做到 500 万用户；招人、亏损、解散团队后，TA 重新回到「一个人 + AI」。

成长与经历

  1. 2015–2019

    UI 设计师 → 产品经理

    从月薪 3800 的 UI 实习生起步，进入出海公司做影像类产品。参与过月活百万的 App，产品拿过美区榜单第 1、第 2，亲手设计的 App 被苹果 Search Ads 官网展示超过一年。

  2. 2022-08

    裸辞，688 元起步

    受够了凌晨加班和夹板气，月薪 15K 裸辞，没有存款。发帖找开发合作，自己包揽选品、UI、测试和运营。

  3. 2023

    跑通了，也踩坑了

    离职第 5 个月产品收入突破每月 4000 美元，女儿出生；做 AI 自媒体，第 3 条视频 73 万播放。随后盲目扩张，招 6 个实习生做矩阵，全军覆没。「第一次体会到不聚焦的代价。」

  4. 2024

    成立公司，发现网站

    重新招人成立公司；在社群里发现「网站」这个旧产物在海外依然生机勃勃，开始学 AI Coding。

  5. 2025-09

    从 0 开始做 X

    专注 X 内容创作，7 个月做到 5 万粉丝，变现约 20 万元，成为主要收入来源之一。

  6. 2026-04

    重回超级个体

    公司亏损两年后再次解散团队，聚焦 X 上的个人 IP 和 PaywallPro：一个人，AI 辅助。

设计与方法

鱼总的方法论非常落地：先确认有人需要，再做小产品，最后找到能带来用户的入口。TA 做 PaywallPro，是因为自己做订阅 App 时发现大家都在「凭感觉改付费墙」。

团队不一定放大你，可能先放大你的开销。

— 鱼总，航海日志 2026

可以从 TA 身上学什么

  • 设计师也能独立出海：选品、UI、ASO，本身就是核心竞争力。
  • 聚焦胜过扩张：矩阵和团队都可能先放大成本。
  • 公开失败：亏损复盘比成功故事更有用。
  • 用数据做付费墙：变现策略应该有依据，而不是凭感觉。
