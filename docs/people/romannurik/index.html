Roman Nurik：为开发者做设计，为设计师写代码

他在个人网站上写道：「几十年来，我一直在为开发者做设计，为设计师做工具。」在 Google，他是 Google I/O Android App 的首席设计师和前端工程师（2014 年版是最早采用 Material Design 的 Android App 之一）；做了被并入 Android Studio 的 Android Asset Studio；在 Firebase 担任设计负责人和经理长达十年；又作为创始设计师兼工程师参与了 Google 的云端 IDE Project IDX，也就是后来的 Firebase Studio。业余时间，他做出了安装量超百万的动态壁纸 Muzei，以及 DashClock 小部件。如今他在纽约的 Google Labs 探索设计、开发和软件的未来。

4.3 万X 关注者
2007加入 X

2013 年，Roman 用大约四个月，从构思、设计、开发到上线并开源了 Muzei：一款每天给你的 Android 主屏幕换上一幅名画的动态壁纸。它会自动模糊和压暗画面，让图标和小部件更清楚；双击壁纸，名画又会完整显现。它被安装了一百多万次，还开放了 API，让其他开发者可以提供自己的图片源。这是 Roman 一贯的做法：一个设计上的好点子，加上一份让别人也能扩展它的工程。

他到底在做什么？

Roman 的特点是设计和工程都做到一线水平。在 Project IDX，他负责产品与系统设计、品牌，参与产品与技术架构，做出了影响生成式 AI 和工具集成路线的原型，同时还是 AI（自定义 Agent 框架）、前端、IDE 扩展和基础设施方向贡献最多的三位工程师之一。

他还亲手调了编辑器的浅色和深色主题：既要平衡前景和背景的对比，也要照顾相邻语法元素之间的对比；足够大胆以形成独特识别，又足够克制，能让人每天看好几个小时。

可以从他身上学什么

  • 写清楚你做了什么：作品集里的角色和贡献比截图更重要。
  • 为两边的人做工具：开发者和设计师都缺好工具。
  • 一个好点子 + 一个开放 API：Muzei 就是这样长大的。
  • 编辑器主题也值得设计：人们每天要看好几个小时。
  • 老工具可以重生：Asset Studio 变成了 IconKitchen。
