Justin Mitchell：让电子阅读器听你的

TA 的个人网站标题是「I build things…」，作品曾被 TechCrunch 和《华尔街日报》报道。TA 做过一长串小而有趣的产品：被 The Verge 称为「最好的语音笔记应用，没有之一」的 Cleft Notes，自动从 iMessage 复制两步验证码的 2FHey，玩「掷骰写格」桌游的 Roll N' Write，可视化 git 与 Agent 编排工具 Orca，以及给开源贡献者发「版税」的 Royalty。现在 TA 主要在做 CrossPoint Reader：一个社区共建、完全可以改造、永远免费的开源电子阅读器固件，运行在 Xteink X4/X3 等基于 ESP32 的墨水屏设备上，GitHub 上有八千多颗星；以及给电子纸用的开放 SDK FreeInk。

CrossPoint Reader 的 README 开头写得像一份宣言：「开源电子阅读器固件，社区共建，完全可改造，永远免费。」它由一群相信「你的设备应该做你想做的事，而不是厂商替你决定」的开发者和读者维护。官网列出的体验很朴素也很重要：真正的两端对齐和断字、可以点的脚注链接、更平滑的抗锯齿和更快的翻页，以及每次打开都回到上次读到的地方。

TA 到底在做什么？

CrossPoint 想让便宜的墨水屏设备变成好用的阅读器：它现在支持 Xteink X4 和 X3（ESP32-C3）以及 reTerminal Sticky、M5Paper、LilyGo T5 等设备；书库能显示 SD 卡上的所有书，按最近、书名、作者排序，支持搜索；最新的 Nightly 版加入了插件和蓝牙。社区还做了 Calibre 无线传书插件、兼容 KOReader 的同步服务器、不用刷机就能试用的模拟器，以及一个 400 KB 的 SD 卡刷机工具。

TA 的 Royalty 也和这个项目有关：CrossPoint 的 README 顶部有一个「资助贡献者」的徽章，链接到 Royalty，把捐款分给真正写代码的人。
