Jordan Walke：React 是从这里开始的

他在 Facebook 当软件工程师时创造了 React。据维基百科，他先做了一个叫 F-Bolt 的原型，后来改名为 FaxJS；React 2011 年首先用在 Facebook 的动态消息（News Feed）上，2012 年进入 Instagram，2013 年 5 月 29 日开源。如今 React 是世界上使用最广的前端库之一。之后他又创造了 ReasonML：一种基于 OCaml、语法接近 JavaScript 的语言，并参与了原生包管理器 esy 和一系列 Reason 工具。离开 Facebook 后，他现在在 Replit 做产品，X 简介写着「Vibe coder」。他至今仍在思考交互的细节：他希望有一个跑在 iOS 主线程上的 React Native，让开发者必须在意不要阻塞主线程超过 8 到 16 毫秒。

2013加入 X

2026 年 8 月，Jordan 在 X 上贴出一个 GitHub 链接：「我十五年前就在写 CSS-in-JS 了。2011 年。」链接指向 FaxJs 的 README，那是 React 诞生前的原型。同一周，他发了一条「暴论」：工具提示（tooltip）会让你的应用显得廉价，尤其是在你刚要点击时弹出来；每个应用都应该在角落里放一个小帮助栏，悬停时立即显示说明，不会有奇怪的时机问题，也不会遮住你正在看的区域。

他到底在做什么？

Jordan 现在在 Replit 做产品，关注移动端开发和 AI 如何改变设计流程。他公开招募过熟悉 React Native 的开发者，也和 Replit 设计团队一起在 X Spaces 上讨论 AI 对设计的影响。

他对框架的思考一直围绕「交互质量」。他说，如果 React Native 能在主线程上运行 React，它的交互可以好得多、可定制得多；这是他从「传奇级的移动交互工程师」那里学到并且从未忘记的一课。他也认为 AI 编程节省下来的时间，可以用来维护多套原生代码，也可以继续用跨平台框架，然后把时间花在别处。
