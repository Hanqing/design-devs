TA 到底在做什么？

在 Xspark AI，冰沙负责的是具身智能公司的「地基」：网站、数据管线和评测系统。对一家以数据为核心的机器人公司来说，数据怎么流转、模型怎么被评测，决定了研究能走多远。TA 参与的 XPolicyLab 是一个统一的机器人策略评测与部署生态，收录 50 多种先进的操作策略，获得 IROS 2026 ScaleInfra Workshop 最佳工具论文。

业余时间，TA 用自己的方式学习基础设施：从零实现 Go Web 框架、Redis 分布式锁和消息队列，做 CMU 15-445 的实验，并维护一套在 Cursor、Codex CLI、Claude Code 里通用的 Agent Skills。

写作与观点

很多人说，技术不是靠工作学出来的，而是靠自学。我认同，也确实一直在这么做……但我还是会期待：有一天能在工作中真正接触到更难、更复杂、更具挑战的技术问题。
