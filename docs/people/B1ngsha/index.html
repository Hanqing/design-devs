手艺与方法

冰沙的 GitHub 很能说明 TA 的学习方式：通过亲手实现基础组件来理解系统。分布式锁、消息队列、Web 框架，这些都是大厂里「直接用就好」的东西，TA 选择自己写一遍。

这种对基础设施的热情，正是数据驱动的具身智能公司最需要的：数据管线和评测系统决定了模型能走多远。

可以从 TA 身上学什么

  • 造轮子是为了理解：亲手实现一遍，才真正懂。
  • 敢于离开舒适区：从大厂到创业公司，去更前沿的领域。
  • 白天全栈，晚上基建：兴趣是最好的老师。
  • 数据和评测是 AI 的地基：不只是模型，管线同样重要。
