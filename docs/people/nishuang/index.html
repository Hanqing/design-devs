倪爽：商业驱动产品，产品驱动设计

他从幼儿园起就想当画家，父母不让学美术，于是自学了艺术和设计；他崇拜 Marc Newson、深泽直人和乔布斯，本想做工业设计，因为门槛太高转做平面设计，后来赶上 UI / UX 设计兴起进入互联网行业。他在一线互联网公司担任过产品部门负责人，在纳斯达克上市公司和外企做过设计师与总监，也多次创业。近十年前他移居美国，开了 Honest Dot / 倪爽设计工作室，为中国和北美的创业公司提供 UX、品牌和营销设计。他在 X 上有十万多关注者，写了四万多条关于设计、学习和文化差异的推文。

一句话：X 简介「倪爽，设计顾问。超过 20 年经验资深设计师，在美国运营 Honest Dot Design / 倪爽设计工作室，为中国及北美企业提供品牌营销设计、UX 设计两类设计咨询服务」。

代表作：官网案例包括为国际金融公司（IFC，世界银行集团）设计金融科技 SaaS、把电商内部系统改造为公开 SaaS 平台、帮一档播客重塑品牌、帮首次创业者把想法做成可融资的产品。

关键数字：X 关注者约 10.4 万、推文 4.2 万条；官网称作品触达 1 亿多用户；订阅制设计服务每月 2,499 美元起。

超能力：他在 About 页里说，自己的超能力是「同理心极强」。

倪爽的工作室官网不像一般设计师的作品集，更像一份商业提案：设计服务按月订阅，「不限需求、不限修改」，三天免费试用；每个案例的标题都是一个商业问题，比如「怎样为世界银行集团设计一个满足全球银行需求的金融科技 SaaS？」他的一篇博文标题说得更直接：「脱离商业的设计，只是（无足轻重的）装饰。」

他到底在做什么？

倪爽现在的主业是给创业公司当外包的设计总监：从商业目标倒推到用户体验和视觉，既做策略也出像素。他在官网上强调「Founder-Mode」：因为自己也创过业，所以知道创业公司在每个阶段需要什么。

在 X 上，他是中文设计圈最活跃的声音之一：拆解 Humane AI Pin、Arc 浏览器的需求方法、为什么用户把 ChatGPT 当搜索引擎、东西方「察言观色」的文化差异，也会写自动洗手液容器这样的日常设计。

可以从他身上学什么

  • 从商业目标倒推设计：脱离商业的设计只是装饰。
  • 自学也能走很远：没学过美术，一样做了 20 年设计。
  • 简单不等于好用：UI 要以用户能完成任务为准。
  • 把服务产品化：按月订阅、清晰定价。
  • 同理心是设计师的超能力：先理解人，再画界面。
