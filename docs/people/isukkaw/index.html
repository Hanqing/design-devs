一句话：一位在前端工具链、网络规则和性能优化领域都非常活跃的开源维护者，自称「Vibe Code 清理专家」。

代表作：Surge 规则集（★4.6k，适配 Surge / Mihomo / sing-box 等）、nolyfill（清理 npm 依赖中多余的 polyfill）、foxact（为浏览器、SSR 和 RSC 设计的 React Hooks）、DisqusJS、hexo-theme-suka、nali-cli、zsh-proxy。

为什么值得关注：他做的很多事情不显眼，却让整个 JavaScript 生态更快、更轻：少装一个包、少一次重渲染、少一个 SSD 写入。

成长与经历

  1. 2018

    博客与 Hexo

    2018 年注册 GitHub 与 X。为 Hexo 写了主题 hexo-theme-suka，并做了 DisqusJS：在中国大陆通过 Disqus API 渲染评论。之后加入 Hexo 核心团队。

  2. 2019–2020

    网络工具

    Koolshare-Clash（在 Koolshare OpenWrt 上运行 Clash）、zsh-proxy（oh-my-zsh 代理插件）、nali-cli（在终端解析 IP 地理信息），以及持续维护至今的 Surge 规则集。

  3. 2023

    nolyfill 与 foxact

    nolyfill 用一行命令替换掉依赖树里大量过时的 polyfill，「加速安装、减少磁盘占用、延长你宝贵 SSD 的寿命」；foxact 是「做对了」的 React Hooks 工具库。

  4. 2024

    用户脚本与 lint 工具

    Make Bilibili Great Than Ever Before、location-guard-ng 等用户脚本；成为 eslint-plugin-import-x 的核心维护者，并维护 DNSControl 的 Vercel provider，向 Next.js、htmlnano 等项目持续贡献。

  5. ArcBox Labs

    联合创业

    作为联合创始人参与 ArcBox Labs。

手艺与方法

Sukka 的工作有一个共同的审美：正确与轻量。foxact 强调「done right」：每个 Hook 都考虑 SSR 和 RSC 的边界情况；nolyfill 则是对生态「臃肿」的一次系统性清理。

Vibe Code Cleanup Specialist

当 AI 生成的代码越来越多，「清理」本身会变成一门手艺。Sukka 给自己的新头衔恰好说明了这一点。

可以从他身上学什么

  • 做生态的清道夫：减法同样是贡献。
  • 考虑所有运行环境：浏览器、SSR、RSC，一个都不能少。
  • 长期维护基础设施：规则集、lint 插件，需要的是耐心。
  • 用数据说话：性能优化必须有实测。
