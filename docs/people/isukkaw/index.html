TA 到底在做什么？

Sukka 的开源可以分成两块。前端生态：Hexo 博客框架、React 工具库、lint 插件、依赖瘦身工具，以及对 Next.js、htmlnano 等项目的持续贡献。网络基础设施：自动更新的规则集、DNS 即代码、教育网镜像站帮助文档、IP 数据库，以及大量关于 DNS、CDN、家庭组网的长文。

两块工作有同一种气质：做减法、做正确、用数据说话。foxact 的 README 写着它严格遵循 React 最佳实践，「从不在渲染阶段读写 ref」，而这正是很多开源 Hooks 库没做到的。

本页依据 GitHub 个人主页 README 与仓库、博客 RSS 与 X 资料整理，资料截至 2026 年 10 月。skk.moe 有访问验证页，本次以 RSS 和 GitHub 内容为主。

代表作品详解

nolyfill ↗

2023TypeScript★1.2 千

「Speed up your package installation process, reduce your disk usage, and extend the lifespan of your precious SSD.」你已经在用最新的 Node.js LTS，但 eslint-plugin-import、eslint-plugin-jsx-a11y、eslint-plugin-react 等包还在依赖为古老运行环境准备的 polyfill。nolyfill 一行命令把它们替换成轻量的实现，减少 node_modules 体积、加快安装。

它是一次对生态「臃肿」的系统性清理，也直接推动了 eslint-plugin-import-x 这类插件的现代化。

foxact ↗

2023React文档 foxact.skk.moe

「React Hooks/Utils done right. For Browser, SSR, and React Server Components.」所有 Hooks 都能扛住 React 18+ 的并发渲染，严格遵循 React 最佳实践，比如「从不在渲染阶段读写 ref」。每个 Hook 都考虑 SSR 和 RSC 的边界情况。

可以从 TA 身上学什么

  • 做生态的清道夫：减法同样是贡献。
  • 考虑所有运行环境：浏览器、SSR、RSC，一个都不能少。
  • 长期维护基础设施：规则集、lint 插件，需要的是耐心。
  • 用数据说话：性能优化必须有实测。
  • 基础设施即代码：连 DNS 记录也可以用 Git 管理。
