Max Brunsfeld：让编辑器真正读懂代码

他住在俄勒冈州波特兰，是 Tree-sitter 的作者。Tree-sitter 是一个解析器生成器和增量解析库：它能为源文件建立具体语法树，并在你每次敲键时高效地更新它。今天，Neovim、Helix、Zed、GitHub 的代码导航和无数工具都用它来做语法高亮、代码折叠和结构化编辑，GitHub 上有 2.7 万颗星。他在 GitHub 时是 Atom 团队成员，Tree-sitter 最早就是为 Atom 写的；之后他和 Nathan Sobo 联合创办了 Zed。他还写过 Go 测试替身生成器 counterfeiter（★1,144），以及 Vim 插件 vim-yankstack。业余时间他玩音乐和攀岩。

Tree-sitter 的 README 列出它的目标：足够通用，能解析任何编程语言；足够快，能在文本编辑器里每敲一个键就解析一次；足够健壮，即使有语法错误也能给出有用的结果；没有依赖，用纯 C 写的运行时库可以嵌进任何应用。正是这四点，让它从 Atom 的一个子项目变成了整个开发工具生态的基础设施。

他到底在做什么？

Max 的核心工作是让工具理解代码结构。Tree-sitter 给编辑器的不是一串彩色的字符，而是一棵随编辑实时更新的语法树：编辑器可以据此选中整个函数、按结构折叠、查找符号，甚至让 Agent 更准确地理解上下文。他在 2024 年写过一篇博客，介绍如何给 Zed 加语言扩展，他说那是他很久以来给 Tree-sitter 加的最酷的功能之一。

在 Zed，他参与了编辑预测模型的迭代（与推理平台 Baseten 合作），以及 2026 年的 Delta：一个摆脱 Pull Request 局限的协作开发流程。他说团队在过去几个月里已经全面切换到了 Delta。
