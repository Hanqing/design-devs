小黑插图 Skill 的 README 说它「不是通用插画 prompt，也不是 PPT 信息图模板」。它先理解文章里的认知锚点，再把一个判断、流程、结构、状态或隐喻，画成一张有记忆点的 16:9 手绘图：白底、一个黑色实心、白点眼、细腿、空表情的小角色「小黑」，加上少量红橙蓝批注。伊恩卖的不是「能画图」，而是一种统一、有辨识度的风格。

审美与观点

人人都在用 AI，差距从哪来？上手变容易了，判断反而难了。

— 伊恩，Indie Builders 介绍页

伊恩的观点很一致：AI 时代稀缺的不是执行能力，而是判断力和品味。TA 的 Skill 都把「先理解，再表达」放在第一步：小红书图文先出分镜表让你确认，小黑插图先找文章里的认知锚点。

可以从 TA 身上学什么

  • 把风格写成 Skill：审美可以被封装、复用和传播。
  • 作品集是长期资产：Dribbble 万粉是所有事情的起点。
  • 先理解，再表达：分镜表、认知锚点，都是在 AI 出图前做判断。
  • 社群提升判断：一个人想不清楚的问题，一群人可以。
  • 项目 + 产品双线：接项目维持收入，用 AI 探索自己的产品。
