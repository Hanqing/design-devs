TA 到底在做什么？

Alex 现在的两条线是 AI Agent 工程和投资。在 Funda AI，TA 参与构建 AI 投资操作系统；业余开源的 finance-skills 遵循 Agent Skills 开放标准，可以装进 Codex、Claude Code 等工具，用于市场分析和接入金融数据源。README 第一行就警告：仅供学习参考，不构成投资建议。

TA 也用投资的眼光看技术：2026 年的一篇文章《JavaScript Market Analysis》从投资角度分析 JS 开发者市场。
