Christian Selig：做出 Apollo，然后体面地告别

他一个人做的 Reddit 客户端 Apollo 在 App Store 上有 18 万个评分、平均 4.76，被很多人称为 iOS 上最好的第三方 App 之一。2023 年 Reddit 的 API 定价让它每年要付出约 2,000 万美元，他选择关停，并公开了全部过程。之后他做了住在灵动岛里的 Pixel Pals（3.7 万个评分），设计了一把开源键盘，2026 年又用自己写的 Vision Pro App 规划第一栋房子。

一句话：一位以细节著称的 iOS 独立开发者，曾在 Apple 工作；他的 App 完全遵循 iOS 的手势和视觉语言，却在每个交互细节上比官方走得更远。

代表作：Apollo for Reddit（2017–2023，4.76 分，180,267 个评分）、Pixel Pals（灵动岛宠物，4.57 分，37,082 个评分）、Amplosion（Safari 去 AMP 扩展，4.9 分）、Achoo（Safari HTML 查看器）、Juno（Vision Pro 上的 YouTube 客户端）、Caldera 键盘、Prospector。

关键数字：X 关注者约 7.4 万、推文 5 万多条；apollo-backend 开源后获得 3.7 千星。

看点：面对每年 2,000 万美元的 API 账单，他没有偷偷关门，而是公开数字、公开与 Reddit 的通话录音、开源后端。透明本身成了一种设计。

他到底在做什么？

Christian 的产品有一个共同点：第一时间拥抱苹果的新能力，然后把它做得很可爱。iOS 15 开放 Safari 扩展，他做了 Amplosion 和 Achoo；iPhone 14 Pro 推出灵动岛，他做了住在灵动岛里的像素宠物；Vision Pro 上市，他做了 YouTube 客户端 Juno；2026 年，他又用 visionOS 在真实土地上按比例预览自己未来的房子。

他的博客则是另一种贡献：《Beware UserDefaults》讲一个难以发现、会丢数据的 bug，并顺手开源了替代品 TinyStorage；《CKSyncEngine questions and answers》《Embedding Godot games in iOS apps is easy now》都是给同行省时间的实战文章。

本页依据 christianselig.com、GitHub、App Store 与 apollo-backend README 整理，资料截至 2026 年 10 月。

成长与经历

  1. 2008

    注册 X

    很早就进入 iOS 开发世界，至今发了五万多条推文。X 简介里一个苹果 Logo 表示他曾在 Apple 工作。

  2. 2015–2017

    Apollo 诞生

    Apollo 的 App Store 描述说它从 2015 年起服务 Reddit 用户；当前这个 App 条目上架于 2017 年 10 月。它以手势、细节和速度著称，拥有大量忠实付费用户。2019 年他还公开了 Apollo 的 bug 追踪器。

  3. 2021

    开源组件与 Safari 扩展

    从 Apollo 的实际需求里抽出 ChidoriMenu、TableOfContentsSelector、Markdownosaur、AccessibleAuthorLabel 等组件开源；iOS 15 发布时推出去 AMP 扩展 Amplosion（4.9 分）和 HTML 查看器 Achoo。

  4. 2022.10

    Pixel Pals

    灵动岛发布后不久，推出住在灵动岛、锁屏和主屏小组件里的像素宠物。

  5. 2023.06

    Apollo 关停

    Reddit 宣布 API 收费，按 Apollo 的用量计算每年约需 2,000 万美元。他公开了与 Reddit 的沟通录音和计算过程，6 月 30 日关停 Apollo，并开源了 apollo-backend。

  6. 2024

    Juno、键盘与 TinyStorage

    为 Vision Pro 做 YouTube 客户端 Juno（10 月因 YouTube 方面的意见下架），开源 JunoSlider；用 Ergogen 和 KiCad 设计了分体式、人体工学无线键盘 Caldera；发现 UserDefaults 会丢数据后开源了 TinyStorage；还用 3D 打印「治好了 Mac mini M4 焦虑」。

  7. 2025

    Godot、GIF 与 App Clip

    写了在 iOS App 里嵌入 Godot 游戏、制作高质量低体积 GIF、App Clip 本地体验等文章。

  8. 2026

    Prospector 与第一个家

    和女朋友开始建造第一栋房子，他写了 visionOS App Prospector，在土地上按真实比例预览建筑方案；同年还写了对 iPhone Air、Fitbit Air、Rivian R2 的看法。

代表作品详解

Apollo for Reddit ↗

2015 / 2017–2023iOS已关停

一个人做的 Reddit 客户端：可定制的手势、精致的媒体浏览、快速的列表滚动，以及无数「比官方多想一步」的细节。它的设计哲学是尊重平台、再超越平台。

2023 年 Reddit 宣布 API 收费后，Christian 算出 Apollo 每年要付约 2,000 万美元。他选择了一条少见的路：公开数字、公开录音、给订阅用户处理方案，然后在 6 月 30 日关停，并把后端（通知检查与 subreddit 监视器，Go 编写）开源出来，「希望这些代码能对别人有用」。

Prospector ↗

2026visionOS开源

「The coolest use for the Vision Pro.」他在博客里写，建房子的每个决定都很难回头：「软件里不喜欢一个功能可以改掉，墙放错了可不行。」于是他做了一个 visionOS App，把大型模型（比如房屋设计图）按真实比例放在真实的土地上预览。

长处与局限

维度长处局限 / 需要留意
产品细节与口碑极佳，Apollo 和 Pixel Pals 都有数万到十几万评分两款产品先后受平台政策影响（Reddit API、YouTube），平台依赖风险明显

可以从他身上学什么

  • 把一个 App 做到极致：细节堆出来的口碑，能撑起一个人的事业。
  • 警惕平台依赖：Apollo 是所有第三方客户端开发者的教科书案例。
  • 体面地告别：公开原因、照顾用户、开源代码。
  • 快速拥抱新硬件：灵动岛、Vision Pro，每次都第一时间做出有趣的东西。
  • 用技术解决生活问题：从键盘到房子，工具都可以自己做。
