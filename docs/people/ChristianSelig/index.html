Christian Selig：做出 Apollo，然后体面地告别

他一个人做的 Reddit 客户端 Apollo，被很多人称为 iOS 上最好的第三方 App 之一。2023 年 Reddit 的 API 定价让它每年要付出约 2000 万美元，他选择关停，并公开了全部过程。之后他做了灵动岛宠物 Pixel Pals、Vision Pro 上的 Juno，还自己设计了一把键盘。

一句话：一个来自加拿大东海岸、曾在 Apple 工作过的 iOS 开发者，以极致打磨的交互和坦诚的写作著称。

代表作：Apollo for Reddit（2017–2023）、Pixel Pals（灵动岛上的像素宠物）、Juno（visionOS 上的 YouTube 客户端）、Caldera 分体键盘、Prospector（用 Vision Pro 预览建筑图纸）。

为什么值得关注：Apollo 事件成为「平台风险」的标志性案例；而他面对危机时的透明与体面，同样值得学习。

Christian 的个人网站开头很朴素：「I'm an iOS developer and creator of Pixel Pals, Apollo, and other apps!」最新的一篇文章，讲的是他和女朋友开始建造第一个家：程序员的大脑很难接受「墙一旦砌错就不能删掉」，于是他发现了 Vision Pro 最酷的用途，在真实土地上 1:1 预览房子。

成长与经历

  1. 2008

    注册 X

    很早就进入 iOS 开发世界。X 简介里「Previously at 」是一个苹果 Logo：他曾在 Apple 工作。

  2. 2017

    Apollo for Reddit

    一个人做的 Reddit 客户端，以手势、细节和速度著称，多次获得设计类推荐，拥有大量忠实付费用户。他还公开了 Apollo 的 Bug 追踪器。

  3. 2021

    开源组件

    开源 ChidoriMenu（类 iOS 14 下拉菜单）、Markdownosaur（用 Apple 的 Swift Markdown 解析器输出 NSAttributedString）、TableOfContentsSelector 等，均来自 Apollo 的实际需求。

  4. 2022

    Pixel Pals

    iPhone 14 Pro 推出灵动岛后，他做了住在灵动岛和锁屏实时活动里的像素宠物。

  5. 2023-06

    Apollo 关停

    Reddit 宣布 API 收费，按 Apollo 的用量计算每年约需 2000 万美元。他公开了与 Reddit 的沟通录音和计算过程，最终在 6 月 30 日关停 Apollo，并开源了 apollo-backend。

  6. 2024

    Juno、键盘与 TinyStorage

    为 Vision Pro 做了 YouTube 客户端 Juno（后因 YouTube 方面的意见下架），开源了 JunoSlider；自己设计了分体式人体工学无线键盘 Caldera，并开源了 UserDefaults 替代品 TinyStorage。

  7. 2026

    Prospector

    开始建造第一个家，用自己写的 visionOS App 在土地上按真实比例预览建筑方案。

个人网站

christianselig.com ↗

一个非常传统的个人博客：一句自我介绍，然后是按时间排列的长文。文章常常配大量截图和视频。

博客里的技术长文也很有名，比如如何在 iOS 上实现某个系统级动效，他会一步步拆解并给出代码。

X 简介里有一句「Pronounced See-lig. i love aminals. 🌱」。这种轻松可爱的语气，也出现在他的每一款 App 里。

设计与手艺

Apollo 的设计哲学是尊重平台、超越平台：完全遵循 iOS 的手势和视觉语言，却在每一个交互细节上比官方 App 走得更远。他开源的组件几乎都在「模仿 Apple 的感觉，再多一点点好处」。

体面地告别

面对每年 2000 万美元的 API 账单，他没有偷偷关门，而是公开数字、公开录音、给用户退款方案并开源后端。透明本身成了一种设计。

可以从他身上学什么

  • 把一个 App 做到极致：细节堆出来的口碑，能撑起一个人的事业。
  • 警惕平台依赖：Apollo 是所有第三方客户端开发者的教科书案例。
  • 快速拥抱新硬件：灵动岛、Vision Pro，每次都第一时间做出有趣的东西。
  • 用技术解决生活问题：从键盘到房子，工具都可以自己做。
