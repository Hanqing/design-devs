agent-browser 的文档开头写着它的设计原则：Agent 优先。输出是紧凑的文本，而不是 JSON，因为这样更省 token；页面快照返回带引用编号的无障碍树，让 Agent 能确定地选中元素；五十多个命令覆盖导航、表单、截图、网络、存储和调试。这是 Chris 一系列工具的共同出发点：如果用户不再是人，而是 Agent，开发工具应该长什么样？

他到底在做什么？

Chris 在 Vercel Labs 做的是为 Agent 时代重新设计的开发者基础设施。agent-browser 让编程 Agent 能可靠地操作浏览器、录像、看网络请求和 Web Vitals；portless 把 localhost:3000 换成 https://myapp.localhost 这样稳定好记的地址，「为人类，也为 Agent」；json-render 把大模型生成的界面限制在你定义好的组件和动作里，兼顾灵活与安全。

scriptc 走得更远：利用 TypeScript 编译器检查过的类型直接生成机器码，输出的程序不需要安装 Node.js 就能运行，依赖的 npm 包也一起编译；无法编译的代码会在构建时给出诊断。

观点

Replace port numbers with stable, named .localhost URLs. For humans and agents.

— portless 官网

「For humans and agents」几乎是他所有工具的副标题：同一个工具，既要让人用得舒服，也要让 Agent 用得准确、省 token。

可以从他身上学什么

  • 把 Agent 当成用户：输出要紧凑、可确定。
  • 文档也给 LLM 读：一键复制 Markdown。

  • 小痛点也值得做成工具：端口号就是一个。
