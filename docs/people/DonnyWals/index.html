Donny Wals：实用地学 Swift

他住在荷兰阿姆斯特丹一带，是 iOS 工程师、博主和作者，自称「独立创业者」（solopreneur）。他的网站 donnywals.com 的目标是「通过实用的教程帮你学 Swift 和 iOS 开发」，长期稳定更新；他写了三本以「Practical」开头的书：《Practical Combine》《Practical Core Data》和《Practical Swift Concurrency》，也做工作坊和大会演讲。他自己的应用 Maxine 是一个记录最大重量（one rep max）的健身应用，他在健身房里训练时也拿它当 AI Agent 工作流的试验场。2026 年他写了好几篇关于「Agent 式 iOS 开发」的文章：给 Agent 项目搭交付流水线、让 Agent 构建并运行应用、以及 AI 驱动开发中「人的触感」为什么重要。业余时间他弹吉他，最近还迷上了《万智牌》。

他到底在做什么？

Donny 一边写书和教程，一边做自己的应用。他的 X 帖子常是一条 Swift 并发小知识：AsyncStream 只该有一个消费者，两个任务同时迭代会各自拿到一部分值；actor 里每个 await 都是其他调用可以插队的地方，await 之前读到的状态之后可能已经变了；同时做两件事时 async let 往往就够了，不一定需要 Task Group。

2026 年秋天，他在把 Maxine 适配新的 iPhone Duo，结果「走上了一百万条支线任务」，顺手改进了很多界面细节。他的经验是：不能只用 Xcode 27 重新编译然后祈祷一切正常。他也在 SwiftLeeds 大会上和大家交流 Agent 工作流。
