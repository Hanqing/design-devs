网站与线上形象

tanstarter.dev ↗

TanStarter 的官网是标准的「出海 SaaS」范式：一句话价值主张、三个社会证明数字（250+ 客户、3000+ Discord 成员、500+ 提交）、私有 GitHub 访问、终身更新、无限项目。

页面专门强调「AI-Powered Codebase」：清晰的结构和一致的命名，让 AI 助手秒级生成完整功能。

他的模板官网本身就是模板的最佳演示：用户看到的网站，就是他们买到后能得到的网站。

设计与方法

Fox 的产品思路是「卖铲子」：在 AI 出海淘金热里，给淘金者提供最趁手的工具。模板的设计重点在于为 AI 编程而优化：一致的命名、清晰的模块边界，让 Claude Code 能理解并扩展。

他的定位

主业是大厂高工，副业搞独立开发；公开构建，专注 AI 相关的技术分享。

可以从他身上学什么

  • 把经验产品化：自己踩过的坑，就是别人愿意付费的捷径。
  • 社群是护城河：三千人的 Discord 让模板持续迭代。
  • 为 AI 写代码：代码结构不仅给人看，也给 Agent 看。
  • 副业也能做成事业：稳定主业 + 持续公开构建。
