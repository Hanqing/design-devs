Frank Wang：从 Serverless 到开源编程 Agent

TA 和 Jay V 一起创办了 Anomaly：先写了广受欢迎的 Serverless Stack 教程，做了无服务器 CI 服务 Seed，再做出开源框架 SST，让开发者用代码在自己的 AWS 和 Cloudflare 账户上搭全栈应用，并参与维护把 Next.js 部署到 AWS 的 OpenNext。2025 年 4 月，团队开源了终端里的编程 Agent OpenCode；一年多后，它在 GitHub 上有 22 万颗星、950 多位贡献者，官网称每月有 1,600 万开发者使用。Frank 的中文 X 简介只写了一句：「opencode.ai 创始人」。

TA 到底在做什么？

OpenCode 是一个开源的 AI 编程 Agent：可以在终端、IDE 或桌面应用里使用；自动加载合适的语言服务器（LSP）；支持在同一个项目里并行开启多个 Agent；可以把任意会话分享成链接，方便参考或排查。

在那之前，Frank 和团队用 SST 解决了另一个问题：把全栈应用部署到你自己的云账户里。SST v3 把部署引擎从 AWS CloudFormation 换成了 Pulumi 和 Terraform，可以管理 AWS、Cloudflare 等多家提供商的资源。

可以从 TA 身上学什么

  • 写教程，再写工具：Serverless Stack 教程带出了 SST。
  • 不锁定用户：接入任何模型、部署到任何云。
  • 把隐私写在首页：不存代码，才能进入企业。
  • 长期和同一群人做事：团队比单个项目更重要。
  • 保持好玩：公司也可以办答题节目、去南极骑车。
