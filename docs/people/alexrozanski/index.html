Alex Rozanski：给 Mac 写了十五年控件

TA 在 GitHub 上自我介绍是「全栈工程师和创作者」，X 上则是「maker, artist, engineer, photographer」。TA 为 Apple 平台开发了很久，从 Objective-C / C++ 到 Swift，从 AppKit、UIKit 到 SwiftUI。早年 TA 写的 Mac 控件 PXSourceList（仿 Finder 侧栏的源列表）和 PXListView（按 UITableView 思路优化的 Mac 列表视图）被用在不少应用里。2023 年大模型刚能在本地跑时，TA 做了 LlamaChat：一个可以在 Mac 上本地运行 LLaMA、Alpaca、GPT4All 模型并聊天的原生应用，GitHub 上有 1,500 颗星。TA 的个人网站说，自己和 Raycast、Facebook、Apple 等合作过，现在在纽约做新东西（@uuuntitleddd）。

PXListView 的 README 写着它的来历：TA 先写了一篇博客讨论 Mac 列表视图的性能，然后把文章里的思路做成了一个控件。和 iPhone 的 UITableView 一样，它会复用显示行的视图，所以即便有大量行，内存占用也很低。从一篇文章到一个被人用在产品里的控件，这是 TA 一贯的做法：把一个具体问题研究透，再给出干净的 API。

TA 到底在做什么？

Alex 的作品集中在Mac 原生体验。LlamaChat 让普通用户不用碰命令行，就能在 Mac 上本地运行开源大模型；为此 TA 还维护了 llama.cpp 的一个 Swift 分支 llama.swift，以及一个支持 Swift 并发和流式输出的 shell 命令封装 Coquille。Slick 是一个在图片周围生成柔和、随内容变化背光的 SwiftUI 视图。

TA 的个人网站更像一个生活页面：除了作品，还展示最近看的电影和听的专辑、喜欢的歌手。
