Chris Banes：Android 界面细节的守门人

他在 Google 的 Android 开发者关系团队待了近九年，主导了 AppCompat 和 Design Support Library 的工程工作，创造了从图片中提取配色的 Palette 库；在那之前，他写的 Android-PullToRefresh 和 PhotoView 是无数 App 的标配。离开 Google 后，他在 Twitter 带领 Android 客户端界面团队；现在在 The Trade Desk 用 Kotlin 多平台和 Compose 多平台构建 Ventura 电视系统的 Android、iOS 和电视客户端。业余时间，他维护 Compose 多平台的背景模糊库 Haze，还写了一套给 AI Agent 用的 Kotlin 与 Compose Skill。

他到底在做什么？

Chris 的工作始终围绕让 Android（现在是多平台）界面更精致。Haze 是他现在最主要的开源项目：为 Compose 多平台提供硬件加速的视觉效果，覆盖 Android、iOS、macOS、桌面和 Web。2026 年的 Haze 2.0 把模糊做成可插拔的效果引擎，加入了基于折射的「Glass」效果，并实验性地支持 Android 原生背景模糊。

他也在思考 AI 编程。2025 年底的长文《The Disappearing Middle》担心：新人靠提示词完成实现，资深工程师又把同样的工作交给 Agent，软件行业的「学徒阶梯」就被自动化掉了。2026 年他发布了给 Agent 用的 Kotlin、Compose 与 Android Skill，并写了《Not every agent task needs a plan》。

2023–Compose 多平台★2.6 千

AppCompat、Design Support Library 与 Palette ↗

GoogleJetpack 前身

AppCompat 让 Material Design 能在旧版 Android 上运行；Design Support Library 带来了悬浮按钮、Snackbar、折叠工具栏和 NavigationView；Palette 从图片中提取主色，让界面随内容变色。这几样东西塑造了 2014 年后 Android App 的样子。

可以从他身上学什么

  • 在意细节：转场、滚动和小交互决定了 App 的质感。
  • 项目可以「完成」：Tivi 到了 1.0，就体面地结束。
  • 官方出了新 API，就说清关系：Haze 和渐进模糊的那篇文章是好榜样。
  • 只把能验证的工作交给 Agent：学习的部分留给自己。
  • 开源是帮助开发者的方式：库、工具和分享。
