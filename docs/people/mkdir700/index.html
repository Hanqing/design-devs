成长与经历

  1. 2019–2021

    从脚本开始

    2019 年注册 GitHub。2020 年写了超星学习通课堂签到与健康打卡脚本（★310）和打卡签到合集；2021 年做过某期刊检索接口的逆向分析。

  2. 2024

    UniClipboard 起步

    用 Rust 开始做跨平台剪贴板共享工具，目标是「无缝的剪贴板体验」；同年为 Solana 交易解析器做了 Python 绑定。

  3. 2025

    EchoPlayer 与 x-summary

    EchoPlayer 让你用真实电影和剧集系统训练听力、发音和口语；x-summary 一键生成 X 推文与搜索结果的摘要。博客写下《在 zsh 里同时用上 Vim 和 Emacs 快捷键》。

  4. 2026

    AI 编程与人生思考

    写《Agent Teams 完全配置手册》《月成本 100 元内爽用 Codex》《暴力而优雅：DOS 程序员如何用两个字节控制屏幕》《为什么熵增定律反而说明 AI 很难真正取代人》，以及《一场被截断的人生》《要不要离职，回老家做一人公司？》；开源 wx-ime-sdk。UniClipboard 扩展到 iPhone 与 Android，并提供在线试用。

设计与手艺

UniClipboard 的设计原则很明确：无账号、无服务器、端到端加密。剪贴板里常常是密码、验证码和私人内容，所以「只在你自己的设备之间流动」比任何功能都重要。
