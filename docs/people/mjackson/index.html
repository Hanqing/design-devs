Michael Jackson（MJ）Remix 联合创始人与负责人 · React Router 联合作者 · UNPKG 作者 · Shopify · 加州卡尔斯巴德

Michael Jackson：做了很多网站都在跑的工具

他住在加州卡尔斯巴德，在 Shopify 领导 Remix 项目。他的个人网站说：「在那之前我联合创办了 Remix Software，再之前，我花了十年时间做了很多网站都在用的工具。」这份清单确实很长：2014 年和 Ryan Florence 一起做了 React Router，「十多年后它仍是大多数 React 应用的骨架」；2015 年做了 UNPKG，「npm 上一切内容的 CDN」，任何包里的任何文件都能通过一个 URL 访问；管理浏览器会话历史的 history 库；最初的 expect 断言库，后来捐给了 Jest；以及 2000 年代末流行的图片视频灯箱 Shadowbox.js。他和 Ryan 还联合创办了给工程团队上 React 课的 React Training。2020 年两人创办 Remix Software，2022 年被 Shopify 收购。2026 年 8 月，不再基于 React 的 Remix 3 发布候选版。

2007加入 X

2024 年，他开了一个叫 remix-the-web 的仓库：「给 Remix（或任何框架！）用的开源工具。」里面是一个个基于 Web 标准、可以在任何 JavaScript 环境里运行的小包：流式解析 multipart 的 multipart-parser、给 File 对象做键值存储的 file-storage、惰性流式文件 lazy-file。这个仓库后来归档，开发并入 Remix 3；它也体现了他一以贯之的偏好：贴着 Web 平台做小而可组合的工具。

他到底在做什么？

MJ 正在把Remix 3推向正式版：一个「全栈」的 Web 框架，把服务器、路由、数据、UI、资源和测试统一在 Web 标准之上。2026 年 10 月，他发布了一个演讲，用几个例子展示 Remix 3 如何简化 Web 开发，并诚恳地请观众告诉他怎样成为更好的演讲者；团队也在直播里介绍了 Remix 3「不打包」的资源交付方式 remix/assets。

他对 AI 时代的软件工程非常乐观：「这是软件和软件工程的开端。我们才刚刚开始。」
