蓝星：一张纸，两支笔

TA 在做「豆蔻 Doco」：一个人和 AI Agent 共同写作的文档基础设施。人用编辑器，Agent 用 MCP、CLI 和 API，两者在同一份文档里做块级编辑、版本校验和实时协作。TA 还做了多机智能远控 Agent dsh-alpha，并分享 AI 编程、产品与投资思考。

Doco 的官网中英双语，导航分为 Edit、Live、Collaborate、Infrastructure、Tech、API、Docs。「Behind the name」一节专门解释豆蔻的名字：「Small beginnings. Growing ideas.」

「Craft」一节写着：「流畅的写作是底线。打开就写，边想边排。工具快到可以被忘记，思考才会登场。」

设计与思考

Doco 的关键设计是稳定的块 ID 与版本校验：Agent 修改文档时不会覆盖人刚写的内容，人也能看到 Agent 改了哪一块。这是「人机共写」从玩具走向基础设施的前提。

The tool is fast enough to be forgotten, and only then does the thinking take the stage.

— Doco 官网

可以从 TA 身上学什么

  • 给新协作方式做基础设施：人和 Agent 需要同一份文档。
  • 名字也是设计：「豆蔻」让技术产品有了温度。
  • 同时服务人和机器：编辑器 + MCP + API。
  • 工具要快到被遗忘：让思考成为主角。
