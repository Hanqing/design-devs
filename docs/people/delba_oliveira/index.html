TA 到底在做什么？

TA 现在帮开发者更好地使用 Claude Code。TA 在 X 上分享的大多是一句话就能用上的技巧：Ctrl+O 在长对话里搜索，/ 查找关键词，n 跳到下一处；输入 ! 直接运行 shell 命令，结果会回到对话里；Ctrl+B 把长任务放到后台；/diff 在对话旁边显示未提交的改动；用 --ax-screen-reader 启动屏幕阅读器模式。TA 也介绍团队正在测试和发布的功能，比如 Auto 模式和 Claude Code Projects。

在 Vercel 的几年，TA 的工作体现了「开发者教育」的完整链条：信息架构、写作、图示、课程平台、视频。TA 用 Remotion 搭了一个以代码生成动画视频的框架，让概念解释可以像写组件一样迭代。
