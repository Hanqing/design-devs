Ian Storm Taylor：会写框架的平面设计师

他在罗德岛设计学院（RISD）学平面设计，后来成为数据基础设施公司 Segment 的联合创始人。他也是一位很受尊重的开源作者：Slate 是一个「完全可定制」的富文本编辑器框架，GitHub 上有 3.2 万颗星，被大量产品用来构建自己的编辑器；Superstruct 是一个简单、可组合的数据校验库；Permit 是不预设立场的 Node.js 认证库。Segment 早期开源的静态站点生成器 Metalsmith 和 CSS 预处理器 Myth 也有他的参与。2022 年他开源了一个生成艺术工具包 Void，用来做笔式绘图仪作品。他的 X 简介写着：designer, coder, hiker, gamer, learner，「现在很少来这里了」。

他 2012 年写过一篇很短的设计贴士《Design Tip: Never Use Black》：屏幕上的纯黑几乎从来不是你真正想要的颜色。另一篇《Refactoring Github’s Design》开头写道：「把一个界面削减到只剩绝对必要的元素，是设计中最令人满足的任务之一。」这些文章至今仍被设计师转发，也解释了 Slate 的设计哲学：不替你做决定，只给你最必要的积木。

他到底在做什么？

Ian 的开源作品都遵循同一个原则：完全可定制、不预设立场。Slate 不提供一个现成的编辑器，而是提供构建编辑器的框架：数据模型、插件、渲染都可以替换，所以能做出从 Notion 式块编辑器到协作文档的各种东西。Superstruct 让你用可组合的结构定义和校验数据，而不是写一大堆 if。

近几年他把兴趣转向生成艺术：Void 是一个创意编程工作室应用，可以调节草图的变量、随机种子和特征，带图层面板，导出给笔式绘图仪。他在 X 上记录过一个发现：p5.js 的 random() 用的是老式线性同余生成器，会产生「看起来不怎么随机」的图案。
