Ryo Lu：让任何人都能做软件

他的 X 简介写着：「Designed Cursor, Notion, Stripe, built startups. I make a world where anyone can make software.」他在 Asana、Stripe、Notion 做过设计，后来主导 Cursor 的设计。2026 年 8 月，他在旧金山科技圈待了十年之后离开 Cursor，「需要一种不同的节奏」，卖掉了所有东西，9 月搬到台北。他业余用 Cursor 做了 ryOS：一个跑在浏览器里、模仿经典 Mac 和 Windows 的桌面系统，带 AI 助手和一整套小应用，现在又加了词典、健身、台北 YouBike 导航和 Netflix 双语字幕扩展。他还在 ryo.lu 上写日记式的短文，谈效率崇拜、品味的平均化和「有灵魂的软件」。

他到底在做什么？

Ryo 的核心信念是让软件制作人人可及。在 Cursor，他参与塑造了一个设计师和工程师都能用 AI 写代码的编辑器；在个人项目里，他亲自示范：ryOS 是一个在桌面、平板、手机上都能用的网页桌面环境，有多款内置应用和一个「懂系统」的 AI 助手，代码开源，附有架构和 API 文档。

离开 Cursor 后，他把 ryOS 当成生活记录：在台北喜欢上 YouBike，就给 ryOS 加了一个带语音导航的地图；想学语言，就做了一个支持中日韩发音标注的 Netflix 双语字幕扩展；iPhone Duo 一出，ryOS 就有了「翻盖手机里的完整桌面」。

可以从他身上学什么

  • 设计师也该写代码：AI 让这件事变得容易。
  • 做自己的「玩具」：ryOS 是作品集，也是实验场。
  • 警惕趋同：别只看别人在做什么。
  • 允许慢下来：效率不是生活的全部。
  • 把生活变成软件：骑车、学语言都能变成应用。
