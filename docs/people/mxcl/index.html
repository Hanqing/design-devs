Max Howell：不客气，以及抱歉

他是英国裔美国工程师，住在北卡罗来纳州。2009 年，他写出了 macOS 的包管理器 Homebrew，后来扩展到 Linux，用户数以千万计；他在 X 简介里写：「Creator of Homebrew. You’re welcome and I apologize.」更早，他在伦敦的 Last.fm 开发过桌面客户端 Audioscrobbler。2015 年他发了一条著名的推：Google 有 90% 的工程师在用他写的软件，他却因为没能在白板上翻转二叉树被拒，这条推成了反思白板面试的标志。他还写了 iOS 圈最流行的异步库之一 PromiseKit（★1.4 万）。如今他在做 Automic Vault：一个把命令行凭据从明文文件里搬出来、控制哪个签名应用能用哪个凭据的新型密钥管理器，「为 AI Agent 使用命令行的时代准备安全层」。

他到底在做什么？

Max 现在关注的是包管理和命令行的下一代安全。Automic Vault 把 CLI 密钥移出明文文件，并控制「哪个签名的应用可以用哪个凭据运行哪个工具」；Package Manager Manager 盘点你 Mac 上所有包管理器和它们装的包，告诉你什么过时了、什么占空间；Portal 想让远程终端会话也做到「just works」。

他也公开接咨询：一种是产品命名，一口价，给出带有定位、语气和未来词汇的名字；另一种是用 AI Agent 在五天内做出一个精致的应用。他在博客上写过《Why I lean toward accelerating AI》：他宁愿慢一点，但更担心不加速会发生什么。
