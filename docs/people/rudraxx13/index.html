一句话：「i build tiny mac things.」一个用小而精致的 Mac 工具展示交互功力的年轻工程师。

代表作：NotchMind（刘海里的音乐控制、文件暂存与 AirDrop、下载进度、剪贴板历史、计时器等 28 个工具，$7.99 买断）、TapNoise（20 种键盘音效，从低沉的 thock 到「小爪子」，还有一个键帽小伙伴 Tappy）。

主业：构建 AI Agent、LLM 评测工具和小型 Web 应用。

设计与手艺

Rudra 的两款产品都是微交互的作品：一个让刘海「悬停即开」，一个让敲键盘有声音反馈。它们不解决大问题，但每天会被使用几百次，所以细节和手感就是全部。

「Every clip is a real recording」这样的标注，也体现了 TA 对真实性的重视：营销页上的每一个动画都是 App 本身。

可以从 TA 身上学什么

  • 小工具也值得精致：高频使用的东西，手感就是价值。
  • 用真实录屏做营销：比概念图更有说服力。
  • 交叉推荐：两款产品互相导流。
  • 主业 AI + 副业 Mac：两种能力互相加强。
