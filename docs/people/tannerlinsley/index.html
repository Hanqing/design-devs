Tanner Linsley：一整套开源应用栈

他住在犹他州，是 TanStack 的创始人，也是 SEO 数据公司 Nozzle 的联合创始人。他最早为人熟知的是 React Table 和 React Query：一个是无样式的表格与数据网格工具，一个让「服务器状态」管理变得简单，后者几乎成了 React 应用请求数据的默认选择。后来这些库都去掉了 React 前缀，变成可以用于 React、Vue、Solid、Svelte、Angular 的 TanStack Query、TanStack Table，再加上 Router、Start、Form、Virtual、Ranger、Charts，以及 2026 年 10 月刚发布 1.0 的 TanStack AI。TanStack 官网显示总下载量约 184 亿次、每周约 1.77 亿次。2026 年 10 月，全栈框架 TanStack Start 发布 1.0 正式版。更早，他也参与过 Chart.js、React Static 和 Crossfilter。

TanStack 的原则写在官网上：库的核心与框架无关、由逻辑驱动，所以同一套逻辑可以在 React、Vue、Svelte、Solid 等框架里使用；从头用 TypeScript 构建，「类型安全是设计出来的」；而且这些库都是围绕真实产品和真正在交付的开发者构建的。这也是 Tanner 一路走来的方式：他的库几乎都源于他在 Nozzle 遇到的实际问题。

他到底在做什么？

Tanner 正在把 TanStack 从「一组好用的库」变成一整套应用栈：Router 提供类型安全的路由，Start 是基于它的全栈框架，Query 管服务器状态，Form 管表单，Table 和 Virtual 处理大数据量的界面，AI 则提供「你的 AI，你的方式」的模型集成和实验性的 Agent 框架。官网首页甚至有一个输入框，让你描述想做的东西，从提示词开始搭项目。

团队也会公开一些逆潮流的工程决定，比如博客《We Stopped Using RSC on TanStack.com》。TanStack 有一个越来越大的维护者团队，Query 的 TkDodo、AI 的 Alem Tuzlak 和 Jack Herrington 等都是核心成员。
