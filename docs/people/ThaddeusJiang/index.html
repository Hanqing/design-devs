他到底在做什么？

TJ 的工作分两部分：为日本客户做全栈开发，以及做自己的小产品。后者多半来自生活：save_it 是一个 Telegram 机器人，帮你保存网上的图片视频并用语义搜索；Vmemo 让「视觉型」的人用图片做笔记、用 AI 搜索；campcat 监控露营地的预约信息；ZipcodeJP 号称「世界一番はやい郵便番号検索サービス」。

他的博客是「数字花园，自留地，个人备份」：几百字的工作笔记，标题带日期，比如 PostgreSQL 改了环境变量不会自动改密码、Codex 终端用不了全局工具。

写作与观点

TJ 的工程哲学务实而简洁：能用 PostgreSQL 就用 PostgreSQL；GitHub Actions 配额用完了，就用 gh-signoff 把 iOS CI 搬回本地；用 XState 实现 EffectTS 宣称的特性，同时保持 TypeScript 语法。他也在反思 AI：vibe coding 反而让他「重新慢了下来」。
