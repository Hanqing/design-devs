Andrew Clark：从 Recompose 到 Hooks

他住在纽约曼哈顿，是 React 核心团队成员，现在在 Vercel 做 Next.js。他的个人网站只有两句话：「我是 React 的核心贡献者。我参与过的项目包括 Hooks、Suspense 和 Server Components。」在加入 React 团队之前，他写了 Recompose（★1.5 万），一个给函数组件和高阶组件用的工具集。2018 年 Hooks 提案公布当天，他在 Recompose 的 README 里写道：Hooks 解决了我三年前想用 Recompose 解决的所有问题，而且更多。他还写过一篇解释 React 新核心算法的《React Fiber Architecture》（★1.3 万），成为很多人理解 Fiber 的入门文档。早年他也做过 Flux 库 Flummox 和 redux-router。

他到底在做什么？

Andrew 现在的工作横跨React 和 Next.js：让静态内容和用户个性化内容（比如购物车）能在同一个页面混合，又不带来意外的服务器成本；让导航变得「即时」，并用一个 instant() 测试来验证页面结构（是否可缓存、有没有足够的加载骨架），不受网络条件干扰。他说 2026 年 8 月的一个版本里，有些东西他从 2017 年第一个 Suspense 原型起就在思考。

他也很关注底层性能：他发现 V8 的 JIT 不会内联 Atomics，a[1] 只要 2 条指令，而 Atomics.load 要大约 130 条，于是自己去给 V8 提了补丁。他对 React 的 <ViewTransition> 很兴奋，但坦言浏览器 API 还有很多粗糙的地方。

观点

Value Over Slop (VOS): how much better a framework, library, or other piece of software is compared to a minimally-steered, AI-generated replacement

— Andrew Clark，X，2026-09

在 React Flight 安全漏洞引发批评时，他回应说漏洞确实严重，应该审视原因，但「任何公正的人都不会把原因归结为草率或缺乏严谨」，这个协议的设计倾注了多年的心血。
