NeoDB 是一个开源、联邦化的书影音标记社区，常被看作豆瓣的开放替代。它有好的理念，却缺好用的手机端。citron 做了 Piecelet：一个原生 iOS 应用，记录、评分、讨论你读的书、看的电影和剧、听的音乐、玩的游戏。为开放社区做一个好客户端，往往比再造一个平台更能帮到人。

TA 到底在做什么？

citron 的作品有两条线。一条是开放网络与原生体验：Piecelet 让 NeoDB 在 iPhone 上好用；Crane 给 Apple 的 container 命令行做了原生 Mac 界面；SymbolKit、DominantColors 是写给 Swift 开发者的小包。另一条是解决身边的小麻烦：不重装就能打开 Chrome 里的 Gemini 功能、把校内链接一键转换成学校的 WebVPN 地址、把 Arc 书签导出来。

在 Photon，TA 参与把 AI Agent 带到人们已经在用的聊天渠道：iMessage、WhatsApp、SMS、Telegram、Slack，而不是把 Agent 困在网页聊天框里。

观点与取向

从作品看，citron 的取向很清楚：支持开放网络（NeoDB、Mastodon），尊重原生体验（SwiftUI、Mac 原生应用），以及「去用户已经在的地方」：无论是校园网的 WebVPN，还是人们每天打开的 iMessage。

可以从 TA 身上学什么

  • 为开放社区造工具：好客户端能让小众平台被更多人用起来。
  • 从身边的麻烦开始：校园网、评教、书签导出，都可以是第一个项目。
  • 学生也能做真实产品：竞赛、上架应用和工作可以同时进行。
  • 新工具出来就跟上：Apple container 发布后很快就有了 GUI。
  • 去用户已经在的地方：iMessage 比新 App 更容易被接受。
