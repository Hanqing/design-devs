Anthony Short：用纯函数渲染界面

他是来自澳大利亚的 Web 设计师和开发者，现在住在旧金山，曾在 Airbnb 和 Segment 工作。他在开源社区最有名的作品是 Deku（★3.4 千）：一个「用纯函数和虚拟 DOM 渲染界面」的库。在 React 还以类组件为主的 2014 到 2015 年，Deku 就主张不用类和局部状态，只用函数，把状态管理和副作用交给 Redux 这样的工具，可以替代 React 并兼容它的生态。更早，他写过 Sass 编码规范 idiomatic-sass、Compass 的 CSS 模式库 stitch-css、一系列 Backbone 插件，以及 Mac 编辑器 Espresso 的主题和插件。他也在保险科技公司 Newfront 工作过，后来在一家约 20 人的航空航天创业公司招聘前端工程师，技术栈是 Radix、Tailwind、Next.js 和 tRPC。

他到底在做什么？

Anthony 近年公开活动很少：他自己说有将近一年没用 Twitter，再次发帖是为了给一家约 20 人的航空航天创业公司招前端工程师。他的公开作品主要集中在 2010 到 2019 年：从 Espresso 编辑器插件、Sass 和 Compass 模式，到 Backbone 组件，再到 Deku 和 Next.js 路由 hook。

Deku 的价值在于早早指出了方向：组件就是函数，状态和副作用放到外面。几年后 React 的函数组件和 Hooks 成为主流，这个思路被整个行业接受。
