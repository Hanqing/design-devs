lencx：给 AI 套上好用的桌面外壳

TA 是 Web、Rust、Tauri 和 Electron 开发者，2022 年 12 月 ChatGPT 刚发布不久，TA 就用 Tauri 做了一个非官方的 ChatGPT 桌面客户端，支持 Mac、Windows 和 Linux，一度在 GitHub 上获得 5.5 万颗星，是当时最受欢迎的 ChatGPT 桌面应用之一。之后 TA 把精力转向 Noi（★9 千）：一个把多个 AI 网站放进同一个窗口、支持多窗口、会话隔离、提示词管理和内置终端的「AI 浏览器」，现在还能被 Claude Code、Codex、Gemini CLI 通过命令行控制。2026 年，TA 又推出了基于 DeepSeek Harness 的本地优先桌面 Agent 工作区 Minke，以及给 Agent 用的原生工具集 Opsail。TA 写过 Tauri 系列教程和「用前端视角学习 Rust」，在公众号「浮之静」写作。

TA 到底在做什么？

lencx 一直在做AI 的桌面入口。Noi 强调「交互优先」：多窗口并行、会话隔离、历史和提示词保存在本地，还有内置终端和 noi 命令行，让编程 Agent 也能操控它。Minke 则把对话、文件、终端和一个共享浏览器放在同一个工作区里，支持云端和本地模型，手机上可以通过 Tailscale 或 Cloudflare Access 远程使用。

Opsail 是「Agent 可以依赖的原生工具」：一套模块化的原生工具包，给软件 Agent 提供小而可组合、可靠的能力。lencx/skills 则把 TA 的实战经验写成可重复执行的 Agent 技能。
