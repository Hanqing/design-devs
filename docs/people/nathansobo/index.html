Nathan Sobo：从 Atom 到 Zed，再造编辑器

他住在科罗拉多州博尔德，是代码编辑器 Zed 的创始人。在那之前，他在 GitHub 参与创造了 Atom：一个「可以随意改造的 21 世纪文本编辑器」，它催生了 Electron，GitHub 上有六万多颗星。他在 Atom 上做了实时协作编辑 Teletype 和它背后的 CRDT，还尝试过用 Rust 重写 Atom 内核的实验项目 Xray。Atom 在 2022 年停止维护后，他和 Max Brunsfeld 等人用 Rust 从零写了 Zed：自研 GPU 渲染的界面框架 GPUI，多人协作，AI 可选。Zed 2024 年开源，2025 年获红杉 3,200 万美元投资，2026 年 4 月发布 1.0；8 月，他们又推出了 Delta：一个和 Agent 一起写代码、用来替代 Pull Request 的多人环境。

Nathan 在 X 上写过两句话：「如果你的代码很美，那就是它设计良好的强烈信号。」紧接着补了一句定义：「设计良好 = 快、正确、易于修改、可靠。」这是他做 Zed 的标准：一个编辑器既要像游戏一样以每秒 120 帧渲染，也要能多人实时协作，还要在 AI 时代保持「AI 可选」。

他到底在做什么？

Zed 官网现在挂着两个产品：Zed（2021 年起，「世界上最快的 IDE，开源，AI 可选」）和 Delta（2026 年，「由 DeltaDB 驱动、与 Agent 一起写代码的多人环境」）。Nathan 的说法是：写软件已经变成和 Agent 的对话，现在队友也能加入；线程是软件开发的新基本单位，而 delta 是新的提交。

他在 Zed 博客上的文章也在讨论同一件事：《Software Is Made Between Commits》《Xanadu Was Waiting for Agents》。Zed 团队自己已经从 Pull Request 迁移到了 Delta。

代表作品详解

Zed ↗

2021–Rust★9.2 万

「A high-performance, multiplayer code editor from the creators of Atom and Tree-sitter.」用 GPU 渲染界面，内置实时协作，支持 Vim 键位、Git 和扩展；AI 功能可选，部分 AI 功能付费。它的 Rust 界面框架借鉴了 Tailwind 的思路，他说：「一个想法能走多远真有意思。」

Delta ↗

2026DeltaDB

「Replace PRs with Delta.」一个没有 Pull Request 限制的协作开发流程，团队成员和 Agent 在同一个线程里工作。Max Brunsfeld 说，这是他们创办 Zed 起就想做的东西。

Atom ↗

GitHub已于 2022 年归档★6.1 万

「A hackable text editor for the 21st century」，基于 Electron。Teletype 让开发者实时共享工作区，背后是他写的字符串序列 CRDT。
