余弦（Cos）慢雾科技（SlowMist）创始人 · 安全研究者 · 《Web 前端黑客技术揭秘》作者

余弦：在区块链黑暗森林里写自救手册

他是中国 Web 安全圈的老牌黑客：曾任知道创宇技术副总裁、带领 404 安全团队，参与打造漏洞平台 Seebug 和网络空间搜索引擎 ZoomEye，写过畅销书《Web 前端黑客技术揭秘》。2018 年 1 月，他创办慢雾科技，转向区块链生态安全。他写的《区块链黑暗森林自救手册》被翻译成日、韩、阿拉伯、印尼等多种语言，教普通人保护自己的加密资产；2026 年，慢雾又发布了面向高权限 AI Agent 的安全实践指南。

「掌握这些，你就掌握了加密资产的安全。」《区块链黑暗森林自救手册》开头这样写。区块链世界像一片黑暗森林：钓鱼签名、恶意授权、假钱包、供应链投毒，一个确认按钮就可能让你损失全部资产。余弦把多年安全事件应急的经验写成了一本普通人也能读懂的手册，开源、免费、多语言，还在持续更新。

他到底在做什么？

慢雾科技是一家区块链安全公司：做智能合约与交易所审计、安全事件应急响应、链上资金追踪和反洗钱情报。余弦本人常在 X 上第一时间分析钓鱼与盗币事件，提醒用户避坑，他自嘲是「救火运动员」。

2025 年起，他把注意力扩展到 AI Agent 安全：慢雾发布了面向高权限自主 Agent 的安全实践指南，主张从「基于主机的静态防御」转向「Agent 零信任架构」；还有一个给 Agent 用的安全审查 Skill，核心原则是：「每一个外部输入在验证前都不可信。」他也公开过一个打开项目文件夹即可能触发命令执行的编辑器配置问题的概念验证。

本页依据 GitHub 个人 README 与慢雾相关仓库、慢雾官网、36 氪与安全内参等报道和 X 资料整理，资料截至 2026 年 10 月。本页不展开任何攻击技术细节。

观点

To me, a true hacker needs to possess at least two core abilities: the ability to discover 0days and the ability to engineer hacking solutions.

— 余弦，GitHub 个人 README

他的另一句口号是「HACK TO CREATE」：黑客技术的意义在于创造，而创造的一部分，就是把防御经验写成人人都能用的手册和工具。

可以从他身上学什么

  • 把经验写成手册：应急响应的教训应该让更多人受益。
  • 每个外部输入都不可信：对 Agent 和对人一样。
  • 签名前看清楚：一次确认可能损失全部资产。
  • 发现问题，也要工程化地解决：黑客的两种能力。
  • 开源、多语言：安全知识不该有门槛。
