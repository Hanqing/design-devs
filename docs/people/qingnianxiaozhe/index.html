TA 到底在做什么？

工作上，TA 在飞书生态做企业 AI：「模型往往只是其中一块，周围是业务流程、数据、权限、消息和真实的人。」开源的 aPaaS OpenAPI Node / Go 客户端、飞书抽奖机器人、DeepSeek Harness 的飞书双向控制器，都来自这条线。

业余时间，TA 做「解决自己遇到的问题」的小产品：App Store Price 让订阅价格更透明；Pinlist 跨区浏览、关注 App 的更新；AIUsage 统计你在各种 AI 编程工具上花了多少 Token 和钱；Calends 是自托管的订阅账本。

写作与观点

Running is only the beginning. It feels done when the right result reaches a real person and I can still understand and change the system six months later.

— Ethan Zhao，yizhe.me About

TA 的做事方式是：先把最小版本尽早跑起来，再把每一个错误分支修干净。这和 TA 喜欢的电子维修是同一种耐心。

维度长处局限 / 需要留意
成长零基础自学到全栈 + 企业 AI—

可以从 TA 身上学什么

  • 零基础也能走很远：碰到不懂的，就追下去。
  • 重新定义「完成」：半年后还能看懂、还能改，才算做完。
  • AI 落地在模型之外：流程、数据、权限才是企业 AI 的难点。
  • 为自己做透明工具：价格、用量，让决策有依据。
  • 先跑起来，再打磨：最小版本尽早上线。
