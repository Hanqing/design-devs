青年小哲：从不会恢复数据库备份到做出一串产品

2019 年 TA 第一次搭博客时，还写着自己「完全没有编程背景，连 WordPress 数据库备份都不会恢复」。几年后，TA 在飞书生态里做企业级 AI 应用，业余做了全球 App Store 价格对比 App Store Price、iOS 关注清单 Pinlist 和 AI 编程用量统计 AIUsage。

一句话：「最佩服两种人：一种代码写得牛的，一种文章写得牛的。」一个靠好奇心一路自学成长的全栈工程师。

代表作：App Store Price（实时采集并对比各国 App Store 定价，帮助开发者理解全球定价差异）、Pinlist（专注的 iOS 关注清单）、AI Token Usage Statistics（扫描本地会话日志，统计 Claude Code、Codex 等工具的 Token 用量与成本，可自托管）。

个人：河南洛阳人，沈阳读大学，杭州读研，北京工作后回杭州成家；痴迷电子维修，认真想过去 Apple Store 学修设备。

设计与方法

Running is only the beginning. It feels done when the right result reaches a real person and I can still understand and change the system six months later.

— Ethan Zhao，About

TA 喜欢「顺着故障一点点追下去，把坏掉的东西修好」。这种维修师的耐心，也是 TA 做产品的方式：先跑起来，再把每一个错误分支都修干净。

可以从 TA 身上学什么

  • 零基础也能走很远：好奇心是最好的老师。
  • 先跑起来，再打磨：最小版本尽早上线，发布前抠细节。
  • AI 落地在模型之外：流程、数据、权限才是企业 AI 的难点。
  • 为开发者做透明工具：价格、用量，让决策有依据。
