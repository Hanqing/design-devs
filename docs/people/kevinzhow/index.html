一句话：一个「Code, Design and Crafts」的开发者，用设计师的眼光写 iOS，又用开发者的耐心做语言学习产品。

代表作：PNChart（★9.6k，Objective-C 图表库）、Waver（类 Siri 声波动画）、Oyomi 捧读（AI 日语阅读器）、Kana Origin（假名学习）、Hanami（日语手写输入法）、Miraa（AI 听写与跟读）；著有《PRODUCTER：从 0 到 1 打造产品》。

为什么值得关注：TA 把「学习一门语言」这件事拆成了阅读、书写、听说多个产品，每一个都打磨得很有温度。

Kevin 的 X 账号 2009 年就注册了，GitHub 简介是三个词：「Code Design and Crafts」。2025 年 3 月，TA 在博客上写：「最近经常想起自己为什么离开公司自己做产品，都已经是 7 年前的事情了。当时为了能够按照自己的意志去做产品，做一款足够独特、有趣的产品。」

成长与经历

  1. 2013

    PNChart

    一个「简单又漂亮」的 iOS 图表库，最初用于 TA 参与的 Piner 和 CoinsMan 两款 App。它成为国人开源 iOS 库里最知名的作品之一，接近一万星。

  2. 2014–2015

    动效与设计实验

    Waver（Siri 式声波）、RealtimeGradientText、NaughtyImageView（精灵图动画）、RichTextView（基于 TextKit），还有一个名为「ios-with-girlfriend」的教学 Demo。设计与代码的结合在这一时期成形，TA 也在 Dribbble 上分享设计。

  3. 2015

    Catch 与 Yep

    与 Nix Zhu 等人在 Catch 团队开发社交 App Yep（「Meet Genius」，帮人找到身边有技能的人）。项目后来完整开源，获得近六千星，是当年国内最知名的 Swift 开源 App 之一。

  4. 2018

    离开公司，独立做产品

    按照自己的意志去做「独特、有趣」的产品。之后来到日本，开始做日语学习工具。

  5. 2019–2023

    Oyomi 捧读 与 Kana Origin

    Oyomi 是 AI 日语阅读器：语法分析、词性标注、EPUB 阅读、朗读，2023 年加入「OCR 工作台」，一拍扫尽不懂的日语。Kana Origin 帮助入门者学习假名，Hanami 则是日语手写输入法。

  6. 2023

    Swift on Server Tour

    在博客连载七篇《Swift on Server Tour》，从「为什么这可能是你的好选择」讲到构建完整 API，此前还写过用 Swift 编写 WebAssembly。

  7. 2025–2026

    新的副本：Miraa 与 Agent

    2025 年 3 月写下《写在新的旅程开始前》，之后参与 Miraa（AI 转写 + 跟读的多语言学习助手）。2026 年开源 Rungic（「掌上 AgentOS」：一台 Android 手机就是一台 Linux 桌面电脑 + 帮你干活的助手），以及 Raft 的原生 Flutter 客户端。

设计与手艺

产品哪里出了问题，就是那里的人才密度出了问题。

— Kevin Zhow《产品随想 2：产品力与人才密度》

TA 在这篇文章里写：自己对一个产品的想法在发布前至少会变更三次；遇到有产品感的设计师，「最后可能是 TA 告诉你应该怎么做」。这是一个做了十几年产品的人对「谁在做产品」的诚实回答。

TA 的作品在视觉上都很轻：PNChart 的动画曲线、Waver 的声波、Oyomi 的阅读界面，都在追求「看起来简单」。这背后是设计师和工程师两种身份的长期磨合。

可以从 TA 身上学什么

  • 围绕一个主题做产品矩阵：读、写、听、说，每个环节一个工具。
  • 在生活的地方找需求：住在日本，就为学日语的人做工具。
  • 漂亮的开源库是最好的作品集：PNChart 十几年后仍是 TA 的名片。
  • 诚实面对节奏：「这些年事情虽然做得慢了些，但现在有了更成熟的思考。」
