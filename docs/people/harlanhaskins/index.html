TA 到底在做什么？

Harlan 的专长是在语言、编译器和应用框架之间穿梭。TA 在 Apple 做过 Swift 编译器，也做过 visionOS 上的 SwiftUI 和 UIKit；TA 的 visionOS 示例项目 PizzaBuilder 演示了跨场景的坐标空间转换。近两年的小库都很实用：用 Swift 并发安全地包装 NSItemProvider、客户端或服务端生成链接预览、UIKit 与 SwiftUI 通用的变形容器视图。

TA 对 Swift 6 有一句很好的总结：采用 Swift 6 主要的烦人之处，是它逼你把原本就在做的假设写出来；但从此不必再做这些假设，带来的自由是巨大的。

代表作品详解

LLVMSwift ↗

SwiftLLVM C API 封装★761

「A pure Swift interface to the LLVM API」，提供原生、易用的组件，「让编译器开发变得有趣」。

Trill ↗

编程语言★276

一门简单、类型安全的编译型语言，部分受 Swift 启发：函数、结构体、指针、带方法的类型、垃圾回收类型、重载、元组和闭包。

Silt ↗

编程语言★244

进行中的依赖类型函数式语言，语法和类型系统类似 Idris 和 Agda，通过 LLVM 直接编译成原生代码，目标是不需要垃圾回收。
