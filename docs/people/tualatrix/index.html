图拉鼎：从 Ubuntu Tweak 到二十年独立开发

大学时写的 Ubuntu Tweak 曾是 Ubuntu 必装软件；之后十几年，他做了 Manico、One Switch、效率控、PasteNow、MarkMark、PopTranslate。一个住在杭州良渚的独立开发者，坚持登记工作时间，也把每一次低谷和恢复都写进了博客。

一句话：从 2007 年的开源 Linux 工具起步，2013 年转向 Mac，此后十多年专做小而专注、尊重系统习惯的效率工具。如今和做产品经理兼设计师的太太一起，以杭州图拉鼎科技的名义开发产品。

代表作：Ubuntu Tweak（2007）、Manico（2013，至今 v3.14）、效率控与 One Switch（2019）、PasteNow（2021）、MarkMark（2024）、PopTranslate（2025）。

关键数字：X 关注者约 11.3 万，发了 11 万多条推文；2021 年他 47.55% 的工作时间花在 PasteNow 上。

自我介绍：「新晋奶爸，生活在杭州良渚的开发者。」

图拉鼎有一个坚持了好几年的习惯：登记自己的工作时间。所以在 PasteNow 两周年时，他能给出精确的数字：2021 年他 47.55% 的工作时间花在 PasteNow 上，One Switch 是 4.41%，Manico 是 3.32%。很少有独立开发者会这样诚实地面对「时间都去哪了」。

他到底在做什么？

图拉鼎的产品几乎都在做同一件事：把 macOS 已有的能力，用更顺手的方式交给用户。Manico 让你用 Option + 数字键直接切换 App；One Switch 把隐藏桌面、深色模式等二十多个系统操作做成开关；PasteNow 增强的是系统级剪贴板；PopTranslate 让你在任何应用里选中文字就能翻译、解释或改写。

他的博客则记录了一个独立开发者真实的节奏：精确的时间分配、一次花了一年多的产品立项、疲倦与「开新坑」、和太太的合作磨合，以及去 Apple Park 参加 WWDC25。

本页依据 imtx.me（含 About 与博客文章）、各产品官网、App Store 和 GitHub 整理，资料截至 2026 年 10 月。

成长与经历

  1. 2007–2008

    Ubuntu Tweak

    大学期间开始做的开源项目，让普通用户轻松配置 Ubuntu 系统与桌面，一度成为 Ubuntu 上的必装软件。同期还写了 Gentoo overlay 和一个 Google Reader 客户端 lazy-reader。

  2. 2010–2012

    Linux 桌面工具

    注册 X（至今 11 万多条推文）；写了 OpenVPN 指示器、Fcitx 输入法的 GTK 前端、Chrome 的 Linux 原生通知插件，也做过一些 Django 应用。

  3. 2013.10

    转向 Mac：Manico

    发布小巧易用的 App 启动与切换工具 Manico，至今仍在维护，2026 年 8 月更新到 v3.14。

  4. 2015

    奇点 for 微博

    为 iOS 设计的第三方微博客户端，「不一般的刷微博体验」，后来下架。

  5. 2019–2020

    效率控、One Switch、Moment、In Translator

    效率控聚合二十多个小工具（缩小图片、打码、PDF 水印）；One Switch 是快捷开关；Moment 记录日程和时间进度。In Translator 最早是给太太翻译网页用的 Safari 插件，2020 年底变成原生翻译工具。

  6. 2021.04

    PasteNow

    增强系统剪贴板的 Mac 应用，次年推出 iOS 版。这是他第一次在写代码前先写需求文档、用 Figma 画到接近高保真的原型图。

  7. 2023

    低谷与恢复

    年终总结的标题是《向外连接与恢复成长的一年》：经历低谷后重新与外界建立连接，随后「一系列惊喜的事情接连不断地发生」。

  8. 2024

    MarkMark 与疲倦

    「稍后读 + 网络收藏夹」工具 MarkMark 从立项到发布花了一年多，3 月「赶鸭子上架式」发布后，他耗尽了耐心。于是写下《把「开新坑」作为「心灵按摩」》。6 月，太太设计的 PasteNow 官网上线，支持支付宝和 Stripe 购买。

  9. 2025

    PopTranslate 与 WWDC25

    太太从大厂离职，两人开始一起做产品。3 月发布「AI First、macOS Native」的翻译工具 PopTranslate；6 月去 Apple Park 参加 WWDC25。

  10. 2026

    新晋奶爸

    X 简介更新为「新晋奶爸，生活在杭州良渚的开发者」；PasteNow 持续迭代到 2.35 版。

代表作品详解

PasteNow ↗

2021macOS + iOS原生剪贴板工具

「Maximize the power of Copy & Paste.」一个注重隐私和简洁的原生剪贴板工具：拖放收集与取用、iCloud 同步、全键盘操作与自定义快捷键、按条件自动归类的智能列表、按应用设置的排除规则、空格预览与右键编辑。

它也是图拉鼎「有图纸的项目」：开发前他克制住写代码的欲望，先写需求文档，再用自己不熟悉的 Figma 画原型，一直画到接近高保真，「后来产品的样子基本上就是照着原型图去实现的」。

Manico ↗

2013macOS启动与切换

默认用 Option + 数字键启动或切换到对应的 App，不再需要 Command+Tab 一个个遍历，也不用去程序坞里找；用久了就会形成肌肉记忆。支持三种模式：Dock 模式（映射程序坞）、切换器模式（映射已打开的 App）、自定义模式（任意 App、任意快捷键）。

细节上很体贴：可以开启「静默模式」在某些 App 里不打扰；「用量」图表告诉你每天调用了多少次 App；FAQ 里还专门解释了如果需要输入 Option + 数字原本对应的 ™、£ 等字符该怎么办。14 天免费试用，一个许可证可在三台设备上激活。

PopTranslate ↗

2025.03macOSAI First

「一款默认使用 AI 引擎、设计精美、灵活快速、随叫随到的原生翻译工具。」在 Mac 上任何能选中的文本上弹出工具栏，就能翻译、解释或重写；也可以像普通 App 一样从状态栏打开。

「重写」功能来自他自己的需求：他日常要用英文邮件和海外用户沟通，不想用中翻英，而是自己先用英文写一遍，再让 AI 完善，「我相信这能提升我的英语应用水平」；加上 macOS 的 Writing Tools 迟迟没有登陆国行 Mac，于是他把重写整合进了翻译工具。它的前身就是那个为太太翻译网页而做的 In Translator。

从他的文章里能读到的几件事

  • 先画图纸，再写代码。他坦言做新产品卡住时，根本原因是「又回到了边想边写边用的老路，这是一个很『程序员』的做法」。
  • 允许自己疲倦。战线过长会耗尽耐心；开一个新坑，也可以是恢复精力的方式。
  • 「天然搭档」不等于「完美搭档」。程序员和产品经理兼设计师的组合需要磨合，他们从官网这样的小项目开始分工。
  • 从自己的需求出发。In Translator 为太太翻网页而生，PopTranslate 的重写功能为自己写英文邮件而生。

如果当时我的职业是一个产品经理兼设计师，然后我把文档和设计稿交给程序员的话，程序员一定会很开心——因为我没有乱改需求或加需求了。

— 图拉鼎，《PasteNow 两周年随感》

长处与局限

维度长处局限 / 需要留意
产品Mac 原生、克制、尊重系统习惯；单品寿命长（Manico 维护了 13 年）产品线较多，精力分散时会影响迭代节奏（他自己也写过）
商业多款付费产品，官网支持国内外支付PasteNow 在美区 App Store 评分 3.69（36 个评分），口碑在不同市场有差异
写作坦诚记录时间、疲倦和恢复，非常有参考价值博客更新不规律，2024 年一整年几乎没有更新
合作与太太组成「程序员 + 产品设计」的完整小团队两人团队抗风险能力有限

可以从他身上学什么

  • 登记工作时间：用数据回顾投入，而不是凭感觉。
  • 先写需求、画原型：给自己当一次产品经理，能少走很多弯路。
  • 允许自己换方向：开新坑也可以是恢复精力的方式。
  • 做平台原生的好公民：增强系统能力，而不是另起炉灶。
  • 公开维护作品清单：哪些在维护、哪些已停止，坦诚面对用户。
