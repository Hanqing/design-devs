Rauno Freiberg：吞噬细节的交互设计师

爱沙尼亚的交互设计师，Vercel 设计团队的核心成员。TA 做了几十个让人惊叹的交互原型，写了《Invisible Details of Interaction Design》，整理了「好的 Web 界面细节清单」，并做了一本可交互的交互设计手册 Devouring Details 和一部《软件设计史》。

一句话：「Make it fast. Make it beautiful. Make it consistent. Make it carefully. Make it timeless. Make it soulful. Make it.」当代 Web 交互设计最有影响力的设计工程师之一。

代表作：Devouring Details（23 章、23 个可下载 React 组件的交互参考手册）、History of Software Design、interfaces（★1.9k，好界面的细节清单）、inspx（像素级布局检查）、ui-playbook、Vesper 主题；以及 Vercel 的大量界面与原型。

为什么值得关注：TA 把「感觉对了」这种模糊的东西，拆解成了可以学习、可以复用的具体细节。

设计与手艺

Have you ever noticed that some animation sequences can be improved with just a touch of delay? Or that some interactions just feel better without any motion at all?

— Devouring Details

Rauno 的设计方法是用代码做设计：每个想法都做成真正可交互的原型，在手上试，而不是在静态稿上想。TA 的原型常常只关注一个瞬间，比如输入框消失、工具栏变形、文字模糊显现，但正是这些瞬间决定了产品的质感。

可以从 TA 身上学什么

  • 细节是可以学的：把「感觉对了」拆成具体的原则和组件。
  • 用原型思考：在真实交互里迭代，而不是在静态稿里争论。
  • 为每一年留档：年度原型站是最好的作品集。
  • 学习历史：理解软件设计的过去，才能设计未来。
