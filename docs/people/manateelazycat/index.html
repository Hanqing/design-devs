王勇：在 Emacs 里生活了二十年

TA 自学计算机和编程，2005 到 2007 年做手机游戏开发，2007 到 2009 年开过一家服装厂，2010 到 2018 年是深度操作系统（Deepin）的 CTO；2019 年起经营多家 IT 公司，现在是懒猫微服的 CEO。懒猫做的是给开发者和技术爱好者的私有云硬件：7 盘位全固态、最高 96 TB 的「懒猫微服」，号称 2070T 算力、128 GB 显存、可跑 2,840 亿参数大模型的「懒猫 AI 算力舱」，以及 AI 摄像头。TA 也是 Emacs 圈最高产的作者之一：用 PyQt 把浏览器、PDF 阅读器等图形程序嵌进 Emacs 的 EAF，「极快」的 LSP 客户端 lsp-bridge，以及几十个插件。TA 的博客写了 867 篇文章、一百五十多万字。

TA 到底在做什么？

现在王勇的主业是给工程师造私有 AI 基础设施。懒猫微服是一台带自家 LZCOS 系统、内网穿透、零信任硬件设计和应用商店的家用服务器；最近应用商店上线了「打赏榜」和「催更榜」，网盘加了文件保险箱。懒猫 AI 算力舱则主打大模型推理：TA 在一个月里移植了六十多个模型，把主流推理引擎都深度试了一遍，还自己优化 GLM 5.3 Flash 的预填充性能。

TA 的另一面是 Emacs 和 Linux 桌面。lsp-bridge 把所有计算放到外部 Python 进程，让 Emacs 保持流畅；holo-layer 是 Emacs 的多媒体图层；2026 年 TA 又迷上了 Arch 系发行版 Omarchy，写到了第二十个插件。

代表作品详解

Emacs Application Framework ↗

Python + PyQtEmacs★3.5 千

「A free/libre and open-source extensible framework that revolutionizes the graphical capabilities of Emacs.」在 Emacs 里运行浏览器、PDF 阅读器、视频播放器、终端等图形应用，目标是「Live in Emacs」。

lsp-bridge ↗

2022–Emacs Lisp + Python★1.8 千

「A blazingly fast LSP client for Emacs.」把语言服务器通信放到外部进程，避免 Emacs 单线程卡顿，至今仍在维护。

懒猫微服 ↗

私有云硬件 + 系统

「懒猫，顶尖工程师的私有 AI 基础设施。」产品线包括懒猫微服（AI 数据中心）、懒猫 AI 算力舱和懒猫 AI 摄像头，配套应用商店和开发者文档。
