TA 到底在做什么？

Kieran 的项目几乎都围绕 Pi 编程 Agent 展开：Pi Index 帮人找扩展；Pace 把 Pi 的会话、轨迹、真实的 Token 与成本搬到桌面 GUI 上；PiNomad 基于 Pi Durable，在你自己的机器上运行、每次模型和工具调用都做检查点，Mac、Web、iPhone 三端连接同一次运行；dureview 让你在 PR 里评论 /dureview，就用你自己的 ChatGPT 订阅得到 P0–P3 分级的审查意见。

这些工具都很「实在」：真实成本、可恢复的运行、自托管。这和 TA 在大厂做开发者工具的背景一致。

代表作品详解

Pi Index ↗

2026Astro + React已上线

「Make Pi your own.」Pi 编程 Agent 的社区目录：179 个资源、26 个分类，覆盖网页搜索、子 Agent、安全权限、持久记忆、上下文管理、代码审查、主题等，支持中英文搜索和一键复制安装命令。

它还有 Talks 栏目，收录 Pi 作者们的访谈并附英文转写和 AI 摘要。About 页写得很清楚：独立维护，与 Pi 官方无关，修正请提 GitHub issue。

PiNomad ↗

2026.10TypeScript自托管

「The durable coding agent for your own machine.」Agent 在你自己的机器上运行，使用这台机器的 shell 和仓库；每次模型和工具调用后写检查点，宿主崩溃或重启也能从断点继续。设备通过一次性二维码配对，经端到端加密通道通信，可走局域网、tailnet 或只能看到密文的中继。

可以从 TA 身上学什么

  • 把大厂经验带出来：开发者工具背景让你天然懂开发者。
  • 做新生态的目录：索引是生态最早的基础设施。
  • 让 Agent 可恢复：检查点和自托管，比更聪明的模型更能解决实际问题。
  • 说清楚边界：非官方就写明非官方。
  • 写作即思考：周报和长文帮助理清方向。
