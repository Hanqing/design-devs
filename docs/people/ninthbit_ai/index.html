Kieran Zhang：在 AI 时代，一个人能做的事远超从前

在华为做了多年 IDE 与开发者工具：自研编程语言的语言服务、鸿蒙的 IDE 集成与性能调优、把 AI 带进移动开发与运维。2026 年他离开大厂做自己的产品：Pi 编程 Agent 的桌面 GUI、开源语音输入法、AI 编程订阅价值基准。

一句话：一个从 IDE 与编程语言工具链走出来的「AI 原生独立开发者」，相信「软件工程里一切都是权衡」。

代表作：Pi Index（Pi 编程 Agent 扩展、主题、技能与提示词模板的精选索引）、Pace（Pi 编程 Agent 的桌面 GUI）、Voily（开源 macOS 语音转文字）、SubWorth（衡量 AI 编程订阅「值多少 API 钱」的开放基准）。

为什么值得关注：他的离职理由很有代表性：「不是对大厂失望，而是在 AI 时代，一个人能做的东西已经远超从前。」

设计与思考

If the years taught me one thing, it is this: in software engineering, everything is a trade-off.

— Kieran Zhang，About

他喜欢「用分析哲学的方式拆解问题」，又越来越倾向儒家思想中务实、入世的一面。这种组合让他的工具都很「实在」：Token 真实成本、订阅真实价值、语音真实落到光标处。

可以从他身上学什么

  • 把大厂经验带出来：IDE 与工具链背景让他天然懂开发者。
  • 做生态的索引：Pi Index 这样的「目录」是新生态最早的基础设施。
  • 用数据回答争论：SubWorth 把「哪个订阅更值」变成可测量的问题。
  • 写作即思考：周报和长文帮助他理清方向。
