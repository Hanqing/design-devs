Marc Edwards：为设计师造一把更精确的尺

他是澳大利亚墨尔本的设计师，Bjango 的创始人。Bjango 最有名的产品是 Mac 系统监控工具 iStat Menus，2024 年发布了「全部重写」的第 7 版。这几年他把精力放在为设计师做工具上：2024 年 11 月发布色彩转换与设计系统工具 Pinwheel，正在开发一款「设计师的设计工具」Skala，承诺性能极快，文件格式开放、可以放进 Git。他在 Bjango 网站上写了大量关于色彩管理、SVG 导出精度、设计工具内存占用的硬核文章，还录了一系列「图标速画」视频。他也写音乐：1998 年和朋友合写的歌《Believe》在 25 周年时出了重混版，Bjango 甚至还卖声码器和合成器插件。

大多数设计师不会去测设计工具的内存占用，Marc 会。他在 Bjango 的文章里对比了主流设计工具打开同一份文件时用了多少内存，量过各家模糊半径的实际效果，研究过 SVG 导出的小数精度，还写过一个四篇连载的色彩管理系列。这些测量最后都指向一件事：他要自己做一款设计工具 Skala，并承诺它会是「同类工具里最快的之一」。

他到底在做什么？

Marc 正在做的 Skala 被描述为「the designer’s design tool」：既尊重经典设计工具的传统，又要激进地拓展可能性。官网已经透露了一些细节：参考线本身就是图层，有名字、颜色和透明度，可以分组、复制到其他文档，可以一起移动、旋转和错切；文档格式是开放规范，可以存进 Git 仓库。

Pinwheel 是这条路线上的第一个产品：一个转换颜色、创建设计系统和测试无障碍对比度的 Mac 应用。它支持四种颜色混合方式，因为他认为 OKLCH 虽然好看，但色相差太远时效果并不理想。

可以从他身上学什么

  • 测量，而不是凭感觉：内存、精度、模糊都可以量化。
  • 开放文件格式：设计文件也应该能进 Git。
  • 录下你的过程：图标速画就是最好的教程。
  • 多一个爱好：音乐和天文摄影也能成为产品。
