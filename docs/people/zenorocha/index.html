Zeno Rocha：痴迷于开发者体验

他生于巴西库里蒂巴，现在住在旧金山。2009 年他从 Flash 开始做软件工程师，做过 Liferay Cloud 的首席产品官和 WorkOS 的开发者体验副总裁，然后创办了面向开发者的邮件服务 Resend，官网称用户已超过 400 万。他做过大量广受欢迎的开源项目：2013 年因为在马德里一家医院里电脑被偷、重装后找不到满意的配色，他做了 Dracula 主题，如今覆盖四百多款应用、官网称有 1,100 万用户，付费版 Dracula Pro 截至 2023 年卖出超过 25 万美元；不依赖 Flash、只有 3 KB 的复制库 clipboard.js（★3.4 万）；用 React 写邮件的 React Email（下载量 300 万以上）。他写过近两百篇文章，在 11 个国家做过一百三十多场演讲。

他到底在做什么？

Resend 想做的是开发者真正喜欢用的邮件基础设施：简洁的 API、用 React Email 写模板、清楚的投递数据。2026 年它不再只是在别人的服务上加一层：Resend Forge 是自研的发送引擎，Resend Inboxes 让 Agent 通过 MCP 或 Skill 接入收件箱，人和 Agent 在同一个线程里回复。

他的开源作品都体现「体验」二字：clipboard.js 的理由写得很清楚，复制文本到剪贴板不应该需要几十步配置、几百 KB 的代码，更不该依赖 Flash。Dracula 的目标是在所有应用里提供一致的体验，因为他一直相信切换上下文是有代价的。

写作与观点

  • The two types of quality

Copying text to the clipboard shouldn't be hard. It shouldn't require dozens of steps to configure or hundreds of KBs to load.

— clipboard.js README

他在《The two types of quality》里借用日本人对质量的两种定义：「当然质量」（atarimae hinshitsu）和「魅力质量」（miryokuteki hinshitsu），认为理解二者的区别，是做出用户喜爱的产品的关键。

可以从他身上学什么

  • 把一个小痛点做到极致。
  • 一致性有价值：一套配色走遍所有应用。
  • 开源可以导向生意。
  • 分清「当然质量」和「魅力质量」。
  • 持续公开构建。
