Marcin Krzyżanowski：用 Swift 把文本编辑从头再写一遍

TA 是专注 iOS 和 macOS 的软件工程师，现在在笔记应用 Goodnotes 做 iOS 开发。TA 以开源闻名：CryptoSwift 是用纯 Swift 实现的加密算法库，GitHub 上有一万多颗星；ObjectivePGP 为 iOS 和 macOS 提供 OpenPGP 加密与签名；OpenSSL 包把 OpenSSL 打包给 SwiftPM、CocoaPods 和 Carthage 使用。这几年 TA 深入 TextKit 2，从零写了可复用的文本视图组件 STTextView，用来替代 NSTextView 和 UITextView。TA 还做了一系列开发者工具：在线 Swift Playground、Mac 上的 Linux 虚拟机启动器 VMDesktop、不用建项目就能跑 Swift、Python、JS、Go 和 Rust 的轻量编辑器 Notepad.exe，以及给 Claude Code 和 Codex 用的原生 Mac 应用 Commander。

TA 到底在做什么？

Marcin 的两条主线是安全和文本。CryptoSwift 提供 AES、ChaCha20、SHA、HMAC 等标准算法的纯 Swift 实现，README 里专门有「推荐默认值」一节，帮人避开不安全的用法。STTextView 和 STTextKitPlus 则把 TextKit 2 的经验沉淀成可以复用的组件和工具函数。

TA 的独立产品都是开发者工具。Notepad.exe 的口号是「Make something. Run it. Keep it.」：五行 Swift、Python、JavaScript、Go 或 Rust 不应该需要一个项目；想法成形后，可以再加依赖、Linux 目标，或者导出成 Mac 应用。它还能在模拟器里跑 SwiftUI 和 UIKit 原型。
