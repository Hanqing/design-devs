他到底在做什么？

肘子的工作有三条线：深度文章（常常从一个具体的 Bug 或 API 行为出发，深入到框架的设计意图，再给出可运行的代码）；每周周报（每周一和全球开发者分享 Swift、SwiftUI、Core Data、SwiftData 的优质内容，开头是一篇他自己的评论）；开源库（几乎都来自写文章时碰到的真实问题）。

2026 年他越来越多地讨论 AI 对苹果开发的影响：哪种框架对 Agent 更友好、怎样让 AI「看见」SwiftUI 预览，以及在北京参加苹果首届 App Incubator 活动后对「AI 中转类 App」的忧虑。

ObservableDefaults ↗

2024Swift 宏★408

在 SwiftUI 里管理大量 UserDefaults 键常常意味着重复代码，而 @AppStorage 只面向单个值，也不覆盖 iCloud 键值存储。ObservableDefaults 用类宏把 Swift Observation 同时接到 UserDefaults 和 iCloud 键值存储，一次声明、到处可观察。

CoreDataEvolution ↗

2024Swift现代 Core Data

为现代 Core Data 项目带来 actor 隔离、Swift 优先的 NSManagedObject 声明、类型化路径、运行时模型元数据和模型工具。他的判断是：Core Data 依然是很多依赖成熟对象图、迁移和存储行为的 App 的务实基础，但它需要跟上 Swift 并发时代。配套文章叫《Why I Am Still Thinking About Core Data in 2026》。
