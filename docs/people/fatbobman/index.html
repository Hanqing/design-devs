东坡肘子：为了恢复身体开始写代码的人

他踏入苹果开发，起初是为了一个特别的理由：用编程来改善因药物创伤而变得迟钝的大脑，顺便做一个自己用的 App。几年后，他成了中文世界最重要的 SwiftUI / Core Data 博主之一，每周一发布的 Swift 周报有五千多订阅者，还获得了 Apple 开发者社区认可。

一句话：iOS 开发者、博主、父亲。一个「偶然的机会」让他成为苹果生态开发者，如今写作已是生活的重要组成部分。

代表作：博客「肘子的 Swift 记事本」（中英双语）、Fatbobman's Swift Weekly（5000+ 订阅）；开源 ObservableDefaults、SwiftUIOverlayContainer、SwipeCell、Infinite4Pager、CoreDataEvolution、PersistentHistoryTrackingKit、iCloudSyncStatusKit。

荣誉：因长期写作与整理周报，被 Apple Developer Community Recognition 收录。

成长与经历

  1. 2019

    迈入开发

    2019 年注册 GitHub，开始学习 Swift 和 SwiftUI，初衷是恢复身体、做一个自己用的 App。

  2. 2020

    开始写博客

    创建「肘子的 Swift 记事本」，记录学习中碰到的问题；同年开源 SwiftUIOverlayContainer 和 SwipeCell（类似邮件 App 的左右滑动菜单）。

  3. 2021–2022

    SwiftUI 与 Core Data 深度

    SheetKit、NavigationViewKit 扩展 SwiftUI 的弹窗与导航；PersistentHistoryTrackingKit 处理 Core Data 持久化历史，让 App 与扩展合并、清理事务。BlogCodes 收集所有博文代码。

  4. 周报

    Fatbobman's Swift Weekly

    每周一与全球开发者分享 Swift、SwiftUI、Core Data、SwiftData 的优质文章，Substack 订阅者超过五千。

  5. 2024–2026

    Observation 与 SwiftData 时代

    ObservableDefaults 融合 SwiftUI、Observation、UserDefaults 与 iCloud 键值存储；CoreDataEvolution 为 Core Data 带来 SwiftData 风格的 actor 隔离与宏；Infinite4Pager 提供四向无限滚动；iCloudSyncStatusKit 监控 iCloud 同步状态。成立 Fatbobman Digital Limited。
