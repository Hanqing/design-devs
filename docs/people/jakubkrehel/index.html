Jakub Krehel：你能看出区别吗？

他是住在纽约的设计工程师，目前是 Interfere 的创始设计工程师，公司在做「互联网的自愈层」。他从 2023 年开始认真经营个人网站 jakub.kr，写的都是让界面「感觉更好」的细节：渐变、OKLCH 颜色、共享布局动画、拖拽手势。2026 年他把这些经验做成了两样东西：一本叫 Interfaces 的设计工程杂志，几个月就有了一千两百多名订阅者；一套给 AI Agent 用的界面 Skill，两个仓库加起来有一万两千颗星。他还做了 React 加载动画库 loading.dev 和 OKLCH 入门指南 oklch.fyi。

他到底在做什么？

Jakub 专注于说清楚「为什么这个界面感觉更好」。他的 Skill「make-interfaces-feel-better」把这些细节列成清单：动画、排版、图标、悬停状态、光学对齐、同心圆角、阴影、点击区域。新的 /state-machine Skill 会在一个临时页面上用模拟数据渲染组件的所有状态，方便一次检查完。

在 Interfere，他负责官网和设计系统：给安全页做了一个「文字藏在盾牌后面」的标题效果，用两份叠在一起的标题实现；还公开了一个小型设计系统文档页，涵盖基础、排版和基础组件。

他的建议常常很具体：动画尽量改 transform，不要改 width、height、left 这类布局属性，因为它们每一帧都会触发重新布局，主线程一忙动画就会卡顿。

可以从他身上学什么

  • 训练分辨力：能看出差别，才能做出差别。
  • 把细节写成清单：人和 Agent 都能用。
  • 一次看全所有状态：加载、空、错误、成功。
  • 学 OKLCH：它让颜色更可预测。
  • 动画只动 transform。
