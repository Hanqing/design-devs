Steve Ruiz：一个原型长成了公司

他住在伦敦，是开发者、设计师，「现在也是创业公司创始人」，学的是视觉艺术。他给 Framer 做过教学内容，帮 Play 设计过 iOS 上的移动端设计工具，同时在 GitHub 上做了一个又一个画布小实验：模拟压感的手绘线条库 perfect-freehand，在两点或两个形状之间画出漂亮箭头的 perfect-arrows，多人光标插值库 perfect-cursors。2022 年，这些实验汇成了 tldraw：一个 React 无限画布 SDK，GitHub 上有 5 万多颗星。他的演示站 tldraw.com 每月有近 50 万活跃用户，公司已完成 A 轮融资。2026 年 10 月，他又放出了一个打磨了八个月的笔记应用测试版。

他到底在做什么？

Steve 把画布交互的难题一个个拆成小库。手绘线条要模拟压感和速度；箭头要优雅地绕开形状；多人光标在网络延迟下要平滑插值；图层排序要用分数索引。每个问题他都写过文章或开源库，比如博客里的《All About Arcs》和关于排序的两篇连载。

现在他运营 tldraw 公司，同时继续做原型：一个跨 iOS、网页和 Android，支持实时多人协作和离线的笔记应用；一个跑在 M5StickS3 小设备上的聊天项目。他也在招「以前写过代码的设计师」。

可以从他身上学什么

  • 多做原型：其中一个可能变成公司。
  • 把难题拆成小库：每个都能单独发布。
  • 写实现笔记：几何和排序问题值得记下来。
  • 演示站就是产品：tldraw.com 带来了大量用户。
  • 艺术背景是优势：它让你知道线条应该长什么样。
