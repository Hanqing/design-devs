Loren Brichter：发明了下拉刷新的人

他 1984 年生于纽约曼哈顿，在塔夫茨大学读电子工程、辅修计算机科学。2006 到 2007 年，他在 Apple 一个五人小组里工作，负责让初代 iPhone 的图形硬件和软件协同；iPhone 一完成他就离开了，创办了自己的公司 atebits。2008 年他发布 Twitter 客户端 Tweetie，在 Tweetie 2 里发明了「下拉刷新」：把列表往下拉、松手就刷新。这个手势后来被几乎所有手机应用采用，包括 iOS 自带的邮件。2009 年他获得 Apple 设计奖，2010 年 Twitter 收购了 Tweetie，成为官方 iPhone 客户端。2011 年离开 Twitter 后，他做了一款基于 Game Center 的文字游戏 Letterpress，2016 年把它卖给了 Solebon。

在 Tweetie 2 之前，刷新列表要点一个按钮。Loren 的想法是：你本来就在往上滚动看最新内容，滚到顶时再往下拉一点，松手，就刷新了。不需要额外的按钮，也不打断手指的动作。这个小手势后来变得如此普遍，以至于很多人以为它从一开始就是 iOS 的一部分。

他到底在做什么？

Loren 的贡献是一批定义了触屏时代的交互模式：下拉刷新；在单元格上滑动、露出隐藏操作；Twitter for iPad 里横向堆叠、手势滑入的面板，让你层层深入又能原路返回；Tweetie for Mac 里沿窗口边缘竖排的标签图标，后来被 Slack 等应用沿用。

他从第一款应用起就在写自己的界面框架：Mac 绘图应用 Scribbles 用了混合矢量渲染引擎，缩放和导出都不损失画质。Letterpress 的词表他开源在 GitHub 上，希望帮到其他做文字类应用的人，也让大家帮忙改进。近年他很少公开发布新作品。

代表作品详解

Tweetie ↗

2008–2010iPhone · Mac

在 Twitter 还没有官方 iPhone 应用时诞生，以速度和细节著称。Tweetie 2 引入下拉刷新和滑动操作；2010 年被 Twitter 收购，成为官方 iPhone 客户端的基础。

Letterpress ↗

2012iOS 文字游戏

基于 Game Center 的多人文字游戏：在 5×5 字母格里拼词，占领格子。游戏规则是在内测中逐步打磨出来的。

SimFinger ↗

2009Objective-C★1.2 千
