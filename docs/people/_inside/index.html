Guilherme Rambo：他对 AirPods 略知一二

来自巴西弗洛里亚诺波利斯的开发者。曾在 9to5Mac 用逆向工程挖出苹果未发布的功能；做了让 Mac 拥有 iPhone 式 AirPods 弹窗的 AirBuddy（如今已是第 3 版）；写了非官方 WWDC 客户端和 Apple Silicon 虚拟机 VirtualBuddy；还发现过让 App 偷听 Siri 对话、一行代码让 iPhone 变砖的漏洞。

他到底在做什么？

Rambo 的 GitHub 语言分布里，Swift 有 68 个仓库、Objective-C 有 33 个，几乎全是苹果平台。他的工作可以分成三类：让 Mac 用起来更像 iPhone 的产品（AirBuddy、NoiseBuddy）；给开发者的工具（WWDC App、VirtualBuddy、AssetCatalogTinkerer、StatusBuddy）；以及安全研究（SiriSpy、Safari 历史泄露、Darwin 通知漏洞）。

三者背后是同一种能力：深入理解系统内部是怎么做的。逆向工程让他能做出和系统一样流畅的弹窗动画，也让他发现系统本身的问题。

本页依据 rambo.codes、AirBuddy 官网与帮助中心、GitHub、TechCrunch 报道整理，资料截至 2026 年 10 月。

代表作品详解

AirBuddy 3 ↗

2019 → 2026macOS 14+付费 · 也在 Setapp

「Your Mac's new favorite sidekick.」看电量、连 AirPods、控制正在播放的音乐、在多台 Mac 之间移动外设，都不用离开手头的事。第 3 版把这些整合进一个 Action HUD：附近的 AirPods、连接进度、聆听模式、正在播放、低电量提醒都出现在同一个会随屏幕自适应的位置。

背后是对设备型号的精细支持：AirPods 和 Beats 的设备定义可以通过「空中更新」保持最新。另有可交互的电量、AirPods、正在播放小组件，可以放在桌面或锁屏上，并为每块显示器单独布局。

2022Swift开源

在 LightBuddy 那篇里，他对「被苹果 Sherlock」给出了一个很成熟的看法：起初他很失望，后悔没早点发布；但转念一想，如果真的已经投入大量精力发布，再被系统功能取代，感觉会更糟。更积极的看法是：苹果把一个功能做进系统，说明它对很多用户有吸引力；而苹果的实现往往是最基础的版本，第三方 App 仍然可以提供更多功能和定制。

可以从他身上学什么

  • 深入平台底层：理解系统怎么做，才能做得像系统一样好。
  • 把好奇心变成产品：逆向研究的副产品，常常是很棒的工具。
  • 负责任地披露漏洞：先报告，修复后再写成文章分享。
  • 接受被 Sherlock：平台会吸收好点子，独立开发者要不断前进。
