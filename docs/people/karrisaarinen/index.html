Karri Saarinen：质量要么在公司基因里，要么不在

他来自芬兰，住在加州，是项目管理工具 Linear 的联合创始人兼 CEO。在那之前，他在 Airbnb 和 Coinbase 做设计；在 Airbnb 时，他嫌 Jira 太难用，还给自己写了一个改善体验的 Chrome 扩展。2019 年 1 月，他和 Jori Lallo、Tuomas Artman 一起创立 Linear，要做一个比 Jira 好得多的工具，同年完成红杉领投的 420 万美元 A 轮。Linear 2021 年实现正向现金流，2025 年完成 8,200 万美元 C 轮；据维基百科，2026 年 8 月员工股份转让对公司估值 25 亿美元，年经常性收入超过 1 亿美元，客户包括 OpenAI、Salesforce、Cursor、Coinbase 和 Ramp。现在 Linear 把自己定义为「团队和 Agent 的产品开发系统」。

他到底在做什么？

Karri 正在把 Linear 从项目管理工具变成「团队和 Agent 的产品开发系统」。官网首页演示的是这样一个流程：在 Slack 里提出问题，Linear 自动建 issue，「分诊智能」打上标签，有人 @Linear 让 Agent 试着修，它就改了两个文件，开出一个等待审阅的草稿 PR。

2026 年的新功能包括 Loops：把重复任务变成共享、可靠的工作流，Slack 和 GitHub 里的事件也能触发；以及团队文档，他说目标是年底成为「人和 Agent 的文档最快、最好的地方」。他自己用 Loops 每周搜索网上提到他文章的内容，汇总成一份 Linear 文档。他的个人网站本身也是用 Linear 写和构建的。
