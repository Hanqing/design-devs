Chaofan Shou：一份写满「Things I Broke」的履历

UCSB 本科、伯克利博士辍学、FuzzLand 联合创始人兼 CTO、漏洞赏金累计 190 万美元。他的主页上列着从 2016 年上海政府网站到 2024 年 Devin.ai 的一长串「搞坏过的东西」。2026 年 3 月 31 日凌晨，他的一条推文让 Claude Code 的源码在全网「被开源」。

一句话：一个用自动化方法系统性找问题的人：模糊测试、静态分析和程序分析，是他从论文到创业再到漏洞赏金的共同武器。现在他在做 AI 基础设施。

代表作：ItyFuzz（智能合约混合模糊测试器，ISSTA '23，★1.1 千）、CorbFuzz（ASE '21）、FuzzLand（帮助追回 3,000 万美元以上被盗资产）、Hadoop / MongoDB 配置缺陷检测器 daudit。

关键数字：X 关注者约 8.1 万；2020–2022 年漏洞赏金累计 190 万美元（含锁仓代币）；6 篇顶会论文。

自我介绍：X 上写「senior slop engineer」，GitHub 上写「senior script kiddie 🌮」。

他到底在做什么？

Chaofan Shou 的路径很少见：研究和实战一直并行。在 UCSB 读本科时，他一边在实验室做浏览器安全策略的模糊测试，一边在漏洞赏金平台上挖真实世界的漏洞；在伯克利读博时，他把论文里的智能合约模糊测试器 ItyFuzz 直接变成了创业公司 FuzzLand 的核心产品。

这种「用工具批量找问题」的思路也解释了 2026 年那件事：他注意到 Claude Code 2.1.88 的 npm 包里附带了完整的 source map，随即在 X 上公布。发布流程本身，就是攻击面的一部分。

本页依据 scf.so 个人主页、GitHub、论文与报道（36氪、heise）整理，资料截至 2026 年 10 月。漏洞列表均来自他本人主页的公开披露。

成长与经历

  1. 2015–2016

    少年白帽

    2015 年注册 GitHub；2016 年向上海政府网站报告了上百个 SQL 注入与文件包含等漏洞。2017 年开源 daudit：检测 Hadoop、MongoDB、MySQL 等配置缺陷的工具（★105）。

  2. 2019–2020

    大厂漏洞

    陆续发现网易（XSS + CSRF，可接管 10 亿以上账号）、Gogs（竞态条件绕过策略）、百度（多个存储型 XSS，可接管 2.18 亿账号）、网易企业邮箱等问题。

  3. 本科

    UC Santa Barbara

    在 Tevfik Bultan 教授组参与研究，发表 CorbFuzz（用模糊测试检查浏览器的 CORB 安全策略，ASE '21）、IoT 侧信道缓解（IOT '22）、稀有种子生成（ISSTA '23）等论文。

  4. 2020–2022

    Salesforce、Veridise 与 190 万美元赏金

    在 Salesforce 做安全工程师（静态分析、内网扫描服务、数据管道），之后在区块链安全公司 Veridise 主导智能合约与区块链的自动化测试工具；这几年的漏洞赏金累计达 190 万美元。

  5. 博士

    UC Berkeley Sky Computing Lab

    师从程序分析领域的 Koushik Sen，发表 ItyFuzz（ISSTA '23）。他在主页上轻松地写：「but I dropped out :p」。

  6. 2022–2025

    FuzzLand

    联合创办 Web3 安全与高频交易公司 FuzzLand 并任 CTO。据主页介绍，FuzzLand 帮助从黑客手里追回 3,000 万美元以上资产，守护 / 管理超过 50 亿美元资产。2025 年被 Solayer 收购，他加入 Solayer 构建高性能 SVM 区块链。

  7. 2026.03.31

    Claude Code 源码事件

    凌晨发现 Claude Code 2.1.88 的 npm 包附带完整的 source map 并在 X 上公布，帖子 24 小时内获得数千万次浏览。Anthropic 回应称这是发布打包时的人为失误。

  8. 2026

    转向 AI Infra

    主页写着「I am now working on AI infra」；同年开源 agentpay-sdk：让 AI Agent 在策略约束和人工审批下付款、持有资金、跨链转账。

代表作品详解

ItyFuzz ↗

ISSTA '23Rust智能合约模糊测试

「Blazing Fast Bytecode-Level Hybrid Fuzzer for Smart Contracts.」一个结合符号执行与模糊测试的混合测试器，支持 EVM 和 MoveVM，可以在链下，也可以直接对链上已部署的合约找漏洞。论文的核心思想是基于快照：把链上状态存成快照反复探索，大幅提升 DeFi 漏洞的发现效率。

安装方式很有黑客风格：curl -L https://ity.fuzz.land/ | bash，再运行 ityfuzzup。

CorbFuzz ↗

ASE '21C浏览器安全

CORB（跨源读取阻止）是浏览器防止恶意网页读取跨站敏感数据的机制。CorbFuzz 用模糊测试检查各浏览器对这一策略的实现是否有缺陷。这是他在 UCSB 的第一篇一作论文。

方法与观点

  • 研究与实战双轮驱动。论文里的工具直接用在真实世界的漏洞上，真实世界的漏洞又给研究提供问题。
  • 自动化地找问题。从 Hadoop 配置检测到合约模糊测试，他的工具都在把「靠经验找漏洞」变成「靠系统找漏洞」。
  • 发布流程就是攻击面。一个打包时忘记去掉的 source map，就能暴露一款明星产品的全部源码。
  • 自嘲是一种姿态。「senior slop engineer」「senior script kiddie」「but I dropped out :p」，严肃的履历配上轻松的语气。

可以从他身上学什么

  • 把「搞坏过的东西」写成作品集：安全研究员最有说服力的履历。
  • 研究与实战双轮驱动：论文里的工具，直接用在真实世界。
  • 敢于放弃「标准路径」：伯克利博士辍学，去创业，再被收购。
  • 检查自己的发布流程：source map、调试符号、环境变量，都可能是泄露口。
  • 用最少的设计说最多的话：纯文字主页，信息密度极高。
