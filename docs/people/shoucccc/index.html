Chaofan Shou：一份写满「Things I Broke」的履历

UCSB 本科、伯克利博士辍学、FuzzLand 联合创始人兼 CTO、漏洞赏金累计 190 万美元。2026 年 3 月 31 日凌晨，他的一条推文让 Claude Code 的源码在全网「被开源」。

一句话：一位顶尖的安全研究员和系统工程师：写论文、做模糊测试工具、创业、挖漏洞，现在转向 AI 基础设施。

代表作：ItyFuzz（ISSTA '23，基于快照的链上智能合约模糊测试器）、FuzzLand（帮助从黑客手中追回 3000 万美元以上，守护超过 50 亿美元资产）、CorbFuzz（ASE '21）。

为什么值得关注：他的个人主页把「我搞坏过什么」当作作品集来展示，这本身就是一种极具个性的设计。

8.1 万X 关注者
2018加入 X

Chaofan Shou 的 X 简介写着「senior slop engineer」，一个自嘲。但他的个人主页上有一栏叫「Things I Broke」，三十多条记录从 2016 年排到 2024 年：Twitter、百度、网易、CVS、FTX、Etherscan、Devin.ai……读起来像一份反过来的通缉名单。

成长与经历

  1. 2016–2020

    少年白帽

    2016 年就向上海政府网站报告了上百个 SQL 注入与文件包含漏洞；之后陆续发现百度、网易（可影响十亿级账号）、Gogs 等的安全问题。

  2. 本科

    UC Santa Barbara 计算机科学

    在 Tevfik Bultan 教授组参与研究，发表 CorbFuzz（用模糊测试检查浏览器安全策略，ASE '21）、IoT 侧信道缓解（IOT '22）等论文。

  3. 毕业后

    Salesforce → Veridise

    在 Salesforce 做安全工程师，负责静态分析（SAST）、内网扫描服务与数据管道；之后在区块链安全公司 Veridise 主导智能合约与区块链自动化测试工具。2020–2022 年的漏洞赏金累计达 190 万美元。

  4. 博士

    UC Berkeley Sky Computing Lab

    师从程序分析领域的 Koushik Sen 教授，发表 ItyFuzz（ISSTA '23）。他在主页上轻松地写：「but I dropped out :p」。

  5. 2022–2025

    FuzzLand 联合创始人兼 CTO

    与 Jeff Liu 一起创办 Web3 安全与高频交易公司 FuzzLand，用模糊测试和 AI 分析智能合约。2025 年 FuzzLand 被 Solayer 收购，他加入 Solayer 构建高性能 SVM 区块链。

  6. 2026

    Claude Code 源码事件与 AI Infra

    3 月 31 日凌晨，他发现 Claude Code 2.1.88 的 npm 包里附带了完整的 source map，随即在 X 上公布，帖子 24 小时内获得数千万次浏览。Anthropic 回应称这是发布打包时的人为失误。目前他转向 AI 基础设施工作。

个人网站

scf.so ↗

一个纯文字的学术风格主页：一段简短的自我介绍，然后是 Publications、Talks、Things I Broke 三个部分。

「Things I Broke」又分为 Security Issues 和 Privacy Issues 两组，每一条都写清年份、目标和影响，例如「2023 - Twitter XSS + CSRF + CSP bypass leading to all Twitter accounts take over」。

域名 scf.so 只有三个字母，是他名字的缩写。这种极简与内容的密度形成了强烈反差。

手艺与方法

他的研究与实战高度一致：用自动化的方法系统性地找问题。模糊测试、静态分析、程序分析，是他从论文到创业再到赏金的共同武器。

作品集也可以是一份漏洞清单

把「搞坏过的东西」写成作品集，是安全研究员独有的自我表达方式，也是最有说服力的能力证明。

可以从他身上学什么

  • 研究与实战双轮驱动：论文里的工具，直接用在真实世界的漏洞上。
  • 敢于放弃「标准路径」：伯克利博士辍学，去创业。
  • 发布流程本身就是攻击面：一个 source map 就能暴露全部源码。
  • 用最少的设计说最多的话：纯文字主页，信息密度极高。
