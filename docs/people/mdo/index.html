Mark Otto：给整个 Web 一套默认样式的设计师

2007 年他从大学退学，搬到加州的设计公司 ZURB 做设计和开发；之后加入 Twitter，与 Jacob Thornton（@fat）一起做出了 Bootstrap，后来成为世界上最流行的前端框架之一。2012 年底他加入 GitHub，重新设计了 Issues、对话页和分栏 Diff，一路做到设计总监、高级设计总监和 GitHub 第一位首席设计师。2023 年他离开工作十年多的 GitHub，在 The Pierre Computer Company 担任首席产品官，为开发者和 AI Agent 做代码托管和 Diff 渲染工具。

他到底在做什么？

Mark 是少有的既画稿又写 CSS 的设计负责人。在 GitHub，他亲手设计并上线了新版 Issues、对话页、分栏 Diff、系统字体和深色顶栏；管理过 30 人的设计、插画和写作团队；后来又放下管理，专心做品牌项目、GitHub Shop、内网和 Universe 大会的主视觉。

在 Pierre，他做的是新一代开发者工具：pierre.computer 和 code.storage 面向开发者与 AI Agent 提供代码托管，开源库 diffs 基于 Shiki 渲染代码差异，trees 负责高性能文件树。此前的实验产品 Pierre.co（代码托管、代码评审、文档和 CI 一体）已在 2025 年关闭。

本页依据 markdotto.com（About、Work、Blog）、GitHub 仓库与 README 和 X 资料整理，资料截至 2026 年 10 月。

代表作品详解

Bootstrap ↗

2011–CSS · JS★17.5 万

「最流行的响应式、移动优先前端框架。」网格系统、组件、工具类和完整文档，让不擅长设计的开发者也能快速做出像样的界面。它的影响远超代码本身：一代 Web 应用都带着 Bootstrap 的影子。

配套的 Bootstrap Icons 提供 2,000 多个开源 SVG 图标；仓库默认分支已经在开发 Bootstrap 6。

Code Guide ↗

2012规范★8.5 千

diffs 与 trees ↗

2026Pierre 开源

diffs 是基于 Shiki 的代码差异渲染库，支持语法高亮和主题；trees 是追求性能和可定制的文件树组件。它们延续了他在 GitHub 设计分栏 Diff 时的关注点：怎样让人看清代码到底改了什么。
