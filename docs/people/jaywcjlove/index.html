TA 到底在做什么？

小弟调调做两类东西：帮人找东西的清单和速查表，以及解决一个具体小问题的 Mac 应用。Awesome Mac 的 README 说，它「已远远超出最初的预期，变得更加全面和精细」；Awesome Swift macOS Apps 则专门收集用 Swift 写的开源 Mac 应用，给学 Swift 的人当范例。

TA 的应用都很小而直接：DockLift 点击 Dock 里的窗口就把它拉回当前屏幕，Deskmark 给桌面加水印方便录视频，Screen Test 测试显示器画质，Time Passage 问你「我还能活多少天」。PermissionFlow 是一个帮 macOS 应用引导用户授权的开源库。TA 在各项目 README 里写着：使用 TA 的应用也是支持 TA 的一种方式。

本页依据 wangchujiang.com、GitHub 个人简介与仓库 README 和 X 帖子整理，资料截至 2026 年 10 月。各应用的下载量与收入未公开；性别未见本人明确表述，本页用 TA。
