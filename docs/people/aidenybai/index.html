TA 到底在做什么？

Million 现在是一家前端编程数据研究实验室：为前沿编程 Agent 构建环境和评测，让 Agent 在从未见过的代码库里做工程师每天做的事：开发功能、部署应用、调试问题。ReactBench 就是其中之一，在真实代码库上给编程 Agent 的前端能力打分。

开源工具则把同样的目标交给开发者：React Scan 无需改代码就能高亮渲染过多的组件；React Doctor 对代码做确定性检查，覆盖状态与副作用、性能、架构、安全和无障碍；React Grab 让 Agent 直接定位到你选中元素背后的源码，官方称能让 Agent 快两倍、更准确；bippy 则「黑进」React 内部，读取 Fiber 树。
