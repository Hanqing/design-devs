TA 到底在做什么？

Ivan 的主题始终是让 LLM 应用变得可靠：结构化输出、合成数据和二元指标。Instructor 让你只定义一个 Pydantic 模型，就能从任何大模型拿到经过校验的 JSON，不用自己解析、处理错误和重试。

在 Manus，TA 做的是通用 Agent：TA 写过怎样从零搭一个编程 Agent（约 200 行 TypeScript），怎样迁移到 React Ink 做流式终端界面，以及「智能体搜索」为什么重要。2026 年 TA 做了一个实验：在 30 万 token 的语料上，简单的 grep 比 SQLite 全文检索便宜 29.6%，准确率还更高。

2023–Python★1.4 万

「Structured outputs for LLMs.」定义一个模型，从自然语言里把数据抽出来，就这么简单。它基于 Pydantic 做校验和类型安全，支持多家模型提供商。Ivan 写过《How Instructor Works》，拆解它的内部机制。

Kura ↗

2025Python★538

受 Anthropic CLIO 论文启发：用语言模型给对话打标签，再基于向量递归聚类，帮你在不暴露个人信息的前提下，理解成千上万条聊天记录里用户真正需要什么。

Building An Agent ↗

2025TypeScript系列文章

参照 Thorsten Ball 的 Go 版本，用 TypeScript 从一个约 200 行、能读写和列出文件的编程 Agent 开始，一步步加上智能体搜索、子 Agent、待办任务和记忆。核心观点：Agent 就是在对话循环里拿到正确工具的大模型。

TA 的评测哲学是：用二元指标评估主观任务，用合成数据扩大覆盖，用统计检验确认提升不是偶然。简单的东西更容易被坚持做下去。

可以从 TA 身上学什么

  • 先写简单的评测：能跑起来比完美更重要。
  • 怀疑你的提升：用统计检验排除偶然。
  • Agent 没那么神秘：就是循环里的大模型加工具。
  • 用数据挑战直觉：grep 有时就是比数据库好。
  • 学点完全不同的东西：一门外语也能改变职业方向。
