John Resig：从 jQuery 到日本浮世绘

他是 jQuery 的创造者。据维基百科，他 2005 年还在罗切斯特理工学院读书时，因为受够了各浏览器 JavaScript 的不一致而开始写 jQuery，2006 年 1 月在纽约 BarCamp 上公开发布。jQuery 后来成为部署最广的 JavaScript 库，至今仍运行在约 77% 的头部千万网站上。2007 到 2011 年，他在 Mozilla 做 JavaScript 布道师和工具开发者，还做了 Processing.js、选择器引擎 Sizzle 和分布式测试工具 TestSwarm，写了《JavaScript 忍者秘籍》和《精通 JavaScript》两本书。2011 年 5 月他加入可汗学院，现在是首席软件架构师，2012 年主导了可汗学院面向零基础学生的编程课程。业余时间，他是日本木版画（浮世绘）的研究者：他创建的 Ukiyo-e.org 能用一张照片在 24 家以上的机构里搜索相似的版画，收录超过 22 万幅。

他到底在做什么？

John 的白天在可汗学院：作为首席软件架构师，他关注工程效率，最近在推广用 AI 做代码审查，也夸 GitHub 新的 Stacked PRs 预览「一次把 5 个叠加的 PR 送进合并队列」。

他的另一半时间给了日本版画。Ukiyo-e.org 汇集了来自博物馆、大学、图书馆和拍卖行的版画图像与元数据，最大的特点是图像相似度搜索：上传一张照片，就能找到其他收藏里的同一幅或相似的版画。他最近把 Google Analytics 从网站上移除，换成自建的、不用 Cookie 的统计。
