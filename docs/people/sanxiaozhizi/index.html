三咲智子：给库作者一把更快的打包器

TA 在 GitHub 上叫 sxzz，常驻东京和深圳，是 Vue、Vite、VueUse、unjs、unplugin 和 Oxc 的核心团队成员。TA 最有影响力的作品是 tsdown：基于 Rolldown 的库打包工具，主打「优雅」和极快地生成类型声明文件，已有 4.3 千颗星，GitHub 上超过 100 星、用它构建的项目已有 873 个，安装体积比 tsup 还小。TA 还做了给 Vue 扩展宏和语法糖的 Vue Macros（★2 千），参与了无虚拟 DOM 的 Vue Vapor 研发，是 Mastodon 网页客户端 Elk 的作者之一，以及在线语法树浏览工具 AST Explorer。2026 年 7 月，TA 把 Rich Harris 的 magic-string 完整迁移到纯 ESM 和 TypeScript，发布了期待已久的 1.0。TA 也做了对比不同地区汉字字形的小工具 hanji。注：X 上的 @sxzz 是另一个人，TA 的 X 账号是 @sanxiaozhizi。

TA 到底在做什么？

三咲智子专注于让库的构建和类型生成变快。tsdown 基于 Rolldown 和 Oxc，配套的 rolldown-plugin-dts 负责打包 .d.ts 文件，并通过 Volar 支持 Vue、Astro 等文件类型。TA 不断压缩工具的体积：把 Babel 工具链换成 yuku 后，tsdown 安装体积减少约 5 MB，比 tsup 还小。

在 Vue 生态里，TA 写过《Vue 3.3: Major New Features》，Vue Macros 让开发者提前试用社区提出的新语法和宏。TA 也参加 HackerGame 这样的信息安全比赛并写解题报告。
