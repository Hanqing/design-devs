Sanket Sahu：从 NativeBase 到一句话生成 App

他住在印度班加罗尔，联合创办了设计与开发公司 GeekyAnts，并担任 CEO 十多年，把它做成一家全球化的产品工程公司；现在由联合创始人 Pratik 接任 CEO，他作为董事会成员继续支持团队。他在开源社区最有名的作品是 React Native 组件库 NativeBase（★2 万），之后是基于 Tailwind（NativeWind）的复制粘贴组件库 gluestack-ui，以及用 Vue 写原生应用的 Vue Native、设计转代码工具 BuilderX。现在他在做 RapidNative：用自然语言描述，就能生成真正的 React Native 应用，官网显示已经交付了 36 万多个提示。他还开源了一串有意思的项目：在浏览器里运行 React Native 的 reactnative.run、用 TypeScript 写的迷你类 Linux 系统 Lifo、不用 Docker 就能本地运行的 Supabase 兼容后端 tinbase。

他到底在做什么？

Sanket 的主线是让移动应用的构建变得极快。RapidNative 面向创始人、产品经理和 UX 设计师：用一句话描述，得到一个可以分享、可以发布到应用商店的全栈移动应用。底层的 browser-metro 把 Metro 打包器的架构搬进浏览器，支持热更新、Expo Router 和 npm 包，全在客户端完成。

他也在试验新范式：geeknative 用一份规格说明，让编程 Agent 分别用 SwiftUI、Jetpack Compose 和 React 原生实现同一个功能，「不用跨平台技术的跨平台应用」；jetplane 能在一台机器上同时跑几十个 Expo 开发服务器；life-os 是一个用 Markdown 仓库加 AI 记录人生一切的模板。
