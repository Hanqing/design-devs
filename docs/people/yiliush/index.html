Yiliu：做让人成为更好的思考者的软件

TA 是设计师和程序员，想做「帮助人们成为更好的思考者和创造者」的软件。2018 到 2024 年，TA 深耕空间计算：先做了 VR / AR 里的思维空间工具 Softspace，写了三篇长文讲它的起源、基础和设计；最后做成了 AR 生产力应用 Spaceframe。现在 TA 在做 Cube Computer：一台给编程 Agent 用的云电脑；其中的 Proton 是一台持久运行的 Linux 机器，8 个虚拟 CPU、内存从 2 GB 弹性扩到 64 GB，每月 20 美元、按秒计费，关上笔记本 Agent 也能继续工作。TA 的经历跨度很大：当过艺术家奥拉维尔·埃利亚松工作室的研究负责人，在哈佛设计研究生院读过建筑（X 简介说是退学），做过摩根士丹利的投资分析师，本科在哥伦比亚大学读计量经济学。

TA 到底在做什么？

Yiliu 现在做的是编程 Agent 的「家」：一台装好你的工具、能跑长任务、合上笔记本也不会停的云端 Linux 电脑。Proton 的定价很直接：8 个虚拟 CPU、2 GB 保证内存、按需涨到 64 GB、50 GB 持久磁盘，每月 20 美元覆盖 730 个运行小时，停机就停止计费，余额用完时机器挂起、磁盘保留。

TA 之前多年探索空间界面：TA 说自己喜欢「让我能同时用上更多大脑」的界面。Softspace 和 Spaceframe 把笔记、文件和想法摆在三维空间里，让思考变成可以走进去的地方。
