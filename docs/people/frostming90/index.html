Frost Ming：人生苦短，我用 Python

TA 是深圳的 Python 开发工程师，最有名的作品是 PDM（★8.7 千）：一个支持最新 PEP 标准的现代 Python 包与依赖管理器，2019 年底开始开发，是 Python 社区里 Poetry、uv 之外的重要选择之一。TA 还写了可扩展的 Markdown 解析器 Marko、查找和下载 Python 包的 unearth、统一多家语音合成服务的 tetos，维护「为人类设计的 Git」legit（★5.7 千），并做了为知乎链接生成分享卡片的 Telegram 机器人 fxzhihu。2026 年 OpenClaw 爆火后，TA 和 PsiACE 一起把小型 Python Agent 项目 Bub 改造并重写成「一个可以用插件组合的小型 Agent 运行时」。TA 的 X 简介引用李白《侠客行》：「赵客缦胡缨，吴钩霜雪明」。TA 也爱摄影，在 Telegram 上有一个周刊频道。

2026 年 4 月，TA 写了《我们为什么要重写 bub?》。Bub 最早是 PsiACE 的一个小型 Python Agent 项目；OpenClaw 爆发后，TA 不满足于当一个纯粹的使用者，想拆开看看它是怎么做的。他们先把 Bub 改造成在 Telegram 群里用的「龙虾」式自主 Agent，加上基于 tape 的记忆机制。但每加一个消息渠道、每积累一个技能，都要往 Bub 本体里塞代码和开关，TA 意识到「这样下去，bub 迟早会变成另一个 nanobot，甚至另一个 OpenClaw」，于是决定用插件重写它。

TA 到底在做什么？

Frost Ming 的主线是Python 的打包和工具链：PDM 遵循 PEP 标准，支持锁文件、依赖组和插件；unearth 负责从索引里找到并下载合适的包；pdm-packer 能把项目打包成 zipapp；onepm 帮你自动挑选正确的包管理器。

2026 年，TA 的另一条线是Agent 运行时。Bub 官网写着「Composable · Tape-driven · Channel-agnostic」：从一个能用的 Agent 开始，用插件改变它的思考、记忆和连接方式。TA 在 X 上批评过每家都从零重写 agent loop、工具和 MCP 的做法：「pi 这种项目存在的意义不就是被下游使用吗？」
