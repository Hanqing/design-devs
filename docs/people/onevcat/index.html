成长与经历

  1. 2011–2012

    从 Unity 开始

    2011 年注册 GitHub，同年开始写博客 OneV's Den（「上善若水，人淡如菊」）。早期作品 XUPorter 帮 Unity 3D 导出的 Xcode 工程自动添加文件和框架，之后又做了长期维护的跨平台 Unity WebView 插件 UniWebView。

  2. 2013

    VVDocumenter-Xcode

    输入 /// 就自动生成文档注释模板的 Xcode 插件，★8k，成为当年 iOS 开发者的必装插件。

  3. 2014–2015

    Swift 元年与 Kingfisher

    Swift 发布后写下《Swifter：100 个 Swift 必备 Tips》；2015 年发布纯 Swift 的图片下载与缓存库 Kingfisher，至今仍是 Swift 生态最主流的图片库之一。同年还有 APNGKit、Rainbow。

  4. 日本

    赴日工作，加入 LINE

    来到日本工作，之后加入 LINE（GitHub 公司一栏：LINE Corp.，位于横滨），长期参与大规模 iOS 客户端开发。

  5. 2016–2019

    objc 中国与写书

    主持 objc 中国，组织翻译了 objc.io 的《函数式 Swift》《Swift 进阶》《Core Data》《集合类型优化》《App 架构》以及后来的《Thinking in SwiftUI》；自己写了《SwiftUI 与 Combine 编程》和《Swift 异步与并发编程》。

  6. 2025–2026

    Agent 时代的工具人

    博客写《一个半月高强度 Claude Code 使用后感受》《Magpie 和「AI 贼船」——当代码变得廉价时》《用好你的 jj——重新思考 Agent 时代的版本控制》；开源 Prowl、sim-use、argue、tang、Glyphon、Croc24（24 点小游戏）、vs2x（VS Code 主题转 Xcode 主题），另开了专写 AI 的博客 ai.onev.cat。

设计与手艺

onevcat 的开源库都有一个共同点：API 设计非常「Swifty」。Kingfisher 的 imageView.kf.setImage(with:) 成为了后来许多库模仿的命名空间风格。好的 API，本身就是一种设计。
