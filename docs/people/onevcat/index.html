onevcat：一个为创作者创作的人

中文 iOS 圈尊称「喵神」。TA 写了 Swift 生态里最常用的图片库之一 Kingfisher（★2.4 万），写了《Swifter》《SwiftUI 与 Combine 编程》《Swift 异步与并发编程》，创办 objc 中国翻译了 objc.io 的一整套书。如今长居日本，在 LY Corporation（原 LINE）工作，2026 年一口气做了 Prowl、sim-use、argue、Glyphon 等 Agent 时代的工具。

TA 到底在做什么？

onevcat 的十五年，可以分成三段：造工具（Unity 插件、Xcode 插件、Kingfisher）；写书和翻译（让成千上万中文开发者读懂 Swift 和一流的 objc.io 内容）；以及 2026 年的「Agent 时代工具人」：给终端编程 Agent 做原生指挥中心 Prowl，给 Agent 装上看见和操作模拟器的眼睛和手 sim-use，让多个 Agent 结构化地辩论 argue。

TA 的博客分成三个文集，名字都很古雅：技术文章叫「能工巧匠集」，生活随笔叫「一得之愚集」，吐槽叫「南箕北斗集」。About 页的自我描述是：「其实什么都会点儿，但是好像什么都不精……大概是在日本待久了的原因，被评价为『整个人透着淡淡的死气』。」

本页依据 onev.cat、OneV's Den 博客（含 About 与 2026 年文章）、GitHub 主页与 README 整理，资料截至 2026 年 10 月。

成长与经历

  1. 2011–2012

    从 Unity 开始

    2011 年注册 GitHub，同年开始写博客 OneV's Den（「上善若水，人淡如菊」）。早期作品 XUPorter 帮 Unity 3D 导出的 Xcode 工程自动添加文件和框架，之后又做了长期维护的跨平台 Unity WebView 插件 UniWebView。

  2. 2013

    VVDocumenter-Xcode

    输入 /// 就自动生成文档注释模板的 Xcode 插件（★8.2 千），成为当年 iOS 开发者的必装插件；同年还有仿 iOS 7 短信弹簧效果的 collection view 布局。

  3. 2014–2015

    Swift 元年与 Kingfisher

    Swift 发布后写下《Swifter：100 个 Swift 必备 Tips》；2015 年发布纯 Swift 的图片下载与缓存库 Kingfisher，以及 APNGKit、Rainbow、RandomColorSwift。

  4. 2016–2017

    objc 中国与 FengNiao

    组织翻译 objc.io 的《函数式 Swift》《Swift 进阶》《Core Data》《App 架构》等；用 Swift 写 SMTP 库 Hedwig；2017 年发布清理 Xcode 工程中未使用资源的命令行工具 FengNiao（★3.6 千）。

  5. 赴日

    加入 LINE

    来到日本工作，加入 LINE（后为 LY Corporation），长期参与大规模 iOS 客户端开发。

  6. 2019–2022

    写书

    写了《SwiftUI 与 Combine 编程》和《Swift 异步与并发编程》，主持翻译《Thinking in SwiftUI》。

  7. 2025

    Agent 时代的起点

    写《一个半月高强度 Claude Code 使用后感受》《Magpie 和「AI 贼船」：当代码变得廉价时》，以及对苹果 Foundation Models 边界的测试；11 月底开始用 OpenClaw（当时还不叫这个名字），把 Agent 调教成一群「猫娘」。

  8. 2026

    一年十个新工具

    2 月发布 Prowl；3 月写《用好你的 jj：重新思考 Agent 时代的版本控制》，回国参加 Let's Vision 26；4 月发布 argue；之后是 sim-use（以 LY Corporation 名义开源）、tang、Glyphon、YiTong、Xin、Croc24；10 月写《一些关于开发的杂谈话题：代码审核》。

代表作品详解

Kingfisher ↗

2015Swift★2.4 万

「A lightweight, pure-Swift library for downloading and caching images from the web.」异步下载与缓存、图片处理器、渐进式加载、SwiftUI 支持。它的 API 设计非常「Swifty」：imageView.kf.setImage(with: url) 这种 .kf 命名空间风格，后来被许多库模仿。

十多年来它一直跟进每一代 Swift、每一次平台变化，2026 年 10 月仍在更新。好的 API 本身就是一种设计，长期维护本身就是一种承诺。

2026CLILY Corporation 开源

「给 agent 装上眼睛和手」：一个跨平台命令行，让 AI Agent 用统一的命令观察并操作 iOS 模拟器和 Android 模拟器 / 真机：看见画面、点按元素、验证结果。它是在公司内做的工具，以 LY Corporation 的名义开源。onevcat 开玩笑说，介绍文章先用中文写、翻成日文发在公司技术博客，再从日文「翻译」回中文发在自己博客，「多少有点出口转内销的行为艺术」。

argue ↗

2026.04TypeScript多 Agent

一个结构化的多 Agent 辩论引擎：多个 AI Agent 独立分析同一个问题，互相挑刺，再投票，最后给出一份带证据、带分歧、带可信度分数的结论。它与具体的 Agent 框架无关，可以接入不同的 harness。

可以从 TA 身上学什么

  • 写书是最深的学习：把一门语言写透，你就真的懂了它。
  • 翻译也是贡献：objc 中国让成千上万中文开发者读到一流内容。
  • 长期维护：Kingfisher 十年如一日地跟进每一代 Swift。
  • 在新时代重新出发：资深工程师同样可以在 Agent 时代做新工具。
  • 把工作变成「环境」：让任务在碎片时间里持续推进。
