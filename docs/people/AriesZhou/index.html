他到底在做什么？

Aries 的工具都来自日常的不方便：X 上的长文没有目录，读到一半找不到位置，于是有了 X-TOC；书签越存越乱，于是有了 Bookmark Assistant；每次更新 Chrome 扩展都要在商店后台手动改文案、换图、填隐私声明，于是有了 DashBye，「少一点后台，多一点发布」。

他相信「AI 会让世界变得更好」，也在 AI 的帮助下做以前不熟悉的技术栈。但他的博客同样在冷静地讨论 AI 带来的副作用：逆向工程的门槛消失之后软件保护会怎样，开源许可证在「AI 洗稿」面前的边界在哪里。

代表作品详解

X-TOC ↗

2026.02浏览器扩展JavaScript

「XTOC helps you navigate structured X Articles, save useful passages with their source context, and move your clips into an open format when you are done reading.」给 X 的长文章加上目录导航，随手保存有用的段落并保留来源上下文，加标签、写笔记、搜索，读完后导出为 Markdown 或 JSON。数据都在本地。

DashBye ↗

2026.09TypeScript CLI开源 · 无服务器

「Less dashboard. More shipping.」一个只在本地运行的命令行工具，把 Chrome Web Store 的扩展包、商店文案、图片素材和隐私声明，和扩展代码放在一起做版本管理，并同步到商店草稿。它解决的是开发者常常忽略的「最后一公里」：发布素材也是代码的一部分。

Bookmark Assistant ↗

2026.10Chrome 扩展GPL-3.0

在本地管理 Chrome 书签，可选用 AI 生成摘要和标签，并同步到 Notion。完整源码以 GPL-3.0 开源。

开发中本地优先AI 知识库

把 Obsidian、Markdown 和本地文件变成 AI 工具可以检索、并且能追溯到原始出处的知识库。

可以从他身上学什么

  • 从抱怨开始：每个日常不便都是一个工具的起点。

  • 真诚地写作：不喊口号，写真实的困惑与思考。
