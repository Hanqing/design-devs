Acbox 的 GitHub 自我介绍是这样开头的：「你好呀，我是 Acbox！你也可以叫我小箱子哦！」后面跟着一串颜文字。这份轻松感也体现在 TA 的作品里：一个给 Logo 变成小马的工具、一个在浏览器里玩植物大战僵尸的云存档项目，以及一个认真做的 Agent 平台。

成长与经历

  1. 2021

    注册 GitHub

    开始系统学习前端与全栈开发，技术栈很快扩展到 TypeScript、Go、Python、Bun、Deno、Electron。

  2. 2024

    前端底层实验

    vue-string-compiler 让 Vue 字符串在浏览器里直接编译成组件，无需构建工具；just-physics 是一次物理引擎尝试；pony-logos 把任何 Logo 变成可爱的小马。

  3. 2025

    ChatTutor 与 Guideboard

    ChatTutor 是一个可视化、可交互的 AI 家教，后转移到组织 HugeCatLab 维护，获得 1.3k 星；同一组织还有面向 AI 生成的 DSL「Sciux」。Guideboard 则是送给交通迷们的地铁站风格指示牌生成器。

  4. 2026

    Felinic 与 Memoh

    全力投入团队 Felinic（「Felinic principle changes the world」）：Memoh 是开源多 Agent 平台，每个 Agent 拥有独立电脑与长期记忆，可托管 Claude Code、Codex；同时还有 Android 自动化 Agent Autofish、Go 语言 AI SDK twilight、MCP 凭据网关 connect-it 以及 Felinic 设计系统。

域名就是 TA 的名字：ac.box，一个「箱子」。页面描述写着「Acbox — Developer · Open Source · 小箱子」，是一个用前端框架渲染的单页作品集。

TA 还用 Slidev 维护了一个公开演讲幻灯片仓库，把自己在社区里的分享都开源出来。

设计与手艺

Acbox 的作品里能看到很强的「视觉表达」偏好：ChatTutor 不只给答案，而是画出来；Guideboard 复刻了地铁导视系统的排版；Felinic 有自己的设计系统 ui，标志是一只猫 🐱。

TA 也很关注 AI 时代的开发者体验：agents-md-updater 用 Codex 或 Claude Code 自动保持 AGENTS.md / CLAUDE.md 与代码同步；codex-complete-sound 在 Codex 跑完时播放提示音。都是很小但很贴心的东西。

可以从 TA 身上学什么

  • 把爱好变成作品：交通、游戏、猫，都可以是项目灵感。
  • 小团队也要有设计系统：统一的视觉语言让产品更像一个整体。
  • 开源是最好的履历：五年 GitHub，从小实验做到数千星的平台。
  • 给 Agent 时代的小痛点做工具：文档同步、完成提示，越小越容易被用起来。
