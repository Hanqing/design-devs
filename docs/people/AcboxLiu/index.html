TA 到底在做什么？

2026 年，Acbox 的主要精力在 Felinic。这个团队做的 Memoh 想解决一个很具体的问题：AI Agent 需要一个属于自己的、一直在线的「电脑」。笔记本合上了，Agent 还得能继续跑定时任务、操作浏览器、记住上下文。

在此之外，TA 还做了大量「给开发者的小工具」：一个更顺手的 GitHub 桌面客户端、自动同步 AGENTS.md 的工作流、Codex 跑完时播放提示音的脚本。还有不少纯粹出于爱好的项目：地铁指示牌、浏览器里玩《植物大战僵尸》、把 Logo 变成小马。

本页依据 GitHub 个人主页与各项目 README、贡献者统计、ac.box 和 X 资料整理，资料截至 2026 年 10 月。

代表作品详解

Memoh ↗

2026.01Go + TypeScript开源 · 可自托管

「Give every AI agent its own cloud computer.」Memoh 给每个 Agent 一个隔离的工作区：独立的文件系统、桌面、浏览器、网络和长期记忆，7×24 小时在线。你可以用自己的 API Key 运行内置 Agent，也可以把现有的 Claude Code、Codex 托管进去。

和 Agent 对话的入口非常多：Telegram、Discord、飞书、微信、Web 界面。Agent 能跨会话、跨平台记住上下文，操作浏览器，调用 MCP 工具，跑定时任务。README 的用法建议很生活化：给自己跑一个，给每个家庭成员部署一个，或者在一台机器上跑一整队。

  • 两种部署：Memoh Cloud 直接登录使用；或者一行 curl -fsSL https://memoh.sh | sh 自托管，并为国内用户提供镜像加速选项。
  • 架构：Server 和 Channel 拆成两个服务，通过内部 RPC 通信；不用 Docker 时也能合成一个进程运行。
  • 文档：README 提供英、中、日三种语言。

可以从 TA 身上学什么

  • 把爱好变成作品：交通、游戏、猫，都可以是项目灵感。
  • 在团队项目里做主力：个人仓库星数不高没关系，贡献者统计会说明一切。
  • 小团队也要有设计系统：统一的视觉语言让产品更像一个整体。
  • 给 Agent 时代的小痛点做工具：文档同步、完成提示，越小越容易被用起来。
