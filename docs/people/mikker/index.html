Mikkel Malmberg：为挑剔的人做 Mac 应用

TA 住在丹麦，经营一家很小的产品工作室 Brainbow，专门为创作者做平台：Backers Club（丹麦品牌 10er.com 的国际版）让播客和视频创作者按期收取支持，不用经营会员等级，「为你已经在发布的内容收钱」。TA 同时在 GitHub Next 做研究。TA 做 Mac 小工具很出名：Leader Key 是一个「比你的启动器更快的启动器」（★2.3 千），现在被更完整的启动器 Tuna 取代；Moves 让你按住修饰键动动鼠标就能移动和缩放窗口；Dinky 是一个平铺窗口管理器；还有文本扩展器 Poof、极简文本编辑器 Fst。在 Ruby 社区，TA 写的 passwordless 让 Rails 应用用「魔法链接」免密码登录。TA 也做视频，参与丹麦国家广播 P1 的科技与社会节目，还做过丹麦第一档喜剧播客。

Tuna 的官网写着：「像一个句子一样构建。」它沿用了老牌启动器 Quicksilver 的一个结构：找到一个东西，选择要对它做什么，再可选地说它要去哪里。应用、文件、文字、笔记、任务、剪贴板、窗口，全都用同一种方式操作，「学会一次，每个新来源和扩展都自然就懂了」。它用原生 Swift 从头写起，不需要订阅，不需要云端，默认保护隐私。

TA 到底在做什么？

Mikkel 的作品可以分成三条线：键盘至上的 Mac 工具、Rails 生态，以及帮创作者赚钱的平台。Mac 工具都很「小而极致」：Moves「只做一件事，并且做好」；Dinky 的介绍是「不用了亲爱的，我们家里有 Hyprland」；fut 是一个带快捷键、分屏输出和 YAML 配置的小型 TUI 任务运行器。

TA 也在探索 AI 编程工作流：semantic-review 给编程 Agent 做语义级的 diff 审阅；steve 让 Agent 通过无障碍 API 操控 Mac 应用；TA 还在试验把 Pi 的持久化 Agent 和 Rails 应用结合，用 Rails 的约定和工具承载 Agent 的存储与工具。

观点

Always update. Like @aarondfrancis would say “be like water.” You gotta move with the times.

— Mikkel Malmberg，X，2026-10

TA 认为 Claude 等模型「现在品味很好」，连界面和审美也是，只要你让它们跳出训练时的模板。TA 也直言希望 Apple 为窗口管理这类功能提供真正的 API。
