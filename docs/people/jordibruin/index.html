Jordi Bruin：做自己喜欢、也能帮到人的东西

阿姆斯特丹的独立开发者，以惊人的速度把苹果的新框架变成真实产品：给 FaceTime 加字幕的 Navi、把 OpenAI Whisper 带到 Mac 上的 MacWhisper、纠正坐姿的 Posture Pal，还有一系列被开发者反复引用的 Swift Charts、TipKit、visionOS 示例。TA 的公司 Good Snooze 在 App Store 上有二十多款 App。

TA 到底在做什么？

Jordi 的产品方法是「新框架 + 真实需求」。每年 WWDC 之后，TA 都会迅速用新 API 做出东西：SharePlay 之后是 Navi，Swift Charts 之后是图表示例集，灵动岛之后是 Dynamic Islands 设计合集，TipKit 和 visionOS 之后是对应的示例项目。这些开源示例让 TA 在开发者中广为人知。

TA 的 App 有很强的无障碍倾向：帮无法说话的人打电话的 Unmute、给通话加字幕的 Navi、帮你纠正坐姿的 Posture Pal、扫描过敏原与素食成分的 Soosee、看图翻译菜单的 Cibo。帮到少数人的功能，往往对所有人都有用。

本页依据 MacWhisper 官网、GitHub 与 README、App Store、9to5Mac 与 Silicon Canals 的报道整理，资料截至 2026 年 10 月。

  5. 2023

    MacWhisper

    OpenAI 开源 Whisper 后，把它做成原生 Mac App，以及 iOS 版 Whisper Transcription；同年发布 TipKit 和 visionOS 示例、一键重置 App 权限的 FromScratch，以及基于 ChatGPT 的 GeePeeTee。

    Good Snooze 持续经营

    3 月上架 Daily NLP；9 月上架 AI 语音备忘录助手 Mono。

代表作品详解

MacWhisper ↗

2023macOS免费 + Pro

「The all-in-one Mac app to transcribe it all.」用 Whisper、Parakeet 等模型在 Mac 本地转写音频、视频、会议和系统音频，私密、快速。官网首屏是动态的大字，场景词轮流出现：讲座、视频、播客、私人文件；下面是一个模拟的「Zoom Meeting Detected · Record」通知。

  • 拖拽转写：采访、语音备忘录、讲座、字幕，拖进来就行。
  • 后台会议记录：转写 Zoom、Teams、Webex、Skype 和 Discord 通话，「No bots joining」，不需要机器人入会。
  • 实时听写：在任何 App 里用语音输入消息、笔记和文档。
  • 播客与 YouTube：说话人识别、YouTube 视频转写。

www.macwhisper.com ↗

TA 的 X 简介把主页指向 MacWhisper。官网用 Framer 搭建，功能按场景分组：会议、听写、播客、YouTube、App 音频，每个场景一句话说清楚。顶部只有 Pricing、Documentation、Try for free、Buy now。

维度长处局限 / 需要留意

可以从 TA 身上学什么

  • WWDC 是灵感来源：每个新 API 都可能是一个新产品。
  • 为无障碍而设计：帮到少数人的功能，往往对所有人都有用。
  • 示例项目建立声誉：开源示例让 TA 在开发者中广为人知。
  • 本地优先：MacWhisper 的隐私承诺本身就是卖点。
  • 保护自己的时间：明确告诉用户去哪里找支持。
