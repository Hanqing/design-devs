Jordi Bruin：做自己喜欢、也能帮到人的东西

阿姆斯特丹的独立开发者，以惊人的速度把苹果的新框架变成真实产品：给 FaceTime 加字幕的 Navi、把 Whisper 带到 Mac 上的 MacWhisper，还有一系列被开发者反复引用的 Swift Charts、TipKit、visionOS 示例。

一句话：「Building things I like, that help people.」一个擅长把苹果新 API 变成「有用的小产品」的独立开发者。

代表作：MacWhisper（本地运行 Whisper、Parakeet 等模型的 Mac 转写应用）、Navi（用 SharePlay 给 FaceTime 加实时字幕与翻译）、Cibo（菜单翻译）；开源 Swift-Charts-Examples（★2.5k）、Dynamic-Islands、TipKit-Examples、visionOS-Examples、FromScratch、cooldown。

为什么值得关注：他的很多产品都和「无障碍」有关：字幕、转写、听写，让更多人能参与对话。

Jordi 的 X 简介很直接：「Indie dev at Good Snooze. Building things I like, that help people. Barely on here, no support in DMs.」他不怎么在社交网络上表演，但每年 WWDC 后，开发者都会去他的 GitHub 看新框架该怎么用。

成长与经历

  1. 2008–2009

    早期

    2008 年注册 X、2009 年注册 GitHub，长期活跃于 Apple 开发者社区。

  2. 2021-04

    黑客松上的灵感

    参加一次黑客松，用电话 API 让无法说话的人通过文字转语音打电话。WWDC21 的 SharePlay session 让他想到：能不能给 FaceTime 加字幕？

  3. 2021-12

    Navi

    基于 SharePlay 为 FaceTime 通话提供 20 种语言的实时字幕和翻译，Mac 上字幕直接叠在视频窗口上。9to5Mac、iThinkDiff 等媒体纷纷报道。

  4. 2022

    示例项目

    Swift Charts 发布后整理出覆盖各种图表类型的示例集（★2.5k）；灵动岛推出后又复刻了一组 Dynamic Island 设计供大家参考。

  5. 2023

    MacWhisper

    OpenAI 开源 Whisper 后，他把它做成原生 Mac App：拖拽转写音视频、后台录制会议（无需机器人入会）、实时听写、播客说话人识别、YouTube 转写。同年发布 TipKit 与 visionOS 示例。

  6. 2024–2026

    Good Snooze

    以 Good Snooze 的名义持续经营 MacWhisper 等产品，加入 Parakeet 等新模型，并开源 Changelogger、StoreKit-Examples 和 Apple 框架示例索引。

他的 X 简介把主页指向 MacWhisper。官网首屏是动态的大字「transcribe it all」，场景词「lectures、videos、podcasts」轮流出现，下面是一个模拟的「Zoom Meeting Detected · Record」通知。

功能按场景分组：会议、听写、播客、YouTube、App 音频，每个场景一句话说清楚。

早期他还用 Notion 页面做产品文档与支持页，这是独立开发者节省时间的常见做法。

设计与手艺

Jordi 的产品哲学是「新框架 + 真实需求」：SharePlay 本来是一起看电影的 API，他用来做字幕；Whisper 本来是一个模型，他把它变成了会议记录工具。他总能在新技术里看到被忽视的人群。

他的示例仓库同样是一种设计：每个都配有清晰的截图和分类，让其他开发者几分钟内就能找到想要的效果。

可以从他身上学什么

  • WWDC 是灵感来源：每个新 API 都可能是一个新产品。
  • 为无障碍而设计：帮到少数人的功能，往往对所有人都有用。
  • 示例项目建立声誉：开源示例让他在开发者中广为人知。
  • 本地优先：MacWhisper 的隐私承诺本身就是卖点。
