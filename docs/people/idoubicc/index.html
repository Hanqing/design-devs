TA 到底在做什么？

idoubi 是典型的「高频发布」型独立开发者：追着 AI 的每一波新机会快速上线产品。GPTs 商店出来时做 GPTs Works，AI 搜索火了做 ThinkAny，MCP 协议发布后很快做了 MCP.so，成为最常被引用的 MCP 服务器目录之一。

2026 年 TA 的重心转向 Agent 基础设施：FastClaw 是用一个二进制文件运行自己的 AI Agent 的框架，每个 Agent 有独立的性格、记忆、技能和工具，可以挂到网页、API 或九种聊天应用上；Open Agent SDK 在进程内跑完整的 Agent 循环，不依赖命令行；Termany 是同时运行多个编程 Agent 的终端。
