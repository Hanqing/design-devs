TA 到底在做什么？

Randy 现在以 Randynamic Studio 的身份做自己的产品：读书笔记导入导出工具 Notepal、Nowdex、Browserfly、EpubKit，以及 2025 年的两个开源桌面工具：配置 Claude Code 的 ccmate 和文件格式转换器 PandocX。博客首页最上方就是这几个产品的链接，下面是「Worked at」的公司 Logo 墙。

TA 的产品与写作都强调「生产者」心态：不只消费信息，而是输出代码、产品和文字。这也是 TA 辍学、离职、独立的底层逻辑。

本页依据 Randy's Blog（About 与文章列表）、GitHub 主页与 README、X 资料整理，资料截至 2026 年 10 月。

成长与经历

  1. 2008

    开始学编程

    13 岁开始学编程。2011 年注册 GitHub 和 X。

  2. 2014

    V2EX API 与 StoreDB

    整理 V2EX 非官方 API 文档（★375），做了 localStorage 增强库 StoreDB。同年参加高考，考入广州大学华软软件学院。

  3. 2015

    WebShell、ToProgress 与退学

    WebShell 把 Web App 打包成原生 OS X 应用（★1.5 千）；ToProgress 是 2.2 KB、零依赖的顶部进度条；还有菜单栏日历 iCultus、图片轮播 PureSlider。本科一年后退学。

  4. 2015–2020

    大厂之路

    先后在奇志科技、阿里巴巴、蚂蚁金服、虎牙直播、微软中国工作。业余做了微博的 macOS HTML5 客户端 sinatine（2017）、用 Google Fonts 生成文字 Logo 的 Picas（2018）。

  5. 2021

    Cusdis

    开源轻量（约 5 KB gzip）、隐私友好的评论系统 Cusdis，作为 Disqus 的替代品；同年写下《做这个世界的生产者》，并给自己设立每月 20 美元的开源捐赠预算。

  6. 2022

    小作品

    ossart 把你的 GitHub 活动打印成艺术品；sairin 用 GitHub Issue 生成博客。

  7. 2023

    独立与 28 岁

    开始做自己的产品，Notepal 上线；写下《28 岁，我还想生猛下去》；一个浏览器插件第三天就卖出 1,000 元；在清迈冥想学习 7 天后写道：「我不再追求幸福」。

  8. 2024–2026

    不上班的日子

    写《不上班的第一年》《2024：在夜海中观望浪潮》《我们高估了智力的重要性》《现代浏览器插件开发指南》《在 Claude Code 中使用 GLM 4.6 的体验》《让 AI 戴着镣铐跳舞》《高考随想》；2025 年开源 PandocX 和 ccmate；Cusdis 宣布停止维护。
