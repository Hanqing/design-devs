Randy Lu（卢涛南）Product Engineer · 写作者 · 独立开发者

Randy：大一退学，做这个世界的生产者

1995 年生于广东中山，2008 年开始写代码，大学一年后退学。TA 在阿里巴巴、蚂蚁金服、虎牙、微软中国工作过，写出了开源评论系统 Cusdis；2023 年离职后，TA 靠自己的产品生活，并坚持写一个「读者可以自愿付费」的博客。

一句话：一个辍学的程序员、写作者，相信「用技术创造价值——做出有人觉得好用、并愿意为之付费的产品」。

代表作：Cusdis（★2.8k，轻量、隐私友好的 Disqus 替代品）、WebShell（2015，把网页打包成 Mac 应用）、ccmate（配置 Claude Code 的工具）、Picas、ossart、sairin；产品 Nowdex、Notepal、Browserfly、EpubKit。

为什么值得关注：TA 的博客诚实记录了辍学、离职、创业、冥想与年终总结，是中文独立开发者里最好读的个人写作之一。

Randy 在 About 页里写：「小时候的理想是成为一名程序员，用技术改变世界。现在的理想是用技术创造价值——做出有人觉得好用的产品或服务，并愿意为之付费。」TA 的博客全部免费，但每篇文章下面都放着付款方式，「也可以自愿对我的内容付费」。

成长与经历

  1. 2008

    开始学编程

    13 岁开始学编程。2014 年做了 V2EX 非官方 API 文档和 localStorage 增强库 StoreDB。

  2. 2014–2015

    高考、退学与 WebShell

    高考后进入广州大学华软软件学院，一年后退学。2015 年做了 WebShell：把 Web App 打包成原生 OS X 应用（★1.5k），比后来的 Pake 早了七年；还有轻量顶部进度条 ToProgress。

  3. 2015–2020

    大厂之路

    先后在奇志科技、阿里巴巴、蚂蚁金服、虎牙直播、微软中国工作。2017 年做了微博的 macOS HTML5 客户端 sinatine，2018 年做了用 Google Fonts 生成文字 Logo 的 Picas。2020 年写下《离开阿里巴巴》。

  4. 2021

    Cusdis

    开源轻量、隐私友好的评论系统 Cusdis，作为 Disqus 的替代品。同年写下《做这个世界的生产者》，并给自己设立每月 20 美元的开源捐赠预算。

  5. 2023

    清迈、浏览器插件与 28 岁

    写下《28 岁，我还想生猛下去》；做了一个第三天就卖出 1000 元的浏览器插件；在清迈冥想学习 7 天后，「我不再追求幸福」。

  6. 2024–2026

    不上班的第一年

    以 Randynamic Studio 身份做自己的产品：Notepal、Nowdex、Browserfly、EpubKit；写《不上班的第一年》《「代码艺术家」不会被 AI 取代》《我们高估了智力的重要性》，开源 ccmate。

设计与思考

如果人生可以选择，我希望我可以在一个法治国家参选议员从事政治，业余写代码和做音乐。

— Randy Lu，About 页

Randy 的产品与写作都强调「生产者」心态：不只消费信息，而是输出代码、产品和文字。这也是 TA 辍学、离职、独立的底层逻辑。

可以从 TA 身上学什么

  • 学历不是唯一路径：作品和能力同样能打开大厂的门。
  • 写作让人看见你：博客让 TA 的产品和思想被更多人找到。
  • 小插件也能赚钱：第三天卖出 1000 元，验证了需求。
  • 给开源捐赠预算：享受生态，也回馈生态。
