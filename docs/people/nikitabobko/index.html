TA 到底在做什么？

Nikita 现在最主要的作品是 AeroSpace：一个 i3 风格的 macOS 平铺窗口管理器。它不依赖 macOS 原生的 Spaces（因为限制太多），而是自己模拟虚拟工作区，所以切换工作区没有动画、速度很快，而且不需要关闭系统完整性保护（SIP）。这让它也能用在公司电脑上。

TA 把 AeroSpace 当作一个严肃的工程项目来管理：明确列出 1.0 之前的阻塞项，比如把可变的双向链表核心树重写为不可变的持久化单链树，以及为每个应用开一个线程来绕过 macOS 阻塞的辅助功能 API。

本页依据 nbobko.com、AeroSpace README 与文档、GitHub 仓库和 X 资料整理，资料截至 2026 年 10 月。

代表作品详解

AeroSpace ↗

2023SwiftPublic Beta

「AeroSpace is an i3-like tiling window manager for macOS.」核心特性：基于树的平铺布局；受 i3 启发；快速的工作区切换，没有动画；自己模拟虚拟工作区；纯文本配置（TOML，适合 dotfiles）；CLI 优先，附 man page 和 shell 补全；不需要关闭 SIP；i3 式的多显示器支持。

社区管理也有规则：项目不直接接受 Issue，要先在 GitHub Discussions 的 7 个频道之一讨论。

观点与价值观

AeroSpace 的「Project values」可以看作 Nikita 的软件观：面向高级用户；键盘优先；尽量避免破坏性变更，但不能因此让软件停滞，如果必须破坏，就要谨慎并给出有帮助的提示；除非必要，不使用 GUI。

For advanced users, it's easier to edit a configuration file in text editor rather than navigating through checkboxes in GUI.

— AeroSpace README，Project values

长处与局限

维度长处局限 / 需要留意
产品i3 体验在 Mac 上最接近的实现之一，不需关 SIP仍是 Beta，1.0 前可能有破坏性变更
工程公开路线图，问题拆解清晰受限于 macOS 辅助功能 API 的性能与稳定性
定位高级用户和开发者非常满意没有 GUI，新手门槛高
分发Homebrew 自动更新未经 Apple 公证，需自行判断信任

可以从 TA 身上学什么

  • 剃牦牛毛也有价值：为了一个工作流写一个窗口管理器，结果帮到了几万人。
  • 尊重平台限制：不关 SIP 也能做出好体验。
  • 明确目标用户：写清楚「为谁做」和「永远不做什么」。
  • 公开路线图：把 1.0 的阻塞项列出来，用户就知道在等什么。
  • 文本即配置：可版本化、可分享。
