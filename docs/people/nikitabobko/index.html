Nikita Bobko：一个业余剃牦牛毛的人做出了 AeroSpace

前 JetBrains 工程师，参与过 Kotlin 编译器与 IntelliJ 相关工作。因为在 macOS 上找不到满意的平铺窗口管理器，他自己写了一个 i3 风格的 AeroSpace，如今有两万三千多星，成为 Mac 上最受欢迎的平铺窗口管理器之一。

设计与手艺

AeroSpace 的设计取舍非常清晰：不注入系统进程、不要求关闭 SIP，用公开 API 尽可能实现平铺体验。这让它比同类工具更容易被普通用户和公司电脑接受。

配置完全基于文本文件，所有行为都可以被版本管理和分享。对键盘流用户来说，这本身就是一种「设计感」。

可以从他身上学什么

  • 剃牦牛毛也有价值：为了一个工作流写一个窗口管理器，结果帮到了几万人。
  • 尊重平台限制：不关 SIP 也能做出好体验。
  • 跨语言交流：用 Kotlin 的语言讲 Swift，降低理解门槛。
  • 文本即配置：可版本化、可分享。
