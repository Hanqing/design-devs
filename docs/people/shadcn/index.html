shadcn：不是组件库的组件库

他的 X 简介只有一句：「I own a computer.」他是 Vercel AI 团队的设计工程师，做出了 shadcn/ui：一套设计精良、无障碍、默认值考究的组件，但它不是一个装进 node_modules 的依赖，而是一份你复制进项目、可以随意修改的代码。官网说它是「最流行的『组件库』」，GitHub 上有十多万颗星，ChatGPT、Claude、Gemini 等主流大模型都会用它写界面。在此基础上，他做了代码分发系统 shadcn/registry，每周分发一千多万个组件；他还和 Jared Palmer、Shu Ding、Max Leiter 一起做出了 v0。2026 年他发布了 Agent 活动组件 Trace、30 倍速的 Tailwind 类名合并引擎 cn、审计代码库的 Agent Skill「improve」，以及一个 39 美元的 Mac 应用 Copper。

他到底在做什么？

shadcn 现在关注的是代码的分发方式。shadcn/registry 让任何人都能发布自己的组件注册表，用一条命令把代码复制进项目；他认为 AI 会「吃掉」我们的依赖，团队会越来越需要一个内部的「开放代码」注册表，而不是埋在 node_modules 里，Agent 从注册表里拉代码。最近他还做了一个生成 OIDC 认证配置组件的注册表。

他也在给 AI 应用造界面积木：Trace 用一个抽象表示推理、工具调用、队列、思维链和子 Agent；AI Elements 和聊天机器人模板配合 AI SDK 使用。他的 improve Skill 体现了另一种分工：用最强的模型理解代码库、判断什么值得做、写出规格，再交给更便宜的模型执行；「计划就是产品」。
