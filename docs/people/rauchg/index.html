2014 年，Guillermo Rauch 写了一篇《富 Web 应用的 7 条原则》：服务端渲染不是可选项、要立即响应用户输入、要对数据变化做出反应、要预加载……十年后回头看，这几乎就是 Next.js 和 Vercel 的产品路线图。他先在文章里把一件事想清楚，再用开源项目把它做出来，最后用一家公司把它推给全世界。

他到底在做什么？

Rauch 的主线始终是让 Web 更快、让开发者更省心。他在个人网站上说，做过 Socket.IO 和 Mongoose 之后，他看到了一个机会：为「开发者体验」（DX）构建工具和云基础设施。于是有了 Next.js 这个 React 框架，以及部署它的平台 Vercel。

2023 年起，Vercel 推出 v0，用自然语言生成 React 界面；2025 年他在博客里写《The AI Cloud》，把 Vercel 重新定位为承载 AI 应用和 Agent 的云。据 Vercel 官方公告，公司 2025 年 9 月完成 3 亿美元 F 轮融资，投后估值 93 亿美元。

本页依据 rauchg.com（关于页与文章列表）、GitHub 仓库与 README、Vercel 官方融资公告和 X 资料整理，资料截至 2026 年 10 月。融资与用户数字以公司公告为准。

代表作品详解

Next.js ↗

2016React 框架开源

Next.js 把 2014 年那篇文章里的原则落到了代码里：页面默认在服务端渲染，按路由拆分代码，开发者几乎不用写配置。之后它不断加入静态生成、增量再生、App Router 和 React Server Components，成为最常用的 React 框架之一。

Vercel ↗

2015 年创办前身 ZEIT

Vercel 的核心体验是「git push 就上线」：每次提交都生成一个可以分享的预览地址。Rauch 在关于页里写到，这个平台支撑着 Washington Post、Porsche、Under Armour、Nintendo 等公司的线上业务。

2025 年起它自称「AI Cloud」，在托管网站之外，提供 AI SDK、AI Gateway 和运行 Agent 的基础设施。

融资
2025 年 9 月 F 轮，估值 93 亿美元

Socket.IO ↗

2010实时通信

让浏览器和服务器之间的实时通信变得简单。Rauch 在关于页里提到，它的底层引擎曾支撑 Notion 的实时同步和 Coinbase 的第一个交易产品。

《Pure UI》提出，界面应该被看成「状态到视图的纯函数」，设计师和工程师应该一起把所有状态画出来。这篇文章影响了很多团队讨论设计与组件的方式。

可以从他身上学什么

  • 先把原则写下来：2014 年的 7 条原则，后来成了产品路线图。
  • 开源是最好的名片：Socket.IO 和 Mongoose 带来了后来的一切。
  • 用自己的产品搭自己的网站：博客就是 Next.js 的样板。
  • 小工具也值得发布：ms、wifi-password 这样的工具被用了十亿次。
  • 跟着时代重新定位：从前端云到 AI Cloud。
