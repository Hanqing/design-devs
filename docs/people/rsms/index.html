Rasmus Andersson：设计师，也写编译器

他是瑞典人，现在住在加州伯克利。他是 Spotify 最早的员工之一，在那里几乎负责了整个设计部门四年；之后去了 Facebook，主导一个操作系统项目的设计（Facebook Home 由此诞生），又当了一年软件工程师，和 Lee Byron、Nick Schrock、Dan Schafer 一起创造了 GraphQL；再后来是 Dropbox，以及「整个公司能坐进一张沙发」时的 Figma。他设计的 Inter 字体被 GitHub、Mozilla、Figma、Pixar 等数百万人使用。业余时间他写虚拟机、编程语言和编译器。现在他在做自己的公司 Playbit。

他到底在做什么？

Rasmus 横跨视觉设计和底层系统两端。Inter 是一款为屏幕设计的字体：高 x 字高、可变字重、丰富的 OpenType 特性，比如根据周围字形自动调整标点的上下文替代，以及带斜线的零。另一边，他写了 RSM 虚拟计算机、类 C 的系统语言 Compis、可移植的 LLVM 工具箱 llvmbox，还做过 WebAssembly 入门教程。

他的公司 Playbit 目前官网只写着「something new coming soon」。从他最近的帖子看，他在用一台二手 Mac mini 搭 CI 和性能追踪，也会给 ChatGPT 做一个 ESP32 实体小设备当周末项目。

Compis / RSM ↗

C系统编程

Compis 是「C 精神」的现代系统语言，可以和 C 混写，把 clang、lld 等 LLVM 工具打包进一个可执行文件；名字来自瑞典语 kompis（伙伴）。RSM 是一台带简单 RISC 指令集和虚拟内存的虚拟计算机。
