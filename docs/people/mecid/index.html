Majid Jabrayilov：每周一篇，写了七年 SwiftUI

来自阿塞拜疆巴库的 Swift 开发者。2019 年 SwiftUI 发布以来，他几乎每周都在博客上写一篇 SwiftUI / Swift 实践文章，同时编辑《SwiftUI Weekly》，并独立开发健康类 App CardioBot、NapBot 和 PlatePal。

一句话：「Swift developer, SwiftUI addicted.」全世界 SwiftUI 学习者最常读的博客之一的作者。

代表作：博客 Swift with Majid、Newsletter《SwiftUI Weekly》、App CardioBot（心率与健康洞察）、NapBot（睡眠）、PlatePal；开源 SwiftUICharts（★1.6k，支持无障碍的图表库）、swift-unidirectional-flow。

为什么值得关注：他总是在苹果发布新 API 的第一时间写出清晰、可运行的示例，并且很多都直接来自自己 App 的真实需求。

Majid 把 X 和 GitHub 的位置都写成了「Dynamic Island」（灵动岛）。这个玩笑很贴切：他的博客总是第一时间出现在苹果新功能的旁边。2026 年 10 月，他刚写完《为 iPhone Duo 适配你的 App》。

成长与经历

  1. 2017

    Android 客户端 Robird

    早年也写过 Android：一款外观精美的 Twitter 客户端 Robird。

  2. 2019

    SwiftUI 元年

    SwiftUI 发布当年开始写博客（最初托管在 mecid.github.io），并发布 swiftui-recipes-app（单一状态容器架构）和 UIKitSwiftDSL。很快成为 SwiftUI 社区最重要的作者之一。

  3. 2020

    SwiftUICharts

    一个支持无障碍的 SwiftUI 折线图与柱状图库，体现了他对 Accessibility 的重视。同年还写了 tvOS 示例 App。

  4. 2022

    单向数据流

    开源 swift-unidirectional-flow：用最新的 Swift 泛型与并发特性实现单向数据流。

  5. 独立开发

    CardioBot、NapBot、PlatePal

    成立以自己名字命名的公司，专注「注重细节、可靠、长期有价值的高质量移动 App」。CardioBot 是他最知名的作品，覆盖 iPhone 与 Apple Watch。

  6. 2026

    Foundation Models 与 iPhone Duo

    持续跟进苹果的新技术：Foundation Models 多模态输入、迭代式数据加载、SwiftUI API 回移植，以及第一款折叠屏 iPhone Duo 的适配。

个人网站

swiftwithmajid.com ↗

首页是最新文章列表，每篇一段两三句的引子：先抛出一个真实问题（「一个页面需要 40–50 个异步请求怎么办？」），再说「这周我们来聊聊……」。

导航只有 Categories、Archive、Feed、SwiftUI Weekly、Sponsorship。

这种固定的格式和节奏，让读者形成了「每周二读 Majid」的习惯。持续，是他最大的设计。

设计与手艺

Majid 的文章几乎都来自他自己 App 的真实问题：CardioBot 需要几十个 HealthKit 查询，于是有了迭代式数据加载；需要图表，于是有了 SwiftUICharts。写作和产品互相喂养。

I focus on building high-quality mobile apps with attention to detail, reliability, and long-term value.

— Majid Jabrayilov，About 页

可以从他身上学什么

  • 固定节奏：每周一篇，七年不断，就是一份事业。
  • 从产品中提炼文章：真实问题写出来的内容最有用。
  • 重视无障碍：图表库也要支持 VoiceOver。
  • 第一时间跟进平台：新 API 出来，就是新文章和新功能的机会。
