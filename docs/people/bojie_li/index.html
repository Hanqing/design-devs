李博杰：从数据中心网络到会学习的 Agent

中科大少年班、中科大与微软亚洲研究院联合培养博士、华为首批「天才少年」，后来创业做 AI Agent。他写的开源书《深入理解 AI Agent》在 GitHub 上收获了 5.5 万星；2026 年以独立研究者身份又写了一本《深入理解 AI Infra》，还在一年里提交了四万多次代码。

一句话：一个从网卡、总线一路做到 Agent 的系统研究者。底层理解让他总能量化地讨论问题；他的「反共识」是：当所有人都去卷 Coding Agent，他选择做人与 AI 的交互，尤其是语音。

代表作：《深入理解 AI Agent》（★55,263）、《深入理解 AI Infra》（★6,824）、USTC 评课社区、OpenURMA（统一总线协议的净室实现），以及 2026 年的一组网络与 Agent 工具：queqiao、tunless、agentreach、GreenBubbles、DoNotType。

关键数字：GitHub 近一年贡献 44,769 次；X 关注者约 1.5 万；在 SIGCOMM、SOSP、NSDI 等顶会发表论文。

看点：他的每篇近期论文都配一个可交互的网站；书稿、PDF、按章配套代码全部开源，并被社区翻译成十几种语言。

他到底在做什么？

李博杰的研究兴趣可以概括为「Agent 的两朵乌云」，这也是他 2026 年 6 月在 Flink Forward Asia 主题演讲的标题。借用开尔文勋爵的比喻，他认为 Agent 面前有两个大难题：第一，如何流式地、实时地与环境交互，比如边听边想边说的语音 Agent；第二，如何像人一样从成功和失败的经验中自主学习。

与此同时，他也是一位极其高产的工程师和写作者：两本开源书、一批网络与 Agent 工具、一个运营了十多年的大学评课社区，以及大量演讲整理和长文。

本页依据 01.me 博客与 Research 页、GitHub、各书稿与项目 README、IT之家与澎湃新闻的报道整理，资料截至 2026 年 10 月。

DoNotType ↗

2026SwiftmacOS · Windows · Android · iOS

「Voice input that transcribes what you said, grounded in what's on your screen.」结合屏幕上下文的语音输入：它知道你在看什么、在哪个应用里，所以能把专有名词、代码标识符转写对。这正是他「语音正从次要模态走向主要模态」观点的落地：他认为语音输入比打字快 3–5 倍，认知负荷也更低。

网络老兵的工具箱：queqiao · tunless · agentreach ↗

2026.08Go / Swift网络
  • queqiao（鹊桥，★417）：自托管的广域网优化传输，专为两端都由你控制的长距离困难链路设计。基于带认证的 QUIC，可回退到 TLS/TCP，入口是 SOCKS5；关键思路是「把丢包当作擦除，而不是拥塞」。
  • tunless（★116）：不用 TUN 设备的透明代理，在 socket 层捕获流量交给你现有的 SOCKS5 代理：没有假 IP、不劫持路由、不需要第二套 TCP 栈。
  • agentreach（★182）：让你的编程 Agent 连到任何能 SSH 的机器上工作，而服务器端「永远拿不到你的 Agent」。
  • GreenBubbles（★395，Rust）：让 AI Agent 实时读取你在 Mac 上的微信聊天记录，只在本地存储。

几个核心观点

  • 「大世界假设」：主流 Scaling Law 暗含「小世界假设」，以为有用的知识就那么多，学一次就够；但真实垂直场景里的知识根本不在训练语料里。最强的能力是学习与适应，这也解释了为什么很多 Coding Agent 跑分很高，到真实场景却不好用。
  • 语音是被低估的主模态：如果语音交互足够自然，人就不必困在格子间里用不健康的姿势长期打字，「完全可以坐在海边、草地或家里独立办公」。
  • 「有趣」和「有用」是正交的：有趣门槛低、易传播但上限低；有用更难但上限高。两者会像钟摆一样来回摆动：现在先做有用的，等 AGI 把人从生产中解放出来，有趣会重新回归。

我特别讨厌同质化竞争。

维度长处局限 / 需要留意
研究顶会背景 + 工业界大规模系统经验，能把问题量化独立研究者身份下的论文多为预印本，同行评议情况需看具体论文

方向坚持做语音与人机交互，避开同质化竞争语音 Agent 的商业化路径仍在探索中

可以从他身上学什么

  • 系统功底是长期资产：从网卡、总线到 Agent，底层理解让他总能量化地讨论问题。
  • 把书和课都开源：写作是对知识最彻底的整理，也是最好的个人名片。
  • 论文配交互网站：让研究被更多人看懂。
  • 把旧作品还给社区：用净室实现重写自己的博士工作和工业项目，让它们可复现。
  • 避开同质化：当所有人都涌向同一方向时，认真想想反面。
