成长与经历

  1. 2015–2016

    从练手项目开始

    2015 年注册 GitHub，2016 年做了「知乎日报」Swift 练手项目，开始写博客（Hexo + NexT）。

  2. 2017–2018

    深挖 UIKit 细节

    CustomJSONDecoder、SwiftyOC；文章《iOS 原生 App 是怎么 deselectRow 的？》研究系统 App 的取消选中动画，并整理成开源的最佳实践；还写了 GitLab 动态 Environment URL 的实践。

  3. 2019

    Swift 语言演进

    介绍 Opaque Result Types、Property Delegates（后来的 Property Wrappers），写下《Swift 的字符串为什么这么难用？》，以及 WWDC 2019 SwiftUI 集成、CocoaPods 加速索引等文章。

  4. 2020–2022

    翻译 Swift 并发提案

    系统翻译 Swift 5.5 并发相关的全部核心提案：Atomic、Async/await、Concurrency 与 ObjC 交互、AsyncSequence、Continuation、Actors、Sendable，成为中文开发者学习 Swift 并发的重要资料。

  5. 2024–2026

    端侧 AI 与生活折腾

    尝试用 MLX Swift 做端侧机器学习（mlx-swift-mvp、MLX-Sort），写 GLSL 滤镜；在少数派分享数字生活与效率方法。

手艺与方法

Kem 的「设计感」体现在对交互细节的执着上：一个 cell 取消选中的时机和动画，TA 会去研究系统 App 到底怎么做。好的产品，就是由这些不起眼的细节组成的。

翻译提案是一件辛苦且不显眼的事，却让更多中文开发者能直接读懂语言设计者的思考。

可以从 TA 身上学什么

  • 读一手资料：Swift Evolution 提案是理解语言的最好入口。
  • 翻译也是贡献：降低整个社区的学习门槛。
  • 研究系统 App 的细节：它们是最好的交互教材。
  • 让生活可被折腾：工程师思维也可以用来改善日常。
