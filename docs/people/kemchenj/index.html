Swift 的 String 为什么不能用 str[4] 取字符？很多人只是吐槽，Kem 却写了一篇长文解释：String 的每个字符由 1 到 4 个 UTF-8 编码单位组成，元素不等长；如果用 Int 做索引，一次简单的遍历就会从 O(n) 变成 O(n²)。那些「难用」，其实是 Swift 有意为之的设计。

TA 到底在做什么？

Kem 的写作分两类：一类是翻译一手资料，把 Swift 语言设计者的提案原原本本带给中文读者；另一类是拆解细节：系统 App 的 cell 是在什么时机、用什么动画取消选中的？验证码输入框怎么实现？怎么让一个函数只在 Debug 下执行？

近几年 TA 的 GitHub 出现了新方向：用 MLX Swift 做端侧机器学习的最小示例（mlx-swift-mvp、MLX-Sort），以及用 GLSL 写滤镜。

本页依据博客 Hackable life?（文章与归档）、GitHub 仓库与 README 和 X 资料整理，资料截至 2026 年 10 月。

Swift 的字符串为什么这么难用？ ↗

2019原创长文

借 SE-0265 提案，解释 Collection.Index 的设计：String 底层是 UTF-8 编码单位的集合，对外是字符的集合，元素不等长，所以用自定义 Index 记录偏移量，让遍历保持 O(n)。文章把「API 繁琐」还原成一个性能与正确性的取舍。

可以从 TA 身上学什么

  • 读一手资料：Swift Evolution 提案是理解语言的最好入口。
