Jay：开源编程 Agent 背后的公司

TA 住在多伦多，是 Anomaly（Anomaly Innovations）的 CEO。这家公司先做了 SST：一个「在你自己的基础设施上构建全栈应用」的框架（★2.6 万），以及配套的免费教程 SST Guide（原 Serverless Stack）。2025 年，他们推出了开源编程 Agent OpenCode。据维基百科，OpenCode 与模型无关，可以在终端、桌面应用和 IDE 里使用，支持本地模型、LSP 诊断和 MCP；Cloudflare 在开发实验项目 Vinext 时就用了它。OpenCode 官网显示，它在 GitHub 上已有 22 万多颗星、950 位贡献者，每月有 1,600 万开发者使用。2026 年 10 月，Jay 宣布 OpenCode 的日活用户达到 200 万。

TA 到底在做什么？

Jay 带领 Anomaly 在做开源 AI 编程 Agent。OpenCode 的当前版本主要用 TypeScript 写、跑在 Bun 上；它与 2025 年 9 月归档的一个同名 Go 项目不是同一个。维基百科还记录，2026 年 2 月 Anthropic 澄清消费级 Claude 订阅不能通过未授权的第三方工具使用，OpenCode 随后移除了用 Claude Pro / Max 订阅登录的支持。

TA 的 X 时间线大多是短句和梗图：「这是软件的黄金时代」，「我们有算力短缺，可为什么你知道的每家 SaaS 公司都想做推理？」
