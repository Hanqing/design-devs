个人网站

kelvinmade.com ↗

网站像一本杂志：编号「K / M — 001」、章节「01 / SELECTED WORK」「02 / THE PLAYGROUND」「03 / THE MAKER」，中英文混排，大字标题与小号等宽注释交替出现。

每个作品都配有一个可交互的小预览，比如腕记的「记录中 12:07」和小红书发布预览卡片。

「不必每个想法都成为产品。但每个想法，都可以有一个开始。」这句话放在实验室板块的空位里，是整个网站最温柔的设计。

设计与方法

Kelvin 的方法很直接：从一个具体的问题开始，做出来，听反馈，再慢慢打磨。他的工具都在解决内容创作者的真实摩擦：跨平台搬运、封面制作、语音记录。

可以从他身上学什么

  • 极短周期验证：一天做完，三天看结果。
  • 做创作者的工具：你自己就是用户。
  • 本地优先：隐私和速度都是卖点。
  • 网站要有编辑感：编号、章节、留白，让小作品也显得郑重。
