Adam Wathan：工具类优先，改变了一代人写 CSS 的方式

他原本是一名加拿大的 Laravel 开发者，写过 Laravel 表单和 OAuth 小库，做播客 Full Stack Radio，在 Laracon 上讲「Cruddy by Design」。为了一个副业项目，他和 Jonathan Reinink 写出了一套「工具类优先」的 CSS 框架，2017 年开源，就是 Tailwind CSS。之后他与设计师 Steve Schoger 合写了面向开发者的设计书《Refactoring UI》，创办 Tailwind Labs，推出 Headless UI、Heroicons 和付费组件库。2026 年，Tailwind 的周安装量超过 1 亿；同年 9 月，他宣布 Tailwind Labs 加入 Shopify，Tailwind CSS 继续以 MIT 协议开源。

2012加入 X

Tailwind 刚出来时，很多人觉得它「丑」：HTML 里塞满了 `flex`、`pt-4`、`text-gray-700` 这样的类名，看起来违背了「样式与结构分离」的老规矩。Adam 的回答是一篇长文和一个框架：别再为每个组件想语义化的类名，直接在标记里组合小而单一的工具类，设计约束由配置文件来保证。几年后，它成了最流行的 CSS 框架之一。他后来在 X 上说，有些工具「你得用了才懂为什么更好，就像当年的 Tailwind」。

他到底在做什么？

Adam 的核心作品是 Tailwind CSS：一个工具类优先的 CSS 框架，让人不离开 HTML 就能快速搭出定制化界面。围绕它，Tailwind Labs 做了无样式的可访问组件 Headless UI、图标库 Heroicons、付费的组件与模板库，以及免费的视频课程。

2026 年对他是剧烈变化的一年：有报道称，AI 工具让文档流量和收入下滑，团队年初裁减了工程人员；9 月，他宣布 Tailwind Labs 加入 Shopify，为框架找到一个「长期、稳定的家」，Tailwind CSS 保持 MIT 开源，团队继续主导开发。现在他在 X 上大量讨论 AI 编程工作流，比如怎样在代码里微调界面细节而不被 Agent 的反馈循环拖慢。

本页依据 Tailwind CSS 官方博客《Tailwind Labs is joining Shopify》、GitHub 仓库与 README、CMSWire 等报道和 X 资料整理，资料截至 2026 年 10 月。裁员与收入相关信息来自二手报道。

代表作品详解

Tailwind CSS ↗

2017–MIT★9.8 万

「A utility-first CSS framework for rapid UI development.」用小而单一的类组合界面，配置文件定义间距、颜色、字号等设计约束，构建时只生成用到的样式。它也非常适合 AI 生成代码：样式和结构在同一处，模型容易读写。

GitHub
tailwindlabs/tailwindcss ★98,019

《Refactoring UI》 ↗

2018图书与 Steve Schoger 合著

写给开发者的界面设计书：不讲抽象的设计理论，而是给出可以立刻应用的具体技巧，比如用灰度而不是字号建立层级、少用边框、用阴影表达深度。

可以从他身上学什么

  • 挑战旧规矩：「关注点分离」不一定是唯一答案。
  • 用约束代替自由：设计系统写进配置文件。
  • 开发者也能学设计：《Refactoring UI》给出具体方法。
  • 开源要有可持续的模式：商业产品养活开源。
  • 时代变了就调整：为项目找到长期的家。
