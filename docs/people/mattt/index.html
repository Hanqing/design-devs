Mattt：他的代码跑在大多数 Apple 设备上

他住在俄勒冈州波特兰。在 iOS 开发的早年，他写的网络库 AFNetworking 几乎是每个应用的标配，后来的 Swift 版 Alamofire 有 4.2 万颗星；他创办的 NSHipster 专门讲 Objective-C、Swift 和 Cocoa「被忽视的角落」，影响了一代 Apple 开发者。他在 GitHub 个人简介里写：「我的代码运行在全球大多数 Apple 设备上。」他在 Apple、GitHub、Heroku 和 Replicate 工作过。这两年他把精力转向 AI 与 Apple 平台的交汇：iMCP 让 Claude、ChatGPT 等通过 MCP 访问 Mac 上的信息、通讯录、提醒事项、日历、HomeKit；AnyLanguageModel 是 Apple Foundation Models 框架的「即插即用替代品」，可以接 OpenAI、Anthropic、Gemini、本地模型和 Hugging Face。他还在推动一项把波特兰市和马尔特诺马县政府合并的公民倡议。

他到底在做什么？

Mattt 现在在做让 AI 接入 Apple 设备上的个人数据。iMCP 是一个免费开源的 macOS 应用，向任何支持 MCP 的客户端提供信息、通讯录、提醒事项、日历、电话记录、语音信箱和 HomeKit 等服务；1.7 版本加入了「家」服务，可以编辑提醒和日历事件。emcee 则能为任何带 OpenAPI 描述的网络服务生成一个 MCP 服务器。

在模型层面，他和 Hugging Face 的工程师一起维护 swift-transformers，以及 AnyLanguageModel：开发者可以沿用 Apple Foundation Models 的 API，自由选择模型和提供方，包括 OS 27 的私有云计算；它甚至能在 Linux 上运行。为了更快从 Hub 下载模型，他们还写了 swift-huggingface 和 swift-xet。
