术士木星：AI 接管低维，人类专注高维

一位在广州做独立游戏的设计师兼开发者，GitHub 自我介绍是「AI Native 的独立游戏开发者」，主力是 C# / Unity，也用 Godot。TA 是 Game Jam 常客：Global Game Jam 2024 的《咸鱼不想死》获得广州站投票第四，2025 年做了 2–4 人手柄联机的《石油之王》，2026 年在 CiGA Game Jam 做了锚定陨石甩飞船的《你抛不过我你信吗？》。同时，TA 把游戏开发经验做成给 AI Agent 用的 Skill：Godot 知识库、游戏设计方法论，以及一套用 AI 做游戏配乐的工作流。

TA 到底在做什么？

术士木星同时做两件事：一是高频参加 Game Jam、快速做原型，把一个荒诞点子在 48 小时里变成能玩的游戏；二是把游戏开发知识喂给 AI，做成 Claude Code 和 Codex 可以直接安装的 Skill 和插件。

TA 的 GitHub 里也有大量「为活动服务」的小工程：CiGA Game Jam 2026 的组队大厅（Cloudflare Pages + D1 + R2）、比赛排行榜、早期验证原型；以及一个离职前帮你清理个人敏感数据的「跑路.skill」。

2026网页游戏

「弹珠清污，收工升级，再下一口井。」用弹珠清理下水道，赚钱升级，然后挑战下一口井。名字里的「AAA」是独立开发者的自嘲。

你抛不过我你信吗？ ↗

2026CiGA Game Jam 广州站

一款街机游戏：把飞船锚定在陨石上，绕着它旋转充能，然后甩出去加速。核心就是一个手感很好的动作。

Pixel Cosmos Studio ↗

2026Godot 4 工具

生成像素 / 体素 3D 星球与像素星空，导出给游戏用。延续 PixelPlanets / PixelSpace 的色板和图层思路并扩展到三维：8 类星球预设、云层与星环、动态循环动画导出为 PNG 帧序列，还能「复制动态实现说明」直接交给工程接入。界面支持中英切换。

godot-game-dev-skill ↗

2026Claude Code 插件

以 Godot 官方文档为首要依据，支持在线查 docs.godotengine.org 或离线查本地文档，覆盖 GDScript、C#、着色器、UI、物理、网络、导出和性能，并加了一层轻量的 Game Jam 原型护栏。

写作与观点

  • 2026
    用 AI 零基础做出像《小丑牌》一样的游戏配乐
  • 2026
    AI 原生游戏不是让 AI 接管世界

我一直很羡慕那些一听就能认出来的游戏音乐。画面都不用出现，前几个音一响，玩过的人就知道是哪款游戏。

— 术士木星，《用 AI 零基础做出像〈小丑牌〉一样的游戏配乐》

TA 的思路是先做出一个可以反复变奏的音乐动机，再让 AI 按场景编排，让整款游戏的音乐「听得出是同一款」。

可以从 TA 身上学什么

  • 多参加 Game Jam：限时逼出点子和取舍。
  • 让 AI 做低维的事：查文档、搭工具、出素材。
  • 把经验做成 Skill：下次的自己和别人都能用。
  • 为社区造工具：组队大厅、排行榜都是贡献。
  • 游戏要有能被记住的声音：先做一个音乐动机。
