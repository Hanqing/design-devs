Simon B. Støvring：给 iPhone 写开发者工具的人

他是丹麦的 iOS 开发者，GitHub 资料显示他在 Shape（shapehq）工作，业余时间做了一整排给「爱折腾的人」用的应用。Scriptable 让你在 iPhone 上用 JavaScript 写自动化脚本和主屏小组件；Data Jar 给快捷指令提供一个键值存储；Runestone 是一款基于 Tree-sitter 的 iPad 和 iPhone 纯文本编辑器，它的核心开源后有三千多颗星；Jayson 是手机上的 JSON 查看器。2026 年他又发布了 brrr，一个用一次 HTTP 请求就能给自己设备发推送的工具，适合让 AI Agent、脚本和 CI 提醒你；以及一个构思了十多年的小游戏 Wavy Road。

2026 年 4 月，Simon 写了一篇《Put Your Coding Agents in Your Pocket》：Claude 有时在他煮咖啡时需要一个回复，Codex 有时在他离开电脑时完成了任务，「而我最好的点子很少在体面的时刻出现」。他搭了一套随时从手机访问 Mac 上 Agent 的方案，甚至给其中一个版本起名叫「Codex from the shitter」。几周后他发布了 brrr：只要一次 HTTP 调用就能让手机震动，不用注册，不存消息，没有仪表盘。

他到底在做什么？

Simon 专注于把电脑上才有的开发者能力搬到 iPhone 和 iPad 上。Scriptable 把 JavaScript 和 iOS 原生接口（文件、日历、提醒事项）连起来，还能用脚本写主屏小组件。Runestone 的编辑器核心用 Tree-sitter 解析语法树，支持行号、不可见字符、页面参考线等功能，任何开发者都可以把它嵌进自己的应用。

他也做好玩的东西：2017 年用 Apple 私有框架 AvatarKit 做了一个独立的 Animoji 应用；Festivitas 给 Mac 的 Dock 和菜单栏挂上会闪的圣诞彩灯；Wavy Road 是一个你来控制道路、而不是控制车的街机游戏。

Scriptable ↗

「用 JavaScript 自动化 iOS。」脚本可以读写文件、日历、提醒事项，可以被快捷指令调用，也可以渲染成主屏小组件。

Runestone ↗

2022–Swift★3.2 千

「A performant plain text editor for iOS.」应用版像是「更强大的 TextEdit」；框架版让任何 iOS 应用都能嵌入代码编辑器，支持语法高亮、主题、搜索替换等功能。

brrr ↗

2026iPhone · iPad · Mac免费

「Just push notifications for your devices. That’s it.」装好应用，拿到一个 webhook，任何能发 HTTP 请求的东西（Agent、脚本、自动化、CI、智能家居）都能给你发推送。消息不存储在后端，历史只保存在设备上。

可以从他身上学什么

  • 把能力搬到新平台：手机上也需要脚本和编辑器。
  • 核心开源，应用收费：Runestone 两者兼得。
  • 极简是功能：brrr 没有账号、没有仪表盘。
  • 老点子也值得做：Wavy Road 等了十年。
