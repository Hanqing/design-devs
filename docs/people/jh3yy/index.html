Jhey Tompkins：「等等，这是怎么做到的？」

他的 X 简介写着「designing interfaces. engineering experiences. many can build it. few can explain it.」他是网页创意交互圈最高产的人之一：在 X 上发了将近五万条帖子，几乎每天一个用 CSS、JavaScript、WebGL 或 Web Audio 做的小实验。他做过多年 Web 外包，客户包括 Monzo、Eurostar、Nike 和 Uber；后来在 Google 做 Chrome 的开发者关系工程师，再到 Vercel 做设计工程，现在在 Shopify 的品牌设计工作室。他把这些实验拆解成教程，放在「Craft of UI」上。

他到底在做什么？

Jhey 的工作方式是先做出来，再讲清楚。他几乎每天把一个界面想法做成可以玩的原型：全息贴纸、超空间按钮、渐进模糊卡片、分格翻牌显示屏、数字拨盘，然后录屏、发帖，常常附上一段核心 CSS。比如用 mix-blend-mode: multiply 做镂空文字，这条帖子收获了两千多个赞。

Craft of UI 是这些实验的系统化版本：不是一门固定的课，而是不断增长的作品库。每个条目从一个真实界面出发，拆解哪些重要、哪些不重要、约束从哪里来，以及结构、行为和动效如何共同决定结果。

观点

taste without creative risk eventually becomes conformity

— Jhey Tompkins，X，2026-10

他也写到工具的两面：工具要么降低你交付的门槛，要么抬高你能做出的上限。他说自己从来没有能同时探索这么多想法，又这么在意细节。他的建议简单直接：「post like nobody’s watchin’」。

可以从他身上学什么

  • 每天做一个小东西：积累比灵感更可靠。
  • 能做出来，还要能讲清楚：拆解图和代码片段很重要。
  • 先用平台：HTML 和 CSS 能做的，不急着上库。
  • 敢于有个性：别让作品变成千篇一律的灰。
  • 公开发：就当没人在看。
