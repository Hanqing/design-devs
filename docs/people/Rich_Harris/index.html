Rich Harris：为其余的我们做 Web 开发

他学的是新闻，先后在《卫报》和《纽约时报》的互动图表部门工作，为新闻报道做可视化和交互作品。正是在这样的工作里，他做出了一系列改变前端生态的工具：JavaScript 模块打包器 Rollup（★2.6 万），以及把声明式组件编译成精准更新 DOM 的高效 JavaScript 的框架 Svelte（★8.8 万）。Svelte 这个名字是他和《卫报》同事一起选的。2021 年 11 月，他离开《纽约时报》加入 Vercel，全职做 Svelte。2024 年 10 月，Svelte 5 发布。他还写了 magic-string、degit、ramjet 等被广泛依赖的小工具。他的 X 简介写着「Cheese fan」，现在主要在 Bluesky 上发帖。

他到底在做什么？

Rich 的核心想法是让框架在编译时消失。Svelte 不是在浏览器里运行一个庞大的运行时，而是在构建时把组件编译成直接操作 DOM 的代码。Svelte 5 引入了「runes」响应式系统，SvelteKit 则是基于它的全栈应用框架。

他的很多小工具都来自编译器工作的需要：magic-string 让你在修改源码字符串的同时生成 source map；estree-walker 遍历符合 ESTree 规范的语法树；sorcery 把一串 source map 追溯回最初的源文件；code-red 是写「X 编译到 JavaScript」编译器的实验工具包。
