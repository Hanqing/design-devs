个人网站与线上形象

opencli.info ↗

TA 的主要「门面」是产品官网。OpenCLI 的首页只说一件事：通过你已登录的 Chrome 去导航、点击、填表、提取，无需站点适配器；重复的流程再沉淀为可复用命令。

Raft 的首页用一段工程频道的模拟对话展示「人与 Agent 同在一个频道」：CI 状态、代码评审、性能数据都由 Agent 汇报。

X 上 TA 以「卡比卡比」之名分享 AI 编程心得与工具发布，简介里同时挂着 Apache PMC 身份和三个在做的产品。

设计与手艺

数据库工程师看世界的方式是「接口 + 执行计划」。OpenCLI 系列正是这种思维：把每一个网站都当成一个可以被查询的数据源，给 Agent 一个确定、可组合、可复用的调用方式。

从 CS-Awesome-Courses 到 Apache PMC，再到一年内十几个 CLI，TA 的路径说明：扎实的系统能力在 AI 时代不但没有贬值，反而让人能更快地做出可靠的工具。

可以从 TA 身上学什么

  • 长期投入一个开源社区：从贡献者到 Committer 再到 PMC，需要的是持续数年的深度工作。
  • CLI 是 Agent 的最佳接口：命令行可组合、可脚本化、可审计。
  • 复用用户的已有状态：登录态、本地数据，比重新集成 API 快得多。
  • 快速成系列：一个模式跑通后，迅速复制到多个平台。
