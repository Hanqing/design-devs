Andrej Karpathy：从零开始，把神经网络讲给所有人

他在多伦多大学上过 Geoff Hinton 的课，在斯坦福跟着李飞飞读博，设计并主讲了斯坦福第一门深度学习课程 CS231n；之后成为 OpenAI 创始成员，2017 到 2022 年任特斯拉 AI 总监，带领 Autopilot 的视觉团队，2023 年短暂回到 OpenAI。离开大公司后，他把主要精力放在教育上：YouTube 上的《Neural Networks: Zero to Hero》、一行行手写的 micrograd、nanoGPT、llm.c，以及 100 美元就能训练出一个聊天模型的 nanochat。他还发明了「vibe coding」这个词；2026 年 3 月，他让 AI Agent 自己在单卡上做 nanochat 训练研究，这个 autoresearch 仓库很快拿到了近 10 万颗星。

他到底在做什么？

Karpathy 现在的身份更接近全职的 AI 教育者。他的 YouTube 视频分两条线：技术线是《Zero to Hero》，从反向传播一路手写到 GPT；大众线是《Deep Dive into LLMs like ChatGPT》和《How I use LLMs》。2024 年他创办 Eureka Labs，想做一所「AI 原生」的学校，第一门课是 LLM101n。

他的开源项目都遵循同一个原则：最小、可读、能跑。micrograd 用一百来行代码实现自动求导；llama2.c 用约 700 行 C 跑推理；nanochat 覆盖完整训练流程。2026 年的 autoresearch 更进一步：让 AI Agent 自动在单卡上做 nanochat 的训练研究。README 开头是一段科幻式的玩笑：研究曾经由「肉做的计算机」在吃饭睡觉之间完成。

本页依据 karpathy.ai、Bear Blog（2025 年 3 月起）、GitHub 仓库与 README 和 X 资料整理，资料截至 2026 年 10 月。

《Power to the people》的观点很有意思：以往的新技术总是先被政府和大公司使用，再慢慢扩散到个人；大语言模型反过来了，普通人最先、也最充分地从中受益。
