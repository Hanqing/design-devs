Tom Krcha：一块会和 Agent 一起设计的画布

TA 是 pen.dev 的创始人。pen.dev 原名 pencil.dev，自称「一块为大胆的想法而生的 Agent 画布」：你可以在画布上直接让 Agent 做设计，再用手精修每个细节，最后导出回代码。它可以接 Claude、OpenAI、Grok、Qwen、Gemini、Kimi、DeepSeek、MiniMax 等模型，支持用 ChatGPT 或 Claude 订阅登录、填 API 密钥，或者通过 MCP、WebMCP、命令行连接；成千上万个图层靠自研的 WebGL 管线保持流畅。TA 入选过 a16z 的 speedrun 创业加速计划。很早以前，TA 就在做「设计和代码之间的桥」：Drawscript 能把 Illustrator 里的形状变成 Objective-C、C++、JavaScript、Processing、ActionScript 等语言的绘图代码；TA 还写过不少 Photoshop 脚本和 Adobe Generator 教程，以及基于 P2P 的 Flash 实时多人游戏库。

TA 到底在做什么？

pen.dev 想解决的是设计和代码之间来回搬运的问题。你可以从任何应用导入界面到画布上，也可以导入 HTML 或 Figma 文件；画布上有组件，文件是开放格式；内置浏览器让你在应用里打开任意网页。设计时，你可以手动调整，也可以召唤 Agent；做完后导出回代码。最近的更新包括标题栏里的多文件标签页和完整的 MCP 服务器支持。

TA 自己的开发方式也很「Agent 化」：TA 说用 GitButler 同时在同一个运行中的构建里处理多个分支、配多个 Agent，开发速度提高了十倍。
