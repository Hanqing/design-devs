Matt D. Smith：浮动标签的发明者

他是界面设计教育平台 Shift Nudge 的创始人，在设计领域做了二十多年，带过创业公司和全球品牌的设计，经营设计工作室二十多年。他最广为人知的发明是「Float Label」：输入框的占位文字在你开始输入时浮到框的上方变成标签，这个模式后来被 Apple、Google 和无数公司采用。他还设计了 Figma 插件 Contrast 和 Flowkit。他的课程被 OpenAI、Anthropic、Pentagram、Figma 等公司的设计师使用；现在他把 Shift Nudge 打造成「面向界面设计师和 AI 构建者的现代设计学校」，新增了 Claude Code 课程，每周发一封设计邮件。他毕业于佐治亚大学平面设计专业，住在佐治亚州雅典市。

他到底在做什么？

MDS 正在把界面设计教育搬进 AI 时代。Shift Nudge 的课程从经典的界面设计、Figma 入门、作品集，扩展到 Claude Code：教设计师在代码里直接做出真实的东西，再回到 Figma 打磨。他的周邮件主题也围绕这些变化：《What even is taste?》《The last 20% of a design》《Figma isn't enough anymore》《Tools don't use themselves》。

FloatPrompt 是他做的一个「AI 的隐形操作系统」：一种可移植的人机协作协议，把你的声音、上下文和思路在不同 AI 平台之间保留下来，让 AI 的建议变成可执行的规格。

Float Label ↗

交互模式

输入框里的占位文字在获得焦点或输入内容后上浮为标签，既节省空间又不丢失上下文。如今它几乎是移动端表单的默认做法。

FloatPrompt ↗

2025–人机协作协议

「The invisible OS for AI.」上传一个模板，说「run floatprompt on [my content]」，或用 float map、float extract、float build 等触发词。
