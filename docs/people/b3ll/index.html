TA 到底在做什么？

Adam 的核心关注是「响应性」：动画要能被手指随时打断、随时接管，界面要像物理世界一样有惯性和弹性。Motion 把这个理念做成了引擎，Adjustable 和 Decomposed 是帮你调出「对的手感」的工具。

TA 的另一条线是音频：用 Swift 写合成器、做 AudioUnit 效果器 J_NO Chorus、把黑胶唱片通过 AirPlay 串流（Tunetable）、做把专辑放到主屏幕的 Albums。

代表作品详解

Motion ↗

2020Swift · SIMDiOS / macOS / tvOS

「An animation engine for gesturally-driven user interfaces.」用 SIMD 驱动，完全用 Swift 编写。它让你轻松做出符合物理规律、可打断的动画：弹簧、衰减、关键帧，并且和手势识别器无缝配合。

它解决的问题很具体：系统动画一旦开始就难以被手指「接住」，而 Motion 的每个动画都可以随时被手势接管。

可以从 TA 身上学什么

  • 手感需要调：给参数加滑杆，在真机上反复尝试。
  • 动画要可打断：手势驱动的界面，才是真正的响应式。
  • 越狱精神：去做系统「不允许」的事，往往能发现新交互。
  • 把爱好带进代码：合成器和黑胶，成了最受欢迎的演讲和 App。
  • 工具会被系统吸收：SetNeedsDisplay 的能力后来进了 UIKit，这说明方向是对的。
