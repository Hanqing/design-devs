Matt Massicotte：让 Swift 并发不再可怕

TA 住在加拿大蒙特利尔，是 Apple 平台的老牌开发者，曾在 Crashlytics 和 Apple 工作，后来创办 Chime Systems，做 Mac 代码编辑器 Chime。今天很多人认识 TA，是因为 TA 在 Swift 并发上的大量写作和演讲：TA 的博客有一套从「一个网络请求」讲起的入门系列，还提出过「Split Isolation」这类问题模式的命名；TA 的演讲题目包括《Swift Concurrency is new and hard, and you can do it》（2024）和《How to Approach Approachable Concurrency》（2025）。TA 维护着一批小而精的 Swift 库，比如 Swift 并发队列 Queue、Xcode 项目检查工具 XCLint、类型安全的本地存储 Empire，以及让 AppKit 和 UIKit 不用条件编译就能共用代码的 NSUI。TA 的 GitHub 简介是：「我来这里只做两件事：写点代码，喝点茶。我永远不会喝完茶。」

TA 到底在做什么？

Matt 是 Apple 开发者圈里最常被请教 Swift 并发问题的人之一。TA 的入门系列从最常见的场景讲起：一个网络请求、从存储读取、有状态的系统、遵循协议、设计协议；进阶文章深入到协议与全局 Actor 的关系、「无状态 Actor」、Swift 分组讨论里悬而未决的问题。TA 还会每年整理一份 WWDC 观看清单。

TA 的开源库也围绕「让 Apple 开发少点麻烦」：Empire 是一个强调类型安全和低开销的记录存储，基于比 SQLite 简单得多的有序键值存储；NSUI 解决 AppKit 和 UIKit 之间「小差异让人抓狂」的问题；Multipass 把 Bluesky 和 Mastodon 的信息流合并成一条时间线，TA 自己也说它「刚刚勉强能用」。

本页依据 massicotte.org（首页、博客、About）、GitHub 仓库与 README 和 X 资料整理，资料截至 2026 年 10 月。TA 已基本转到 Mastodon，X 上最近的帖子停留在 2023 年初；各段任职年份未公开。性别未见本人明确表述，本页用 TA。
