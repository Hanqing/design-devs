鸡蛋仔：让时间一目了然

一位住在杭州良渚旁边的 iOS 开发者。TA 的时间追踪 App Gika 不让你给每段时间打一堆标签，而是只问一个问题：这段时间是「向上」「平衡」还是「节制」？2026 年，TA 的公司又上架了两款新作：可以自托管、让人和 AI Agent 一起工作的 Wuhu，以及在所有 Apple 屏幕上播放自有片库的 Arcroom。

一句话：X 简介「良渚边上的一个 iOS 开发，欢迎下载我的时间追踪 app Gika」。

代表作：Gika（2022 年上架，已更新到 v2.0.6）、Wuhu - Generative Space（2026）、Arcroom（2026）。

关键数字：Gika 中国区 31 个评分、均分 4.0；三款 App 都由杭州的同一家公司发布；X 推文约 2,700 条。

Gika 的核心设计：每段时间只分三类：Thrive（向上）、Balanced（平衡）、Limit（节制），「不要一锅标签汤」。

大多数时间追踪工具问的是「你在做什么」，Gika 问的是「这段时间让你变得更好、保持平衡，还是需要节制」。一次点击完成标记，再用日程网格和月历把一天、一个月的时间变成一眼能看出模式的图形。记录本身成了反思，而不是负担。

TA 到底在做什么？

鸡蛋仔的三款 App 看起来很不一样，但有一个共同点：你的数据，你自己掌控。Gika 记录你的时间；Arcroom 的片库就是你自己存储上的普通文件夹，不需要装服务器软件、不需要注册账号；Wuhu 连接的是你或团队自己托管的服务器，由空间管理员决定 Agent 能用哪些 AI 服务和工具。

Gika ↗

2022iOS免费 + 高级版订阅

「Your time, clearly mapped.」正计时、倒计时、番茄钟可以同时运行；每段时间一键归入向上、平衡或节制；日视图的时间网格和月历帮你发现模式；按日、周、季、年汇总睡眠、运动、冥想和前三个项目的时间，可以读取 HealthKit 的睡眠与运动数据。

Arcroom ↗

2026iOS / macOS / tvOS / visionOS免费

把电影和剧集放在你自己拥有的片库里：本机、NAS 的 SMB 共享，或另一台 Mac 通过 WebDAV 共享的片库。导入时转换为适合流式播放的格式，起播即时、拖动流畅，导入过程中就能开始看。

从 TMDB 匹配海报和剧集信息，文字和 PGS 图片字幕都能清晰渲染，播放进度通过 iCloud 私密同步。

Wuhu - Generative Space ↗

2026Mac / iPhone / iPad自托管

一个人和 AI Agent 一起处理文档、对话和实时数据的自托管工作空间。在空间里和常驻 Agent 对话、分配任务、跟踪进度，查看它产出的结果和用到的文档。App 免费，不附带托管账号或 AI 订阅，需要空间所有者的邀请链接。

设计观点

Gika 的设计哲学是「用更少的选项表达更多」：三个词胜过一堆标签。Arcroom 的哲学是「你的存储，你的规则」：片库就是普通文件夹。Wuhu 则把这种掌控感带到了 AI 协作上：模型和工具由空间运营者自己选择。

Every session fits into Thrive, Balanced, or Limit — no messy tag soup.

— Gika App Store 描述

可以从 TA 身上学什么

  • 用更少的选项表达更多：三个词胜过一堆标签。
  • 拥抱系统新能力：小组件和实况活动让 App 出现在锁屏上。
  • 一个产品打磨很多年：持续迭代比不断换方向更难得。
  • 可视化帮助发现模式：网格与月历让时间看得见。
  • 把数据还给用户：普通文件夹、自托管服务器。
