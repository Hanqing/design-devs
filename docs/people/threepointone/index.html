Sunil Pai：我为做东西的人做工具

他住在伦敦，说自己是「产品导向的系统工程师、创始人和开发者工具构建者」。他曾在 Facebook 的 React 核心团队工作，写过 act() 的说明与示例；在 Oculus 做过社交 VR；在 Cloudflare 领导过 Workers 的开发者工具；后来创办了让多人实时应用变简单的 PartyKit，2024 年被 Cloudflare 收购。回到 Cloudflare 后，他做的是 Agents SDK（★5.9 千）和长时间运行的 AI 系统，即「为 AI Agent 打造的持久化基础设施」。更早，他写过 React 时代有名的 CSS-in-JS 库 glamor（★3.7 千）。2026 年 10 月 23 日，他宣布这是自己在 Cloudflare 的最后一天：「（又一次。）这是我一生中最好的职业和机会。」

他到底在做什么？

Sunil 最近几年的核心是有状态的分布式系统：PartyKit 让开发者用很少的代码做多人协作和实时应用；在 Cloudflare，他把这套思路扩展到 AI Agent，让 Agent 可以长时间运行、保存状态、按计划唤醒。他喜欢「把新的基础设施原语变成人们能理解、采用并在上面构建的产品和抽象」。

他的写作越来越多地讨论这门手艺本身：当编程的「材料」在变，资深工程师的判断、品味和职责会变成什么。离开 Cloudflare 的同一周，他在 Cloudflare Connect 大会上展出了一个叫「City That Remembers」的装置。
