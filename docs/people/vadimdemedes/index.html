Vadim Demedes：在停电的夜里做应用

TA 是乌克兰的开发者。2017 年，TA 和 Sindre Sorhus 一起维护 Node.js 测试运行器 AVA 时，厌倦了拼字符串来输出漂亮的结果，于是提议用 React 组件来写命令行界面。这就是 Ink：用 React 和 Flexbox 布局构建交互式命令行应用，GitHub 上有四万颗星，Cloudflare、Linear、Terraform、Shopify 的 CLI 都在用它。2024 年 TA 决定离开 Ink，把它交给 Sindre：自从俄罗斯 2022 年全面入侵乌克兰，「我生活里的一切都围着战争转」。TA 一直在做小而精的应用：为乌克兰每天停电而做的离线稍后读 Linkjar、Astro 内容集合的 CMS Darkmatter、截干净网页截图的浏览器 Confectionery、像 Postman 一样操作 SQL 数据库的 Rosefinch。

Ink 的诞生故事是 TA 最爱讲的：2017 年，TA 和 Sindre 在泰国一个偏远小岛上度假，晚上喝了很多酒。TA 提出用 React 组件来生成命令行输出，Sindre 很喜欢这个点子。TA 当时不会写 React 的自定义渲染器，就想「管 TA 呢」，自己重写了一个和终端兼容的 React。后来 Ink 换成了真正的 React 自定义 reconciler，兼容上千个社区库。TA 写道：「我从没想过 Ink 会火。它给了我职业生涯里最好的机会，真正让我的工作和生活变得更好。」

TA 到底在做什么？

Vadim 的作品分两类：改变开发者工具的开源库，以及解决自己具体问题的小应用。Ink 让命令行界面可以像网页一样用组件搭建，Pastel 在 Ink 之上做了一个「类似 Next.js 的 CLI 框架」：在 commands 文件夹里建文件就是命令，用 Zod 定义参数。

TA 的应用常常有一个具体的起因。Linkjar 是因为乌克兰每天都有停电，Wi-Fi 和蜂窝网络都断了，TA 想趁这段「被迫没有干扰的时间」读完攒下的几百篇文章；Darkmatter 让人用表单编辑 Astro 内容集合，2024 年 TA 用 Rails 和 Hotwire 做网页版，「看不到一行 React」；2026 年 9 月 TA 把 Confectionery 从 130 MB 的 Electron 应用重写成 2.8 MB 的原生 SwiftUI 应用。

本页依据 vadimdemedes.com（首页与《Moving on from Ink》）、各应用官网、GitHub 仓库与 README 和 X 帖子整理，资料截至 2026 年 10 月。Linkjar 官网注明已停止提供。性别未见本人明确表述，本页用 TA。
