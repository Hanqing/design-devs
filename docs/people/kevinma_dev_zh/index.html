Kevin Ma：被迫独立的第三年

TA 到底在做什么？

SentiaRead 是一款 AI 英文阅读器：把你本来就想读的小说、文章和网页变成学习材料。读到生词时，它给出贴合上下文的释义，而不是一串生硬的翻译；遇到绕来绕去的长句，它帮你拆开；查过的词会在之后的阅读里反复出现，帮你真正记住。

在 X 和博客上，Kevin 分享的是一个独立开发者的「全栈」生活：怎样用 Claude Code 给每类公司事务建目录、积累上下文、完成一次银行合规核查；怎样把美国公司的银行从一家迁到另一家；以及回音法这样的英语学习方法。

2026全平台AI 英语阅读

官网把痛点写得很具体：查词打断思路、每个词都认识却读不懂句子、背过的单词在文章里又不认识、读两页英文就犯困。SentiaRead 用上下文释义、长句拆解、生词复现来逐一解决。

它支持 iPhone、iPad、Android、Mac、Windows、墨水屏设备和 Chrome，并跨设备同步。

可以从 TA 身上学什么

  • 先活下去：外包和咨询能给产品争取时间。
  • 别只顾写代码：营销和 SEO 同样重要。
  • 用 Agent 放大一个人：两个月做出一款完整产品。
  • 给事务建上下文：每类事一个目录，让 AI 越来越懂你。
  • 做自己需要的东西：想读英文原著，就做一个阅读器。
