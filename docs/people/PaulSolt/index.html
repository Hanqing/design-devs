TA 到底在做什么？

Paul 有三重身份。工程师：在 GoPro 负责过面向数百万用户的 Quik App 功能，现在在 Omni Federal 担任与美国国家地理空间情报局（NGA）合作的地理空间 App 的 iOS 负责人。独立开发者：Super Easy Apps 名下有计时器、咖啡等 App。教育者：从大学课堂、Lambda School 到 YouTube，持续教人写 iPhone App。

2025 年起，TA 全面转向用 Codex 等 AI Agent 构建 App，并在 YouTube 和 X 上公开记录过程。TA 的口号「What works • what breaks • why」很有教师的风格：不只展示成果，还讲清楚 AI 什么时候会出错、为什么。

代表作品详解

Super Easy Timer ↗

2018macOS 15+免费

「A timer that stays on top of every window.」打字就能开始：「5 min」「2h 30m」「5pm」；中途输入「Add 5 min」就能加时，不用重来。新模式也是一样的用法：打「pomodoro」「tabata」「stopwatch」或「clock」。

每个功能都用一句真实场景来解释：放在菜单栏，让时间一直在屏幕顶端；缩到角落，工作时也能扫一眼；全屏，让房间后排的人也能看清倒计时；它甚至能浮在全屏的 Keynote 和 PowerPoint 之上。可以用全局快捷键在任何 App 里控制它，也可以直接用官网上的免费网页版。

Core ML 蜘蛛识别相机 ↗

个人项目Vision · Core ML微距摄影

一个完整的端侧机器学习项目：自制数据管道和 macOS 工具来整理训练数据，其中包括一个用来过滤模糊、噪点照片的图像质量分类器（处理了 11,344 张照片）；训练了多个 Core ML 模型（蜘蛛检测器和辅助分类器）并反复评估；做了为快速移动的蜘蛛定制的微距相机体验（对焦峰值、自动对焦、自动拍摄）；最后用 SwiftUI + AVFoundation 在实时视频上跑 Vision / Core ML 推理。

DocSetQuery ↗

2025.12Python给 Agent 用

「Tooling for Agents to Create Markdown Documentation from DocSet Bundles.」苹果的文档以 DocSet 包的形式存在本地，Agent 不容易读。这个工具把它们转成 Markdown，让 Codex 等 Agent 在写 iOS 代码时能查到准确的 API 文档。

可以从 TA 身上学什么

  • 自然语言就是最好的 UI：「5 min」胜过三个滚轮。
  • 把一件小事做到极致：一个计时器也能做出口碑。
  • 履历里写数字：「280 万用户」「115 万用户」比「负责若干功能」有力得多。
  • 黑客松也能改变产品：iPad 横屏和新版引导都是从黑客松长出来的。
  • 拥抱新工具，但记录真相：AI 有用，也会坏，都要说出来。
