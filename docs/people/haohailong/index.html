郝海龙：写推理小说的持证私家侦探

这可能是名单里最特别的一位：推理小说作家、作词人、老师，澳大利亚维多利亚州持证私家侦探，也是一个会写代码的人。TA 在 2014 年汉化 WordPress 主题、写 Octopress 插件，2026 年又做了修复 EPUB 的离线 PWA、双页 PDF 切割工具和一键复制链接的浏览器扩展。

一句话：「在下行的电梯里做一个清醒的人。」一个用文字、侦探执照和代码同时理解世界的人。

代表作：写作：推理小说与评论、「推理之象」社群的推象谜题（如《望乡驿》）；工具：EPUB Tweaker（本地修复 EPUB，解决 Send to Kindle 失败与中文直排问题）、PDF Slicer（浏览器本地把双页扫描切成单页）、LinkTap（修饰键点击复制链接）、MarkEdit 扩展（发布到 Typlog、导出 Textpack）；早年的 Wilson WordPress 主题汉化和 banlan.show 播客网络主页。

为什么值得关注：TA 提醒我们，「有设计感的开发者」不一定以开发为主业，代码可以是写作者手里的一把好用的工具。

成长与经历

  1. 2009–2014

    早期博客与主题

    2009 年注册 Twitter，2013 年注册 GitHub。2014 年汉化了瑞典设计师 Anders Norén 的 Wilson WordPress 主题，为 Octopress 写了 GitHub 风格的 CodeRay 代码块插件。

  2. 2019

    班兰播客网络

    为 banlan.show 播客网络制作主页。

  3. 澳洲

    私家侦探

    移居澳大利亚，取得维多利亚州私家侦探执照；在博客里写《奇遇东京谈话会：我有一个朋友是私家侦探！》。

  4. 写作

    推理小说与谜题

    写推理小说和书评（如纸城境介《你的解谜由我证明》、雨穴《诡地图》），在「推理之象」社群不定期发布谜题，并整理《郝海龙读过的东野圭吾作品列表》。

  5. 2026

    为读者和写作者造工具

    EPUB Tweaker、PDF Slicer、LinkTap 和两个 MarkEdit 扩展：全部本地运行、注重隐私，解决 TA 自己读书和写作时遇到的麻烦。

郝海龙做工具的方式和写推理小说很像：先找到一个具体的「案件」（Kindle 发送失败、中文直排错乱、双页扫描），再一步步排查，直到找到真相并解决它。

可以从 TA 身上学什么

  • 代码可以服务写作：工具让读与写都更顺手。
  • 隐私优先：文件处理全在本地，读者更安心。
  • 多重身份互相滋养：侦探的观察力、作家的叙事力、开发者的动手能力。
  • 为小社群做内容：推理谜题让读者变成参与者。
