TA 到底在做什么？

郝海龙的主业是写作：推理小说、书评、谜题、随笔。2026 年，TA 开始为读者和写作者做工具，全部本地运行、隐私优先：EPUB Tweaker 在浏览器里修复和微调 EPUB，解决 Send to Kindle 失败和 Kindle 中文直排问题；PDF Slicer 把双页扫描的书或乐谱切成按顺序排列的单页；两个 MarkEdit 扩展分别导出 TextBundle 和直接发布到 Typlog。

这些工具都来自自己的读写流程：读电子书、扫描纸书、在 MarkEdit 里写稿、在 Typlog 上发布。

本页依据 haohailong.com（关于、作品、近期文章）、bio.link 主页、GitHub 仓库与 README 和 X 资料整理，资料截至 2026 年 10 月。

可以从 TA 身上学什么

  • 代码可以服务写作：工具让读与写都更顺手。
  • 隐私优先：文件处理全在本地，读者更安心。
  • 多重身份互相滋养：侦探的观察力、作家的叙事力、开发者的动手能力。
  • 为小社群做内容：推理谜题让读者变成参与者。
  • 结束也要说明：关停的项目都写了说明。
