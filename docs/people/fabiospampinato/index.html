Fabio Spampinato：努力写好软件

TA 住在伦敦，在 Meta 工作，所有简介都只有一句话：「Trying to write good software.」TA 最有名的作品是 Notable（★2.3 万），「一个不烂的、基于 Markdown 的笔记应用」：笔记就是普通的 Markdown 文件，编辑器和 VS Code 用的是同一个，支持 KaTeX 公式和 Mermaid 图表，没有厂商锁定。TA 还写了「小得离谱的 jQuery 替代品」cash（★7 千），基于 Signals 的高性能前端框架 Voby，以及一个不到 1 KB、为代码清晰而优化的 Solid 响应式核心简化实现 flimsy。TA 在 GitHub 上有 429 个公开仓库，大多是追求极小体积、零依赖的工具库：原子化读写文件的 atomically、构建漂亮命令行的 tiny-bin、一键发版的 bump，以及 VS Code 插件 Todo+。

TA 到底在做什么？

Fabio 的作品有两条线：Notable 这样的桌面应用，和大量极小、极专注的库。Voby 是 TA 对 Signals 响应式的完整实践，flimsy 则把 Solid 的响应式核心压缩到一个文件里，方便人读懂。cash 用现代浏览器 API 实现 jQuery 风格的 API，体积小得多。

TA 在 X 上的话题很广：语法高亮其实不需要构建完整的语法树、Web 仍然缺一个好用的持久化存储方案（「你还在用 IndexedDB？太蠢了」应该成为常识）、Firefox 的性能分析器比 Chrome 的更好用、RSA 加密的几个冷知识。

It's a bit annoying that people making ugly software are some of the people that benefit the most from AI 🤔
