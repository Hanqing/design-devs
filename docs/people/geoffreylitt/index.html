Geoffrey Litt：让每个人都能改造自己的软件

他研究「可塑软件」：在这种计算环境里，任何人都能以最小的阻力改造软件，让它适合自己。他本科在耶鲁读电子工程与计算机科学，早年在创业公司做设计和工程，后来在 MIT 读人机交互博士，导师是 Daniel Jackson；之后在独立研究实验室 Ink & Switch 当资深研究员，2025 年参与发表了长文《Malleable software: Restoring user agency in a world of locked-down apps》。现在他在 Notion 继续这条路。他做过 Wildcard：一个把网页数据变成表格、用公式改造网站的浏览器扩展；也写过一系列被广泛转发的 AI 交互文章，比如《Enough AI copilots! We need AI HUDs》和《Code like a surgeon》。

Geoffrey 在 X 上讲过一个高中故事：他在课上无聊，用 TI-83 BASIC 写了一个会给出「略微错误答案」的恶作剧计算器，准备装到朋友的计算器上，结果自己在化学考试时不小心用了它。很多年后，他研究的问题本质上没变：普通人能不能像改计算器程序那样，随手改造自己每天用的软件？

他到底在做什么？

Geoffrey 认为 AI 辅助编程能开启「个人软件」的新时代：让程序员更开心，也让普通人能做出只为自己服务的工具。他的文章《AI-generated tools can make programming more fun》和《Stevens》都在示范这件事：用很小的代码量，搭一个完全按自己需求运转的助手。

在交互设计上，他反对把一切都做成聊天框。《Enough AI copilots! We need AI HUDs》主张 AI 应该像飞行员的抬头显示器一样，把信息直接叠加在你的工作环境里，而不是坐在旁边等你提问。在 Notion，他关注的是团队如何共享 Agent 的上下文、技能和记忆。

代表作品详解

Malleable software ↗

2025Ink & Switch 长文

「在应用被锁死的世界里恢复用户的能动性。」文章梳理了为什么今天的软件难以改造，以及让软件可塑需要哪些技术和设计条件。他在主页上把它作为理解自己工作的首选入口。

Wildcard ↗

2019–浏览器扩展★302

「让任何人都能构建浏览器扩展、修改网站以满足自己的需求。」它把网页上的数据显示成一张熟悉的表格：可以排序、过滤、加批注，甚至用电子表格公式从其他网站拉数据。

I work on malleable software: computing environments where anyone can adapt their software to meet their needs with minimal friction.

— Geoffrey Litt，geoffreylitt.com

他对 Agent 的经验很实用：给 Agent 画代码图时，「展示具体的示例数据，而不只是抽象架构」；Skill 能跨模型世代保持有效，「只要它更像规格说明，而不是一步步的指令」。他还猜测，教学能力可能是给 Agent 写提示的最好前提：看到平庸的作品，能立刻说清它为什么不好、该怎么改。

可以从他身上学什么

  • 软件应该能被用户改造。
  • 别把一切都做成聊天：想想 HUD。
  • 做个人软件：AI 让「只给自己用」变得划算。
  • 认真对待兴趣：为它找到严肃的反馈场合。
  • 写规格，不写步骤：Agent 的 Skill 才能长久。
