Mariana Castilho：设计，然后亲手做出来

TA 是产品设计师，也是设计工程师：不只画设计稿，还亲手把它写成代码上线。TA 在 Vercel 参与过 v0 和 Vercel Marketplace 的设计，在 Pierre Computer 设计并开发了新版首页和引导流程，又在 AI 编程公司 Poolside 为网页和 IDE 做设计。2026 年 9 月，TA 加入 Profound，同月公司宣布完成 1.8 亿美元 D 轮融资。此后 TA 几乎每周都会发一个新功能：导航里的预览卡片可以直接回答 Agent 的提问；全局命令面板可以搜索平台上的每一个页面、文件和操作；「上下文总览」用 3D 图把知识之间的连接画出来。

TA 到底在做什么？

Mariana 的工作是让 Agent 产品的工作流不被打断。在 Profound，用户不必切换页面，就能在导航的预览卡片里直接回答 Agent 的问题；一个全局面板可以搜索并触发平台上的任何内容：预览文件、和 Agent 开聊、下载 PDF。上下文总览用 3D 可视化加侧栏，帮人看清上下文之间如何关联、哪里有缺口，还能直接问 Agent。

在 Pierre，TA 设计并实现了新的引导流程，利用这个流程顺便收集用户的编程档案；宣言页上的签名来自 Pierre 创始人 @fat。TA 也帮朋友和 Emil Kowalski 设计过文档页面。
