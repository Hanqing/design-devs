Lukáš Kubánek：痴迷于结构化的 Mac 开发者

来自捷克、住在德国德累斯顿的 Swift 开发者。读计算机时他从 Windows 换到 Mac，被独立开发者的原生应用打动，于是决定做一个画软件架构图的 Mac 原生编辑器。这个想法从 2011 年走到 2020 年上架，就是 Diagrams。为了它，他从零写了一个受 React / Redux 启发的画布框架 CanvasKit。

一句话：X 简介「Obsessed with structuring things」。个人网站上写：「我喜欢整个过程，但尤其喜欢工程部分。我的热情在于把所有细节做对。」

代表作：Diagrams for Mac（Mac App Store 与 Setapp，多次获 Apple 推荐）、LoremIpsum / LoremSwiftum、OrderedDictionary、DetachablePopoverExample、自定义键盘布局 Lupulus。

关键数字：2022 年时 Diagrams 每周约 1,300 名独立用户；2022 年起改为免费下载 + 5 天试用 + 22.99 美元一次性买断；GitHub 近一年 1,867 次贡献。

媒体评价：MacStories 的 John Voorhees 说它「Mac-native, and it shows」；John Sundell 说它是自己设计软件架构时「最喜欢的可视化工具」。

Diagrams 最难的部分是画布。2017 年，Mac 上没有任何可以借用的第一方框架，Swift 还很年轻，工具链也弱得多。Lukáš 决定自己写一个，叫 CanvasKit，借鉴了 JavaScript 世界里 React 和 Redux 的声明式 UI 与单向数据流。这个决定让 Diagrams 晚了几年上架，也让它成为 Mac 上手感最「原生」的图表工具之一。

他到底在做什么？

Lukáš 现在两条腿走路：继续维护 Diagrams，同时以自由职业者身份为客户的 iOS 和 macOS 项目做 Swift 开发。他的个人网站把这件事讲得很清楚：「What am I doing now?」去看 Now 页；「Interested in working with me?」去看 Work 页。

Diagrams 的设计核心是「结构优先」：它不是自由画布，而是由元素和关系构成、有规则的结构。这和他「痴迷于结构化」的个性完全一致。

成长与经历

  1. 2011

    想法的起点

    刚开始学软件开发，他发现用图表描述系统很有价值，却找不到合适的 Mac 工具：要么偏重图形设计，要么复杂得让人望而却步。

  2. 2012–2015

    Mac 小工具与开源

    做了给 iA Writer 增加 PDF 导出的 Mac 服务；开源 Objective-C 的 LoremIpsum、Swift 版 LoremSwiftum、OrderedDictionary、展示 Yosemite 可分离 NSPopover 的示例；2014 年完成学士论文；还记录了一个「我遇到的 Swift bug」仓库。

  3. 2017

    Structured Path

    创办 Structured Path GmbH，全力投入 Diagrams，从零写画布框架 CanvasKit。

  4. 2020

    Diagrams 上架

    2020 年初在 Mac App Store 和 Setapp 上线，多次获 Apple 推荐。设计师 Alex 与他合作三年，奠定了 Diagrams 的界面与视觉。

  5. 2022

    转折点

    销量回落、合作者离开，他把定价改为免费下载 + 5 天试用 + 一次性买断，并开始做自由职业；同年起公开发布年度回顾，写下《The Diagrams Story》。

  6. 2023–2024

    游牧与安家

    冬天在加那利群岛和保加利亚班斯科远程工作；从柏林搬到德累斯顿；从 Twitter 转到 Mastodon。

  7. 2026

    放慢节奏

    在《Stuck in Low Power Mode》里解释了博客为何安静：他经历了一段健康上的挫折，正在调整工作与生活的节奏。
