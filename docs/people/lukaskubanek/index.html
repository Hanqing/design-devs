Lukáš Kubánek：痴迷于结构化的 Mac 开发者

来自捷克、住在德国德累斯顿的 Swift 开发者。TA 创办了 Structured Path GmbH，独自打造原生、基于文档的图表编辑器 Diagrams for Mac，如今也作为自由职业者为客户做 iOS 和 macOS 应用。

一句话：「Obsessed with structuring things.」一个热爱把细节做对的 AppKit 开发者。

代表作：Diagrams（2017 至今，原生 Mac 图表编辑器）；开源 LoremIpsum / LoremSwiftum（占位文本生成）、OrderedDictionary、DetachablePopoverExample、iA-Writer-Export。

技能：AppKit、SwiftUI、UIKit、Combine、Swift Concurrency、TCA、CloudKit 同步、逆向工程，以及用 Claude Code 的 Agentic Coding。

Lukáš 的个人网站开头写：「我热爱在数字世界里建造东西。我享受整个过程，但尤其喜欢工程部分。我的热情在于把所有细节都做对。」TA 偶尔会利用「位置自由」，在捷克、加那利群岛和保加利亚工作。

成长与经历

  1. 2012–2014

    从 Mac 工具开始

    2012 年做了给 iA Writer 增加 PDF 导出的 Mac 服务；2013 年开源 Objective-C 的 LoremIpsum 生成器，次年 Swift 发布后又写了 LoremSwiftum；还做了展示 Yosemite NSPopover 分离 API 的示例。2014 年完成学士论文。

  2. 2015

    Swift 数据结构

    开源 OrderedDictionary 等 Swift 实现，以及 Mac 图标预览小工具。

  3. 2017-11

    Structured Path 与 Diagrams

    创办 Structured Path GmbH，独立打造 Diagrams：一款原生、基于文档的 Mac 图表编辑器，TA 负责产品愿景、架构与开发。

  4. 现在

    自由职业 + Diagrams

    继续开发 Diagrams，同时作为自由职业者为客户的 iOS / macOS 项目提供 Swift 开发服务。每年在博客发布年度回顾。

设计与手艺

Diagrams 的设计核心是「结构优先」：图表不是自由画布，而是有规则的结构。这与 TA「痴迷于结构化」的个性完全一致。

Not a designer, but something I care deeply about and have a strong eye for making it feel right.

— Lukáš Kubánek 谈 UX 设计

可以从 TA 身上学什么

  • 把一个 App 做很多年：Diagrams 从 2017 年持续至今。
  • 诚实地标注能力：技能页写清楚擅长什么、还在学什么。
