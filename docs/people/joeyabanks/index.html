Joey BanksBaseline Design 创始人 · 设计系统设计师 · 前 Twitter、Webflow 设计系统负责人 · 前 Figma 设计师布道师

Joey Banks：系统是手段，人才是目的

他住在俄亥俄州哥伦布市，是一位设计系统设计师。他曾带领 Twitter 和 Webflow 的设计系统，也在 Figma 做过设计师布道师（Designer Advocate），教大家用好组件、变量和工作流。后来他独立出来，创办了设计系统咨询公司 Baseline Design，为团队提供设计系统的策略、搭建与培训：组件和令牌、治理规则、让系统保持健康的工作流，以及「不用我们在场也能运转系统」的培训。他在 X 上有八万多关注者，常常拆解 Apple 发布会里的界面细节。

2026 年 10 月，Joey 分享了他最喜欢的设计工作流：先在 Claude Code 里把真实的东西做出来，再用 Figma Console MCP 把最重要的界面决策和组件拉回 Figma。代码负责做出最好的版本，Figma 负责记录和共享决策。这条帖子收获了六百多个赞。他说，自己对设计这个角色的未来「感到非常乐观和兴奋」。

他到底在做什么？

Baseline 的工作是打好设计系统的地基。官网写道：有的团队带着一个需要重构的组件库来找他们，有的已经有了组件库，但需要一个懂得如何运营它的团队，还有的团队必须先解决一个设计系统战略问题，才谈得上开始搭建。客户评价说，经过 Baseline 的指导，设计团队都理解了组件和工具，还顺便搭起了内部设计系统。

他也在考虑开一门 Framer 进阶课程，因为这一年他用 Framer 学到了「超多东西」。
