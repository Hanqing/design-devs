TA 到底在做什么？

Liu Liu 的路径非常少见：从底层框架一路做到消费级产品。大多数 AI 应用依赖现成的推理框架，而 Draw Things 跑在 TA 自己写的 libnnc 上，再通过 s4nnc 和 swift-diffusion 接到 Swift。因此 TA 能针对 Metal 和 Apple Silicon 做非常深的优化，甚至在 2025 年就在实验 Metal 4 的张量运算。

Draw Things 的定位很清楚：服务器级的图像模型，在你自己的设备上离线运行，提示词和图片都不离开设备，本地生成完全免费。

成长与经历

  1. 2008

    静水铭室

    开始在博客「静水铭室」写作，题词「静水可铭，丰山须镂」。

  2. 2010

    libccv

    「出于对当时所用计算机视觉库的不满」，TA 以极简为灵感写了 ccv：更容易部署、组织更简单、对依赖很谨慎。如今它能在 macOS、Linux、FreeBSD、iPhone、Android、树莓派上运行。

  3. 2013

    Facebook Videos

    在 Facebook 与他人一起创立视频业务。

  4. 2014

    klaus 与 libnnc 的起点

    用 libccv 在 iOS 上展示当时最先进的图像分类器（klaus），做了 docomputersdream.org。年底 TA 意识到神经网络「将是唯一重要的算法」，而 ccv 里的实现没有多路网络、自定义损失和自动微分，于是从零开始写 NNC。

  5. 2014–2020

    Snapchat iOS

    编写和维护 Snapchat 的 iOS 应用六年。业余写了 C 协程示例、Bazel 的 CUDA 规则、移动端数据存储 dflat（SQLite ❤️ FlatBuffers）。

  6. 2020–2022

    Swift 与机器学习

    发布 s4nnc，写《On Designing Deep Learning Library API in Swift》《Data Science Setup with Swift in 2021》；修完 MIT 的 Underactuated Robotics，写人形机器人研究笔记和 PPO / SAC 实现细节。

  7. 2022.11

    Draw Things

    Stable Diffusion 开源后不久，用 swift-diffusion 把它塞进 iPhone，Draw Things 上架。

  8. 2023–2026

    持续迭代

    Draw Things 扩展到 iPad 和 Mac，几乎每周发布新版本；2025 年被 Apple 新闻稿提及；TA 继续在 GitHub 上维护 ccv、s4nnc 和 swift-diffusion。

代表作品详解

Draw Things ↗

2022iOS / iPadOS / macOS免费 · 离线

「Server-grade AI models. Quickly generate images, locally and offline.」在 iPhone、iPad、Mac 上本地运行图像生成模型，支持文生图、图生图、局部重绘等完整创作流程。完全离线，提示词和作品都留在设备上。

它背后是一整条自研技术栈：libnnc 负责计算，s4nnc 提供 Swift 接口，swift-diffusion 实现扩散模型推理。
