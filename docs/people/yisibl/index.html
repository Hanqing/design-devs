一丝：在 Chrome 里写 CSS 的人

TA 在阿里巴巴工作，是国内最大的矢量图标库 iconfont.cn 的负责人，也是 Rust 写的 CSS 工具 lightningcss 的核心成员。TA 开发的 resvg-js 把 Rust 写的 SVG 渲染引擎 resvg 带到了 Node.js 和浏览器，用来在服务端快速把 SVG 渲染成 PNG。这两年 TA 和同事 @imCGQAQ 直接给 Chromium 贡献新的 CSS 特性：polygon(round) 圆角多边形在 Chrome 150 上线，shape-outside 配合 shape() 在 Chrome 149 上线，还在推动它们进入 Interop 2026。早在 2013 年，TA 就以「CSS 大草原」博客和 Emmet、PostCSS 相关工具在中文前端圈出名。

TA 到底在做什么？

一丝的工作横跨图标、渲染和标准三层。iconfont.cn 是阿里巴巴体验团队做的矢量图标库，提供图标下载、在线存储和格式转换；resvg-js 则解决「在服务器上把 SVG 变成图片」这件事，速度快，跨平台，不依赖浏览器。

在标准层面，TA 关注 CSS 的细节到了数值精度：TA 指出 color-mix 的插值规范会让 (0.5 + 0.5) / 2 不等于 0.5；建议只调透明度时用新的 alpha() 而不是 color-mix；提醒大家用 border-shape 代替 clip-path。TA 也对 Oxc 选择的 CSS 解析库提出过疑问，担心它跟不上标准演进。

观点

iOS 的圆角不是超椭圆（superellipse）。这也是不同技术背景的人使用 vibe coding 在结果上会带来的巨大差异，有时候产生的结果看起来不错，但实际上从根本上就错了。

— 一丝，X，2026-06

TA 的立场一贯是：专业知识决定结果。AI 能写出看起来对的 CSS，但只有懂规范的人才知道它是不是真的对。TA 也是 ISO 8601 日期格式的坚定拥护者：「只有 YYYY-MM-DD 才是最好的！」

可以从 TA 身上学什么

  • 深入到标准层：不满意就去改浏览器。
  • 用 Rust 加速前端工具：napi-rs 让绑定变简单。
  • 注意数值精度：CSS 里 0.5 也可能不是 0.5。
  • 推动跨浏览器：一个浏览器实现了，还要争取 Interop。
