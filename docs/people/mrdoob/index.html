mrdoob：让网页有了三维

TA 的 X 简介是一句自嘲：「Award losing non creative junior vibe coder. May or may not have something to do with @threejs.」这个「可能有关系」的项目，是网页 3D 图形的事实标准 three.js：TA 在 2010 年 4 月把它发布到 GitHub，它的源头可以追溯到 TA 在 2000 年代初参与的 demoscene（演示场景）创作，最初用 Flash 的 ActionScript 写，2009 年移植到 JavaScript。如今 three.js 有 11.7 万颗星、两千多位贡献者，支持 WebGL 和 WebGPU 渲染。TA 还写了网页性能监视器 stats.js、着色器画廊 GLSL Sandbox 和序列编辑器 frame.js。这两年 TA 用 AI 做了一连串好玩的东西：把《雷神之锤》（Quake）移植到 three.js、一个只有 784 KB 的程序化纽约城市模拟，以及 Kenney 赛车游戏模板的 JavaScript 版。

TA 到底在做什么？

mrdoob 仍然是 three.js 的核心维护者。它的目标写在 README 第一句：做一个易用、轻量、跨浏览器、通用的 3D 库。维基百科记载，TA 的贡献包括 API 设计、Canvas 与 SVG 渲染器，以及负责合并各方贡献；而 WebGL 渲染器能顺利加入，正是因为渲染代码一开始就被设计成独立模块。

TA 也在用 AI 加速创作，并对此毫不避讳：Starter Kit Racing 的 README 写着「用 Claude 移植到 JavaScript」；一个识别汉字、给出假名、罗马音和英文的网页应用，全部用本地模型在设备上运行；当 demoscene 社区 pouët 上 AI 反感情绪高涨时，TA 干脆「vibe code 了一个关于这件事的 demo」。

本页依据维基百科 Three.js 条目、GitHub 仓库与 README 和 X 帖子整理，资料截至 2026 年 10 月。个人网站 mrdoob.com 是一个纯 three.js 作品页，没有文字自述；TA 的雇主和所在地未公开，性别未见本人明确表述，本页用 TA。
