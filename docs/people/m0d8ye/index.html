TA 到底在做什么？

Max Lv 的开源有两条主线。一条是网络：Android 代理工具（GAEProxy、ProxyDroid、shadowsocks-android）、C 语言的 shadowsocks 实现、TCP 拥塞控制实验，以及 2026 年用 Rust 重写的 Clash / mihomo 兼容内核 meow-rs 和它的 macOS、Android 客户端。

另一条是「让旧东西重新发光」：把旧安卓手机变成 Linux 服务器（ServerBox），在 macOS 原生窗口里运行 Android 应用（Mandroid），把 1995 年的《仙剑奇侠传》DOS 版完整移植成 Rust 并用神经网络实时超分。芯片工程师的性能直觉和游戏玩家的情怀，在这些项目里交汇。

本页依据 GitHub、maxlv.net 博客、madeye.github.io 与各项目 README 整理，资料截至 2026 年 10 月。

meow-rs 与宝莲灯 BaoLianDeng ↗

2026Rust + Swift + KotlinApp Store

meow-rs 是用 Rust 写的高性能 mihomo（Clash Meta）兼容内核：规则分流、多种代理协议、透明代理、DNS 嗅探、REST API 和内置 Web 面板。它在 mihomo 之外多做了两件事：当链式代理的某个成员能通过测速、却连不上后续服务器时，依然能让「dialer-proxy」链路工作；以及记一本「日志簿」，记录引擎做过的事（重载、订阅失败、崩溃、链路节点掉线）。

宝莲灯是基于它的 macOS 代理应用，使用 NETransparentProxyProvider 在 socket 层拦截流量，比传统 TUN 方案更快，已上架 App Store。配套还有 Flutter 界面的 Android 客户端 meow-android。TA 专门写了一篇《用 Claude Code 把三万行 Go 项目移植到 Rust：Agent 团队与 Harness 调优》。

gterm ↗

2026.05Swift + ZigiOS 终端

一个基于 Ghostty 引擎（libghostty）的 iOS SSH 终端。难点在于 iOS 不允许本地 fork/exec shell，终端必须由 SSH 数据流驱动：TA 为此 fork 了 ghostty，在它的 Zig termio 层里新增了一个 passthru 后端。这意味着要读懂一个 30 万行 Zig 项目的 IO 架构并做侵入式修改，而 TA 此前从没写过 Zig。

从第一次提交到可以通过 TestFlight 安装，只用了 5 个活跃日、64 次提交，期间完成了 libghostty 交叉编译成 iOS XCFramework、swift-nio-ssh 集成、自定义屏幕键盘、钥匙串存储与 TOFU 主机密钥、fastlane 发布流水线。

《AI Agent 把独立开发压缩进碎片时间》的三个判断

  • 语言不再是门槛。Agent 没有缩短学一门语言的时间，而是让这个问题不再重要：人的瓶颈从「能不能写」变成「能不能读懂并审查」，而读比写容易一个数量级。
  • 从几个月到几天。以前要按季度计算的业余项目，现在几个活跃日就能完成。
  • 默认并行。Agent 跑长任务的几十分钟到几小时里，人可以切到另一个项目去派活或审查。每次介入只需要 10–30 分钟的「审查与转向」，一个下午写不完 TCP 栈，但 15 分钟足够读一个 diff、跑测试、指出下一步。

TA 还改了记录想法的习惯：以前把想法丢进 Notion，「等有空再展开」，结果大多数想法死在了列表里；现在想法一出现，就直接打开 Agent 写成计划。

可以从 TA 身上学什么

  • 用数据讨论 AI：拿自己的提交记录说话，而不是凭感觉。
