Max Lv 2009 年就注册了 X。十几年前，TA 写的 GAEProxy 和 ProxyDroid 是很多 Android 用户接触「全局代理」的起点；后来 TA 写下的 shadowsocks-android，成为这个领域最知名的客户端之一。如今 TA 的博客叫「Lv. MAX」，记录的是一个芯片工程师在 AI 时代重新拿起业余项目的快乐。

成长与经历

  1. 2011

    GAEProxy

    基于 Google App Engine 的 Android 代理工具，用 C 写成，是 TA 最早的知名开源项目（现已弃用）。

  2. 2012

    ProxyDroid

    Android 全局代理工具，至今仍有 2.5k 星，并在 2026 年用 Kotlin 重新整理。

  3. 2012 起

    shadowsocks-android

    为 Android 编写 shadowsocks 客户端，并与 Mygod Studio 一起长期维护，成为 GitHub 上最受欢迎的 Android 网络工具之一。TA 也是 shadowsocks-libev（后来的 shadowsocks-c）的核心维护者。

  4. 2016

    tcp_china

    一个针对中国网络环境的 TCP 拥塞控制算法实验，显示出 TA 在网络协议层面的功底。

  5. 职业

    NVIDIA 芯片架构师

    在 NVIDIA 上海从事芯片架构工作（据其 GitHub 与项目页自述）。

  6. 2026

    AI 时代的开源井喷

    一年内发布 ServerBox（旧安卓手机变 Linux 服务器）、ad-skipper（本地 VLM 跳开屏广告）、Mandroid（在 macOS 原生窗口中运行 Android 应用）、gterm（基于 libghostty 的 iOS 终端）、rv（GPUI 写的 VNC 客户端）、《仙剑奇侠传》DOS 引擎 Rust 移植等。

设计与手艺

十年的开源贡献如今都在大模型里，即使是一个免费的、非最强的模型，也能在几小时内写出一个可用的混淆插件。这个愿景第一次在实践中变得可及。

TA 移植《仙剑》时最看重的是可验证：怎样证明 Rust 版本与原版行为一致，怎样设计「mega kernel」，怎样用实测数据调 WebGPU。芯片工程师的严谨和游戏玩家的情怀，在一个项目里汇合。

可以从 TA 身上学什么

  • 用数据讨论 AI 对开发的影响：TA 用自己项目的提交记录来分析，而不是凭感觉。
  • 旧设备、旧游戏都值得重做：ServerBox 和仙剑移植都是「让旧东西重新发光」。
  • 长期维护的价值：一个客户端维护十几年，本身就是一种设计。
  • 主业与业余互相滋养：芯片架构的性能直觉，用在了 WebGPU 和推理优化上。
