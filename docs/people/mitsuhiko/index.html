Armin Ronacher：从 Flask 到 Agent 运行时

他是奥地利开源程序员，住在维也纳，以 Python Web 框架 Flask（★7.5 万）闻名，也写了模板引擎 Jinja、WSGI 工具库 Werkzeug、命令行库 Click 等 Pallets 项目。据维基百科，他早年为德国 Ubuntu 社区门户 ubuntuusers 做开发，2005 年成为德国 Ubuntu 协会的创始成员；后来在 Plurk、游戏网络公司 Fireteam 工作，又在 Sentry 投入了整整十年。2012 年成为 Python 软件基金会院士，2014 年获得 PSF 社区服务奖。他现在创办了 Earendil，一家「打造软件和开放协议、增强人的主动性、弥合分歧、培育持久快乐」的公益公司，核心产品之一是极简的 Agent 工具包 Pi（★11.7 万），2026 年 10 月发布 1.0。他的 Rust 作品也很受欢迎：快照测试库 insta、Jinja 兼容的模板引擎 MiniJinja、diff 库 similar。

Pi 的官网写着：「Pi 是一个极简的 Agent 运行框架。让 Pi 适应你的工作流，而不是反过来。」它故意不带子 Agent 和计划模式这类功能：你可以让 Pi 自己把需要的东西写出来，或者装一个按你的方式实现的包。「改变运行框架，而不是你的工作流」：需要新命令、新工具或界面调整，就让 Pi 当场修改自己，输入 /reload，继续工作。2026 年 10 月，Earendil 发布了 Pi 1.0 和支持持久运行的 Pi Durable。

他到底在做什么？

Armin 现在在 Earendil 做Agent 工具和开放协议。Pi 支持 15 家以上的模型服务商，有交互、打印 / JSON、RPC 和 SDK 四种模式，可以用扩展、技能、提示模板和主题定制，并打包成 Pi 包通过 npm 或 git 分享。GitHub 贡献统计显示，Pi 的最大贡献者是 badlogic（Mario Zechner），Armin 排在第二。Earendil 的其他项目还包括 Radius 和 Lefos。

他的博客 lucumr.pocoo.org 持续发表关于 AI 编程的思考：什么是 Codemode、如何解读 Pangram、他对 P(doom) 的看法。据维基百科，2026 年 6 月《华尔街日报》报道了他对软件行业过度使用 vibe coding 的批评。他在 X 上的观察也常被大量转发，比如：「AI 再有趣，我们过去 30 年也造了太多糟糕的软件，现在宇宙在惩罚我们的罪过。」
