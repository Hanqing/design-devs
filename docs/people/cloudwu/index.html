云风（吴云洋）游戏程序员 · skynet 作者 · 自由职业者

云风：写了三十年代码，依然只想做游戏

二十岁左右，他在大学里写出二维游戏引擎「风魂」；2001 年加入网易，风魂「阴差阳错」挽救了《大话西游》项目，他也参与了《大话西游 2》《梦幻西游》。2011 年他离开网易，与叮当等人在广州创办简悦，写出了被中国游戏行业大量使用的服务端框架 skynet。2017 年底简悦被阿里收购，成为灵犀互娱；他退出管理，专心做自研引擎 Ant。2024 年 5 月 Ant 项目被关停，他离职成为自由职业者，开始用自己写的 Lua 2D 框架做独立游戏。

他到底在做什么？

云风最广为人知的作品是 skynet：一个基于 Actor 模型、用 Lua 写业务的多用户服务端框架。README 写着它「在中国游戏行业被大量使用」，现在也在向其他行业和英语开发者扩散。

离开阿里后，他把精力放在客户端：ltask 是受 skynet 启发的 Lua 多任务库，可以在 N 个系统线程上运行 M 个 Lua 虚拟机；soluna 把 sokol 图形库和 ltask 结合成一个跨平台 Lua 2D 游戏框架，能跑在 Windows、Linux、macOS 和浏览器里。他用它做了桌游《Deep Future》的数字版。

本页依据云风的 BLOG、GitHub 仓库与 README、搜狐与阿里云开发者社区的报道和访谈以及 X 资料整理，资料截至 2026 年 10 月。博客中的家庭与健康内容未收录。

成长与经历

  1. 大学时期

    风魂

    二十岁左右开发二维游戏引擎「风魂」系列，在国内早期游戏开发者中流传很广。

  2. 2001

    加入网易

    4 月入职网易，据他的博客，风魂引擎「阴差阳错」挽救了《大话西游》项目；之后参与《大话西游 2》《梦幻西游》。

  3. 2005

    《游戏之旅》

    出版《游戏之旅：我的编程感悟》，写下自己的编程与游戏开发经验。

  4. 2011

    离开网易，创办简悦

    与丁磊沟通数月后离职，年底与叮当、陈伟安等人在广州创办简悦科技。

  5. 2012–2016

    skynet 与手游

    2012 年开源 skynet 和 C 协程库；2013 年为转型手游开发 ejoy2d，用于《陌陌争霸》；2014 年发布 sproto；2015 年翻译 Lua 5.3 中文文档。

  6. 2017–2024

    阿里灵犀与 Ant 引擎

    简悦被阿里收购，成为灵犀互娱。2018 年起退出管理，主导自研 3D 引擎 Ant，并做 ltask、luaecs、lua-bgfx 等基础库。

  7. 2024

    再次启程

    5 月宣布离职，最后工作日为 5 月 20 日，计划做一款 Windows 平台的独立游戏。

  8. 2025–2026

    soluna 与 Deep Future

    发布 Lua 2D 框架 soluna 和桌游《Deep Future》数字版；博客大量写游戏设计分析与算法。

代表作品详解

skynet ↗

2012–C · Lua★1.4 万

一个轻量的在线游戏服务端框架：每个服务是一个独立的 Lua 虚拟机，通过消息通信，底层用 C 实现调度和网络。它把多线程并发的复杂度藏在框架里，让业务程序员只写顺序的 Lua 代码。

十多年后它仍在维护，GitHub Wiki 里列出了大量使用它的公司和项目。

GitHub
★14,180 · ⑂4,274

soluna ↗

2025–C · Lua★383

「Sokol + Lua = Soluna。」基于 sokol，整合 ltask 做多线程，通过 WebAssembly 也能跑在浏览器里，提供在线示例和每夜构建。这是他离开大公司后，给自己做独立游戏打造的工具。

Deep Future 数字版 ↗

2025–Lua可在线游玩

R. Winder 设计的桌游《Deep Future》的数字版。这是一款「边玩边做」的游戏：开局只有地图、纸和几张卡片，世界、科技和过去文明的遗迹在游戏过程中不断生成。支持中英文，可在 Windows、Linux、macOS 和浏览器上玩。

个人网站研究

blog.codingnow.com ↗

「云风的 BLOG」仍然跑在 Movable Type 3.2 上，副标题「思绪来得快去得也快，偶尔会在这里停留」。二十年来几乎没有改过样子：一篇篇长文、固定链接、留言。

可以从他身上学什么

  • 做你真正想做的角色：管理不是程序员唯一的上升路径。
  • 简单的抽象活得最久：skynet 十几年仍在被使用。
  • 先给自己造工具：soluna 就是为独立游戏写的。
  • 写博客二十年：思考会在文字里留下来。
  • 玩游戏也要做研究：把体验写成设计分析。
