Sam Selikoff：把前端 UI 开发教好

TA 住在纽约曼哈顿，现在是 Vercel Next.js 团队的成员。TA 的个人网站写着：「从 2016 年起，我以教授 Web 上的 JavaScript UI 开发为生。」TA 早年活跃在 Ember 社区，和朋友 Ryan Toronto 一起做了视频教学网站 EmberMap，2022 年 10 月又一起推出了面向前端开发者的订阅视频网站 Build UI。TA 还创造了 Mirage.js（★5.5 千），一个在客户端模拟服务器的工具，让前端可以在没有后端的情况下构建、测试和分享应用；和 Ryan 一起主持每周的 Frontend First 播客；在 React Conf 2024 上讲了《React Unpacked: A Roadmap to React 19》。TA 的 YouTube 视频以一步步手写复杂交互闻名：iOS 音乐应用的仿制、可调整大小的面板、交互式日历。

2010加入 X

2026 年 8 月，TA 发帖说，刚加入 Next.js 团队时，对 Cache Components 并不怎么兴奋，因为它唯一的用例是文档、电商、营销这类偏静态生成的网站。但到了 16.3，Cache Components 可以完全在浏览器里工作："use cache" 不再只是构建时预渲染，还能把请求时渲染的 RSC 存在浏览器里。同月 TA 开玩笑说，是时候在所有项目里全局搜索那段老写法了：useState(false) 加 useEffect 判断是不是在浏览器里。

TA 到底在做什么？

Sam 现在在 Next.js 团队做开发者教育和框架功能的落地：写《Next.js 16 Recipes》系列，比如「用 promise 和 Client Components 共享数据，让页面尽早渲染甚至预渲染」；跟进 Cache Components 和 Activity 相关变化，在 GitHub issue 里给开发者写详细的更新说明；在大会上做现场编码演讲。

TA 的教学风格是从零手写。2026 年 1 月，TA 发布了一个用 Next.js 16 构建混合式 AI 聊天机器人的演讲，并自问：「这会不会是我最后一次每一行都亲手写的现场编码演讲？」
