Cyandev：一个原生优先主义者的工程笔记

前字节跳动、阿里巴巴工程师，现在在一家「视频会议软件」公司做 Mac 客户端。他写 SwiftUI 版 2048、给 React 开发者的 SwiftUI 速查表、iOS 备份提取工具，也在博客里认真讨论所有权、Send/Sync 和 Swift 并发隔离。

一句话：一个对用户界面和交互设计着迷的软件工程师，「原生优先主义者，讨厌到处都是浏览器」。

代表作：ibackupextractor（Rust，★1.3k）、SwiftUI-2048、Daysquare（优雅的 iOS 日历控件）、swiftui-for-react-devs、SimRun（在 Mac 上直接运行模拟器 App）、little-agent（轻量嵌入式 Agent 框架）。

为什么值得关注：他的博客把系统编程的深度和对交互的审美结合在一起，是中文技术写作里很难得的风格。

Cyandev 的 GitHub 简介写着：「vibe coder by day, real coder by night.」他的 About 页引用了费曼的一句话：「What I cannot create, I do not understand.」（我不能创造的，我就不理解。）

成长与经历

  1. 2012

    注册 GitHub 与 X

    早年活跃在知乎和各种技术论坛，后来都退出了。他自称「数字考古」爱好者，用过 Mountain Lion、Vista 和 KDE 4。

  2. 2016

    iOS 与 Android 组件

    Daysquare（一个优雅的 iOS 日历控件）、CVPasscodeController（原生观感的密码输入界面）、android-FancyBehaviorDemo（自定义 CoordinatorLayout 行为）。

  3. 2019–2020

    SwiftUI 时代

    SwiftUI 发布当年就写了 SwiftUI-2048 和基于 Metal 的视频播放器；2020 年整理了给 React 开发者的 SwiftUI 速查表。

  4. 阿里巴巴 → 字节跳动

    大厂客户端

    先后在阿里巴巴和字节跳动工作，积累了大型客户端工程的经验。2022 年写了 XcodePatch（拯救 Xcode 的补丁合集）和关于 Objective-C atomic、Swift Package Plugin 沙盒的文章。

  5. 2023

    Rust 与 React 的思考

    用 Rust 写了 iOS 备份提取工具 ibackupextractor；博客里写《为什么所有权很重要》《But What is Send and Sync?》《Idiomatic Signals for React》《Thoughts on React Server Components》。

  6. 现在

    视频会议软件的 Mac 客户端

    在一家「视频会议软件」公司做 Mac 客户端开发。2025–2026 年博客写了 Swift Concurrency 隔离、基于原则的性能优化、用 WebGPU 造一场雪、《再见，Next.js》和《为 Electron App 设计扩展系统》；2026 年开源 SimRun 和 little-agent。

设计与手艺

I'm fascinated by user interface and interaction design… I love digging into the essence of things and thinking with the first principle.

— Cyandev，About 页

他说自己是 Apple 粉（「至少曾经是」），喜欢乔布斯的产品哲学和苹果的设计品味：「也许苹果已经变了很多，但它最初的精神一直启发着我。」他的作品与文章，都是这种精神在工程层面的延续。

可以从他身上学什么

  • 跨语言思考：用 Rust 的所有权理解 Swift 并发，用 SwiftUI 理解 React。
  • 做速查表：帮别人跨越技术栈，是最受欢迎的开源形式之一。
  • 从第一性原理写文章：讲清楚「为什么」，而不只是「怎么做」。
  • 白天 vibe，晚上 real：拥抱 AI，但保持亲手写底层代码的能力。
