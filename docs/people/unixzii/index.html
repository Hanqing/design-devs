他到底在做什么？

Cyandev 的作品和文章有一条主线：跨语言、跨平台地理解同一个问题。用 SwiftUI 理解 React（反过来也一样），用 Rust 的所有权理解 Swift 的并发隔离，用 Chromium 的服务机制给 Electron 设计扩展系统。他的博客很少写「怎么做」，更多在写「为什么」。

2026 年，他把这种好奇心用在了 AI Agent 上：用 Rust 写了一个类似 Claude Code / Codex 的轻量嵌入式 Agent 框架 little-agent，又做了在浏览器里浏览 Agent 会话日志的 agent-explorer；10 月发布的 SimRun 则能把 iOS 模拟器里的 App 直接跑在 Mac 上。

本页依据 cy4n.dev（含 About 与文章）、GitHub 个人主页与仓库 README、X 资料整理，资料截至 2026 年 10 月。

代表作品详解

ibackupextractor ↗

2023Rust★1.3 千

iOS 备份文件并不按原始目录结构存储，想从某个 App 的沙盒里取回一个文件非常困难。这个工具可以把整个备份归档还原成 iPhone / iPad 上原来的文件系统布局，让你像浏览普通文件夹一样查看。Mac 用户可以直接从 GitHub Releases 下载。
