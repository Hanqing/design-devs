Morten Just：做出来，发出去，让人能试

他在 Google 做了大约十年 UX 设计师，参与过 Google 地图、Android 和公司内部孵化器的项目；离开后创办了 Otato 公司，在苏黎世做 Rotato：一款把截图放进 3D 设备模型、几分钟就能做出产品动画的 Mac 应用，官网称有 20 万以上的用户。他的另一个产品 Convert3D 是在浏览器里本地转换 3D 模型格式的免费工具，自 2023 年起累计用户超过 220 万。他是那种想到就做、做完就发的人：GitHub 上有 161 个公开仓库，X 简介写着「I post stuff you can try」。

他到底在做什么？

Morten 的主线是让设计师更快做出好看的产品展示。Rotato 把截图或录屏放进 iPhone、MacBook 等 3D 模型，拖动时间线就能生成产品动画，后来又延伸出网页版、视频编辑器 Rotato Edit 和无时间线的 Rotato Video。

另一条线是浏览器内的免费工具：Convert3D 在本地完成 STEP、FBX、OBJ、USDZ 等格式的转换，文件不上传服务器，已经支持 WebMCP 让 AI Agent 直接调用；Rotato Tools 提供压缩、裁剪、变速等视频小工具。最近他还在做给 Agent 用的一次性邮箱 Agent’s Inbox。

观点

他在 X 上分享大量用 AI 做原型的实验：让 Grok 机器人接管 iPhone 锁屏、发实时活动；让 Agent 为一道菜和一家超市生成一整个购物应用；用 ChatGPT 生成可点击的移动端原型。他也做过一个实验：用脚本把 Raycast 和纯原生的 Tinycast 各打开一百次，结果发现基于 Web 和 Node 的新版 Raycast 反而更快。

可以从他身上学什么

  • 做能试的东西：链接比描述更有说服力。
  • 把自己的痛点变成产品：Android Tool 来自设计工作。
  • 免费工具是好入口：Convert3D 带来数百万用户。
  • 本地处理是卖点：不上传就是隐私保障。
  • 用数据回答争论：原生还是 Web，测一测再说。
