TA 到底在做什么？

Dax 在做 opencode：一个开源、可以接任意模型的编程 Agent，有终端界面、网页和桌面客户端。它从一开始就是客户端 / 服务端架构，所以可以让两个客户端并排运行，让 Agent 互相比较；也可以让 opencode 在 Slack 的一个线程里持续汇报进度、截图和视频，团队随时能进来看。

TA 对行业潮流常有不同意见：大家都说单仓库（monorepo）对 Agent 好，他们却刚换成了多仓库；TA 也观察到，AI 让人「拒绝别人做的东西」时不再那么内疚，因为做出来的成本低了。团队还办了一个叫 Rebase 的活动，最近一位单人参赛者赢得了 5,000 美元。
