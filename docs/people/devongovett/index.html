Devon Govett：零配置，极快

他是零配置 Web 构建工具 Parcel 的作者（★4.4 万），也是用 Rust 写的 CSS 解析、转换、打包和压缩工具 Lightning CSS 的作者（★7.7 千），一丝等人也是 Lightning CSS 的核心成员。在 Adobe，他参与 React Aria 和 React Spectrum：一套帮助开发者构建自适应、无障碍、稳健体验的 React 库，React Aria 的组件被大量网站和组件库采用。更早之前，他写了 Node 和浏览器通用的 PDF 生成库 PDFKit（★1.1 万）、字体引擎 fontkit 和 JavaScript 音频解码框架 Aurora.js。2026 年他在为 Parcel v3 设计新的打包算法，并发布了完全用 CSS 滚动吸附实现手势的 React Aria Sheet 组件。

他到底在做什么？

Devon 同时推动两件事：让构建工具更快、更省心，以及让组件天生无障碍。Parcel 的口号是「a build tool for the rest of us」：从开始一个项目、迭代调试到发布，「不用再折腾配置」。Lightning CSS 用 Rust 写成，解析和压缩大文件只要几毫秒。

React Aria 则把无障碍和交互细节封装好：最近的 NavigationTree 组件支持方向键移动、展开折叠、Tab 进入操作按钮；新的 Sheet 组件的滑动手势完全用 CSS 滚动吸附和视图时间线实现，「没有任何 JS 手势处理或动画」，所以能得到和原生一致的高帧率惯性与弹性。他度假订营地时，发现 recreation.gov 用的正是 React Aria 的日期选择器。

观点

this is entirely built with CSS scroll snapping and view timelines – no JS gesture handling or animations.

— Devon Govett，X，2026-10（React Aria Sheet）

他的思路是尽量交给浏览器：能用 CSS 做的手势就不用 JS，能用标准测试验证的解析就去跑标准测试。

可以从他身上学什么

  • 零配置是一种设计。
  • 关键路径用 Rust 重写。
  • 无障碍要做到组件底层。
  • 能交给浏览器的就交给浏览器。
  • 用标准测试套件验证你的实现。
