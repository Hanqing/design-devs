Antoine van der Lee：教 15 万开发者写更好的应用

TA 住在荷兰阿姆斯特丹，从 2009 年开始开发 iOS 应用，曾是 WeTransfer 的 Staff iOS 工程师，负责月活数百万的 iOS 应用开发。现在 TA 是独立开发者，经营 SwiftLee：每周更新的 Swift 博客 avanderlee.com、发给 3 万多名订阅者的 SwiftLee Weekly 周报、Swift 并发等付费课程，以及 Mac 应用 RocketSim。RocketSim 给 Xcode 的 iOS 模拟器加了 30 多种工具：测试、调试、网络监控、截图录屏、无障碍检查、应用动作，还能让 AI Agent 自动操作模拟器，官网称它是「Apple 推荐的必备开发者工具」。2026 年，TA 发布了一系列给 AI 编程工具用的 Agent Skills（SwiftUI、Swift 并发、Swift Testing、Core Data、Xcode 构建优化），其中 SwiftUI Agent Skill 获得 3.7 千颗星。TA 还维护着 App Store Connect 的 Swift SDK。

TA 到底在做什么？

Antoine 把博客、周报、课程和工具做成了一个整体：免费的博客和周报吸引读者，五天免费邮件课程「Swift Concurrency Playbook」引向付费的 Swift 并发课程，RocketSim 则是日常开发里天天用得到的工具。最近 TA 又在做 AI 基础课程，并为课程绘制如何用子 Agent 高效管理上下文的示意图。

TA 的 Agent Skills 采用开放的 Agent Skills 格式，把 SwiftUI 最佳实践、Swift 6 迁移、并发安全、Core Data 建模和 Xcode 构建优化的经验交给 AI 编程工具。TA 认为 Agent 写 SwiftUI 视图越来越多，但还不擅长保证性能、避免不必要的重绘，所以要教它用 Instruments。
