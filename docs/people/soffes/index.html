Sam Soffes：App Store 第一天就在的人

2008 年 iPhone SDK 发布时，他写的 Bible 应用在 App Store 开张的第一天就上架了，后来被极多的人使用，他说「这让人很谦卑」。此后十几年，他在 Lyft、Venmo、GitHub、Hipstamatic、Houseparty 等公司和客户项目里做 iOS 与 Mac 开发，也做自己的应用：待办应用 Cheddar、给截图打码的 Redacted、取色和对比度工具 Contrast；最近几年他在 Apple 做 Podcasts。现在他离开了 Apple，开着自己改装的露营车去潜水、徒步，「去看看外面有什么」。他开源的 SAMKeychain 有五千多颗星，Braun 风格的时钟屏保 Clock.saver 也很受欢迎。他在 X 上的简介是：「I'm not here anymore.」

他到底在做什么？

Sam 现在主要在生活，而不是在发布软件。他的博客近几年以年度回顾和潜水游记为主（菲律宾、科苏梅尔），偶尔写技术笔记，比如在 Apple Silicon 上装 Ruby 和 Homebrew、在 LLDB 里调试 JSON 数据、用 Home Assistant 把 Sonos 接进 Siri。

他早年的开源项目影响了很多 iOS 开发者：SAMKeychain 让钥匙串读写变得简单，SSToolkit 是一个从 2008 年开始的「iOS 好东西合集」；他把 Redacted 和 Contrast 的源码公开存档，「仅供学习」。
