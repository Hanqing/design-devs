TA 到底在做什么？

在公司里，笑林负责的是几条大产品线的动效：资讯 App、VR 视频、AI 手机。在 GitHub 上，TA 做的是让动效可以被精确传递的工具：缓动函数、弹簧参数、圆角曲线，这些在设计稿和代码之间最容易「走样」的东西。

2026 年起，TA 把这套能力带进 AI 编程：web-shader-extractor 让 Agent 先锁定网页上的渲染画面，记录 Shader、资源、渲染图、时序和输入，再生成一个和原效果对得上的本地基线，最后整理成可编辑的项目。

代表作品详解

web-shader-extractor ↗

2026Agent Skill★765

看到一个网站背景特效很漂亮，想知道它怎么做的？这个 Skill 的工作顺序是：锁定目标画面 → 追踪源码或运行时证据 → 做出可运行的基线 → 再整理成项目。它明确写着不用于普通的 DOM/CSS 页面克隆，只针对 WebGL、WebGPU、Canvas 和 Shader。

安装方式是 npx skills add，README 中英双语，并致谢了贡献 2D Canvas 提取方案的合作者。

smooth-corners ↗

2026CSS · npm

把 Figma / iOS 风格的「平滑圆角」转换成 CSS 的 border-radius + corner-shape: superellipse(K)。零依赖、渐进增强：浏览器不支持时退回普通圆角。默认平滑度 0.6，对应 Figma 的 60%。
