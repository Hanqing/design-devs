NIX：学习、创造、分享

TA 到底在做什么？

NIX 的作品有一条清晰的脉络：把自己反复遇到的麻烦自动化。分享到微信和微博的官方 SDK 太难用，就写 MonkeyKing 绕开它们；权限请求代码太啰嗦，就写 Proposer；键盘动画容易出错，就写 KeyboardMan；手写 JSON 模型太累，就从 Coolie 一路做到 Ducky。

TA 偏爱文档型 App：Ducky 和 Anycode 都基于文档模型，数据就在你自己的文件里，可以随时迁移、备份和分享。2026 年 1 月的新作 Crowfi 是一个 Mastodon 客户端，「快、干净，尊重我们使用联邦宇宙的方式」。

  3. 2015

  4. 2015–2016

    Baby 与 Redstone

    Baby 是 Coolie 的继任者，支持 Swift 4 的 Codable、能处理嵌套 JSON；Redstone 是一个状态机库。

  6. 2020–2021

    Ducky 与 Anycode

    2020 年 9 月上架 Ducky Model Editor；2021 年底上架代码片段管理与配图工具 Anycode。

  7. 2023

    Ananda 与 Sensei

    基于 yyjson 的高性能 JSON 模型解码库 Ananda；基于 OpenAI API 的 Mac App Sensei。

  8. 2025–2026

    提醒你让眼睛休息的 GazeAway、在桌面上挂春联的 Couplets by NIX，以及 2026 年 1 月的 Mastodon 客户端 Crowfi。
