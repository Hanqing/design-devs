NIX：学习、创造、分享

2015 年，TA 是开源社交 App Yep 的主力 iOS 开发者，提交数六千多次；同一时期写下 MonkeyKing、Proposer、KeyboardMan 等一批 Swift 库，维护着三千多星的翻译与开发笔记仓库。如今 TA 做 Ducky、Anycode 这样安静好用的文档型 App。

一句话：「I'm NIX. As an app developer, I make apps to help others.」一个话不多、作品很扎实的 Swift 老兵。

代表作：Yep（Catch 团队开源社交 App，★5.9k）、dev-blog（翻译与开发心得，★3.9k）、MonkeyKing（★2.7k，分享到国内社交平台）、Proposer（权限请求）、Coolie / Baby（从 JSON 生成模型）、Sensei（OpenAI Mac App）；App：Ducky、Anycode、HandTalk。

为什么值得关注：TA 的作品几乎都在解决同一类问题：让开发者少写重复代码。

NIX 的 X 简介只有三个词：「Learning || Creating || Sharing」。TA 的 GitHub 上第一个仓库是一份写了十多年的 dev-blog：翻译、开发心得和学习笔记，三千九百星。很多中文 iOS 开发者，是读着它入门 Swift 的。

成长与经历

  1. 2014

    dev-blog 与 Bible Assistant

    开始系统翻译和整理 iOS 开发文章，后来成为中文开发者常读的学习资源。同年写了 Objective-C 的 Bible Assistant App。

  2. 2015

    Catch 与 Yep

    在 Catch 团队与 Kevin Zhow 等人一起开发 Yep（「Meet Genius」），TA 是主力开发者，贡献了六千多次提交。Yep 后来完整开源，成为学习大型 Swift App 架构的经典范例。

  3. 2015–2016

    一系列 Swift 小库

    MonkeyKing（不依赖官方 SDK 分享到微信、微博、QQ 等）、Proposer（让权限请求更简单）、KeyboardMan（键盘动画）、Wormhole（App 与扩展间通信）、Ruler（按屏幕尺寸取值）、Coolie（从 JSON 生成模型）。

  4. 2017

    Baby

    「从 JSON 文件创建模型，连婴儿都能做到」，是 Coolie 的继任者，也是后来 Ducky 的前身。

  5. 后来

    文档型 App

    Ducky Model Editor：从 JSON 推断 JSON Schema、Swift、Kotlin、Dart、Go、Proto 模型；Anycode：管理代码片段并生成漂亮图片；HandTalk：在 iMessage 里和朋友下围棋。

  6. 2023

    Sensei

    基于 OpenAI API 的 Mac App。

设计与手艺

NIX 的库都有很好的命名：MonkeyKing、Proposer、KeyboardMan、Wormhole、Ruler、Coolie（苦力）、Baby。一个好名字本身就是一种设计，让人一眼记住它是做什么的。

TA 偏爱「文档型 App」：Ducky 和 Anycode 都基于文档模型，数据在你自己的文件里，可以随时迁移、备份和分享。

可以从 TA 身上学什么

  • 翻译与笔记也是作品：dev-blog 的影响力不亚于任何一个库。
  • 自动化重复劳动：从 Coolie 到 Ducky，十年只做好一件事。
  • 名字要好记：好名字让开源项目自带传播力。
  • 参与一个完整产品：Yep 让 TA 积累了大型 App 的全部经验。
