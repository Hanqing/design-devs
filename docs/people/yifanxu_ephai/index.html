Yifan Xu：给每个 Agent 一个用完即弃的文件系统

多伦多大学计算机系出身，在新加坡南洋理工读 AI 硕士时退学，现居中国。TA 创办 Ephemeral AI Lab，用 Rust 写了 LayerFS：每个 Agent 都能挂载一个完整、可写、却不需要复制底层数据的工作区，做完工作、提交改动，然后消失。

LayerFS 的 README 用五条核心理念介绍自己：短暂计算（计算只在命令运行时存在）、去中心化 Agent（不同电脑上的 Agent 共享一个无服务器存储）、多 Agent 协调（一个项目多个分支，一个分支多个 Agent）、递归文件系统（任意深度 fork 任意提交）、极致的存储优化。

设计与思考

LayerFS 的核心设计是「工作区是短暂的，历史是持久的」。这和 Git 的思想一脉相承，但被下沉到了文件系统层，让 Agent 不需要理解 Git 也能安全地并行工作。

README 主动写明这是开发者预览、没有断电持久性保证，并附上发布记录与豁免说明。对基础设施项目来说，这种坦诚非常重要。

可以从 TA 身上学什么

  • 在底层解决 Agent 的问题：文件系统级的隔离比约定更可靠。
  • 勇于离开既定路径：退学去做自己相信的东西。
  • 诚实标注成熟度：预览版就写清楚限制。
  • 研究与工程并行：开放论文和可复现材料。
