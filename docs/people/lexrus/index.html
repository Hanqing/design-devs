Lex Tang：让文字优雅变形的人

2002 年开始做 Web，在土豆网、携程做过前端与设计，2011 年自学 iOS。他在 Swift 发布几周后写出的 LTMorphingLabel，让 UILabel 的文字切换像粒子一样燃烧、坠落、蒸发，成为 Swift 早期最受欢迎的开源动效之一。如今他负责产品和 UI 设计，把编码交给 AI Agent，业余独立做了八款 App。

LTMorphingLabel 的 README 第一句说，它最初是为了模仿苹果在 WWDC 2014 上展示的 iOS 8 QuickType 动画。一个 Web 设计师出身的开发者，看到一段几秒钟的文字动画，就在 Swift 发布几周后把它做成了一个开源库，还额外设计了燃烧、蒸发、像素化等一整套效果。这就是 Lex 的风格：关注文字在变化那一瞬间的情绪。

他到底在做什么？

Lex 的作品有两个时期。开源时期（2012–2016）：中文图标字体、iOS 打包脚本、运维 Playbook、LTMorphingLabel、VPNOn，以及一堆用来学习 Swift 的小组件。独立 App 时期（2020 至今）：一系列「补上系统缺失」的 Mac 和 iOS 小工具。

这些 App 都很有「系统补丁」的味道：SwiftyMenu 是「Finder 缺失的菜单」；cmd+x 让 Mac 上的 Command+X 真正能剪切文件，并用 Control+Option+Delete 打开活动监视器，「保留 Windows 的肌肉记忆」；Sharptooth 在菜单栏一键连接蓝牙设备；CouchVox 把 Apple TV 的 Siri 遥控器变成 Mac 的控制器和听写麦克风。

  2. 2011

    通过自学进入 iOS 开发，熟练掌握 Objective-C；也是 CocoaPods 在国内的早期推广者。

  3. 2012–2013

    fontdiao（Font 屌）：用于 Web 和 iOS 的中文图标字体，附国内常用网站与应用的徽标 SVG；ios-makefile：几秒钟打包分发 IPA，还会把 git 提交和分支叠在 App 图标上；PhoneticContacts：给联系人加上拼音，英文系统下也能按拼音分组。

  4. 2014

    Swift 元年

    6 月写出 LTMorphingLabel 和 LTBouncyPlaceholder；7 月发布 ios-dev-playbook，口号是「不会运维的 iOS 开发不是好设计师」；12 月发布 VPNOn，「像英雄一样打开 VPN」。

  5. 2015–2017

    多家公司与更多小作品

    用 PaintCode 做的果冻开关 LTJelloSwitch、算法练习 LeetCode.swift、Swift 文件的 Quick Look 插件，以及「中国程序员常读错的英文单词」App 花灰（Huahui）。

  6. 2020

    RegEx+

    用 SwiftUI 写的正则测试工具，后来加入交互式流程图，可视化地拆解每个正则模式。

  7. 2021–2022

    SwiftyMenu

    「The missing Finder menu」，把常用的 App、脚本和终端命令放进 Finder 右键菜单：右键任意文件或文件夹，就能打开 App、运行 Shell 脚本或 AppleScript，或者在 Terminal、iTerm2、Ghostty 里打开，选中的路径自动作为参数传入；源码开源。

  8. 2025–2026

    Agentic Coding 与八款 App

    开始用 Agent 工具编码：LiveExtractor（6 月）、Sharptooth（7 月）、cmd+x（10 月）、DesignMyClock 屏保（12 月）、SubList 订阅追踪（2026 年 1 月），以及 CouchVox。

代表作品详解

LTMorphingLabel ↗

2014Swift★8.1 千

「Graceful morphing effects for UILabel written in Swift.」一个 UILabel 子类，文字改变时不是生硬地替换，而是逐字符地变形：默认的 Scale，以及 Evaporate（蒸发）、Fall（坠落）、Pixelate（像素化）、Sparkle（闪光）、Burn（燃烧）、Anvil（铁砧砸下）等效果。它被标为「实验性」，却成了 Swift 早期最受欢迎的开源动效之一，2026 年仍有更新。

VPNOn ↗

2014Swift已归档

可以从他身上学什么

  • 设计背景是优势：Web 设计的积累让他的开源库自带美感。
  • 第一时间拥抱新语言：Swift 发布几周就出精品。
  • 让 AI 写代码，自己做设计：一个人也能维护八款 App，并坦然说明分工。
  • 补上系统缺失的那一块：Finder 菜单、剪切文件、蓝牙一键连接，都是每天都会遇到的小痛点。
