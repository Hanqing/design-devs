Lex Tang（汤圣罡）iOS / macOS 开发者 · 前 Web 设计师

Lex Tang：让文字优雅变形的人

2002 年开始做 Web，在土豆网、携程做过前端与设计，2011 年自学 iOS。他的 LTMorphingLabel 让 UILabel 的文字切换像粒子一样燃烧、坠落、蒸发，成为 Swift 早期最受欢迎的开源动效之一。如今他用 AI Agent 独立做了八款 App。

一句话：「he/him/husband/dad」，一个有着二十多年 Web 与设计背景的 iOS / macOS 开发者，早期 CocoaPods 的推广者之一。

代表作：LTMorphingLabel（★8.1k）、VPNOn（★4.5k）、fontdiao（中文图标字体）、ios-dev-playbook、SwiftyMenu（Finder 右键菜单增强）；App：SubList、CouchVox、Sharptooth、RegEx+、LiveExtractor、cmd+x、DesignMyClock。

工作经历：土豆网、携程、现代传播、壹钱包、No NDA、米哈游、PixelForce。

Lex 的个人网站一句话介绍自己：「Hi, I'm Lex Tang. iOS/macOS developer, he/him/husband/dad. Building indie iOS & macOS apps.」在 App 页面，他坦白地写：「从 2025 年起我一直在用 Agentic 编程工具，主要依赖 OpenAI Codex、Google Antigravity 和 SpaceXAI Grok。」产品设计和 UI 设计，则都由他自己完成。

成长与经历

  1. 2002

    从 Web 开始

    开始 Web 开发，先后在土豆网、携程等互联网公司工作，深入理解设计原则、规范与标准。

  2. 2011

    自学 iOS

    通过自学进入 iOS 开发，熟练掌握 Objective-C；同时是 CocoaPods 的早期推广者，帮助大量第三方库接入这个依赖管理工具。

  3. 2012–2013

    中文图标字体与自动化

    fontdiao：可用于 Web 和 iOS 的中文图标字体，附国内常用网站与应用徽标 SVG；ios-makefile：几秒钟打包分发 IPA。

  4. 2014

    Swift 元年：LTMorphingLabel 与 VPNOn

    Swift 发布几周后就写出 LTMorphingLabel：Evaporate、Fall、Pixelate、Sparkle、Burn、Anvil 等多种文字变形效果。同年的 VPNOn 让你「像英雄一样打开 VPN」；ios-dev-playbook 的口号是「不会运维的 iOS 开发不是好设计师」。

  5. 2015 起

    多家公司的 iOS 开发

    在现代传播、壹钱包（yqb.com）、No NDA、米哈游、PixelForce 等公司担任 iOS 开发；业余写了 LTJelloSwitch（用 PaintCode 做的果冻开关）和 LeetCode.swift。

  6. 2022–2026

    独立 App

    SwiftyMenu 补上 Finder 缺失的右键菜单；之后陆续做了订阅追踪 SubList、CouchVox、蓝牙工具 Sharptooth、正则工具 RegEx+、LiveExtractor、cmd+x、DesignMyClock 等八款 App。

lex.sh 简洁得像一张名片：名字、一行身份、两个按钮（Résumé、My Apps）和一排社交图标。

App 目录页写着「Catalog · 8 apps」，每款 App 有详细的功能描述和下载按钮；简历页则用一段文字讲完二十多年的职业路径。

设计与手艺

LTMorphingLabel 是一个「设计师写代码」的典型作品：它关注的是文字在变化那一瞬间的情绪，燃烧、蒸发、像素化。这种对动效的执着，来自他多年的 Web 设计背景。

如今他把编码交给 AI Agent，把产品和 UI 设计留给自己。这也许是很多设计型开发者在 AI 时代的新分工。

可以从他身上学什么

  • 设计背景是优势：Web 设计的积累让他的开源库自带美感。
  • 第一时间拥抱新语言：Swift 发布几周就出精品。
  • 让 AI 写代码，自己做设计：一个人也能维护八款 App。
  • 为生态做推广：早期推动 CocoaPods，同样是贡献。
