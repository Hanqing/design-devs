William Gustafson：让 Mac 保持清醒的人

TA 做的 Amphetamine 是 Mac 上最受欢迎的防休眠工具之一，免费、强大、上架十多年。2020 年底，苹果以「宣传管制药物」为由威胁下架这款已有 43 万次下载的应用；TA 公开申诉、请社区声援，苹果最终改口，承认这个名字和药丸图标是一种「比喻」。

TA 到底在做什么？

William 十多年只认真做一件事：让 Mac 在你需要的时候保持清醒。系统自带的 caffeinate 只是一个开关，Amphetamine 却有「会话」和「触发器」：按时长、按某个 App 运行、按文件下载、按外接显示器、按电量、按 Wi-Fi 网络……普通用户在菜单栏点一下就开，专业用户可以组合出几十种自动化规则。

系统做不到的事，TA 就另想办法：Amphetamine Enhancer 让不满足苹果条件的 Mac 也能用闭盖模式；Power Protect 在合盖运行时保护电池；Expanded Process Detection 让 Amphetamine「看见」更多进程。

本页依据 SaveAmphetamine 仓库的完整记录、GitHub 仓库与 README、Mac App Store 资料、MacRumors / 9to5Mac / AppleInsider 报道和 X 资料整理，资料截至 2026 年 10 月。

成长与经历

  1. 2008–2012

    注册 X 与 GitHub

    早期 GitHub 仓库多是给 Apple 提交 Bug 报告用的示例项目：USB 集线器崩溃、菜单栏多显示器问题等。

  2. 2014.11

    Amphetamine 上架

    免费的 Mac 菜单栏防休眠工具，App Store 描述自称「the most awesome keep-awake app ever created for macOS」。

  3. 2020.01

    Amphetamine Enhancer

    配合 Amphetamine 5.0，增加闭盖模式等新能力；同时开放本地化资源，让社区帮忙翻译。

  4. 2020.12–2021.01

    #SaveAmphetamine

    苹果援引指南 1.4.3（禁止鼓励使用违禁药物），要求改名改图标。TA 公开全过程、提起申诉，发起推文、Reddit 帖子和 Change.org 请愿；MacRumors、9to5Mac、AppleInsider 等广泛报道。1 月 2 日苹果来电，接受申诉。

  5. 2021

    疫情期间的小工具

    做了菜单栏应用 SeeVS，帮人查看 CVS 门店的新冠疫苗余量；还有自动重命名 CleanShot X 截图的脚本。

  6. 2023–2024

    Apple Silicon 与 Sonoma

    发布 Power Protect 和修复 Apple Silicon 闭盖模式问题的脚本；做了 KeyJerk Reactions，用全局快捷键触发 macOS Sonoma 的视频会议反应特效。

SaveAmphetamine ↗

2020.12公开记录

一份理性的申辩书。TA 逐条论证：Amphetamine 不宣传非法药物，也不鼓励滥用处方药；在美国，安非他命是医生给发作性睡病和 ADHD 患者开的处方药；「amphetamine」是化合物的正式名称，不是街头俗称；图标里的药丸没有任何鼓励不当使用的暗示。

结果写在仓库顶部：「Amphetamine Has Been Saved!」苹果代表在电话里表示，现在认可这个词和药丸图标是在「比喻」和「医学意义」上使用。

线上形象研究

William 没有独立的个人网站。GitHub 就是 Amphetamine 的「官方文档中心」：增强工具、本地化、电量保护、脚本资源，每个仓库都写着清晰的说明，开头常是一句「Hello 👋🏼」。

观点与态度

在 SaveAmphetamine 里，TA 坦言自己「对仅凭申诉让苹果改变主意并没有太大信心」，并提前想好了两条退路：立即改名重新上架，或者继续发声等待苹果恢复。最终是社区的声音和一份逻辑清晰的申辩，让结果变了。

Apple now recognizes that the word "amphetamine" and the pill icon are being used "metaphorically", and in a "medical sense."

— William Gustafson，SaveAmphetamine

可以从 TA 身上学什么

  • 一个小工具可以做很深：防休眠这件事，TA 做了十多年。
  • 给专业用户全部开关：同时让普通用户一键可用。
  • 面对平台要据理力争：公开记录、逐条论证、礼貌申诉、寻求声援。
  • 提前准备退路：申诉失败怎么办，先想好。
  • 在限制之外想办法：沙盒做不到的，用独立工具补上。
