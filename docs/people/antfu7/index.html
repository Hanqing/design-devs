TA 到底在做什么？

Anthony 近两年的重心是开发者工具（DevTools）：Devframe 是一个与框架无关的 DevTools 基础，Vite DevTools 可以检查 Vite 打包和流水线的中间状态，Nuxt DevTools 帮你看清自己的 Nuxt 应用。2026 年 9 月起，Nuxt、Vue、Vite 三套 DevTools 终于「既正交又统一」，不必再把 Vue 或 Vite 的功能重复打包进 Nuxt DevTools。

TA 也在把 AI 编程接入自己熟悉的工作方式：@antfu/skills 像 ESLint 配置一样，是一套从生态里精选的 Agent 技能包，通过 skills-npm 让 npm 包能自带技能或声明「技能依赖」；pulls.review 把 Pull Request 的改动按逻辑分组并给出摘要，在命令行里运行时还能调用本地 Agent 做分析。
