面条：把一切都跑在 Cloudflare 上

TA 在南京，自称「前端切图仔，后端三脚猫，运维挖坑人，AI 门外汉」，是专注前端的 Web 开发工程师，也是自托管和 Homelab 爱好者。TA 最受欢迎的作品是 Sink（★7.2 千、被复刻 5 千多次）：一个「简单、快速、安全」、带访问统计、完全运行在 Cloudflare 上的短链接服务。TA 的其他项目也都很有想法：BroadcastChannel 把 Telegram 频道变成微博客；Hacker Podcast 每天自动抓取 Hacker News 热门文章，用 AI 生成中文总结和播客；bm.md 是为微信公众号等平台设计的 Markdown 排版助手；ssh-ai-chat 让你通过 SSH 和 AI 聊天；还有号称「最长域名」的网址加长器 looooo…ong。2026 年 10 月，TA 发布了自己第一款原生 iOS 应用 SeeEat，帮你和伴侣找到都想吃的菜。

TA 到底在做什么？

面条的大部分项目都有一个共同点：用 Cloudflare 的免费或廉价服务，做出别人可以一键部署的小产品。Sink 用 Workers 和 Analytics Engine，cloudflare-worker-image 用 Worker 加 Container 处理图片，ip-api 用边缘函数返回 IP 和地理位置，cloud-code 和 cloud-claw 把 OpenCode、OpenClaw 这样的 Agent 搬到 Cloudflare Containers 上。

TA 也在做「由 AI 驱动的内容」：Hacker Podcast 每天自动生成中文科技播客，AIGC 周刊由 Agent 精选内容。bm.md 则解决中文写作者的老问题：把 Markdown 排版好，复制到微信公众号里不走样，还能生成图片和矢量 PDF。
