Gus Mueller：一家「飞肉」公司的 23 年

2003 年，他在西雅图北边创办了 Flying Meat，目标只有一个：做一款更好的 Mac 应用。第一款产品是获过奖的桌面维基 VoodooPad，后来是图像编辑器 Acorn。Acorn 卖了将近二十年，坚持「没有订阅」，2026 年 10 月刚更新到 8.7，加入了机器学习主体选择、去除物体、修复画笔和 JPEG-XL 支持。他还做了节点式批量图像处理工具 Retrobatch。很多 iOS 开发者也许没用过他的应用，却用过他的代码：SQLite 封装库 FMDB 在 GitHub 上有 1.38 万颗星，在 Objective-C 时代被大量 iOS 和 Mac 应用用来访问数据库。他自称「数字木匠，像素机修工」。

Flying Meat 这个名字来自密苏里州一条攀岩路线：一只倒霉的鹿从崖顶跳了下去，被第一个攀登这条线的人看见了，于是路线就叫「飞肉」。官网 About 页把这个故事讲得很认真，就像 Gus 对待 Acorn：一个人、一家小公司，二十多年只做一件事，「做一个更好的 Mac 应用」。

他到底在做什么？

Gus 的主力是 Acorn：一款「独一无二、没有订阅、没有麻烦」的 Mac 图像编辑器。Acorn 8 系列加入了很多新能力：Synth Fill 画笔一抹就能去掉画面里多余的人和车；修复画笔；从头重写的笔刷引擎；机器学习主体选择和实况文本；用 CSV 批量生成图形的数据合并；LUT 调色；超分辨率放大。它支持快捷指令和 AppleScript，也支持 JPEG-XL。

Retrobatch 是另一个方向：用节点连成工作流，批量处理成千上万张图片。他在 GitHub 上公开了 Retrobatch 的示例工作流和脚本，也维护着 Acorn 的插件 SDK。

代表作品详解

Acorn ↗

Mac图像编辑v8.7.1

支持 macOS 14 及以后的系统（包括 macOS 27），通用二进制，一次买断。单一窗口和工具栏，遵循 Big Sur 以后的 Mac 设计规范；习惯浮动面板的人也可以在设置里打开。

可以从他身上学什么

  • 一个目标做二十年：做一个更好的 Mac 应用。
  • 不订阅也能活：买断制需要持续的大版本。
  • 把内部代码开源：FMDB 本来就是自用的。
  • 跟上新技术：机器学习功能一样能进老应用。
