Chris CoyierCodePen 联合创始人 · CSS-Tricks 创办人（2007–2022）· ShopTalk Show 主持人 · 俄勒冈州本德

Chris Coyier：I like it when you like things

他住在俄勒冈州本德，是 Web 设计师、开发者、教育者和生意人。他说自己这一路「都在经营有盈利的公司，帮你把 Web 设计和开发做得更好」。2007 年到 2022 年，他运营了 CSS-Tricks，这个网站几乎是一代前端开发者查 CSS 用法的第一站，2022 年 3 月他把它卖给了 DigitalOcean。2012 年，他和 Alex Vazquez、Tim Sabat 一起上线了 CodePen，一个面向前端的浏览器内 IDE 和「社交开发环境」，现在正在内测支持通过 import map 引入包的 CodePen 2.0。他和 Dave Rupert 一起主持关于网站设计与开发的播客 ShopTalk Show，写过《Practical SVG》等书，也常在 Frontend Masters 博客上写现代 CSS。他在 chriscoyier.net 上几乎每天都写一篇短博客，还把自己全部的历史推文导进了这个 WordPress 网站。

他到底在做什么？

Chris 现在把主要精力放在 CodePen：一个在浏览器里写 HTML、CSS、JavaScript 并立刻看到结果的环境，也是前端设计师和开发者分享作品的社区。CodePen 2.0 正在内测，加入了通过 import map 使用 npm 包的能力，他会在 Twitch 上直播试用。

他依然热爱写 CSS：他认为 SVG 的 linked-parameters 会改变网站图标系统的做法，研究过用 conic-gradient() 画三角形，直播从零写自己的 CSS reset，每年在 Frontend Masters 博客上总结「你应该知道的现代 CSS」。
