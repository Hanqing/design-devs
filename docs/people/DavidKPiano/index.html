David Khourshid：让不可能的状态真的不可能

他住在佛罗里达州奥兰多，是 Stately 的创始人、XState 的作者，X 简介写着「Making state machines at @statelyai · I play piano」。XState 是一个基于状态机、状态图和 Actor 模型的状态管理与编排库，GitHub 上有三万颗星，让复杂的应用逻辑变得显式、可视化、可测试。Stately 在它之上做了一个可视化编辑器：拖拽画出流程图，自动生成 XState 代码、文档和测试，还能直接模拟运行。这两年他把状态机带进 AI：Stately Agent 让 Agent 的控制流由状态机掌握，模型只能挑合法的事件，「让非法的 Agent 动作变得不可能」。他还在 Frontend Masters 上讲过多期状态机课程。

他到底在做什么？

David 的核心主张是把逻辑画出来。Stately 官网说：从前端用户流程到后端工作流，都可以用可视化编辑器构建和部署，让它成为单一事实来源；代码、图表、文档、测试生成都在一处，「不再有孤岛，永远保持最新」。AI 在每个阶段都能借助状态机帮忙，人类则用可视化编辑器审核和改进。

他认为用状态机定义 Agent 逻辑「被严重低估」：状态机不是死板的工作流，而是 Agent 可以自主重新组合、改进的乐高积木，而且人能读懂。他的说法是「确定性的内核，Agent 化的外壳」。2026 年 10 月，他还开源了 @statelyai/graph，一个以纯 JSON 表示图、能在 DOT、Mermaid、GraphML 等格式间转换的图算法库。
