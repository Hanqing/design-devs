TA 到底在做什么？

WeZZard 的工作可以分成两段。前一段在 Apple 平台和编译器：写 Swift 宏、研究 LLVM 数据结构、拆解 SwiftUI 的「编程语言本质」，在字节跳动参与 UI 框架 DanceUI。后一段从 2025 年开始，转向 AI Agent：做本地编程 Agent 的 PTY harness、从会话日志里挖对话的 minelogue、给纯文本模型补视觉能力的 opencode-vision，以及研究模型可解释性的 jlens-qwen36。

两段工作的共同点是形式决定行为：产品的外形、语言的语法、示例对模型的塑造。这和 TA 的工业设计训练一脉相承。

代表作品详解

jlens-qwen36 ↗

2026Python · MLX可解释性

「A visual debugger for a local Qwen3.6-27B (4-bit) on Apple Silicon / MLX.」它为本地模型拟合一个 Jacobian 透镜，显示模型在每一层、每个 token 位置正在把输出推向哪些词。

TA 用它研究「示例如何塑造模型行为」：为什么规则写得再清楚，模型还是会被提示里的例子带偏。项目有一个只读的在线演示 jlens.wezzard.com。

opencode-vision ↗

2026JavaScriptOpenCode 插件

让 OpenCode 里的纯文本主模型（GLM-5.2、DeepSeek V4 等）把视觉任务委托给你已有订阅里的视觉模型：便宜的模型负责推理，贵的模型只在需要看图时出场。

TA 在《How I got 1,300+ Downloads in 24 Hours》里复盘了这个插件在 npm 上 24 小时下载 1,300 多次的过程。README 明确声明它是社区项目，与 OpenCode 官方无关。

COWMacro ↗

2023Swift 宏

一个名为 @COW 的 Swift 宏：把 struct 改成写时复制语义，复制性能提升 N 倍，N 是 struct 里堆存储的数量。比如一个包含 String、Array、Set、Dictionary 的 struct，复制性能可以提升 4 倍。
