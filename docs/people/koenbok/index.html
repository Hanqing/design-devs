Koen Bok：一半设计师，一半程序员

他在阿姆斯特丹和 Jorn van Dijk 一起经营过设计工作室 Sofa，做 Mac 应用和网站；2011 年 Facebook 收购了 Sofa，他到 Facebook 做产品设计师，负责消息、广告和视频。离开后，两人联合创办了 Framer：最初是一个开源 JavaScript 原型框架，用真实的弹簧物理设计交互动画，后来成为桌面设计工具，2022 年前后又转型为面向设计师的网站构建工具。2025 年 8 月，Framer 完成 1 亿美元 D 轮融资，估值 20 亿美元。他和 Jorn 还一起运营早期基金 Festina。他形容自己「一半设计师，一半程序员，再加一点创业者」。

2008加入 X

Framer 最早的开源 README 写着：「用真实的弹簧物理或 3D 效果来动画，一切皆有可能。」十多年后，Koen 在 X 上发的是另一种话：「是时候为 AI 进化模板了。模板应该是你 Agent 的品味。」从原型库到设计工具再到建站平台，Framer 的形态一直在变，不变的是他想解决的问题：让设计师直接做出真实的东西。

他到底在做什么？

Koen 现在在 Framer 工作，他在个人网站上称它为「一个为网页而建的工具，很多设计师每天都在用」。Framer 让设计师不写代码就能做出可发布的网站：设计、动效、CMS、本地化、SEO 都在一个工具里。客户包括 Miro、Perplexity、Scale AI 等公司。

他的工程底子很深：早年写过 Python 静态站点生成器 Cactus（带 Mac 应用），CoffeeScript 时代的 Framer.js，以及各种小工具。在 AI 时代，他关心的是模板如何成为 Agent 的「品味」。
