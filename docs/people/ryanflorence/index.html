Ryan Florence：重新思考最佳实践

他住在犹他州，和 Michael Jackson 一起创造了 React 生态里使用最广的路由库 React Router，后来又一起做了全栈框架 Remix。他们还创办过 React Training，给公司做 React 培训，Ryan 也做了注重无障碍的组件库 Reach UI。据维基百科，Remix 最初需要付费订阅，2021 年 10 月开源；2022 年团队被 Shopify 收购，并承诺保持开源和独立。2024 年 11 月，Remix v2 并入 React Router v7 成为「框架模式」；2025 年 5 月他们宣布 Remix 3 不再基于 React，而是用自己的组件模型「拥有整个技术栈」。2026 年，Remix 3 进入候选发布阶段，React Router v8 发布并转向开放治理。业余时间他在玩滑水，还在训练会自我学习的《最终幻想 XI》游戏机器人。

Remix 官网现在写着「Re-rethinking best practices」：Web 框架积累了太多看似不可避免的复杂度和间接层，Remix 要用一路通到 Web 标准的 API 重新审视这些假设。新的 Remix 里，「状态就是 JavaScript」：组件只运行一次初始化，然后返回一个渲染 JSX 的函数，状态放在普通变量、对象或类里，而不是 hooks；「更新是显式的」：改完状态后调用 handle.update()。

他到底在做什么？

Ryan 和团队在做Remix 3：一个把服务器运行时、路由、认证、会话、数据库集成、UI 框架、资源编译、动态样式和无障碍组件整合在一起、完全基于 Web API 的「全栈」框架。它强调运行时优先，不把打包器放在架构中心；各个包可以单独使用，也可以整套用。

他在 X 上分享得最多的是 AI 带来的变化：给《最终幻想 XI》机器人设计了一套会被自动检查的 DSL 后，机器人选中真正想做的动作的比例从 58% 提高到 90%；他也观察到身边越来越多不会编程的人在用 AI 做软件，比如帮他管度假屋的五十多岁的经理，用 Codex 做了一个统一控制所有房子智能设备的面板。
