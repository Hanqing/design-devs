Sofish：给中文网页排好每一行字的人

他在 2012 年写下的 typo.css，至今仍是中文网页排版的经典参考，2026 年还在更新；2013 年的 pen 让「所见即所得 + Markdown」的网页编辑器风靡一时。多年前端生涯之后，他成立了小工作室 Built4.Fun，做「慢阅读与认真写作」的小 App：英语分级阅读器 Jinshu、给孩子的中文日记小小作家，以及刚刚上架的读书笔记书伴小书童。

2012 年的中文网页，中英文挤在一起，行高照搬英文，着重号无处可寻。typo.css 把这些问题一次理顺：字体、行高、CJK 断行、中西文间距、着重号。十四年后，它的 README 里多了「现代中文网页排版依据」和「排版契约测试」。Sofish 关心的一直是同一件事：让中文读起来舒服。

他到底在做什么？

Built4.Fun 目前有三款 App，都围绕阅读与写作：Jinshu 是分级 EPUB 阅读器，导入任意英文书，告诉你它对你是「舒适 / 适度挑战 / 困难」，并自动标注生词；小小作家让小学生对着手机讲今天发生的事，App 改写成符合年级的日记，抄到本子上拍照还能得到点评；小书童把微信读书划线、Kindle 摘录和纸书笔记汇在一处，用「今日相逢」每天带回几句旧笔记。

他的产品很照顾不同用户：Jinshu 既有订阅，也有面向 Android 和墨水屏的终身买断，Stripe 支持微信和支付宝；小书童的阅读档案保存在本机，AI 处理资料需要单独同意，普通使用无需注册。

代表作品详解

typo.css ↗

2012 起CSS2026 仍在更新

「中文网页重设与排版 CSS，面向现代中文阅读优化字体、行高、CJK 断行、中西文间距与着重号。」目标是一致化浏览器排版效果，构建最适合中文阅读的网页排版，覆盖桌面和移动平台。

新版仓库加入了设计依据文档、同类库调研、库级升级计划，以及「现代中文排版契约测试」。

观点与风格

Sofish 很少在社交媒体上发言，3.6 万关注者只看到几百条推文。他的观点藏在作品的说明里：翻译是一种责任；要么写代码要么写文档；AI 改写要「保留孩子的声音」，不是把原话抹平。

有些句子，读到时只是划了线。很久以后，才在自己的生活里读懂。

— 小书童 About 页

维度长处局限 / 需要留意

可以从他身上学什么

  • 为母语做基础设施：中文排版需要有人专门去解决。
  • 一个主题做一辈子：从排版到阅读到写作。
  • 小工作室也可以很体面：为自己和少数同好做软件。
  • 照顾不同用户：订阅、买断、墨水屏、微信支付。
  • 把隐私写进默认值：本机存储，AI 单独授权。
