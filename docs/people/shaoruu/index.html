Ian Huang：从浏览器里的 Minecraft 到 Cursor

他从高中起就在浏览器里造体素世界：2019 年用 Three.js、React、GraphQL 和 Node 写出开源 Minecraft 克隆 mc.js，后来用 Rust 重写成 MineJS，再演化成全栈体素引擎 Voxelize。据台湾 iThome 的讲者介绍，他自学编程，原本在伊利诺伊大学香槟分校读本科，被 Cursor 创始人亲自招募，休学成为 Cursor 的 2 号工程师。如今他的个人网站写着 SpaceXSI，此前在 Cursor 创始团队。

关键数字：GitHub 近一年贡献 13,340 次；X 关注者约 3 万；据 iThome，他曾是 ModernWeb 大会史上最年轻的讲者。

个人网站：一个仿 IDE 界面的作品集，内嵌可以多人在线一起搭建的体素世界 create.town。

2019加入 X

「很长一段时间里，我都没法让 Voxelize 的透明效果正确。」2026 年 10 月，Ian 写了一篇长文：玻璃、水、树叶、烟雾在体素世界里互相交叠，根本不存在一个正确的绘制顺序，每修一个排序 Bug 就会冒出下一个。最后他用 2013 年的「加权混合无序透明」算法，在不改 Three.js 源码的前提下彻底绕开排序。这个问题从大学起就困扰他，七年后终于解决。

他到底在做什么？

白天，Ian 做的是 AI 编程工具：据 iThome 介绍，他在 Cursor 设计和构建产品的核心架构，并主张早期创业公司应该专注把产品做好，而不是追逐增长指标和社交媒体热度。据维基百科援引的报道，SpaceX 在 2026 年 6 月以全股票方式收购了 Cursor 的母公司。

业余时间，他一直在做同一件事：在浏览器里跑一个可多人联机的体素世界。Voxelize 支持自定义方块与实体、实时多人和持久化世界，后端用 Rust、前端用 TypeScript 和 Three.js。

本页依据 shaoruu.io（主页与博客）、GitHub 仓库与 README、iThome Hello World Dev Conference 2025 讲者介绍、Cursor 官方博客和 X 资料整理，资料截至 2026 年 10 月。SpaceX 收购一事以公开报道为准。

代表作品详解

Voxelize ↗

2021–TypeScript · Rust★690

「A multiplayer, super fast, voxel engine in your browser!」不用安装、不用插件，在任何现代浏览器里运行持久化的多人体素世界：自定义任意形状和材质的方块，方块可以带元数据；自定义会走动、会交互的实体；实时多人同步。

create.town 是它在生产环境运行的实例，也是 Ian 个人网站的一部分。

包
npm @voxelize/core · crates.io voxelize

mc.js ↗

2019JavaScript★2,677

一个用 Three.js、React、GraphQL 和 Node 写的开源 Minecraft 克隆，是他最早被大量关注的项目。2019 年 8 月，仓库因一份与 Minecraft 相关的 DMCA 通知被 GitHub 屏蔽，至今无法访问。他随后改名为 MineJS 并用 Rust 重写；MineJS 的 README 特别声明，项目只是出于热爱，不隶属于 Minecraft 或任何授权引擎，素材均为免费授权。

typehere.app ↗

2023–2026Web★115

他常用的 typehere.co 下线后，他自己做了一个：一开始只是把内容存进 localStorage 的文本框，后来加了 Vim 模式、⌘K 模糊搜索、工作区和导入导出。

  • 2024-06-09
    What is Voxelize?

For the longest time I couldn't get transparency right in Voxelize.

— Ian Huang，Transparency without sorting

这篇文章写得非常工程：问题是什么、为什么排序注定失败、算法怎么接进 Three.js、水面折射和彩色玻璃怎么特殊处理、帧时间从 3.96 毫秒降到 3.08 毫秒、还有哪些已知局限。他也坦白，这一版是在 AI 模型的帮助下实现的。
