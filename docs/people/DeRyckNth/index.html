DeRyck：给人和 AI 一起写的 Markdown 做一个本地工作台

当越来越多的文档、笔记和代码由 AI 写成，人需要一个地方去「读」和「审」。DeRyck 做的 Resomark 是一个用 Swift 原生构建的 Mac Markdown 应用：所见即所得的实时预览、以渲染后的形式审阅 Git 差异、把你和 AI 一起工作的文件夹钉在一个侧栏里。它说自己「比 IDE 轻，比 Obsidian 轻」。

Resomark 的常见问题里有一句很干脆的回答：「Resomark 是 AI 应用吗？不是。它不生成文字。」它要做的是另一件事：在你已经在用的 AI 工具旁边，做一个审阅和编辑本地 Markdown 的地方。AI 改了你的文档之后，你能在渲染后的页面里直接看到哪里加了、哪里删了，再决定要不要保留。

TA 到底在做什么？

Resomark 有三个核心能力。Live Preview：标题、列表、表格、代码、公式就在你写的地方渲染，光标移进去就能编辑源码，纯 .md 文件始终是唯一事实来源，Resomark 渲染但不重新格式化它。Rendered diff：对 Git 跟踪的文件，在渲染后的文档里高亮增删改，让你在上下文里审阅 AI 写的改动。Local workbench：没有数据库，只是把你 Mac 上真正在用的文件夹钉在一个侧栏里：笔记、Skills、AI 配置、dotfiles。

产品观

Is Resomark an AI app? No. Resomark does not generate text. It works next to the AI tools you already use, as a review and editing layer for local Markdown files.

— Resomark 官网常见问题

这句话说明了 DeRyck 对 AI 时代工具的判断：生成已经不稀缺，稀缺的是让人放心地审阅和接受改动的界面。

可以从 TA 身上学什么

  • 为新的工作方式设计工具：人机协作需要新的审阅界面。
  • 定位要清楚：「比 IDE 轻、比 Obsidian 轻」，一句话说清。
  • 说清楚自己不是什么：「不是 AI 应用」反而让人信任。
  • 尊重文件格式：不重新格式化，不锁定数据。
  • 高频发布：公测期也认真写每一版的更新说明。
