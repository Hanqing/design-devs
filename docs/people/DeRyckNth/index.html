DeRyck：给人和 AI 一起写的 Markdown 做一个本地工作台

当越来越多的文档、笔记和代码由 AI 写成，人需要一个地方去「读」和「审」。DeRyck 做的 Resomark 是一个本地的 Mac Markdown 应用：所见即所得的实时预览、以渲染后的形式审阅 Git 差异、把你和 AI 一起工作的文件夹钉在一个侧栏里。

一句话：一个正在为 AI 时代重新设计「文档阅读与审阅」体验的开发者。

代表作：Resomark（Mac 公测版）：Live Preview（标题、列表、表格、代码、公式就地渲染，光标进入时显示源码）、Rendered diff（在渲染后的文档里高亮 AI 的增删改）、Local workbench（无数据库，只钉住你真正在用的文件夹）。

定位：比 IDE 轻，比 Obsidian 轻；原生、快速，没有插件商店，也不需要配置。

官网按三个核心能力分节：Live Preview（「所见即所得，不用在预览面板之间切换」）、Rendered diff（「以渲染后的 Markdown 审阅改动」）、Local workbench（「把你真正在用的每个文件夹钉住」）。

最后用两句话给出定位：「Lighter than your IDE」「Lighter than Obsidian」。

设计与思考

Resomark 最有洞察力的设计是渲染式 Diff：传统的 Git diff 是给代码设计的，而 AI 改写的文档需要在「看起来的样子」里审阅。把增删改直接标在渲染后的文档上，让非工程师也能放心地接受 AI 的修改。

「纯 .md 是唯一的事实来源」则是另一种尊重：你的文件不会被锁进某个数据库，任何编辑器都能打开。

可以从 TA 身上学什么

  • 为新的工作方式设计工具：人机协作需要新的「审阅」界面。
  • 定位要清楚：「比 IDE 轻、比 Obsidian 轻」一句话说清。
  • 尊重文件格式：不重新格式化，不锁定数据。
  • 做减法：没有插件商店，没有配置。
