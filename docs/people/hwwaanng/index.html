TA 到底在做什么？

简单说，Hwang 在做两件事。本职是带着 YellowPlus 做 AirBuild：你描述想要的 App，一组分工明确的 AI Agent（产品、设计、工程、增长）接力把它做出来，再由专门的 Agent 负责提交 App Store 审核、回复苹果、修复被拒问题并重新提交。

业余则是一个叫「Yellow Plus with Builders」的副业组合：和 Lakr233、EYHN、cats_juice、Yuhang Lu 等朋友按项目临时组队，围绕「AI 编程工具」「开发者小工具」「生活类 App」三条线不停发布。仅 2026 年，hwang.fun 就列出了 Deux、Cookey、MouseDo、LookInside、Stacklight、Screen Cam、Muse Amp、Slabox 八个新项目。

本页依据 hwang.fun、air.build、viber.today、GitHub 与 App Store 的公开信息整理，资料截至 2026 年 10 月。合作项目的开发者账号可能属于合作者本人（例如 Muse Amp、Cookey 在 App Store 的开发者署名是 Lakr233 的本名，Hands Time 署名是 Yuhang Lu），文中会分别注明。

代表作品详解

AirBuild ↗

2026YellowPlus 主产品iOS 26+ / macOS

官网的标题是「AI agents to build your app and handle App Review」。卖点分两层：第一层是一份需求、一整支团队，首页演示里有 Jamie（产品）、Maya（设计）、Eli（工程）、Casey（增长）四个 Agent，共享同一份项目背景，依次接力；可以选云端团队或跑在本机 Mac 上的本地团队，随时切换。

第二层是审核自动化：Submit（准备构建、元数据、截图和审核备注）、Respond（通过 App Store Connect 回复苹果）、Fix（把每个问题派给合适的 Agent 修复）、Resubmit（修好立刻重新提交）。这是独立开发者最熬人的环节，也是 AirBuild 最有辨识度的定位。

  • 支持从一个想法开始，也支持导入 GitHub 仓库。
  • 强调「在手机上也能推进」：官网有一段「Seat 24A. Still shipping.」，表示在飞机上用 iPhone 也能审阅、迭代和发布。
  • 博客写得像产品的一部分：App Clip 小店指南、TestFlight 入门、App Store Connect 全流程、在 iPhone 3G 上用 AI 写 App 的工程实验等，多数提供中文或 12 种语言版本。

Viber ↗

2025.08iOS + 桌面端与 cats_juice、EYHN、Lakr233 合作

「Shape Your Code. Anywhere.」一个移动原生的 Claude Code / Codex 客户端：在电脑上装一个桌面服务端（macOS ARM、Windows、macOS、Linux 都有），iPhone 连上去就能发起编程会话、选择相关文件、让 Agent 生成和修改代码。

比较讲究的是网络设计：可以自建中继服务器，桌面端和手机都只向外连接中继，中继只保存「房间」状态、转发 HTTP 与 WebSocket 消息，并报告两端的连接质量，不需要把开发机暴露在公网上。官网还提供 llms.txt 和一键部署的 Agent Skill。

Slabox ↗

2026.04iOS收藏 / 生活

给评级卡收藏者用的口袋保险箱：扫描 PSA 评级证书上的条码即可录入，每张卡带图片、评分、证书编号、文件夹和「population」（同等级存世数量）数据，还能生成干净的分享图。宝可梦卡（PTCG）、球星卡都适用。

Stacklight ↗

2026macOS 菜单栏Swift · 开源

一个轻量的菜单栏 App，把部署、CI/CD 流水线和 Pull Request 的状态集中到一个小三角图标里：支持 Vercel、Cloudflare Pages、GitHub Actions、Netlify、Railway、Zeabur、Fly.io、Xcode Cloud 和 TestFlight；刷新间隔可调（30 秒到 5 分钟），部署失败或成功会发系统通知。

细节上很「原生」：设置窗口模仿系统设置的样式，API Token 存在 macOS 钥匙串里，支持开机自启动。README 中英双语。

从原型到产品

AirBuild 官网用 Astro 搭建，托管在 Cloudflare。页脚那堆可以用手势抓取的 App 图标，正是 Craft 里 Icon Hands 原型的产品化：Matter.js 物理引擎负责下落和碰撞，MediaPipe 负责识别手掌和握拳。本站页脚的头像掉落效果就是照着它做的。

可以从 TA 身上学什么

  • 原型先公开：Craft 栏目让想法在变成产品之前就能被看到、被试用，Icon Hands 最后真的长进了 AirBuild 官网。
  • 作品页写清合作者：每个项目都挂上合作者头像，既是致谢，也是在展示自己的协作网络。
