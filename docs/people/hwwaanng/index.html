Hwang：Design / Vibe / Shape

AFFiNE 与 Bridge 的早期成员，AirBuild 的创始人。也就是本站排版所参考的那个博客背后的人。他的作品集里有时钟小组件、Lofi 音乐计时器、宝可梦卡牌收藏、SwiftUI X 光调试器，以及一整套给 AI Agent 用的开发工具。

一句话：一个把「设计」「氛围」「塑形」写在简介里的设计师创业者，从开源知识库 AFFiNE 到 AI 应用构建平台 AirBuild，一直站在设计与工程的交界处。

代表作：AirBuild（AI Agent 帮你构建原生 iOS App 并自动处理 App 审核）、Viber（iPhone 上的 Claude Code / Codex 客户端）、LookInside（SwiftUI 图层 X 光）、Hands Time（时钟小组件）、Lofi.、Sleepy Coffee。

彩蛋：本站的视觉风格，正是参照 AirBuild 博客的排版。

个人网站

hwang.fun/projects ↗

作品集用 Next.js 构建，每个项目一行：Logo、名称、年份、一句话描述，部分项目附上合作者头像。分组标题非常克制：Work / Products、Dev Tools、Lifestyle、Earlier。

首页是一个「Design Lab」，放着交互原型和 AI 宝可梦卡牌生成器等实验。

AirBuild 的博客（本站参考对象）则体现了他对阅读体验的讲究：660px 的正文宽度、右侧的粘性目录、编号步骤线、灰底注释与橙色强调，每一个组件都克制而清楚。

设计与手艺

「Design / Vibe / Shape」三个词可以读作他的方法论：先设计，再用 Vibe Coding 快速实现，最后亲手塑形打磨。他的项目常常是小团队协作：与 Lakr233、EYHN、cats_juice 一起做 Viber，与 Yuhang Lu 一起做 Hands Time。

设计也是写作

AirBuild 博客写给小店主的 App Clip 指南，用「外卖窗口和堂食大厅」比喻 App Clip 和完整 App，全文没有一个术语。设计感不只在视觉，也在写作。

可以从他身上学什么

  • 作品集按主题分组：让人一眼看出你在乎什么。
  • 和朋友一起做副业：小团队、短周期、快速发布。
  • 为 Agent 时代做工具：登录授权、Computer Use、审核自动化，都是新的空白。
  • 把博客当产品做：排版、组件、语气都是设计的一部分。
