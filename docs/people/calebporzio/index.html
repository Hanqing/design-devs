Caleb Porzio：靠 GitHub Sponsors 赚到一百万美元

他住在纽约州布法罗，自称「worker on the web」。他做了两个在 Laravel 和前端圈极受欢迎的框架：Livewire 让你不离开 PHP 就能构建动态界面（★2.4 万），Alpine.js 是一个「直接写在标记里」的轻量 JavaScript 框架（★3.2 万）。他曾在 Laravel 咨询公司 Tighten 工作，后来写下《I'm out of a job…》开始全职做开源，并提出了「Sponsorware」：新包先只给 GitHub 赞助者用，达到赞助目标后再完全开源。这个办法让他的收入在两天里多了 1.1 万美元，后来他在 GitHub Sponsors 上累计收入超过一百万美元。现在他在做 Livewire 官方组件库 Flux，并主持播客 No Plans To Merge 和已有六百多期的 Notes on Work。

他到底在做什么？

Caleb 现在的重心是 Flux：Livewire 的官方组件库，「为 Livewire 界面专门打造的世界级组件」，灵活、好用、无障碍，暗色模式和移动端都做好了，基础组件免费，进阶组件付费。他几乎每周都会更新一个新组件或细节：日期时间选择器、卡片、电话输入、饼图、可在隐藏标签页暂停的 Toast 计时器、给 AI 读的文档。

他对细节很较真：他总结过一条排版规则：单行副标题和正文之间用 mt-1，多行的用 mt-2，否则不是太松就是太挤。最近他还用 AI 搭了一个小编辑器，逐个场景、精确到毫秒地用提示词生成 Flux 的宣传动画。他也在考虑要不要做一个 React 版的 Flux。
