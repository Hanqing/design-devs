Baye：一边全球旅居，一边卖 App 的程序员

熊猫吃短信用手机端机器学习拦截「澳门赌场」，ServerCat 让你在手机上管服务器，OpenCat 是最早一批原生 ChatGPT 客户端，DAMA 自动给截图打码。他以 Early Moon, LLC 的名义维护着六七款 App，评分加起来超过两千七百个，人则在世界各地旅居。

一句话：中文独立开发圈最有代表性的「产品型程序员」之一。X 简介写：「一个自由的程序员，以卖 App 为生。边全球旅居边创作产品。」GitHub 上则自嘲「Poor Indie developer」。

代表作：熊猫吃短信（1 代 4.79 分、2 代 4.62 分）、ServerCat（1,004 个评分，4.6 分）、OpenCat（847 个评分，4.64 分）、DAMA（自动打码，4.67 分）、Cleaner for Xcode、Miley AI。

关键数字：X 关注者约 16.4 万；GitHub 近一年贡献 10,525 次；熊猫吃短信 1 代售价 12.99 美元。

爱范儿的专访标题是《那个与「澳门赌场」抗争的男人》。被垃圾短信骚扰的 Baye 没有去写更多关键词规则，而是先花两周时间手动标注样本，证明本地机器学习可行，再做出了一个不请求网络权限、完全离线的短信过滤 App。这个「先验证、再动手」的习惯，贯穿了他之后所有的产品。

他到底在做什么？

Baye 的产品可以分成三条线。隐私与安全：熊猫吃短信在手机端用 Core ML 离线拦截垃圾短信，DAMA 在手机端自动给截图里的人脸、证件号、电话、二维码打码。开发者工具：ServerCat 在手机上看服务器状态、管 Docker、开 SSH；Cleaner for Xcode 清理 Xcode 的海量缓存。AI：OpenCat 是 ChatGPT API 开放两天后就上架的原生 AI 客户端，如今已支持本地模型、Apple Intelligence 和 MCP。

这三条线有一个共同点：能在本地做的，绝不上传。熊猫吃短信甚至「都不会请求网络权限，直到您第一次主动向我们举报垃圾短信」；DAMA「即使在飞行模式下」也能完成全部检测。

本页依据爱范儿专访、少数派与 V2EX 发布帖、GitHub、各产品官网与 App Store 整理，资料截至 2026 年 10 月。

成长与经历

  1. 2009–2013

    Python 与 Django

    X 账号 2009 年注册，GitHub 2011 年注册。早年开源作品包括又拍云的 Django 存储后端 django-upyun 和一套 Django 部署脚本。据专访，他最早在公司上班但不习惯，之后大部分时间远程工作。

  2. 2017.03

    HyperApp

    基于 SSH 和 Docker 的自动化部署工具：几十个常见应用做成商店，点一下就出可视化配置界面，一键装到你的服务器上，还集成了 Let's Encrypt 证书。少数派专文推荐，用户手册在 GitHub 上有 1.5 千星。

  3. 2017.10

    XcodeCleaner

    用 react-native-macos 写成的 Xcode 清理工具（★1.5 千），2019 年用 SwiftUI 重写为 Cleaner for Xcode。

  4. 2017.12

    熊猫吃短信

    利用 iOS 11 新开放的短信过滤接口，用 Core ML 在本地拦截垃圾短信。用户主动举报垃圾短信来扩充样本库，后来他还被「12321 网络不良与垃圾信息举报受理中心」邀请去交流。获少数派和最美应用的年度应用。

  5. 2020

    ServerCat 与 DAMA

    4 月，HyperApp 演化为 ServerCat：服务器状态、Docker 管理与 SSH 客户端；10 月发布自动打码工具 DAMA。2021 年又开源了监控 M1 Mac swap 用量的 Swapman。

  6. 2022.09

    熊猫吃短信 2

    新的机器学习模型架构，适配 iOS 16 的短信分类：在正常和垃圾之外，还能识别财务、订单、运营商、天气等更细的类别。

  7. 2023.03

    OpenCat

    ChatGPT API 3 月 1 日开放，OpenCat 3 月 3 日就上架了，是 Apple 平台上最早的一批原生 AI 客户端。

  8. 2024–2026

    Miley 与持续迭代

    2024 年发布语音输入的 AI 生活助手 Miley；2026 年 OpenCat 加入 Agent 与 MCP 支持，几款主力 App 都保持每月更新。

代表作品详解

熊猫吃短信 ↗

2017 / 2022iOS · Core ML完全离线

「使用 Core ML 机器学习框架在设备端离线过滤垃圾短信，能准确地通过语义识别垃圾短信，不需要手动配置任何过滤规则，开箱即用。」它的模型是用基于统计学的机器学习算法，从几十万（2 代说是百万）条用户举报的短信样本中学习而成，Baye 称之为「集体智慧」。

隐私承诺写得非常具体：不上传用户短信，拒绝云端识别；1 代甚至不请求网络权限，直到你第一次主动举报。V2EX 发布时他承诺「不低于一个月一个版本」，如今 2 代仍在按月更新。

OpenCat ↗

2023.03macOS · iOS · iPadOSAI 客户端

「与您的 AI 开始流畅的聊天。」从最初的 ChatGPT 客户端，长成了一个 AI 平台：语音聊天、文生图、图片对话、翻译、全局键盘扩展（在消息、备忘录、邮件里直接用 AI）、Siri 快捷指令、团队版共享提示词、多模型并存。2026 年的版本支持本地模型、自带 API Key、云订阅和 Apple Intelligence，并加入 MCP 与工具调用。

方法与观点

我一般会跳过这个过程，自己先迅速做一个最小可用产品出来，然后直接让潜在用户试用，根据反馈和自己的思考来判断方向到底对不对。

— Baye，爱范儿专访
  • 做自己痛的问题：被垃圾短信骚扰，就去拦截它；Xcode 占满硬盘，就去清理它。
  • 先验证技术可行性：两周手动标注样本，证明本地机器学习能用，再全力投入。
  • 抓住平台新接口：iOS 11 的短信过滤、Core ML、ChatGPT API、iOS 16 短信分类，每个窗口期都是机会。
  • 让用户参与进化：举报样本让「熊猫」越来越聪明。
  • 按月发版：日历版本号本身就是一种承诺。

长处与局限

维度长处局限 / 需要留意
产品多款 App 长期维护、评分稳定在 4.6 以上Miley 等新品评价较少，未复制主力产品的成绩
隐私端侧处理是核心卖点，承诺具体可验证端侧模型的能力受限于设备
商业买断、订阅、免费多种模式并存，养活全球旅居部分产品（OpenCat）所在的 AI 客户端赛道竞争激烈
表达X 上影响力大没有博客，系统性的经验分享较少

可以从他身上学什么

  • 做自己痛的问题：最好的需求验证，是自己每天都在被它困扰。
  • 先验证技术可行性：花两周确认能做，比花两个月做完才发现不行好得多。
  • 隐私是产品力：「不请求网络权限」比任何隐私声明都更有说服力。
  • 抓住平台新接口：苹果每开放一个新能力，都是独立开发者的窗口期。
  • 产品养活生活方式：独立开发不只是职业，也可以是全球旅居的自由。
