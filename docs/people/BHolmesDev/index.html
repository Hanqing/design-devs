他来自美国南卡罗来纳州查尔斯顿，自称「会写点代码的白板人」。他以一分钟左右的白板短视频出名：用几支马克笔把 React Server Components、HTMX、SQLite 这类话题讲得一清二楚。他曾是 Astro 的全职核心维护者，还特意在 GitHub 上澄清：「我没有发明 Astro」，但在那里的经历把他对设计的热爱变成了让开发更容易的热爱。他也发明过自己的元框架 Slinkity。现在他在 Warp 担任开发者体验负责人，X 简介写着「Factory Foreman」：他在帮团队运营一座由 AI Agent 组成的「软件工厂」，做了评估 PR 合并风险的 /merge-risk、改进 Agent 技能的 /skill-doctor 等工具。他还在做一款给人和 Agent 共用的笔记本 Hubble（★1.5 千）。

他到底在做什么？

Ben 在 Warp 做的是「软件工厂」：用 Agent 持续处理 issue、提交 PR，再用另一批 Agent 审查和改进它们。他们把工厂的配置格式称为「给 Agent 的 Terraform」。他的经验很具体：先让 Agent 每天（甚至每周）只捡一个闲置 issue；PR 不好就改进流程，而不是停掉自动化；没有截图或录屏的 Agent PR 不值得花时间审；Agent 的会话应该存到共享的地方，方便安排「自我改进」Agent 去复盘。

他一直喜欢「自己动手造一个」的教学方式：simple-rsc 让你亲手实现一个最简单的 React Server Components，simple-sync-engine 是一个可以自己搭的 SQLite 同步引擎。2026 年他写了《Build a Self-Updating LLM Knowledge Base》，用 Agent 给 Markdown 笔记打标签、建反向链接，自动生成维基和可视化。
