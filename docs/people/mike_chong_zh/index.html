Mike Chong：让每个人无负担做视频

做视频最累的不是创意，而是体力活：拖着进度条找停顿、剪掉「嗯」「啊」和说错的开头、把屏幕录像对到解说的节拍上。PilotCut 的做法是把这些交给你已经在用的编程 Agent：一句提示，它就在原生 Mac 时间线上完成一整轮剪辑，而素材从不离开你的电脑，也不按次收 AI 费用。这是一个程序员看视频剪辑的方式：既然 Agent 能改代码，为什么不能改时间线？

TA 到底在做什么？

Mike 的两款产品都围绕让做视频变轻松。ScreenKite 是录屏和编辑一体的 Mac 应用，包含 AI 辅助剪辑；它不收 AI 费用，而是使用你自己的 Agent 订阅，录像默认只存在本机。PilotCut 更进一步，把整个剪辑交给 Agent：支持 Claude Code、Codex、Gemini CLI、MCP 和本地模型。

TA 也提供付费咨询，内容是「AI 优先」的策略，以及怎样设计全栈应用的架构，让 AI 能快速把它做出来。

可以从 TA 身上学什么

  • 让 Agent 操作专业软件：时间线也可以像代码一样被编辑。
  • 本地优先是卖点：素材不上传，用户更安心。
  • 别向用户收重复的 AI 费：让他们用自己的 Agent 订阅。
  • 把测试当成核心资产：AI 时代的代码观。
  • 双语经营：两个账号覆盖两个社区。
