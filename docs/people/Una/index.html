她到底在做什么？

Una 的工作是让 Web 平台更好用。她说这是一个「很 meta 的角色」：参与设计新的 CSS 和 HTML 能力，做示例来发现问题、展示用例，研究开发者需要什么，然后在博客、播客和大会上讲给所有人。她近两年的博客几乎是一份现代 CSS 新特性清单：contrast-color()、border-shape（非矩形的 Web）、scroll-state(scrolled) 方向感知样式、样式查询主题。

她也关注 AI 怎么帮开发者跟上平台：她认为用 AI 技能把旧的 UI 系统重构得更现代、更灵活是个好办法，「只是一定要测试结果」。
