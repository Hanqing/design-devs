Simon Willison：在公开场合学习 AI

他是英国程序员，现在住在加州半月湾，X 简介自述 He/Him。据维基百科，2003 到 2004 年他和 Adrian Holovaty、Jacob Kaplan-Moss、Wilson Miner 一起创造了 Python Web 框架 Django；毕业后在雅虎技术开发团队工作，参与早期的 Fire Eagle 地理定位服务；2008 年成为英国《卫报》的软件架构师；2010 年底与 Natalie Downe 联合创办会议目录网站 Lanyrd，获得 Y Combinator 投资，2013 年被 Eventbrite 收购。现在他全职做开源：数据探索与发布工具 Datasette（★1.2 万）和在命令行里使用大语言模型的 LLM（★1.3 万）。他从 2022 年起担任 Python 软件基金会理事。他的博客 simonwillison.net 是 AI 领域最勤奋、最被广泛引用的个人博客之一，他在 2025 年 6 月提出的「致命三要素」（lethal trifecta）成了讨论 AI Agent 安全的常用概念。

他到底在做什么？

Simon 的主业是 Datasette 与 LLM 工具链：Datasette 把 SQLite 数据库变成可以浏览、查询和发布的网站与 API；LLM 让你在命令行和 Python 里调用各家模型，配有大量插件；sqlite-utils、shot-scraper 等工具围绕它们组成一个生态。他在 tools.simonwillison.net 上放了一大批「几乎完全由 LLM 生成」的小工具，比如 2026 年 10 月用 Claude 做的「Quick Study」。

他也是 AI 领域最勤奋的公共笔记作者：每有新模型发布，他都会写测试笔记（他的固定测试是让模型画「骑自行车的鹈鹕」SVG）；他持续追踪提示注入和 Agent 安全；也会引用和点评别人的观点，比如 Armin Ronacher 的帖子。
