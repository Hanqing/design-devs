他到底在做什么？

yourQuantGuy 做的是可编程的交易：把一个策略写成机器人，开源出来，让别人也能用。perp-dex-tools 是一个模块化机器人，支持 EdgeX、Backpack、Paradex、Aster、Lighter、grvt、Extended 等交易所，核心策略是自动下单、盈利即平仓，主要目的是刷高交易量，从而拿到交易所的积分和空投。

在 X 上，他更像一个讲解员：比如用 Boros 锁定 Hyperliquid 和 Gate 之间的 BTC 资金费率，再用 CrossEx 跨所共享保证金放大资金效率，并把主要风险讲清楚（价差达到 4% 时会爆仓）。他也会用 Claude 抓取数据，比较五大中心化交易所的储备、持仓和成交量。

本页依据 GitHub 仓库与 README 和 X 公开推文整理，资料截至 2026 年 10 月。他的真实身份与过往任职机构未公开，本页不作推断；生活与家庭内容未收录。本页不构成任何投资建议。
