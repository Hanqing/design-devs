Peter Steinberger：从退休回来，养了一只龙虾

这位奥地利开发者把 PDF SDK 公司 PSPDFKit 自举成九位数的退出，然后倦怠、退休。2025 年 AI 变得足够好，又把他拉了回来：他用 Agent 疯狂写代码，做出了成为 GitHub 星数最多软件项目的个人 AI Agent OpenClaw，并在 2026 年 2 月加入 OpenAI。

一句话：「Came back from retirement to mess with AI and help a lobster take over the world.」iOS 时代的传奇工程师，Agent 时代的新偶像。

代表作：PSPDFKit（现 Nutrient）；OpenClaw（开源个人 AI Agent，现由独立基金会托管）；CodexBar（★2.3 万，菜单栏显示 Codex 和 Claude Code 用量）、summarize、oracle、agent-rules、RepoBar；早年的 Aspects、PSTCollectionView、PSStackedView。

为什么值得关注：他公开分享自己的 Agentic Engineering 方法，比如《Just Talk To It》《Shipping at Inference-Speed》，影响了无数开发者使用 AI 的方式。

Peter 的 About 页第一句话是：「I made OpenClaw — the open-source personal AI agent that became GitHub's most-starred software project.」最后一句是：「The claw is the law. 🦞」中间是一段浓缩的人生：自举公司到九位数退出、倦怠、退休，然后 AI 变好了，把他拉了回来。

成长与经历

  1. 2009–2012

    iOS 开源

    在维也纳活跃于 iOS 社区：PSStackedView（「做对了」的 Twitter iPad 堆叠界面）、PSTCollectionView（兼容 iOS 4.3 的 UICollectionView 替代品）。

  2. 2011

    PSPDFKit

    从一个 PDF 阅读组件起步，创立 PSPDFKit，成为被众多大公司使用的跨平台 PDF SDK。2014 年开源的 Aspects（Objective-C 面向切面编程）至今仍有 8.4k 星。

  3. 2021 前后

    退出与倦怠

    把完全自举的 PSPDFKit 做到九位数级别的退出（公司后来更名为 Nutrient），随后经历倦怠并「退休」。

  4. 2025

    被 AI 拉回来

    AI 编程工具变得足够好后重新开始写代码，一年内发布大量工具：CodexBar、summarize、oracle（卡住时召唤 GPT-5 Pro）、agent-rules、agent-scripts、RepoBar。写下《Just Talk To It——不炒作的 Agentic Engineering》《Shipping at Inference-Speed》，并发起「Claude Code Anonymous」线下聚会。

  5. 2025–2026

    OpenClaw 🦞

    做出开源个人 AI Agent（最初名为 Clawdbot），以龙虾为吉祥物，迅速成为 GitHub 星数最多的软件项目，并移交给独立的 OpenClaw 基金会。

  6. 2026-02

    加入 OpenAI

    加入 OpenAI，致力于「把 Agent 带给每一个人」。下一个目标：「一个连我妈妈都会用的 Agent」。

方法与思考

Peter 的 Agentic Engineering 方法可以概括为「直接跟它说话」：少一些复杂的框架和仪式，多一些清晰的上下文、规则文件和可复用脚本。他把自己的 agent-rules 和 agent-scripts 全部开源。

Why I stopped reading code and started watching it stream by.

— Peter Steinberger《Shipping at Inference-Speed》
他也很坦诚地谈论倦怠：做到九位数退出之后，他并没有立刻找到下一个方向。是 AI 带来的创造乐趣，让他重新找回了「火花」（见他的文章《Finding My Spark》）。

可以从他身上学什么

  • 自举也能做大：不融资，同样可以做到九位数。
  • 为 AI 写网站：.md 版本、开放授权，让知识被 Agent 读取。
  • 把工作流开源：规则、脚本、工具，都可以帮到别人。
  • 倦怠之后还能重来：找到让你兴奋的东西，再出发。
