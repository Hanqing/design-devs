Peter Steinberger：从退休回来，养了一只龙虾

这位奥地利开发者把 PDF SDK 公司 PSPDFKit 自举成九位数的退出，然后倦怠、退休。2025 年 AI 变得足够好，又把他拉了回来：他用 Agent 以「推理速度」写代码，做出了成为 GitHub 星数最多软件项目的个人 AI Agent OpenClaw，并在 2026 年 2 月加入 OpenAI。

他到底在做什么？

Peter 现在做两件事：在 OpenAI 做面向大众的 Agent，同时守护 OpenClaw 的开放与独立。OpenClaw 是一个开源的个人 AI Agent，口号是「The AI that really does things. Any OS. Any Platform. The lobster way. 🦞」。它 2025 年 11 月才建仓，到 2026 年 10 月已有约 39 万颗星。

在此之前，他用 Agent 以惊人的速度发布了一大批开发者工具：菜单栏查看 Codex / Claude Code 用量的 CodexBar、让 Agent 截屏和点击的 Peekaboo、把 MCP 当 TypeScript API 调用的 mcporter、卡住时召唤 GPT-5 Pro 的 oracle，以及他开源的整套 agent-rules 和 agent-scripts。

本页依据 steipete.me（About 与文章）、GitHub 仓库与 README、OpenClaw 仓库数据和 X 资料整理，资料截至 2026 年 10 月。

成长与经历

  1. 2009–2012

    维也纳的 iOS 开源

    PSStackedView（「做对了」的 Twitter iPad 堆叠界面，★1.9 千）、PSTCollectionView（100% API 兼容、支持 iOS 4.3 的 UICollectionView 替代品，★2.5 千）、AFDownloadRequestOperation。

  2. 2011

    PSPDFKit

    从一个 PDF 阅读组件起步，做成被大量企业使用的跨平台 PDF SDK。2014 年开源 Aspects（Objective-C 面向切面编程），至今约 8.4 千星。

  3. 约 2021

    退出、倦怠、退休

    把完全自举的 PSPDFKit 做到九位数退出（后更名 Nutrient），随后倦怠、退休。

  4. 2025

    被 AI 拉回来

    AI 编程变得足够好后重新写代码：VibeTunnel、Peekaboo、Poltergeist、claude-code-mcp、macOS Automator MCP；写《Just Talk To It》《My Current AI Dev Workflow》，发起 Claude Code Anonymous 聚会。年底的 CodexBar、summarize、oracle、RepoBar 都迅速走红。

  5. 2025.11

    OpenClaw 🦞

    开源个人 AI Agent（最初名为 Clawdbot），以龙虾为吉祥物，很快成为 GitHub 星数最多的软件项目。

  6. 2026.02

    加入 OpenAI

    在旧金山与各大实验室交流一周后，选择加入 OpenAI；OpenClaw 移交基金会，OpenAI 承诺支持他投入时间并赞助项目。
