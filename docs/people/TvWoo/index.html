TA 到底在做什么？

Steve 用 AI 把创意直接变成软件。TA 的 Notes 站记录了 Glimmering Isles 的角色制作过程：从 Three.js、Blender 到图转 3D，8 组制作测试、1 组修正记录，写清楚输入素材、过程和实际结果。

博客「余生皆假期」则是 TA 的数字花园：AI 编程的第一次尝试、更新 Discord 机器人、做 Chrome 翻译插件、自动同步 Skill 到 GitHub 的 SkillSync，以及多年的摄影合集和生活随笔。

可以从 TA 身上学什么

  • 非工程师也能造软件：AI 让创意直接变成产品。
  • 小而专注：每个项目只做一件事。
  • 把故事带进产品：叙事感让工具更有温度。
  • 公开制作过程：失败的测试也值得记录。
  • 个人网站容纳完整的人：摄影、插画、写作都是作品。
