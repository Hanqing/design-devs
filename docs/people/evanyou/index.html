尤雨溪（Evan You）Vue.js、Vite 作者 · VoidZero 创始人（2026 年被 Cloudflare 收购）· 新加坡

尤雨溪：从 Vue 到 Vite，再到一整条工具链

他是 Vue.js 和 Vite 的作者，现在住在新加坡。据维基百科，他在 Google 用 AngularJS 做过几个项目后萌生了一个想法：「如果我只把 Angular 里我真正喜欢的部分抽出来，做一个非常轻量的东西呢？」2013 年 7 月，Vue 的第一次提交诞生（当时叫 Seed），2014 年 2 月正式发布。从 2016 年起，他靠社区赞助做全职独立开源开发者。2020 年他推出 Vite，用浏览器原生 ES 模块彻底改变了前端开发服务器的体验，如今每周下载超过一亿次。2024 年他创办 VoidZero，融资 460 万美元，要为 JavaScript 和 TypeScript 打造统一的高性能工具链：Vite、Vitest、Rolldown、Oxc、Vite+。2026 年 6 月，VoidZero 被 Cloudflare 收购，这些项目继续以 MIT 协议开源。

他到底在做什么？

尤雨溪现在的重心是JavaScript 工具链的「统一」：Vite 负责开发体验和构建，Rolldown 是用 Rust 写、与 Rollup API 兼容的打包器，Oxc 提供解析、转换和代码检查，Vitest 负责测试，Vite+ 把它们整合起来。加入 Cloudflare 后，团队进入其新兴技术与孵化部门，继续主导这些项目。

他也在思考性能的另一种可能：与其把 TypeScript 编译成原生代码，不如在某些任务上用特定的写法，让普通 TypeScript 也达到接近原生的性能。
