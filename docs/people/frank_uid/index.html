TA 到底在写什么？

把 Frank 的文章按时间排开，能看到三段清晰的兴趣：2020–2021 年是「炼丹工程」，从紧凑网络结构、调参、类别不平衡、数据增强、知识蒸馏一路写到剪枝、Profiling 和 ML 系统设计；2022–2023 年是「深圳山海」，武功山、大鹏半岛、香港郊野径、双月湾；2024 年之后是「产品与世界」，从 startup 福利、jenni.ai 的冷启动、UTM 归因，写到 Surge AI、科技共和国、美国制裁、英伟达的泡沫周期。

这三段看起来毫不相干，方法却一模一样：先把问题拆成结构，再给每一块配上具体的例子和可以套用的模板。

Frank 没有公开 GitHub 或产品主页，本页依据 frankk.site 的文章与 RSS、X 个人资料整理，资料截至 2026 年 10 月。所在地为根据文章内容的推测。

代表文章详解

海外产品开发经验分享 ↗

2026.06技术 · 商业独立开发手册

开头一句交代了动机：「最近 Claude Code 很好用，很多人都有机会做自己的产品。」全文按产品形态（静态站、完整前后端应用、移动端、桌面端）组织，逐项讲框架选型、部署、数据库、鉴权、支付、AI 服务和图床，并尽量给出免费额度和起步成本。

细节很实用。比如图床一节，讲清楚 Cloudflare R2 负责存原图、Cloudflare Images 负责按需变换：只存一张原图，通过改 URL 参数就能拿到 200px 缩略图、自动转 WebP / AVIF 的大图、裁成正方形的头像，远程图片变换每月有 5,000 次免费额度。SEO 一节则建议博客尽量用 Astro 做静态站，并强调「最核心的还是内容本身」。

我的 Claude Code 实践 ↗

2026.05AI 工具非编程用法

这篇最有意思的地方在于，它讲的大多不是写代码：

  • 把讨论变成网页：和 Claude 聊完一个话题，让它直接生成一个总结网页，需要时主动搜图、插图表，事后回顾「视觉体验会非常舒服」。
  • 整理杂乱的文件夹：在文件夹里开一个会话，借助多模态识别按图片内容或时间分类整理。
  • 处理图片：用代码画 SVG 流程图；按需搜图并优先从维基百科等无版权风险的来源获取；调用 OpenCV 做抠图、裁剪、通道变换。
  • 甚至做视频。

如何迭代与进步 ↗

2026.06方法论

把 Karpathy 讲的「如何成为专家」和费曼讲的「如何检验真懂」归结为一件事：用输出检验输入。然后对应到神经网络的训练循环：Forward 是先动手，Loss 是和理想结果的差距，Backward 加梯度下降是复盘改进。

最打动人的是这一句：人和网络最大的不同是面对大 Loss 会痛，所以要把「批判行为」和「否定价值」拆开。梯度下降只更新参数（行为、技能），不要炸掉架构（你是谁）。文末再对照 Ray Dalio 的《原则》：「痛苦 + 反思 = 进步」。

说服的艺术与十个场景 ↗

2026.06随笔十个模板

从亚里士多德的 Ethos（可信度）、Pathos（情感）、Logos（逻辑）出发，认为今天流行的说服框架都是这三要素的「本地化版本」，然后一个场景一个模板地过一遍：升职加薪用 Claim → Reason → Evidence，面试用 STAR，邮件用 BLUF，路演用 Problem → Solution → Traction，销售用 Pain → Gain → Proof，谈判用 BATNA，文案用 AIDA，亲密关系用非暴力沟通。结尾一句：「框架是地图，真诚是罗盘。」

唯有热爱才能走得长远 ↗

2026.05随笔休谟 × 程序性能

一个只有工程师写得出来的比喻：靠「我应该」驱动的事，就像用 Python 跑一个高频的热循环，链条太长，撑不住；真正热爱的事，像 CPU 直接执行的指令。躲不开的事怎么办？给它手工接上一个直接的情感锚点：集邮式打卡、战胜过去自己的成就感、游戏化和同伴。结论是：「理性负责挑选，热爱负责驱动。」

NCNN 峰值内存实测：MobileNet 逐层分析 ↗

2021.06端侧推理

早期技术文章的代表：在 x86 上用 NCNN 推理 MobileNet，逐层记录峰值内存，比较 light_mode、fp16、int8 等选项的影响。这类「自己动手量一遍」的文章，正是 TA 后来所有写作的底色。

可以从 TA 身上学什么

  • 摘要先行：让读者在三十秒内拿到结论。
  • 用熟悉的模型理解陌生领域：用训练循环理解成长，用热循环理解坚持。
  • 写成手册而不是感想：每篇都给出能直接套用的清单和模板。
  • 自己动手量一遍：从 NCNN 内存实测开始，TA 的结论大多来自亲手验证。
