他到底在做什么？

陈成过去十年的主线是前端工程化：dva 把 React 和 Redux 包装成轻量的 Elm 风格框架；umi 把路由、构建、插件体系整合成一套企业级框架；babel-plugin-import 让 antd、lodash 等库按需加载。这些工具在国内 React 生态里被大量使用。

现在他的主线换成了 AI 编程。Neovate Code 是一个可以交互运行也可以无头运行的编程 Agent，能生成代码、修 bug、做评审、补测试；他整理了 awesome-code-agents，也常在 X 上拆解别人的工具，比如 OpenCode 2 的常驻后台服务架构，或 poteto 的 pstack 工作流。他的习惯是：每天下班前留半小时，把 AI 今晚要跑的 loop 和 goal 定好。
