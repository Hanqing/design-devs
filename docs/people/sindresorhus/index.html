Sindre Sorhus：一个人，一千多个仓库和六十多款 App

2014 年辞掉办公室工作去东南亚背包旅行顺便写开源，结果旅行结束了，开源一直没停。他创建了 GitHub 上星数最多的仓库之一 Awesome（★52 万），维护着上千个 npm 包，又一个人做了 60 多款精致的 Mac / iOS 小工具，用户超过 600 万。2026 年 10 月，他把个人网站改成了用 Swift 编写。

一句话：「Full-Time Open-Sourcerer & App Maker」。不开公司，只靠自己和社区赞助，同时维护 JavaScript 生态里依赖最广的一批基础包，以及一长串「本该是系统自带」的 Mac 小工具。

代表作：Awesome（★522,173）、awesome-nodejs（★6.7 万）、type-fest（★1.7 万）、ky（★1.7 万）、got（★1.5 万）、pure（★1.4 万）、ora、execa、np；App 有 Gifski、Velja、Plash、Dato、Supercharge、Text Lens、Mailway 等。

关键数字：GitHub 粉丝 8.5 万、公开仓库 1,145 个；官网写着 61 款 App、12 年 App 匠龄、600 万以上用户、回复过 1 万多封支持邮件；X 关注者约 6.7 万。

此刻：Now 页面（2026-10-20）写着：在越南旅行，喝着越南咸咖啡，在做一个新的秘密 Mac App，并「试图修复我所有开源项目里的所有 bug（是的，真的）」。

他到底在做什么？

Sindre 的工作有两条线，遵循同一个原则：一个东西只做好一件事。在 npm 上，他写了上千个小而专注的模块（他有一篇博客就叫《Small Focused Modules》），让更大的系统可以像积木一样拼起来。在 Apple 平台上，他做了 60 多款小工具：把视频转成高质量 GIF、选择用哪个浏览器打开链接、在菜单栏放世界时钟、复制屏幕上无法选中的文字……「每一款都只解决一个问题，很多是免费的。」

支撑这一切的是一套很「人」的价值观：他写过《Empathy in Open Source》，提醒大家开源不只是代码，更是人；也写过《Issue Bumping》，解释为什么在旧 issue 下评论「有进展吗？」并没有帮助。

本页依据 sindresorhus.com（About、Now、Apps、Timeline、Blog）、GitHub 与项目 README 整理，资料截至 2026 年 10 月。

成长与经历

  1. 童年

    挪威、乐高与 Flash

    在挪威长大，乐高城市几乎占满整个卧室；九岁做简单网页。课间大家玩 Flash 游戏，他想知道怎么做的，于是反编译、重画角色、加新敌人和排行榜。「我改东西、搞坏、再改回来，直到游戏按我想的那样运行。这仍然是我学习的方式。」

  2. 二十多岁

    真正学会编程

    此前只是复制 PHP 和 JavaScript 而不完全理解。通过给 TodoMVC 做贡献进入开源，后来成为它的维护者之一；也参与了 HTML5 Boilerplate、Yeoman、Grunt 等项目。

  3. 2012

    pure

    漂亮、极简、快速的 ZSH 提示符，至今 ★1.4 万。

  4. 2013–2014

    Quick Look 清单、got、Awesome

    2013 年整理开发者 Quick Look 插件清单；2014 年 3 月开始写 Node.js HTTP 库 got；7 月创建 Awesome：各种有趣主题的精选列表，后来成为 GitHub 上星数最多的仓库之一，衍生出成千上万个 awesome-xxx。同年辞职去东南亚。

  5. 2015–2016

    工具链

    np（更好的 npm publish）、execa（给人用的进程执行）、ora（优雅的终端加载动画）、awesome-electron 等相继发布。

  6. 2018

    Gifski 与 ky

    与 Kornel Lesiński 合作的 Gifski 把视频转成高质量 GIF；ky 是基于 Fetch 的小巧 HTTP 客户端。

  7. 2019

    type-fest

    「一组必不可少的 TypeScript 类型」，如今是 TypeScript 生态的常用依赖之一。

  8. 2024–2026

    App 井喷

    2024 年发布 Supercharge、Scratchpad、App Buddy 等；2025 年发布 Default Browser、Shortcutie、Googly Eyes、Text Lens、Simple Color Palette、Short Run、Menu Drop、Zone Bar；2026 年发布 DS_Store Inspector、Imago（Flux 2 文生图）、Mailway。10 月把个人网站重写为 Swift。

代表作品详解

Awesome ↗

2014精选列表★52 万

「Awesome lists about all kinds of interesting topics.」它不是代码，而是开源世界的「目录」：每个主题一份精选清单，由社区维护，再链接到更多的 awesome-xxx。它定义了一种开源协作的格式，也成为 GitHub 上星数最多的仓库之一。

长期维护一个超级项目的疲惫同样真实：Awesome 的描述里写着「在我有时间处理积压之前，暂时关闭 PR」；awesome-nodejs 写着「因为太多垃圾和低质量提交，暂停接收」；awesome-electron 则直接说「因为我厌倦了审核低质量的东西」。

got · ky · execa · type-fest ↗

2014–2019TypeScript / JavaScriptnpm 基础件

这几个包几乎出现在每个现代 JavaScript 项目的依赖树里：got（★1.5 万）是「人性化且强大的」Node.js HTTP 库；ky（★1.7 万）是基于 Fetch 的小巧客户端，支持现代浏览器、Node.js、Bun 和 Deno，零依赖；execa（★7.6 千）是「给人用的进程执行」；type-fest（★1.7 万）提供一组 TypeScript 标准库里没有、但人人都需要的类型。

它们的共同点是 API 小而友好、文档详尽、几乎每周都在更新。Now 页面实时显示：这一周他在开源上有 157 次贡献、关闭了 101 个 issue、更新了 14 个 npm 包。

Supercharge ↗

2024macOS付费 · 免费试用

「Elevate your Mac experience.」把一系列「系统本该有」的增强功能装进一个 App。它是 Sindre 目前最主推的作品：GitHub 主页和 Awesome 的 README 顶部都放着它的推荐位。

Gifski ↗

2018Swift · 开源与 Kornel Lesiński 合作

「Convert videos to high-quality GIFs on your Mac.」基于 Kornel Lesiński 的 gifski 编码器，能生成色彩远好于常规工具的 GIF。它也是 Sindre 少数开源的 App 之一（★8.6 千），是学习 SwiftUI Mac App 的好范例。

长处与局限

维度长处局限 / 需要留意
开源数量与质量兼具，基础包被整个生态依赖一人维护上千个仓库，积压的 issue 与 PR 难免（他本人也在公开处理）
App小而专注、原生、很多免费，600 万以上用户大部分 App 闭源，且只面向 Apple 平台
社区定义了 awesome 列表文化热门列表因低质量提交多次暂停接收
可持续赞助 + 付费 App 支撑全职开源十二年收入高度依赖个人，存在「巴士因子」风险

可以从他身上学什么

  • 小而专注：每一个包、每一个 App，都只解决一个问题。
  • 边玩边学：改、坏、再改回来，是最原始也最有效的学习方式。
  • 把组件也开源：KeyboardShortcuts、Defaults 让别人做 App 更轻松。
  • 把乐趣放进工作：独角兽、1999 版网站、猜 App 游戏。
  • 一个人也可以很大：不开公司，只靠自己和社区支持。
