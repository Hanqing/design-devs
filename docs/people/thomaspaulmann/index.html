Thomas Paul Mann：为做东西的人做东西

他出生在德国，住在伦敦。在 Facebook、奥迪、ProSieben 和弗劳恩霍夫协会做过软件工程师之后，他在 2020 年和 Facebook 前同事 Petr Nikolaev 一起创办了 Raycast：一个用键盘几下就能控制所有工具的 Mac 启动器。Raycast 有一个开放的扩展商店，扩展仓库有 7,800 多颗星，后来又陆续推出 AI、iOS 版和 Windows 版，2024 年完成约 3,000 万美元的 B 轮融资。2026 年，团队推出了 Glaze：用自然语言生成桌面应用。他的 GitHub 简介只有一句：「Make things for people who make things.」

他到底在做什么？

Raycast 的出发点是减少上下文切换：开发者每天在各种 SaaS 工具之间来回跳，浪费了大量时间。它最初是 Spotlight 的替代品，后来通过开放的扩展 API 长成一个平台：扩展用 React 和 TypeScript 写，在 Raycast 里渲染成原生界面，覆盖 GitHub、Linear、Notion、Jira、Spotify 等常用服务。

这两年 Raycast 的重心是 AI：多模型聊天、屏幕感知、把 AI 接进每一个扩展。2026 年推出的 Glaze 更进一步：不再只是控制已有的应用，而是让任何人用一句话做出自己的桌面应用。

代表作品详解

Raycast ↗

2020–Mac · Windows · iOS

按 ⌥ 空格打开一个居中的窗口，输入几个字母就能启动应用、搜索文件、管理剪贴板、插入片段、调用扩展或 AI。他最喜欢的功能之一是应用热键：⌥A 打开浏览器，⌥L 打开 Linear，⌥N 打开 Notion。

Raycast Extensions ↗

开源TypeScript★7.8 千

Raycast 应用本身闭源，但商店里的扩展全部开源在一个仓库里，任何人都可以提交。script-commands 仓库则让人用 Shell、Python 等脚本快速扩展 Raycast。

2026桌面应用生成器

2026 年 7 月公开测试并登上 Product Hunt。Raycast 团队成员用它做菜单栏小工具和个人应用，并发布到 Glaze 商店。
