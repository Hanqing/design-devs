成长与经历

从博客存档看，Tw93 的公开写作从 2015 年开始，最早的文章是《JavaScript 的数据访问性能优化》和 Vue、Angular、Avalon 的框架比较。那是一个典型前端工程师的起点。

  1. 2015–2016

    前端基本功

    读《JavaScript 设计模式》两遍写笔记，研究 Flexbox、React Native 动画、Generator 与 Channel。文章都很长，习惯用「提出问题、论证问题、解决问题」的结构写。

  2. 2017–2018

    Weex、双十一与 iOS

    在部门分享《Hello Weex》，写 SVG 与 Web 图形学入门；为排查双十一期间的 Weex 性能问题开始学 iOS，2018 年正式参与 iOS 业务开发。这段经历让一个前端工程师长出了「端」的能力。WeexUi 也出自这一时期。

  3. 2019

    XRender

    参与并主导阿里开源的中后台表单 / 表格 / 图表方案 XRender。2022 年它三岁时，TA 用 gource 和 ffmpeg 把仓库历史渲染成一段视频，「给代码祝寿」。

  4. 2020 春节

    妙言 MiaoYan

    一款给工程师用的原生 macOS Markdown 笔记应用：纯文本本地存储、三栏布局、LaTeX、Mermaid。两年后重新打磨开源，成为 TA 最受欢迎的 Swift 项目。

  5. 2021 起

    《潮流周刊》

    每周记录看到的好东西和生活。第 100 期时自己用 Astro 设计开发了官网；第 268 期 TA 写道，这份周刊已写了近六年，全部手写，不用 AI。

  6. 2022 国庆

    Pake

    用 Rust + Tauri 把任意网页打包成几 MB 的桌面应用，一条命令搞定。发布后迅速走红，成为中文开发者里最知名的开源项目之一。

  7. 2025 国庆前

    Mole

    在三亚泳池边写了几百行 Shell，做出命令行清理工具 Mole。之后长出原生 Mac 客户端，一次买断 19 美元，是 TA 第一个付费产品。

  8. 2026

    Kaku、Waza、Kami：AI 时代的新家人

    Kaku 是「AI 友好」的 Mac 终端；Waza 把工程习惯写成 Claude Code / Codex 可执行的 Skills；Kami 让 Agent 输出排版漂亮的 PDF、PNG 和 PPT。同年 TA 写了一系列「你不知道的 Claude Code / Agent / 大模型训练」长文。

个人网站

标题是「Tw93 · 产品工程师、开源作者与写作者」。首页就是文章流：每篇带日期和一段两三行的摘要，近两年的文章集中在 AI Coding、Agent 架构、具身智能和产品复盘。

博客里最能看出 TA 性格的是那些「给团队同学的分享」：《如何做一个产品工程师？》《工程师如何明白地做事情》《大环境不好的情况下如何🐶着》。TA 把工作中的分享整理归档，十年下来，博客成了一份公开的成长记录。

Mole 的官网则是另一种风格：每个功能被映射为太阳系中的一颗星，地球负责清理，月球负责 AI 清理，火星照看软件，水星负责优化。工具很朴素，叙事却很浪漫。

设计与手艺

Anything added dilutes everything else.

— Tw93 的 GitHub 简介

这句话贯穿了 TA 所有的作品：Pake 只做「打包」，妙言只做「写」，Mole 只做「清理」。每个项目的 README 都有一句 emoji 开头的短介绍和一张精心设计的截图。TA 的项目是前端工程师写的，所以在视觉呈现上从不将就。

TA 在 2026 年的博文《Mole 出 Mac 版后，用户教会了我做产品》里总结：删东西之前要先给用户看一眼，平时别来打扰用户，要做到「70 岁的老爷爷也能用」。这是一个开源作者第一次面对付费用户时得到的最朴素的产品课。

长期主义

TA 说自己「喜欢开源，相信 AI，也在投资 AI，不喜欢技术网红环境，相信长期主义」。手写周刊近六年、每个长假写一个项目，就是 TA 理解的长期主义。

可以从 TA 身上学什么

  • 用假期造物：给自己一个固定节奏，比如每个长假一个项目，十年后就是一整个「开源家庭」。
  • 把分享写下来：团队内部的分享归档成博客，就是最好的个人品牌。
  • 从前端跨到端：为了解决一个性能问题去学 iOS，后来写出原生 Swift 应用和 Rust 工具。
  • 做减法：每多一个功能，都会稀释已有的功能。
  • 开源到付费：先用免费开源积累信任，再用原生体验做付费版本（Mole for Mac）。
