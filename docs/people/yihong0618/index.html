他到底在做什么？

yihong 的开源可以分成两个阶段。第一阶段（2019–2024）是「为生活写工具」：跑步数据、读书记录、背单词、玩游戏、Kindle 退出中国、小爱音箱接大模型。这些项目都从「我自己需要」出发，再被成千上万有同样需要的人 fork 走。

第二阶段（2025 至今）是「为基础设施做贡献」。他意识到大模型已经能在短时间内做出那些玩具项目，于是转向「大模型暂时做不到的东西」：在 GreptimeDB、OpenDAL、CPython、TiDB、dify、vLLM 等大项目里修 bug、做优化。

本页依据 GitHub、gitblog 中的 About Me 与年度总结、年份仓库和 yihong.run 整理，资料截至 2026 年 10 月。About Me 中较私人的内容未全部收录。

长处与局限

维度长处局限 / 需要留意
选题从生活需求出发，项目天然有用户早期不少项目依赖第三方平台的非公开接口，平台一变就要跟着修
贡献从玩具项目转向数据库、存储、推理框架等硬核基础设施大量 PR 分布在许多项目上，单个项目的深度因项目而异
社区乐于带新人入门开源，公开分享数据与方法主要内容以中文和 GitHub Issues 形式存在，检索不便
生活把爱好做成工具，长期坚持（跑步、日记、年度仓库）—

可以从他身上学什么

  • 从自己的生活出发：最好的开源项目往往是「我自己需要」。
  • 让工具替你记录：GitHub Actions + 数据可视化，让坚持变得可见。
  • 从玩具到深度贡献：当 AI 让玩具项目变得廉价，就去参与基础设施。
  • 用数据复盘：500 个 PR 按项目、语言、月份统计合并率，比一句「今年很努力」有说服力得多。
  • 公开地生活：愿望清单、年度总结、About Me，都写在公开仓库里。
