一句话：生活在大连、在日企工作的 Python 程序员，喜欢王小波、诗歌、跑步和「奇怪的东西」，把几乎每一个生活爱好都做成了开源项目。

代表作：running_page（★4.5k，个人跑步主页）、bilingual_book_maker（★9.9k，AI 翻译双语电子书）、xiaogpt（★6.9k，小爱音箱接 ChatGPT）、GitHubPoster、gitblog。

为什么值得关注：他示范了一种轻盈的开源方式：从自己的需求出发，做小而有趣的东西，再慢慢成长为 CPython、OpenDAL、GreptimeDB 等项目的贡献者与 Committer。

yihong0618 的 X 简介写着：「喜欢王小波，大概我们能成为朋友。」他每年都会建一个以年份命名的仓库（2024、2025、2026），里面写着当年的愿望清单和他创建的所有项目。2026 年那一页的第一句话是：「多关心家人朋友，如果有余力，去完成自己剩下的遗憾。」

成长与经历

他在博客的 About Me 里列了三十多条关于自己的事：写了二十多年日记、能背近一百位圆周率和《琵琶行》、读过王小波的所有书、马拉松 PB 4 小时 1 分、媳妇是初恋、心情不好会去海边看海。还有一条：「0618 是 0.618 的意思，不是我生日，我也不是刘强东粉丝。」

  1. 2015

    注册 GitHub

    从 Python 起步，喜欢的编程语言至今仍是 Python。

  2. 2019

    gitblog：用 Issues 写博客

    「People Die, but Long Live GitHub」。用 GitHub Issues 写文章，用 GitHub Actions 自动生成 README 和 RSS。这个模式被很多中文开发者效仿。

  3. 2020

    running_page

    把 Strava、Nike Run Club、Garmin、Keep 等平台的跑步数据同步到 GitHub，生成一张可视化的个人跑步主页。他自己的主页 yihong.run 已经记录了超过一万公里。

  4. 2021–2022

    GitHubPoster 与 Kindle 助手

    GitHubPoster 把跑步、读书、背单词、游戏等数据画成 GitHub 风格的热力图和 Skyline；Kindle_download_helper 帮用户在 Kindle 退出中国时批量下载自己买过的书。

  5. 2023

    大模型元年

    xiaogpt 让小米小爱音箱接上 ChatGPT 等大模型；bilingual_book_maker 用 AI 把 epub 翻译成双语对照电子书，成为他星数最多的项目。之后还有 Telegram Bot 合集、DALL·E 3 机器人等。

  6. 2025

    一年 500 个 Pull Request

    他意识到「之前做的玩具项目没那么重要了」，转向给大项目做深度贡献：给 68 个项目提了 500 个 PR，合并 415 个，成为 OpenDAL、GreptimeDB 的 Committer，给 CPython、dify 贡献代码，还参加了 PyCon 并做了几场演讲。

设计与手艺

yihong 的作品很少有复杂的界面，但它们有一种「生活设计感」：把数据变成可以挂在墙上的东西。跑步变成地图，读书变成热力图，一年变成一个仓库。

The best is yet to come.

一次面试带来的转向

去年面试一家数据库公司时，面试官看了他给 Grafana 的 PR 说「原来不是什么大 feature 啊」。他由此意识到「开源只是浅浅地加入是不够的」，于是有了 2025 年的 500 个 PR。

可以从他身上学什么

  • 从自己的生活出发：最好的开源项目往往是「我自己需要」。
  • 让工具替你记录：GitHub Actions + 数据可视化，让坚持变得可见。
  • 从玩具到深度贡献：AI 让玩具项目变得廉价时，转向参与基础设施。
  • 公开地生活：愿望清单、年度总结、About Me，都写在公开仓库里。
