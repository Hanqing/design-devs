Joaquim Vergès：从第三方 Twitter 客户端到 Agent 工作区

他是 Android 圈的老牌独立开发者：做过备受欢迎的 Twitter 客户端 Falcon Pro 和 Hacker News 阅读器 Hacked。Falcon 撞上了 Twitter 给第三方应用设的 10 万用户上限，他想尽办法绕过限制；2015 年，Twitter 干脆把他招进 Android 核心界面团队。之后他在 Twitch、thirdweb 工作，写过链上游戏 Ethrone 和 Kotlin 多平台框架 Helium。现在他在旧金山做 Nebula：一个让团队成员和 AI Agent 在同一组频道里协作的工作区。

1.1 万X 关注者
2009加入 X

2015 年，Falcon 的用户数到了 10 万，Twitter 停止了它的新用户登录：这是官方给第三方客户端设的令牌上限。Joaquim 想了一连串变通办法，推出了 Falcon Pro 3。几个月后，Twitter 宣布聘请他加入官方 Android 核心界面团队。他当时说：「我想做一个拥有完整 API 和现代界面的杀手级官方 App。」十年后，他在做的仍是「人和信息流」的产品，只是这一次，频道里多了 AI Agent。

他到底在做什么？

Nebula 自称「agent-native workspace」：频道里既有同事，也有 Agent；你写的、说的、展示的都会被记住，并可以主动触发工作。工程师把编码交给 Claude Code 和 Codex，销售和市场把调研和邮件交给 Nebula 自己的 Agent；它还能旁听团队会议，记住决定并开始跟进。Mac、Windows、Linux、iPhone 和 Android 都有客户端。

同一家公司开源的 Bugpatrol 是一支由 Agent 组成的 QA 团队：探索者 Agent 像测试员一样使用 App，裁判 Agent 判断哪些是真 Bug，修复者 Agent 在独立的 git 工作树里写修复，再回到运行中的 App 复测，最后为每个修复开 PR。

可以从他身上学什么

  • 平台限制也能变成机会：被限流的第三方客户端作者被官方招安。
  • 保留一个实验场：在自己的 App 里试大公司不敢试的东西。
  • 跟着前沿走：每一波新技术都亲手做点东西。
  • 让 Agent 的工作可见：所有人都能看到、都能接手。
  • 用 Agent 测 Agent：QA 也可以交给一支 Agent 团队。
