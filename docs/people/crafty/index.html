Nick Butcher：让 Android 应用好看又好动

他在 GitHub 上的自我介绍只有一句：「Android designer and developer.」作为 Google Android 开发者关系团队的一员，他写了 Plaid：一个汇集设计资讯的开源 App，也是 Material Design 在真实应用里的样板，获得了 1.6 万颗星。他在 Google I/O 和 Android 开发者博客上讲动画、矢量图、主题与样式，写下《Motional Intelligence》《Android styling》等系列。后来他转任产品经理，负责 Android 新一代声明式界面工具包 Jetpack Compose。

他到底在做什么？

Nick 的长期主题是 Android 上的视觉与动效：怎样用 VectorDrawable 画图标、怎样让动画「有智能」、怎样用主题属性代替硬编码颜色、怎样让自适应图标在不同设备的遮罩下都好看。他的文章常常配有可下载的小工具，比如一键把系统动画放慢 5 倍的快捷设置开关，方便开发者检查动画细节。

现在他作为产品经理负责 Jetpack Compose，也会在 The Android Show 等节目里回答开发者的问题。

可以从他身上学什么

  • 用一个真实 App 证明规范：Plaid 比任何文档都有说服力。
  • 给自己做调试工具：把动画放慢 5 倍看细节。
  • 用主题属性，不要硬编码：视觉体系才能统一。
  • 动画要能被打断：响应用户比播放完整更重要。
  • 从布道者到产品经理：最懂开发者痛点的人来定方向。
