Folyd（朱爽）Geddle 创始人 · Wanderboat 前联合创始人 · Rust 社区建设者 · 前字节跳动工程师

Folyd：「有德行的理想主义者，极简主义者」

TA 是一位来自北京的 Rust 爱好者和前字节跳动工程师，GitHub 上写着：「我喜欢做人们喜欢用的产品。」TA 做了 Rust 开发者几乎人手一个的浏览器扩展 Rust Search Extension、Rust 搜索引擎 Query.rs、社区刊物 Rust Magazine，以及为了出版杂志而用 Rust 写的静态站点生成器 Zine；还给 rust-lang/rust、tokio tracing、Apache Arrow 和 DataFusion 贡献过代码。之后 TA 联合创办了 AI 旅行应用 Wanderboat，做了 AI 编程语言 AIScript，现在经营面向 AI 与 SaaS 产品的联盟营销平台 Geddle。

2021 年底，Folyd 在字节跳动内部开了一个专栏《To-D 观察室》，分享面向开发者行业的动态和故事，「有点像开发者版的《浪潮之巅》」。专栏很受欢迎，TA 想把它公开发布，但作为「早期互联网去中心化、开放理念的忠实拥趸」，TA 不想发到公众号或知乎。既然专栏是按十篇一季发布的，那就做成杂志；既然没有专门做杂志的静态网站生成器，那就用 Rust 自己写一个。这就是 Zine 的由来。

TA 到底在做什么？

Folyd 的作品分成两类。一类是给开发者的工具和社区：在浏览器地址栏里即时搜索 Rust 文档、crate、属性、官方书籍和错误码的扩展；面向 Rust 的搜索引擎；Rust 社区刊物；用 Arrow、Parquet 和 DataFusion 做的 Rust 可观测性工具 duo；以及把 Google robots.txt 解析器移植到 Rust 的库。

另一类是商业产品：AIScript 把解释型语言和 Web 框架合二为一，帮开发者快速做 AI 应用；Geddle 是 AI 与 SaaS 产品的联盟营销市场，让创作者推广工具、按月拿分成。TA 还经营 Arrfounder、Aiberm 等多款面向出海开发者的服务。

本页依据 folyd.com（首页、博客、项目、关于）、GitHub 个人 README 与仓库、geddle.com 和 X 资料整理，资料截至 2026 年 10 月。Wanderboat 官网检查时需要人机验证，未能读取。部分付费服务涉及第三方账户与额度转售，读者使用前请自行评估合规性。

代表作品详解

Rust Search Extension ↗

2018–浏览器扩展★1.3 千

在 Chrome、Firefox 和 Edge 的地址栏里即时搜索 Rust 的文档、crate、内置属性、官方书籍和错误码。它的「下一代」是独立的搜索引擎 Query.rs，已经支持搜索 Reddit 热帖。

Zine ↗

2022Rust★925

「一个简单、有主见的工具，用来做你自己的杂志。」移动优先、优雅的杂志式排版、按期组织内容，支持 RSS、Open Graph、话题和多语言，最终生成静态网站。Rust Magazine 和 2d2d.io 都用它构建。

AIScript ↗

2024–2025Rust★320

「The next generation language for human and AI.」一门解释型语言加一个 Web 框架，都用 Rust 写成，语法借鉴 Python、JavaScript 和 Rust，目标是让开发者轻松构建 AI 应用。

Geddle ↗

2025–联盟营销平台

连接 AI / SaaS 公司和内容创作者：创作者加入推广计划、制作内容、按月领取经常性佣金，最高 50%；通过 Stripe 直接结算。
