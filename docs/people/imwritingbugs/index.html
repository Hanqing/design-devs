TA 到底在做什么？

DeepChat 是一个开源、本地优先的 AI Agent 桌面客户端，支持多家模型、MCP、Skills、ACP，以及接入即时通讯应用的远程控制。夕阳针是它提交最多的作者，也为它写了配套基础设施：模拟 OpenAI 兼容接口的 mock-openai-api、给 Electron 应用注入小型 Node.js 运行时的 tiny-runtime-injector、聚合模型能力与价格的 PublicProviderConf。

2026 年，TA 把同样的思路延伸到三个方向：多 Agent 团队 DimAgent、语音助手 Vokie，以及一把自己写固件的 Vibe 键盘。

本页依据 GitHub（zerob13 与 ThinkInAIXYZ）、dimagent.com、vokie.com 和 X 资料整理，资料截至 2026 年 10 月。

Vokie ↗

2026macOS / WindowsAI 语音

「你只管说，Vokie 帮你整理。」在任何输入框按下快捷键，口述内容会被整理后粘贴回去；会议时按下快捷键，不用邀请机器人入会，腾讯会议、飞书、Zoom 或线下面谈都能记录，会后得到转写、摘要和行动项。所有记录沉淀在「拾忆」里，可以按授权供 Agent 查询。

2026多 Agent候补名单
