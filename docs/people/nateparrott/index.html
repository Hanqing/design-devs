2014 年，OS X Yosemite 刚刚让 Spotlight 变得更好用，一个学生就把它变成了插件平台：天气、翻译、日程、发邮件，全都能在 Spotlight 里完成。这个项目叫 Flashlight。媒体报道，它好到让 Apple 请作者去 Spotlight 团队实习。十年后，这位作者在 Anthropic 做设计。

TA 到底在做什么？

Nate 的工作方式是「把想法做成能玩的东西」。在 The Browser Company，TA 参与了 Arc 的设计；业余时间，TA 用 Swift 和 JavaScript 做了大量小实验：AI 现场生成网页的「幻想互联网模拟器」web98、一个住在 Dock 里的小球 Ball、一个经常教错东西的学习 App uhohlingo。

这些作品的共同点是幽默和手感：它们不一定有用，但会让人想多玩一会儿。

成长与经历

  1. 2012

    注册 GitHub

    开始在 GitHub 上公开自己的小项目。

  2. 2014–2015

    Flashlight

    给 OS X Yosemite 的 Spotlight 加上基于 Python 的插件系统，支持天气、翻译、日程、发邮件、搜图等上百个动作。MacStories 称它是一个非官方的「粗糙 hack」，内存偶尔会暴涨，但 Mac 社区非常喜欢它。

  3. 2015

    Apple 实习

    据 Cult of Mac 报道，Flashlight 1.0 让 Apple 请 TA 去 Spotlight 团队实习。TA 对 9to5Mac 说，Apple 觉得 Flashlight「有意思」，但「绝对不是请我来把 Flashlight 做进 OS X」。之后 10.10.4 更新让 Flashlight 失效，项目停止维护。

  4. 2016–2017

    Web 实验

    lettercrap 用图片蒙版生成动态 ASCII 艺术；letterdance 让文字在滚动时逐字母过渡；subway 按实际通行时间缩放纽约地铁图；还用 Jupyter 探索神经网络。

  5. The Browser Company

    首位设计师

    TA 在 ShopTalk Show 上说，自己遇到团队前就在做自己的浏览器，后来加入成为公司的第一位设计师，参与了 Arc 的侧边栏、Boosts 等设计。

  6. 2022–2023

    AI 原型

    做了阅读器 feeeed 并开源它的阅读模式 reeeed；用 OpenAI 流式补全做了 web98、uhohlingo、sous、chattoys 等实验。

  7. 2024–2025

    Anthropic

    离开 The Browser Company，加入 Anthropic 做设计。同期开源 Ball、Infinite App Store 和 nat。

设计观点

在 ShopTalk Show 545 期，TA 讲了 Arc 的几个设计决定：侧边栏放在左边，因为放右边的原型让用户把鼠标移过太多空白；「我们把标签页看作新的文件」，所以标签可以重命名、文件夹能跨会话保留；访问 localhost 时自动开启开发者模式，这来自对 Web 开发者用户的调研。

We think of tabs as the new files.

— Nate Parrott，ShopTalk Show 545

可以从 TA 身上学什么

  • 设计师也写代码：可运行的原型是最好的设计文档。
  • 作品就是简历：一个学生项目让 Apple 主动找上门。
  • 给软件一点性格：Arc 被人记住，是因为它有态度。
  • 用幽默表达批评：点击赚金币的网站，比一篇长文更能说明问题。
  • 新技术出现时先玩起来：web98、uhohlingo 都是对 AI 的好奇心实验。
