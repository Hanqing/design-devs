Sherwin Wu：工程师正在变成魔法师

他在 OpenAI 负责 API 开发者平台的工程团队，也就是让全世界开发者用上 OpenAI 模型的那一层：模型接口、微调、Agent 构建工具和底层基础设施。2025 年底，他在 a16z 播客上和 Martin Casado 聊 OpenAI 怎样为 8 亿周活用户构建平台、为什么从「一个通用模型」走向「专用模型与微调」；2026 年初在 Lenny's Podcast 上说，OpenAI 约 95% 的工程师在用 Codex，很多人同时指挥 10 到 20 个并行 Agent。他的 X 简介只有一个词：@OpenAI。

他到底在做什么？

Sherwin 的团队负责 OpenAI 的开发者平台：外部开发者和 OpenAI 自家产品用的是同一套模型和工具。他在 X 上说过，自己最喜欢 OpenAI 的一点就是「让每个人都能用我们自己产品里用的同一套技术来构建」，比如把 ChatGPT 语音背后的双工技术开放到 API 里，或者让企业用和 Codex 相同的 Agent 框架构建自己的内部 Agent。

在 a16z 播客上，他谈到行业观点的转变：单一模型还是多模型、应用层还是 API 层更有价值、上下文工程有多重要，以及开发者为什么会因为信任、优化甚至情感依恋而「黏」在熟悉的模型家族上。

本页依据 X 个人资料与公开推文、Lenny's Newsletter 节目页、a16z 播客介绍、01cloud 工程博客的节目总结和 Martin Casado 的推文整理，资料截至 2026 年 10 月。他加入 OpenAI 之前的经历未找到可靠来源，未收录。

可以从他身上学什么

  • 为模型的未来构建：今天的脚手架明天可能多余。
  • 学会指挥 Agent：并行的 Agent 是新的生产力。
  • 看真实成本：按任务算，而不是按 token 标价算。
  • 平台要和自家产品用同一套技术：开发者才会信任。
  • 让社区参与：行业插件由行业的人来做。
