Owen 在 About 页解释了自己的博客为什么分成三层：Featured 更新频率低，给订阅者；Latest 更新频率较高，给主动来逛的人；Archive 囊括所有内容，更新频率极高，主要给自己看。「这样设计既满足了博客对陌生读者的易读性，又能让作者经常在博客更新。我一直想用这样的博客系统，但是市场上没有，所以我开发了 Jant。」

TA 到底在做什么？

Owen 的作品都在解决同一个问题：怎样更高效、更舒服地获取和沉淀信息。获取端是 Buzzing、沉浸式翻译、Track Awesome List、HN Vault；沉淀端是个人 Wiki、数字花园博客和 Jant。

沉浸式翻译最核心的设计决定是不替换原文，而是在网页每一段后面附上母语译文。它尊重原文，也尊重读者学外语的意愿。这一个小决定，定义了一个品类：如今沉浸式翻译已经覆盖网页、PDF 和在线视频双语字幕。

本页依据 owenyoung.com（About、Projects、Now）、GitHub 与 README、沉浸式翻译官网整理，资料截至 2026 年 10 月。TA 离开沉浸式翻译的具体原因未见公开细节。

成长与经历

  1. 2020

    Actionsflow

    注册 GitHub 与 X。9 月发布基于 GitHub Actions 的免费 IFTTT / Zapier 替代品：用和 Actions 一样的 YAML 配置连接应用、数据和 API，附带 RSSHub 等触发器；之后又做了基于 Deno 的 Denoflow。

  2. 2021

    个人 Wiki

    「Everything I Know by Owen」：用自己写的 Gatsby Theme Primer Wiki 搭建终身维护的个人知识库，兼容 Foam 和 Obsidian，并做了对应的模板。

  3. 2022

    Buzzing、Track Awesome List

    9 月发布 Buzzing：聚合 Hacker News、纽约时报等国外热门资讯并把标题翻译成中文，配套 HN 中文精选、问 Reddit 等 Telegram Bot；10 月发布 Track Awesome List，把 GitHub 最热门的 500 个 awesome 列表按条目添加时间排序；博客迁移到 Zola。

  4. 2022.11

    沉浸式翻译

    在网页每个段落后面插入母语译文的浏览器扩展，让双语对照阅读成为可能，迅速成为最受欢迎的翻译扩展之一。同期还做了网页剪藏 clip。

  5. 2023–2024

    小工具

    wikipedia-to-epub（把维基百科做成电子书）、bookgpt、YAMLScript（YAML as code）、Artab（每个新标签页一张随机艺术作品）；用 .gitignore 白名单把整个 $HOME 目录做成 dotfiles 仓库。

  6. 2025.07

    离开沉浸式翻译

    离开参与创作近三年的沉浸式翻译，回到独立创作。

  7. 2026

    Jant 与 HN Vault

    1 月开始写 Jant，4 月正式发布：一个 Tumblr 风格、单作者、去掉一切社交机制的微博客系统，跑在 Cloudflare Workers 上；HN Vault 让你从 1900 年开始按年阅读 Hacker News 上分享过的文章。

代表作品详解

沉浸式翻译 ↗

2022.11浏览器扩展3,000 万用户

在网页每一段原文后面附上母语译文，让你在一个页面里同时读到两种语言。官网现在的介绍是「一款领先的 AI 双语网页翻译扩展，被全球 3,000 多万用户信任」，功能也从网页扩展到 PDF 翻译和在线视频双语字幕，覆盖 Chrome、Edge 等主流浏览器。

Owen 在 2022–2025 年参与了它的创作。它的成功说明了一件事：在成熟品类里，一个关键的交互决定（不替换，而是并排）就足以开辟新的空间。

Jant ↗

2026TypeScriptCloudflare Workers + D1

「A personal microblogging system as smooth as Threads and Tumblr.」介于传统博客和社交媒体之间：单作者、自托管、去掉一切社交机制。原生支持 Note、Link、Quote、Thread 等内容类型，发布体验像发推一样轻；首页和 RSS 分离，可以把不想打扰订阅者的内容设为「Hidden from Latest」；内容自动同步到 GitHub，方便和 AI 交互。

部署方式很友好：一键部署到 Cloudflare Workers，或者 npm create jant my-site。Owen 自己的博客就是现成的示例。

个人网站研究

www.owenyoung.com ↗

About 页写道：「我把这里定位成我的数字个人花园，存放我的笔记、想法和生活记录。」首页有一块 Pinned：「当前想置顶的一些内容」，比如 TA 学到的概念 Hypomnēma：把读到、听到的真理材料收集起来，再通过练习来塑造自己。

收藏页面包括 Now（像 Story 一样记录生活瞬间，48 小时内有更新时导航上会出现一个小圆点）、Pinned、Wisdom、Thoughts、Quotes、Uses、Books、Sources 等。TA 说自己特别喜欢收藏引言：「对于同一个道理，用不同的语言包装它，区别是非常大的。」

观点与方法

  • 为自己的阅读习惯做工具：Buzzing、沉浸式翻译、HN Vault 都源于此。
  • 降低发布摩擦：写作的最大敌人是「这值不值得发」，所以要把「发」和「推送给订阅者」分开。
  • 尊重别人的注意力：短想法放在自己的花园里，不污染别人的时间轴。
  • 收藏是为了塑造自己：Hypomnēma 不是囤积，而是把真理内化为品格和行动。

可以从 TA 身上学什么

  • 为自己的阅读习惯做工具：最好的需求就在自己每天的信息流里。
  • 一个交互决定可以定义一个品类：不替换原文，而是并排显示。
  • 把「发布」和「打扰」分开：让写作变得更轻松。
  • 做完一件事，勇于离开：回到独立创作，重新出发。
