袁朝发：从零手写大模型，再从零手搓 Agent

他是一名大模型算法工程师，先后在腾讯和字节跳动做过大模型与搜广推相关工作，X 简介写着「ex-ByteDance staff engineer」。业余时间，他以「chaofa 用代码打点酱油」之名在 B 站、YouTube、公众号和博客上讲大模型：从零手写 Self-Attention、LoRA、RoPE，翻译《Hands-On Large Language Models》，用一张 3090 训练自己的小模型；2026 年他改用真名署名，创办 ApeCode.ai，用 500 行 Python 复刻 Claude Code。

他到底在做什么？

袁朝发的内容有一个鲜明的特点：完全从零手写，边写边讲。LLMs-Zero-to-Hero 的 README 写着「致敬 Andrej Karpathy」，从 Attention、GQA、LoRA、DPO、RoPE 一路写下来，配套视频讲解，最低一张 3090 就能训练。

2026 年他把重心从模型转向 Agent：写 Prompt Caching、Harness Engineering 的长文，创办 ApeCode.ai「公开构建」，开源轻量编程助手 apecode 和本地优先的 nanoclaw-py，并准备配套的工程课程。

  • 从零手写一遍：写过 Self-Attention，才真正懂它。
