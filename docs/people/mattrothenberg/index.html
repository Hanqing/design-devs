Matt Rothenberg：设计师、开发者、连续折腾者

他从肯塔基州搬到纽约，自称「设计师、开发者和连续折腾者」。现在他在 Cloudflare 维护设计系统 Kumo（★4.1 千），并管理设计工程团队。此前他在 GitHub Next 探索软件开发的未来，参与过 Copilot 这样的「大热门」；在 Clearbit 搭建了核心设计系统；在 Heroku 做数据产品的 Web 和命令行界面；还帮联合国开发计划署做了 Digital Development Compass，可以快速查看任何国家的数字化准备程度。X 简介里他还提到曾在 Replicate 工作。他给不少知名开源项目做过贡献：Tailwind CSS、React Router、Base UI、Ariakit 和 Paper 的着色器库；早年他写的 Vue 动画库 vue-overdrive、vue-flip-toolkit 也很受欢迎。

2026 年秋天，他每周在个人网站发一篇笔记，主题叫「primitives for generation」（为生成而设计的基础组件）。他在追问一个他自己也说「很有帮助地没有给出答案」的问题：当 Agent 可以按需生成一个视图时，仪表盘到底是用来干什么的？他做了一个原型：给 Cloudflare 命令行加一个「画布模式」，本地 Agent 直接用真实的控制台组件在一张实时画布上回答你的问题。

他到底在做什么？

Matt 在 Cloudflare 一边维护 Kumo 组件库，一边探索 Agent 时代的界面：可以停靠、拖动、缩放的面板，替代展开表格行；重新设计部署流程的第一屏，让你粘贴仓库地址、拖入文件夹或选模板，而不用先选择产品；以及当 Agent 完成大部分 UI 工作时，「变更审查」应该是什么样子，怎么更容易看出视觉和体验上改了什么。

他的业余项目同样偏爱精致的交互：sillon 是一个基于 React 的音频波形组件，想替代 Wavesurfer.js，还支持径向可视化和像 SoundCloud 那样在波形上叠加评论；formulaire 是对 FormKeep 经典 Gridforms 的现代改写；fold-gradient 是一个可以直接复制进 React 应用的 Paper 着色器。
