Raphael Salaja：为没人注意却人人能感到的细节工作

TA 是住在爱尔兰的设计工程师，个人网站上写：「我被那些大多数人从不注意、却总能感觉到的细节吸引。」TA 和 Avara、OpenSea、Daybreak 等团队合作过，现在在 Warp。TA 写了一本免费的「活的界面手册」userinterface.wiki，讲动画原则、弹簧曲线、伪元素和网页声音；做了一个把声音写成数据的网页音频库 web-kits/audio；2026 年 10 月又发布了 Pond，一个免费开源、在后台静静归档你在 X、Instagram、Pinterest 上收藏内容的桌面应用。

TA 到底在做什么？

Raphael 做的是界面里看不见的那一层：文字切换时共享字符滑到新位置（Calligraph），元素在两个状态之间平滑过渡（Cambio），按钮按下时有一声合适的音效（web-kits/audio）。TA 把这些经验整理成 userinterface.wiki 上的长文，又把文章写成给 AI Agent 用的 Skill 文件。

Pond 是 TA 目前最大的项目：一个跨 Mac 和 Windows 的个人网页归档工具，配合浏览器扩展，在后台保存你在各个平台收藏的内容，按你记得的样子找回来。上线后一周内又加了画布、从 Eagle 和 mymind 导入等功能。

可以从 TA 身上学什么

  • 别忘了声音：界面也可以有恰当的听觉反馈。
  • 把知识写成手册：一篇篇积累，最后就是一本书。
  • 减少弹窗：试试不用对话框完成整个界面。
  • 做自己需要的工具：Pond 源于对收藏工具的不满。
  • 先发展自己，再训练 AI。
