Bramus：从 view-source 爱上 Web

他是来自比利时的 Web 开发者，现在在 Google Chrome 开发者关系团队，专注 CSS、Web UI 和 DevTools，也是 CSS 工作组（CSSWG）的成员。他在个人简介里写道：14 岁那年（1997 年）发现了 view-source，从此爱上了 Web。加入 Google 之前，他做过多年自由职业的前后端开发，还当了七年大学「Web 与移动」讲师，教本科生 HTML、CSS 和 JavaScript，「按这个顺序」。他的技术博客 bram.us 从 2001 年写到现在。在 Chrome，他是滚动驱动动画、视图过渡（View Transitions）等新特性最活跃的布道者之一，做了调试滚动驱动动画的 DevTools 扩展，还正在和同事起草用 CSS 声明路由与导航匹配的新提案。业余时间他是 PADI 潜水长（Divemaster）。

他到底在做什么？

Bramus 的工作是让新的 CSS 能力被理解和用起来：写文章、做 CodePen 演示、做调试工具、出 polyfill。他把多年视图过渡实验里反复写的代码打包成工具库；做了 view-transitions-mock，一个同文档视图过渡的非视觉 polyfill；还演示了「可重定向」（可中断）的视图过渡和元素级视图过渡。

他正在和同事一起推动用 CSS 做导航样式：用 @route 定义路由，用 @navigation 查询当前导航，用 :nav-source 选择触发导航的元素。他们已经在 CSS Day 上做了初步介绍，并在博客上征求反馈。

本页依据 bram.us（首页、关于、演讲）、GitHub 仓库与 README 和 X 帖子整理，资料截至 2026 年 10 月。他已主要转到 Bluesky 发帖。姓氏 Van Damme 见于 bram.us，他平时通常只用 Bramus。
