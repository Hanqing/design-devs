他到底在做什么？

拾一的作品几乎都围绕「好看、好用的界面」：博客系统 Mix Space 和它的前端主题 Shiro、给摄影师的照片画廊 Afilmory、qBittorrent 的现代 Web 界面 Torrent Vibe、kawaii 风格的 OKLCH 色彩系统 Pastel，以及 2026 年把这一切收拢起来的排版设计系统「余白 Yohaku」。

2025 年以后，他的产出速度明显变快：近一年接近两万次贡献，用 Agent 写代码、自己验收。2026 年他做了 Lody 的第三方 iOS 客户端、旅行记账 App Nyatabi、Mac 上的 AI 看盘工具 Kansoku，以及在 Slack 里运行 Claude Agent SDK 和 Codex 的 Kagura。

本页依据 innei.in（自述、文章、手记、时间线）、GitHub 主页与 README、Nyatabi 官网与 App Store 资料和 X 资料整理，资料截至 2026 年 10 月。手记中的私人生活内容未收录。

可以从他身上学什么

  • 把个人网站当作品：一个博客主题也能收获四千多颗星。
  • 沉淀自己的设计系统：颜色、字体、留白，写成可复用的规则。
  • 内向也能被看见：作品和写作替你说话。
  • 做 AI 指挥师：自己定需求、做验收，让 Agent 写代码。
  • 警惕效率悖论：生产力提升，也可能带来疲惫。
