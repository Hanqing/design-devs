Steve Schoger：教开发者自己把界面做好看

他住在加拿大安大略省基奇纳，是 Shopify 的高级主任设计师（Senior Staff Designer）。很多开发者认识他，是因为他和 Adam Wathan 合写的《Refactoring UI》：一本从开发者视角讲具体设计技巧的书，官网称已售出三万多本，Goodreads 评分 4.68。早年他在 X 上发的「设计小贴士」系列图片广为流传，后来成了这本书的雏形。之后他作为设计师加入 Tailwind Labs，设计了 Tailwind UI 的大量组件和模板，以及 Heroicons。2026 年 9 月 Tailwind Labs 加入 Shopify，他也随之加入。最近他在探索用 Claude Code 当主力设计工具，一小时的教学视频收获了六千多个赞，这些经验也在被做成 ui.sh。

Refactoring UI 的官网上，Adam Wathan 写了一段自述：他是一个「曾经很不会设计」的全栈开发者，和 Steve 是多年的朋友，一起做过很多副业项目，Steve 负责设计，他负责写代码。很多时候 Steve 只改了几处，界面就变得好看得多，Adam 总想知道为什么。这本书就是对「为什么」的回答：不是讲抽象的设计理论，而是讲开发者能立刻用上的具体战术。

他到底在做什么？

Steve 的强项是把设计直觉拆成可以照做的规则：从层次、留白、颜色、阴影、文字到图片，每一条都配有修改前后的对比。这种风格也延续到了 Tailwind UI：开发者直接复制组件，就能得到专业设计师的默认值。

2026 年他开始把这些规则交给 AI。他录了一小时视频，演示如何把 Claude Code 当作主要设计工具，又用 Claude Code 加语音输入法 Wispr Flow 设计了一个仪表盘。这些经验被整理进 ui.sh：「给界面构建者的 Agent Skills，一套精心打造、按任务组织的提示词和工作流，用来做出不糟糕的界面。」

本页依据 refactoringui.com、ui.sh、X 帖子，以及本站 Adam Wathan 页面中关于 Tailwind Labs 加入 Shopify 的资料整理，资料截至 2026 年 10 月。研究脚本未找到他本人的 GitHub 账号；他在 Tailwind 之前的经历公开资料较少。

观点

“I know this looks terrible, but I have no idea why.”

— 《Refactoring UI》官网，开发者最常见的困惑

他在视频里用的「假」logo 其实是真的：他自己画了标志，再请 ChatGPT 起名，得到了「Axiom」。他对 AI 的态度很实用：设计规则讲清楚了，AI 就能照着做。

可以从他身上学什么

  • 把直觉变成规则。
  • 用前后对比来教设计。
  • 设计师和开发者结对，作品会更好。
  • 把规则写给 AI：ui.sh 就是这样做的。
