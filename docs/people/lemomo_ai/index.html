Lemomo：不用视频模型，用纯代码拍短片

一位在墨尔本「公开构建」的程序员与独立开发者，GitHub 简介写着「给 AI 炒作做压力测试的独立开发者」。TA 的 Lemo-Opuscar 让 Claude 用纯代码生成短片，51 种影片风格，获得四千多星；还有一张图变循环动图的 lemo-wake、给 Claude Code 换皮肤的 lemo-mod，以及在复印件上盖「仅供××使用」的小章。

设计与思考

Lemomo 的作品都有一种「产品化的创意」：不是一个提示词，而是一套风格 + 导演指南 + 技术指南 + 示范作品。用户只需要选择和描述，剩下的交给 Agent。

Stampy 小章则提醒我们，隐私保护可以很小很具体：证件复印件交出去之前，写清楚只给谁用。

可以从 TA 身上学什么

  • 换个思路用 AI：没有视频模型，就用代码生成视频。
  • 把方法打包成 Skill：风格、指南、示例一起交付。
  • 中英双语开源：让项目同时进入两个社区。
  • 小工具解决真问题：一个印章也能保护隐私。
