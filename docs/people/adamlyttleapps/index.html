他到底在做什么？

Adam 经营的是一个 App 组合，而不是一个 App。看他公司名下的作品就能感受到这种策略：宝可梦卡牌估价、比索兑美元换算、YouTube 订阅数、把手机变蓝牙麦克风、鱼类 / 昆虫 / 种子 AI 识别、「这是素食吗」扫描器、排行榜制作、圣经闹钟、学钢琴游戏、把自己变成卡通。每一款都瞄准一个具体的搜索关键词。

2026 年，他把这些年的 ASO 和转化经验写成了 Claude Code Skills：一个分析你的代码、找出核心卖点并生成高转化 App Store 截图；一个参照 Headspace、Noom、Duolingo 等订阅 App 的模式，设计问卷式引导流程。与此同时，他也在实现「想当游戏开发者」的愿望：网页上已经有十几款免费小游戏。

ASO 截图 Skill ↗

2026.03Claude Code Skill★1.8 千

「A Claude Code skill that generates high-converting App Store screenshots for your iOS app.」流程分几步：卖点发现：分析代码库，找出驱动下载的 3–5 个核心卖点；截图配对：检查模拟器截图，为每个卖点配一张；然后用 AI 生成专业的截图图像。这是把十几年的 ASO 经验交给 Agent 的一种方式。

方法论

  • 给学习设一个节奏：每月一款，用发布倒逼成长。
  • 组合胜过单押：不追一个大产品，而是让很多小 App 一起构成稳定的收入。
  • 重视 ASO：截图、关键词、引导页决定了大多数 App 的生死。
  • 爆款不等于赚钱：Swipe the Cat 的病毒传播没有带来预期的变现，教训是先设计好商业模式。
  • 把经验产品化：2026 年把 ASO 与转化经验写成 Skills，让 AI 按他的方法去做。

可以从他身上学什么

  • 失败后重新开始：从割草到 App，人生没有那么多「太晚」。
  • 给学习设一个节奏：每月一款，用发布倒逼成长。
  • 瞄准具体的搜索需求：一个卡牌估价工具，比一个宏大的平台更容易被找到。
  • 把经验交给 AI：写成 Skill，经验就能被反复复用。
