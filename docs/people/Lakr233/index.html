TA 到底在做什么？

Lakr 的作品可以分成三类。Apple 设备的底层工具：在 Mac 上跑虚拟 iPhone、自动备份 iOS 设备、管理多个地区的 Apple ID、一键重启 macOS 的系统服务、读写 NFC 标签。原生 App：AI 客户端 FlowDown、音乐播放器 Muse Amp、刘海文件暂存 NotchDrop。视觉与玩心：网格渐变库 ColorfulX、「借一个上班的进度条」MoneyProgress、在屏幕上显示 Windows 激活提示的 ActivateMac、打碎液态玻璃的小游戏。

TA 的发布频率非常高：大量小项目里，总会长出一个大项目。2026 年的 vphone-cli 就是这样，几个月里成了当年最受关注的 Apple 平台开源项目之一。

本页依据 GitHub（主页 README 与仓库）、FlowDown 官网、App Store 与 hwang.fun 的合作者信息整理，资料截至 2026 年 10 月。个人网站 qaq.wiki 在本次检查时无法访问。

代表作品详解

vphone-cli ↗

2026.02Swift安全研究 · 逆向

「Run a virtual iPhone on an Apple Silicon Mac.」用苹果的 Virtualization.framework 和 PCC（私有云计算）研究虚拟机运行 iOS，面向安全研究、逆向工程和调试。功能包括：在 Mac 上用图形窗口操作虚拟 iPhone、截图录屏；预先打好补丁的固件和包管理环境；导出、导入和克隆虚拟机；可选的本地 HTTP / WebSocket 自动化接口；运行时不依赖 Xcode、Python 或 Homebrew。

README 最有时代感的一段是「Let an agent do it」：直接把一段提示词交给 Claude Code 或 Codex，让 Agent 读取项目里的技能文件、检查环境、安装启动器和对应的 bundle，并且明确要求它「不要改 SIP 和任何主机安全设置，在我确认固件和磁盘空间之前不要创建机器」。

2025.03SwiftiOS 17+ / macOS 14+
