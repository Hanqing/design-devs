代表作：React Compiler（与 Joe Savona、Mofei Zhang 等人一起在 2025 年 10 月发布 1.0）、hiring-without-whiteboards（★5 万+，列出不用白板面试的公司）。

poteto 的 GitHub 头像旁边写着一只小狗颜文字「▼・ᴥ・▼」。在这个可爱的签名背后，是一份横跨 Elixir、Ember、Relay、React Compiler 和 AI Agent 的硬核履历。

成长与经历

  1. 2015–2016

    Ember 与 Elixir 社区

    在 Ember 社区非常活跃：写了 ember-crumbly 等插件，并为 EmberConf 2015/2016、ElixirConf 2016 整理了被广泛引用的会议总结。Elixir 插件 terraform 演示了如何把旧 API 渐进式迁移到 Phoenix。

  2. 2017 前后

    Netflix

    在 Netflix 做 Web 工程（她的 X 简介里写着 prev netflix）。同年发起 hiring-without-whiteboards：一份「不用白板算法题面试」的公司清单，后来成为 GitHub 上最知名的招聘类仓库之一。

  3. Meta 时期

    Relay、Server Components 与工程管理

    在 Meta 带头原型化 Server Components，并在 Relay 的编译器和运行时中加入支持，之后转向工程管理（据 React Conf 讲者介绍）。

  4. 2024–2025

    React Compiler

    React Conf 2024 演讲《Forget About Memo》介绍了原名 React Forget 的编译器：自动做记忆化，开发者不用再手写 useMemo / useCallback。2024 年 10 月发布 Beta，2025 年 10 月发布 1.0。

  5. 2025–2026

    Cursor → xAI

    短暂加入 Cursor 后，转到 xAI（GitHub 组织 @xai-org），参与 Grok 的编程 Agent，同时仍在 React Compiler 核心团队。2026 年开源了 noodle（用 Skill 编排 Agent）、how（解释架构的 Skill）、brainmaxxing（极简持久记忆）等 Agent 工具。

设计与手艺

Lauren 的工作有一条清晰的主线：把专家才懂的优化，变成所有人的默认值。React 的记忆化以前需要开发者理解引用相等、依赖数组和闭包陷阱；编译器把这些知识放进了工具链。

if you want to go fast, go deep first.

— pstack 的介绍

这种思路也延续到了 AI 时代：pstack 强调「写更少但更高质量的代码」，用严谨的工作流让 Agent 并行工作而不失控。她关心的从来不是写得多快，而是能不能放心地交给别人（或机器）去跑。

可以从她身上学什么

  • 把知识编进工具：与其写文档教大家用 useMemo，不如让编译器自动完成。
  • 为社区做整理：会议总结、公司清单这类「整理型开源」同样能影响几万人。
  • 跨社区学习：Ember、Elixir、Relay、React 的经验在她身上互相滋养。
  • 先深后快：在 Agent 时代，深入理解问题依然是速度的前提。
