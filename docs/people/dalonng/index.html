TA 到底在做什么？

根据公开简历，大桥在快手负责快手与 A 站的 iOS 应用，设计并推广了 Swift 组件混编方案，解决公司级工具链里 Swift 混编和二进制化的痛点，并做组件化、构建优化和架构设计。

业余时间 TA 往系统底层走：用 Swift 解析和修改 Mach-O 文件、写 Objective-C 运行时的学习笔记、从目录里扫描 ObjC 类和枚举。2026 年的新项目 Atelier 用 Tuist 组织工程，包含三角形、方块、纹理、灰度等 Metal 着色器实验，以及用 MobileNetV2 在本机给相册图片分类。

代表作品详解

Bourne ↗

2024Swift 宏

「自动解析 JSON，Struct、let。」用 Swift 宏自动生成解码实现，缺失字段用默认值而不是抛错，鼓励不可变的数据模型，避免多线程数据竞争。这是一个在真实项目里吃过 JSON 解析苦头的人才会做的取舍。

swift-macho ↗

2023Swift

「A Swift library for examining and modifying Mach-O files.」同期还 fork 了 MachOView，并写了 FileHandle 的字节操作扩展。理解 Mach-O，是做构建优化和二进制化的基础。

Atelier ↗

2026Swift · MetalTuist

工程由 Tuist 管理，源码按功能组织：Triangle、Square、Texture、Grayscale 每组都有页面、独立渲染器和 shader，共用画布与渲染协议。还有用 MobileNetV2 做的本地相册图片分类，界面支持中英文。
