手艺与方法

大桥的代码有一种「工匠的安静」：不追热点，不写长篇宣传，只是不停地研究自己好奇的东西：类型与元类型、Mach-O 结构、运行时、着色器。

Bourne 的设计选择也很有观点：用不可变的 struct + let 避免多线程数据竞争，用安全默认值代替解析失败。这是一个在真实项目里吃过 JSON 解析苦头的人才会做的取舍。

可以从 TA 身上学什么

  • 长期维护自己的工具：一份 Emacs 配置可以陪你十二年。
  • 向下多走一层：理解 Mach-O 和运行时，会让你更懂 iOS。
  • 用新语言特性解决老问题：Swift 宏让 JSON 解析更安全。
  • 不必张扬：代码本身就是最好的自我介绍。
