黄玄：梦想更好的界面

TA 十岁开始做 Flash 游戏，靠动态图形挣到第一笔钱；中国传媒大学数字媒体艺术本科，罗切斯特理工学院计算机硕士，方向是编程语言和类型理论。2010 年代 TA 在阿里巴巴、娱票儿、饿了么做 Web 和移动应用，并撰文介绍了饿了么升级为 PWA 的过程。之后加入 Meta，为 Web（ReasonML）、XR、React Native 的 Hermes 引擎和 React 做编译器，在 React Conf 2021 上讲了后来成为 React Compiler 的《React without memo》。现在 TA 在字节跳动担任跨平台框架 Lynx 的架构师，Lynx 支撑着 TikTok 的搜索、商城、直播和 TikTok Studio，2025 年开源。TA 的 Jekyll 博客主题（★7.6 千）被复刻了 6,500 多次。

TA 到底在做什么？

黄玄在字节跳动架构 Lynx：一套让开发者用已有的 Web 技能，为移动端和 Web 写出真正原生界面的技术家族，包含渲染引擎、性能导向的双线程 UI 编程模型和基于 Rust 的工具链。官方开源博客写道：「原生是必需品。」TA 在 React Universe Conf 上讲的正是如何让 React 适应双线程。

2026 年，TA 做了 Vue Lynx（Vue 3 在 Lynx 上的自定义渲染器，仍是预览版），还在 Lynx 上做了 Flappy Bird 演示。TA 称赞 Preact 11 在保留精简基础的同时补上了现代 React 特性，适合 Lynx 在上面搭建双线程模型。

本页依据 hux.pro、lynxjs.org 开源公告、GitHub 个人简介与仓库 README 和 X 帖子整理，资料截至 2026 年 10 月。TA 在各公司的具体职级和任期未逐一核实；性别未见本人明确表述，本页用 TA。
