Benji Taylor：为界面卓越做工具

他生于伦敦，住在洛杉矶。他创办过消费软件公司 Los Feliz Engineering，做出实时聊天应用 Honk 和自托管加密钱包 Family；公司被 Aave Labs 收购后，他在那里担任首席产品官；之后他领导了 Coinbase 旗下 Base 的设计。现在他在 SpaceX 担任 X 和 SpaceXSI 的设计负责人，X 上有二十多万关注者。他喜欢做「为界面卓越而生」的开源工具：他是 cmdk 新家 Dip 的成员；2026 年他接连发布了 Agentation（在页面上点选元素、写下批注，生成结构化输出给 AI 编程 Agent，★5 千）、实时动画折线图 Liveline，以及「七支笔都像真的笔」的 React 绘图工具栏 Drawesome。

2026 年 10 月，Benji 分享了团队的一个做法：给整个团队配一个「懂我们品牌」的 Grok Bot，现在任何人都能在几秒内做出一份好看的幻灯片，「我也不用担心有人用错字体」。背后是一个自定义品牌工具，在设计团队划定的边界内生成素材，再通过内部 API 交给机器人调用。这是他一贯的思路：设计负责人的工作，越来越像为别人搭好不会出错的工具。

他到底在做什么？

在 X，Benji 带领设计团队「改进一切」：比如给 X 官方博客做了改版。他也用 Grok Bot 加速实体产品原型：给它草图和 3D 模型，让它帮忙出技术图、准备询价单、和制造商沟通。

他的开源工具都很专注：Agentation 是一个不绑定特定 Agent 的视觉反馈工具，点选页面元素、加批注，复制出结构化信息，帮 AI 编程 Agent 准确找到你指的代码；Liveline 是用 canvas 渲染、60 帧、无需引入 CSS 的实时折线图和 K 线图；Drawesome 的橡皮擦擦的是面积而不是整条笔画，可以导出 SVG 或 PNG。
