vjeux：空格与 Tab 圣战是怎么结束的

他是来自法国的前端工程师，毕业于法国计算机学校 EPITA，之后加入 Facebook。他的 X 简介是一份惊人的清单：React Native 和 Prettier 的联合创造者，Excalidraw、「CSS-in-JS」、Yoga 和 React Conf 的创造者。2014 年他的一场演讲让「CSS-in-JS」成了一个概念；Yoga 是一个面向 Web 标准的可嵌入布局引擎，让 React Native 能用 Flexbox 布局；代码格式化工具 Prettier（★5.2 万）终结了团队之间关于代码风格的争论。据维基百科，2020 年 1 月 1 日他把 Excalidraw 当作个人项目做出来，两天后注册域名，如今这个手绘风格的白板 GitHub 星数超过 12 万，由捷克公司 Excalidraw s.r.o. 维护。2026 年，他用 Claude Code 在一个月内把 10 万行的《宝可梦对战》引擎从 TypeScript 移植到 Rust，还让 AI Agent 在《我的世界》里设计活塞门。

2025 年 10 月，他写了《Birth of Prettier》，讲「空格与 Tab 圣战」是怎么结束的：不是哪一方赢了，而是一项技术发明让争吵的根源不复存在。故事从他在 EPITA 读书时说起：学校发一份格式规则 PDF，作业每违反一条就扣 2 分（满分 20），十处格式问题就是零分。他想写个工具自动修复，但对一年级学生来说太难了。后来他到 Facebook，第一次代码评审就收到一堆格式修改意见，因为公司的规范和学校的不一样。这个问题在他脑中埋了很多年，最终变成了 Prettier。

他到底在做什么？

vjeux 最近在用 AI Agent 做各种「不可能」的实验：把 Pokémon Showdown 对战引擎移植到 Rust，为训练对战 AI 做准备；让 Agent 在《我的世界》里自动建造并缩小 3x3 活塞门，两天就找到了一个花了社区多年才发现的 7x8x1 设计；几个提示词之后，就得到一个在浏览器里渲染这些门的《我的世界》渲染器。

他也让 Agent 帮团队修 JS 错误，并分享它们发现的冷门问题：Playwright 的 page.route() 会关掉 Chrome 的 HTTP 缓存，让整套端到端测试慢 5 倍；swc 压缩器在某种代码模式下内存会指数增长；WebKit 的 WebSocket 实现会截断数据。
