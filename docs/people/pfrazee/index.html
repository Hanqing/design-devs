Paul Frazee：去中心化，但要实用

他住在德州奥斯汀，是 Bluesky 的软件工程师，带领团队开发 Bluesky 社交应用（★1.8 万），常年和 React Native 打交道；他也是 Bluesky 底层协议 AT Protocol 的联合作者。在那之前，他是点对点社交网络 Secure Scuttlebutt 的早期开发者之一，主要做应用和开发体验（Patchwork 客户端）；之后创造了点对点网页浏览器 Beaker Browser（★6.7 千），深度参与 Dat / Hypercore 协议的开发；再之后，他把另一个分布式社交网络 CTZN 的整个开发过程都做成了直播。2022 年底 Beaker 正式归档，他说希望在 Bluesky 继续这个使命。他的个人简介最后一句是：「Paul 没有为这些事受过任何训练。」

他到底在做什么？

Paul 带领团队做 Bluesky 的 Web、iOS 和 Android 应用，同时参与 AT Protocol 的设计。据维基百科，Bluesky 2019 年起源于 Twitter 的一个研究项目，2021 年独立，2023 年 2 月以邀请制上线，2024 年 2 月开放注册；它是 AT Protocol 的参考实现，主打可组合的体验和「算法市场」：用户可以选择或创建自己的信息流、审核与标签服务。

他的博客解释协议设计的取舍：为什么 Bluesky 的富文本用「facets」，为什么 AT Protocol 不用 RDF，如何编写 Lexicon（协议的模式定义）；2025 年底的《Atmospheric Computing》则展望了建立在开放协议上的一整套应用。

本页依据 pfrazee.com（博客与关于页）、维基百科 Bluesky 条目、GitHub 仓库与 README 和 X 帖子整理，资料截至 2026 年 10 月。他已基本转到 Bluesky 发帖，X 上内容较旧。
