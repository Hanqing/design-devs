Ryan Carniato：got signals?

他住在俄勒冈州波特兰，是 SolidJS（★3.6 万）的作者。Solid 用 JSX 写组件，但没有虚拟 DOM：组件只运行一次，之后由细粒度的响应式「Signals」精确地更新 DOM，在性能基准测试里长期名列前茅。Solid 的影响远超它自己的用户规模：这几年 Angular、Preact、Svelte 5 等都走向了 Signals 式的响应式，甚至有 TC39 提案要把 Signals 写进 JavaScript。他的底层库 dom-expressions 也被用来给 MobX、Vue 响应式、Knockout 等做 JSX 渲染。他曾在 eBay 参与 HTML 模板语言 Marko 的开发，现在在 Sentry 工作。他每周在 YouTube 直播，常常一讲几个小时框架架构。

他到底在做什么？

Ryan 一边推进Solid 2.0，一边在直播里系统地思考框架架构。他画了一张「统一架构网格」，把客户端渲染、服务器渲染、服务器组件等组合放进不同象限，最近在探索最后一个象限：Live Server Components，即「一次渲染，所有观看者共享」。

他也在想 AI 会如何改变框架设计。他说 Rich Harris 关于编译器的一篇旧文「是过去十年大多数 JS 框架编译器工作的神谕」，但 AI 让人们需要重新思考它：既然代码大多不是人写的，能不能在编译时做更多事，哪怕生成的代码很丑？
