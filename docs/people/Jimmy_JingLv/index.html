吕立青：用算力节省脑力

TA 在 GitHub 上这样介绍自己：「想做产品，却误入程序世界爱上写作的摄影师。」TA 先后在 Thoughtworks 和阿里巴巴做工程师，翻译过《React 学习之道》，用 GitHub Issues 做「敏捷学习」写了十多年博客，是中文 Roam Research 社区的活跃推动者。2023 年 ChatGPT 爆发时，TA 开源了一个给 B 站视频做 AI 总结的小工具 BiliGPT，后来演变成 BibiGPT：粘贴任意视频或播客链接，30 秒得到带时间戳的总结、全文和思维导图，累计服务超过 100 万用户。

TA 到底在做什么？

BibiGPT 是一个 AI 音视频助理：粘贴链接或上传文件，就能得到结构化总结、字幕、思维导图，并能和内容对话；进阶功能包括字幕翻译压制、看懂 PPT 和白板的视觉分析，以及把视频改写成小红书图文、公众号文章、推特长帖或 PPT 大纲，还能一键存入 Notion、Obsidian、flomo。

2026 年，TA 把 BibiGPT 做成了「Agent 友好」的工具：提供 MCP 服务器、OpenAPI、命令行和给 Claude Code、Codex 用的 Skill，让 AI Agent 也能「看」视频。

长处与局限

维度长处局限 / 需要留意
产品抓住国内平台的空白，用户规模大视频总结赛道竞争者众多
执行从开源到 SaaS 到 Agent 接入，迭代极快—
渠道自己就是内容创作者，懂分发—
依赖多平台覆盖是优势受各视频平台接口与政策变化影响

可以从 TA 身上学什么

  • 从开源小工具起步：BiliGPT 先验证需求，再做成产品。
  • 做海外工具做不到的事：国内平台是护城河。
  • 从第一天就为 Agent 设计：API、MCP、Skill 一个不少。
  • 把工程方法用在个人成长上：用 Issues 做敏捷学习。
  • 自己做内容，自己做分发：创作者也是最好的产品经理。
