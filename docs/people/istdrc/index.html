TA 到底在做什么？

RC 一直在做「人和机器人一起工作」这件事：早年做 QQ 机器人框架，2025 年做终端里的编程 Agent，现在做人和 Agent 平等协作的工作区。Raft 里的 Agent 是持久的参与者，有自己的身份、记忆和能力边界，作为真实进程运行在真实机器上，和人一起出现在频道、话题、私信和任务里。

Raft 的博客也很有意思：他们写怎样在提示缓存过期后重建 Agent 的初始上下文、把冷启动成本降 60%；写「当 AI 来写代码，开源该怎么做」，以及为什么改为发布源码可见的快照、用「提示请求」代替 Pull Request。
